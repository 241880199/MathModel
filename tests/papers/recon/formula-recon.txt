## 一、四个口径的完整定义（口径含糊的参照不算参照）

设 N 为 1–2 位十进制数字（`\d{1,2}`）。

| 代号 | 载体 | 判什么 | 正则（Python `re`，`str` 模式） |
| :--- | :--- | :--- | :--- |
| **R1** | `corpus/papers/md/<合集>/<题号>/<stem>.md`（Task 3 产物，**不由本任务代码产生**） | **整行**只有编号 | `^\s*\((\d{1,2})\)\s*$`，逐行 `re.match` |
| **R1w** | 同上 | 同上，但**括号内允许空白** | `^\s*\(\s*(\d{1,2})\s*\)\s*$` |
| **R2** | `pdftotext -layout <pdf> -` 的 stdout（**不同引擎、不同实现**） | **行尾**是编号 | `\((\d{1,2})\)[ 	]*$`，逐行 `re.search` |
| **R2w** | 同上 | 同上，但括号内允许空白 | `\(\s*(\d{1,2})\s*\)[ 	]*$` |
| **R3** | 原件（PyMuPDF `get_text("dict")`） | 整行只有编号 **且** `x1 >= 页宽 − 0.15 × 页宽`（**计划草稿口径，本任务已废弃**） | R1 的正则 + 该坐标条件 |
| **G**（**本轮新增，换地基**） | 原件（PyMuPDF `get_text("rawdict")` 的**字符级 bbox**） | **行尾**是 `(N)` **且**该 token 的 `x1` 落在**本页**（本页无纯编号行时退到**本篇**）纯编号行的 token x1 **集合** ±3.0pt 内 | 见 **§八**（口径逐字 + 逐条实测 + 新基数） |

**现行参照 = 并集**：`R1' = max(R1, G)`、`R2' = max(R2, G)`（§八 §E：**R1' = 782 · R2' = 790**）。
**R1/R1w/R2/R2w/R3 全部保留为历史口径**（§三 的逐份值不改）——并集只增不减，故是**收紧**。
G 的用途有一条硬边界（§八 §C）：它有 **2 条实测假阳性**（正文行恰好排到版心右缘、行尾正好是
`(N)`：`2502617` p10、`2501869` p3，Δ=+0.2pt），**任何容差都分不开**，故 G **只当 0/1 的
存在性证明用**，不参与任何计数。

* 行尾判法（R2/R2w）：只剥**行尾的 ASCII 空格与制表符**（`[ 	]*$`），**不**剥其它
  空白；行首空白不影响（正则锚在行尾）。全文用 `str.splitlines()` 切行。
* 调用：`pdftotext -layout <pdf> -`（stdout 取回），逐份调用；stdout 按 UTF-8 +
  `errors="replace"` 解码。本机 `pdftotext` 版本 4.00（`pdftotext -v`）。
* **R1 ≠ R1w、R2 ≠ R2w 的份**：`2508861`（R1 0 → R1w 28、R2 9 → R2w 29）与
  `2505199`（R1 56 → R1w 58）。原因：这两篇把编号排成 `( 1 )`（括号与数字之间
  有空格）。**任务书基线表的 743 / 767 是严格口径**，本文件两个口径都登记。

## 二、复算命令（逐字，可直接粘）

```bash
# R1 / R1w（md 侧，逐份）
cd <repo> && python - <<'PY'
import re, pathlib
MD = pathlib.Path('corpus/papers/md/2025美赛O奖论文')
S = re.compile(r'^\s*\((\d{1,2})\)\s*$')
W = re.compile(r'^\s*\(\s*(\d{1,2})\s*\)\s*$')
for m in sorted(MD.rglob('*.md')):
    t = m.read_bytes().decode('utf-8')
    print(m.stem, sum(1 for l in t.splitlines() if S.match(l)),
          sum(1 for l in t.splitlines() if W.match(l)))
PY

# R2 / R2w（pdftotext 第二引擎，逐份）
cd <repo> && python - <<'PY'
import re, subprocess, pathlib
O = pathlib.Path('corpus/历届优秀论文/2025美赛O奖论文')
S = re.compile(r'\((\d{1,2})\)[ 	]*$')
W = re.compile(r'\(\s*(\d{1,2})\s*\)[ 	]*$')
for p in sorted(O.rglob('*.pdf')):
    t = subprocess.run(['pdftotext','-layout',str(p),'-'],
                       capture_output=True).stdout.decode('utf-8','replace')
    L = t.splitlines()
    print(p.stem, sum(1 for l in L if S.search(l)), sum(1 for l in L if W.search(l)))
PY
```

## 八、**几何口径**：换地基（本轮新增；几何口径与「整行纯行」口径的**并集**才是现行参照）

**要解决的问题**（复审本轮 Critical 1 的复验）：`proven` 旧的两个视角（md 纯编号行 /
原件侧整行只有编号的文本行）都只认「**整行只有编号**」，而本语料有 **11 条真编号与公式体
排在同一个 PyMuPDF 文本行**（下表 §B）——它们两侧都不是纯行 ⇒ `proven == 0` ⇒ 封条永不触发
⇒ 检测器丢掉它们时被 B 类逐字说成「已解释」。故**换地基**：把「这一行是不是真编号行」的
观测口径本身加强，用一个**几何**谓词（不引入任何全局绝对常量）。

**口径**（逐字，与 `verify_d.py` 的 `geom_number_lines` 同一量；本脚本自带**第二份实现**）：

> 一条文本行的**行尾 token 就是 `(N)`**，**且**该 token 的 **x1 落在「编号列右缘」±3.0pt 内**。
> 「编号列右缘」= **本页**整行只有编号的行（纯编号行）的 **token x1 集合**；本页一条都没有时
> 退到**本篇**的同一集合。token 的 bbox 由 `get_text("rawdict")` 的**字符级 bbox** 求和
> （整行 bbox 含行尾空白，会污染这个量）。

**结论三条**（逐条证据见下面的 §B/§C/§D）：

1. 它**覆盖那 11 条**同行真编号（**11/11 命中**，最大 |Δ| = 2.7pt）；
2. 7 条 B 类里，**5 条**的 token 离右缘 85.7–272.2pt（远缘）**仍在外**；剩下 **2 条**
   （`2502617` p10、`2501869` p3）是**正文行恰好排到版心右缘、行尾又正好是 `(N)`**，
   Δ 只有 +0.2pt —— **几何口径分不开它们**（假阳性的 Δ 比真编号的最大 Δ 小一个量级，
   没有任何容差能分开）。故本口径**只当 0/1 的存在性证明用，绝不抬高任何计数**：
   一旦当计数用，`2502617` 的 `(1)`（检出 1 条、几何看到 2 条）就会变成「未解释」——
   那正是「把 B 级证据误升格」，复审明令不许。
3. **参照因此变成并集**：`R1' = max(md 严格纯行, 几何存在性)`、`R2' = max(pdftotext 行尾, 几何存在性)`
   （`max` 而不是相加：三个视角看的是同一批物理行，相加会把同一条数两次）。新值
