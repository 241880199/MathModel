## 3. 「覆盖」是**方法族级**、不是短语级（实测 19 条）

  覆盖判据（**逐字复刻 `verify_ids.py` 的 I13**）是「**片里出现任一受控词表变体**」，
  不是「片就是词表词」。实测 **61** 个片被判为已覆盖，其中 **19** 个属于前者——
  它们靠片里含的一个**较短**的词表词过关：

    Bayesian Change-Point Detection          ← Bayesian / change-point detection
    Bayesian entropy analysis                ← Bayesian
    Bayesian framework                       ← Bayesian
    Cox-Monte Carlo                          ← Monte Carlo
    DID Model / DID model                    ← DID
    Dual-stage XGBoost                       ← XGBoost
    EWM-AHP                                  ← AHP / EWM
    Lotka-Volterra Equation / …model         ← Lotka-Volterra
    Multi-objective nonlinear programming    ← nonlinear programming
    NSGA-II Algorithm                        ← NSGA-II
    Non-parametric Bootstrap algorithm       ← bootstrap
    PSM-DID model                            ← PSM / DID
    Random Forest Model                      ← random forest
    SHAP analysis / SHAP model               ← SHAP
    differential evolution optimization      ← differential evolution
    dynamic Bayesian networks                ← Bayesian networks

  **★ 上面那两个数（`61` / `19`）按记录在案的脚本现在复现不出来（2026-09-26，只增不改）**：
  把 `build/t6b2b_covercal.py` **原样重跑**，现行实跑 = **98** 个片被判为已覆盖，
  其中 **19** 个属于前者（**上面那份 19 条清单逐字复现**——现行也数出 19 条，
  但总数是 98 不是 61）。**能说的机制**：被「现行判据」判为已覆盖的片数随**现行词表**变
  （词表 115 → 150 词条，§5 / §9）——词表一长、判为覆盖的片只会更多，与 `61` → `98`
  的方向一致。**但「当时为什么记成 61」未能定因**：`build/` 里没有那一次跑的日志

  必须引入一条**语义判断**（「这个词是不是模型名」）——而本项目的纪律是
  **不得产出无法复核的启发式判断**（`ids-report.txt` 的那条具名边界就是为此立的）。
  **故本路只登记、不收录**；它的价值在于**证明**「不带受控候选池的正文扫描 = 噪声压过
  信号」这个判断是**量出来的**而不是猜的。

  **★ 收口轮对上一段的订正（2026-09-26，只增不改）**：「只登记、不收录」这个**结论仍然
  成立**（新表 0 条 `收录`），但**理由换了、也做成了逐条可核的**：不再靠「划不出线所以不判」，
  而是**每条都给处置 + 类别 + 定位符（`body:<ID>@p<页>`）+ 一条可复核的理由**

  按 A-1 的复合名规则**不增加检索能力、不收**；② 其余（国别码/机构/数据集/物理量/符号/
  指标/标号）**不是方法**。
  **上面那句「必须引入一条语义判断、而纪律不许」因此被就地精确化**：判断做了，但**每一条
  都能指回正文的具体一页一行**——这正是本项目的纪律要的形态（可复核的判断 ≠ 启发式）。
  另：**若真有一条要 `收录`，代价也写在新表的文件头里**（会触发 TAGS/INDEX/MODEL_MAP 与
  三份放行证据的全链路重出，属另一个授权面）——不收**不是**因为判不出来。

## 8. 本阶段**证明不了**的事（与产物、证据同读）

  1. **「匹配度」是「我们认出了作者点名的方法」的程度，不是「模型选得对」的程度**。
     第四节量的是**召回 + 精确性**；「给定题型 X，用模型 Y 合不合适」是**效度**问题，
     **本阶段回答不了**（2a 的 `map-recon.txt` §11 已登记同一条边界）。
  2. **召回的分母是「作者写进 Keywords 的模型」**，不是「作者用过的模型」。
     用了却没写进 Keywords 的模型**不在分母里**（§4 的死角）；`keywords` 栏还被截断
     17 篇（§2）。**故 0.9130 这个数是「对已声明参照的覆盖率」，不是「对真实使用集合的覆盖率」。**
  3. **「覆盖」是方法族级**（§3）——`Bayesian Hierarchical Dirichlet-Multinomial` 这类
     「族级以下的具体模型名」不会被单独收录。
  4. **精确性的「可定位」证明不了语义**：它证明「这个片段确实在那篇的那一页那一行」，
     **证明不了**「作者在那里把它当模型名用」。本阶段**没有做任何语义核对**。
  5. **低置信 = `x1` 是形式标记、不是质量判断**（第三节已逐条声明）。
  6. **宽口径只报了两个汇总数**：27 条宽口径候选里**收录 11 条、不收 16 条**，
     但**没有**为宽口径单独算「逐篇召回」表（主体口径才有那张表）。宽口径的用途是
     **量截断的影响**，不是替代主体口径。
  7. **变异只跑 `--limit 3`**：`verify_map.py` 的判据**不取样**（输入是文本产物），
     `--limit` 只改落点并跳过 `M-1-b` ⇒ 新判据（M-9…M-16）**没有**「全量才跑」的分支，
     故不存在「限样本绿冒充全量绿」的敞口。`M-1-b`（重放性）**只在全量跑执行**，
     它的证据是全量放行证据里的那一行。
  8. **`verify_map.py` 依赖 `git` 可执行**（M-1 用 `git hash-object` / `git rev-parse` /
     `git cat-file`；M-10/M-12 用 `git cat-file blob` 取基线）：环境无 git 时它抛错→判 FAIL
     （fail-closed，但**依赖环境**这一点要写明）。**基线 blob 取不到时不退回工作树**
     （那样会把基线读成增长后的词表，两个量一起变对）。
  9. **`M-16` 的探针在进程内改 `vocab.DEFAULT`**（探针自己还原）：它证明的是
     「`load()` 这条**默认路径分支**在追加后读得到新内容」，**不是**「模块级常量不可改」。
  10. **词表增长只对 2025 这 43 篇量过**：那 48 个新词形在**别的年份**的语料上是否
      合适，本阶段**没有**证据（其余合集未建索引，Task 9 才做）。

  ⇒ 「工作树字节 == 入库 blob」这句话**在本目录里已经不成立**（不是将来时）。

**为什么仍然要登记**：`tools/papers/vocab/models.txt` 的 **blob 被写死进判据**
（`verify_map.py` 与 `coverage.py` 的 `BASELINE_MODELS_BLOB = 0ca91927…`，M-10/M-12/M-14
都拿它当**增长前的基线**），本项目的通则 9 又明令**不得依赖 git 的自动判定**。
一次**全新检出**之后：

* 工作树会变成 CRLF；`git hash-object` 走同一个 clean 过滤器 ⇒ **blob 不变、判据仍绿**
  （三个读取点都做了 `\r\n → \n` 归一：`vocab.load` 用 `splitlines()`，
  `coverage.read_vocab_bytes`、`verify_map.v_vocab_rows` / `v_triage` 都先 `replace("\r\n","\n")`）；
* **但**「工作树字节 == 入库 blob」这句话就不再成立（**而它在 `watermark.py` 上
  已经不成立了**，见本节开头那一段的实测），而本项目的报告体例在好几处直接引用
  该等式（例如变异驱动器的「逐字节还原」断言就依赖「原始字节」这一概念）。

**最小修法（一行，留给裁决）**：在 `.gitattributes` 里加

    tools/papers/**              -text

并附一句理由（与既有三条同族：**判据把 blob 写死了的数据文件，必须存什么取什么**）。
**本轮不改它的理由**：`.gitattributes` 不在任务书的授权改动清单里（授权的是
