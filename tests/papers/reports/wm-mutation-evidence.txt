## 判据的失败条件（可操作表述）

| 判据 | 什么输入使它红 |
| :--- | :--- |
| 三厂商覆盖（§1b） | 任一 recon 记为带水印的论文，置空后前 4 页仍出现 `WM_WORDS` 中的串；或 `font_cov >= struct_cov`（有人把启发式扩到 KaiTi/SimHei）；或有 PDF 打不开；或 81 份对照件受损 |
| A3 多重集差（§3） | `before - after` 中出现任何非 `WM_WORDS` 子串的 span（如标记放宽导致清空正文流——实测 14 份只有 `/PieceInfo` 的论文会中招）；或水印件上移除为空（置空没起作用）；或 span 反而**多出** |
| `strip_in_memory == 0`（§5） | **recon 记为带水印**（`wm_texts` 非空）的论文上 `find_watermark_xrefs` 返回 `[]`——即上表的变异输入。**本文件即为该输入的实测** |
| 对照件未被动（§4） | 对照件的 span 有增删，或 `strip_in_memory` 在其上返回非 0 |

## 已知边界（不声称更强的东西）

A3 是**必要非充分**：正文里若恰好有与 `WM_WORDS` 同字符的孤立 span（如单独一个「校」字），
被误删时不会被察觉。本语料实测 0 例。此边界由 `verify_wm.py` 运行时显式打印，不是事后补记。
