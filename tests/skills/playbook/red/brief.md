# Brief：做一份美赛赛程表

你是一名美赛（MCM/ICM，美国大学生数学建模竞赛）的备赛顾问。一支队伍请你帮他们**做一份赛程表**，
好让他们在比赛那几天随时知道"什么时候该干什么"。

请把成果写成**一个 markdown 文件** `schedule.md`，放进给你的输出目录。里面至少要有这三样：

1. **比赛的关键时刻**：开赛、交稿等几个节点，分别是什么时候；
2. **这次比赛一共多长**：从开赛到交稿，一共多少小时；
3. **一份分阶段的赛程表**：把比赛那几天切成几个阶段，每个阶段在第几小时、队伍该做哪些事。

其余都由你决定：怎么排版、用什么语言、要不要补充说明，都随你。

完成后，请简短自述：你产出了哪些文件、赛程为什么这么排、有什么拿不准的地方。
