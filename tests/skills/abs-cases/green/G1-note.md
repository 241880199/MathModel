## 3. 我没照做的部分 · 及原因

1. **删掉了基线尾部的"正文脚手架"**（`\clearpage`／`\pagestyle{fancy}`／`\newpage`／`\setcounter{page}{1}`／`\rhead{Page \thepage\ }`／`Begin your paper here`，含注释掉的 `\tableofcontents`）。
   **原因**：本文件只装摘要页，留着这些，pdfLaTeX 会多产一页——实测第 2 页内容只有 `Team 2534567 / Page 1 / Begin your paper here`（正文栏高 662.9 pt、末页填充率 0.076），直接违反 skill 自己的"占一页 = `page_count == 1`"判据。**摘要页本身一个字没动**（`\thispagestyle{empty}`、`\vspace*{-16ex}` 都在）。
2. **把基线 `\graphicspath{{.}}` 的行尾注释挪到了上一行**（`% Place your graphic files in the same directory as your main document`）。**原因**：`check-summary.py` 的 C1 把"行内有内容 + 行内出现 `%`"一律计为未转义百分号，而 C1 必须为 0；那条注释是官方模板自带的合法注释，挪行后语义完全不变（正文区再无行尾 `%`）。
3. **队号填 `2534567`**。skill 只规定不得留 `1111111`，没说这个数从哪来；本次是测试件、没有真实队号，故填一个占位数字（**若这是真实提交，须换成真队号**）。
4. **没跑 `mcm-selfreview`**。skill 说"交稿前用 `mcm-selfreview` 做合规与内容自查"，但那是**整份提交物**的"能不能提交"自查；本次交付物只有摘要页一页、没有正文，跑它只会得到一堆"缺目录/缺正文/缺参考文献"的空转结论。
5. **没产出 `mcm-latex-format` 的 ② 格式合规问题清单**。同理：那是**骨架交付物**的配套件，本次交付物是摘要页，不是骨架。

## 4. 我认为它没覆盖到的东西

1. **它只点名了一个自相矛盾的数字（`1.14`），没给"怎么找出其它矛盾数字"的办法。**
   按同一条精神逐项核正文后，我另找出一处**形态不同**的：正文 §4.3 自己定义"`RSA_k` 小于 **0.95** 即判定该级被修复过"，紧接着却写 `RSA = 0.02 < 0.05` 并据此得出"未修复"——按它**自己的 0.95 判据**，0.02 恰恰应当判成"修过"。
   处理：把 `RSA = 0.02` **整个**从摘要剔掉，改用同段里干净的两项证据（Brinell 硬度跨级均匀 89.45 N/mm²、σ_H = 1.8；步间散度 `|RS| = 0.03` 低于 ε = 0.05）。该问仍满足"带数字作答"。
   → 建议：skill 可把"矛盾数字"的判据写成**可执行的两步**（① 结论与所用阈值是否同向；② 同一量在正文里是否出现两次且不等），而不只是举 `1.14` 一例。
2. **没规定"显式标缺"在摘要页上该怎么落笔。** 题面 Task 2 第一问（wear 是否与已有信息一致）正文只**定义**了 `P_A`、**从未算过值**。skill 要求"不许估、显式标缺"，但在摘要页上直白写"缺"对评委是减分写法，而 skill 只给了原则、没给句式。
   处理：写成 `the paper defines it but reports no value for this stair, so none is claimed here` —— 如实、且不假装有结论。
3. **没覆盖"输入参数之间不自洽"这种情形。** 正文 §3.1.2 用 WHO 六个分组的权重算出人群平均体重 **W = 62.8 kg**（`W·g = 616 N`），但实际求解用的表 4 取的是 **G = 700 N**，正文没有调和二者。
   处理：摘要只引用**求解实际用的** `G = 700 N`；`62.8 kg` 我没写进去（写进去就会和 `N_d = 261` 的算式打架）。这是**我自己判断后放弃的信息**，登记在此备查。skill 的判据只管"与**结论**冲突的数字"，没管"**输入**之间打架"。
4. **没给"本地编译 vs 网页端换页点不同"的余量指标。** 它只说本地页数不能代填网页端。我按 `mcm-latex-format` 的提醒，把正文压到距栏底还有 **49.8 pt（约 3.4 行）**才定稿，以免网页端 TeX 版本差异把摘要挤到第 2 页。→ 建议给一个数（如"至少留 2 行余量"）。
5. **没覆盖摘要页要不要加标题行。** 官方模板的摘要页没有标题行，我因此没加（正文标题是 "Stair Wear: Traces of History"）。skill 对此完全没表态。
6. **没覆盖"测试/演练用的假队号"如何处置。** 规则侧只写了"匿名 + 不得留 `1111111`"，没写"拿不到真实队号时能不能填一个假号、要不要标记"。本件按占位处理并在 §3 第 3 条写明。
