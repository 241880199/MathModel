# G2-note —— 产物说明、取舍与不足

## 1. 形式：为什么是 `.tex`（+ 一份验证用的 `G2.pdf`）

- **交付物 = `G2.tex`**：一份**只含摘要页**的完整 LaTeX 源码，以官方 COMAP 摘要模板（本仓修正副本 `mcm-latex-format/assets/mcm-2027-summary.tex`）为基线。选 `.tex` 而不是 `.md`/`.docx`/`.txt`，理由有二：① 美赛提交物是 PDF，而这一页要作为**第 1 页**并进论文，唯一能直接并入的形态就是 LaTeX 源码；② 摘要页的本地判据本身就是"编出来的页数"（`mcm-abstract/check-summary.py`），LaTeX 才可判。
- **`G2.pdf` 不是第二份交付物**，是我用 pdfLaTeX 编出来的**验证渲染**（页数证据），路径由 `check-summary.py --pdf` 指定。判据只认 `.tex`。
- 与基线骨架的**两处偏离**（都记账，不是随手改）：
  1. 模板里 `\graphicspath{{.}}  % Place your graphic files ...` 是**行内注释**，会被 `check-summary.py` 的 C1（`%` 静默吞字符）计 1 次并判 `RESULT: FAIL`。我把该注释提到**独立行**——语义与渲染完全不变（实测被"吞"的 69 字符就是注释本身，无实际损伤），只是让机械判据归零。
  2. 摘要页之后的**分页脚手架**（`\clearpage` / `\pagestyle{fancy}` / `\newpage` / `\setcounter{page}{1}` / `\rhead{Page \thepage\ }` / "Begin your paper here"）**注释掉**了。原因：本件必须满足"只含摘要 → 编译后 1 页"，留着这几行会多出第 2 页。正文成稿时把它们取消注释，或直接把 `Begin/End Summary` 之间的块粘进论文骨架的同一位置。

## 2. 内容怎么定：题面每个子问题 → 摘要里的一句 + 数字出处

题面（`case-C-problem.txt`）的清单我逐条对过，映射如下（页码/小节指正文 `case-C-body.md`）：

**数字纪律**：摘要里每个数字都能在正文找到出处，且**凡正文自相矛盾者不取**。三处按此处理：

1. **USA 游泳 β1**：正文 3.3.3 写 0.0517（+5.3%），3.3.4 与其表 4 写 0.1912（+21.1%）——同一小节两个互斥结果。取 **0.1912**：另有 LOO 区间 [0.18, 0.20]、NegBin 0.2378、ZIP 0.1626 三处佐证，而 0.0517 孤证。
2. **美国的 2028 点预测 142**（表 2）**恰好等于**表 1 中美国总奖牌 95% 区间的**上界 142**——点估计落在 97.5 分位，自相矛盾。摘要**只留区间、不引美国点估计**。
3. **"进步/退步"名单**：3.1.10 只说 USA/CHN/ITA 升、FRA/AUS/GER 降，但表 2 里 GBR 65→69、JPN 45→51、NED 34→41 同样在升。摘要**只复述正文自己的结论**，不从表 2 另推名单（也就避开了这处矛盾）。

另有两处**受题面许可的补充**（不是编造数字）：`SAM/MLI/GUM/PNG/VAN` 展开为国名，用的是标准 IOC 三字码（题面允许用额外资料作 background/context）；标题行沿用正文自己的标题，不改写。

## 4. 这份摘要**还没做到**的地方

1. **队号是占位数字**：`\Team = 2400001`。题目没给真队号，但契约要求该栏**不得留 `1111111`**，故填了一个可核验的占位值。**这是本件唯一的必改项**——交稿前换成真队号，并把提交文件名同时改成 `<队号>.pdf`。
2. **页数只在本机验证过**：pdfLaTeX（TeX Live 2026）编两遍 → `页数=1`、`rc=0`、`硬错误=0`、US Letter 612×792、正文块底 661.6pt（栏底 720pt，**尚余约 58pt ≈ 4 行**）。网页端 TeX 换行点可能不同，**以实际提交那次编译为准**；余额足够，超页风险低。
3. **一页还有余量未用**（552 词正文）。可补而未补：假设 1–5 的具体内容（只写了"2024 阵容与项目延续"这一条）、sensitivity 举例只给了指标而没点明是**马术**分项、表 2 的逐国点估计（因与区间冲突而整表略去）、"哪些国家会进步"只给名单与方向而**没给逐国较 2024 的差值**。
4. **"各国最重要项目"覆盖不全**：正文本身只做了 USA 游泳与 CHN 乒乓两个案例，摘要也只能跟着给这两个；题面问的是"various countries"。
5. **首次夺牌的"胜算"偏乐观**：给的是 500 次模拟的**频率**，未含模型不确定性（正文亦如此），且零牌国的参赛规模很小、一次名单变动就能翻转概率。
6. **东道主系数 74.8 量级可疑但照抄**：正文说"主办国身份使美国总奖牌 +74.76"（美国总奖牌约 126），R² 仅 0.539。我**没有改数**（改动即越界），但这是本摘要里我最不放心的一处，若正文后续修正，摘要要同步。
7. **未做**：AI 使用披露/匿名/25 页预算的**全文**合规自查（不属本件范围，`mcm-selfreview` 负责）；本件也**不含**图表、参考文献。
