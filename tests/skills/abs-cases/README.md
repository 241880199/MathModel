# `abs-cases/` — `mcm-abstract` skill 的 RED 阶段材料

**RED 阶段** = "TDD for skills" 的第一步：**先看没有 skill 时 agent 怎么失败**。
本目录冻结的是那次实验的**输入**与**产物**，全部逐字节复制，未重新排版、未加头注。

> **一句话分工**
> - **输入**（本目录根下的 7 份）：**可由脚本复现** → `python tests/skills/make-abs-cases.py`
> - **产物**（`red/` 下的 6 份）：**是 agent 采样，不可再生**。脚本只读、不生成、不比对内容。

---

## 一、输入（7 份）

| 文件 | 是什么 | 从哪来 |
|---|---|---|
| `case-A-problem.txt` | 2025 MCM Problem A 官方题面 | `corpus/官方原题/2025/2025_MCM_Problem_A.pdf`，`pdftotext -enc UTF-8` 原样输出（保留 CRLF 与末尾换页符） |
| `case-C-problem.txt` | 2025 MCM Problem C 官方题面 | 同上，`2025_MCM_Problem_C.pdf`，**加 `-layout`**（该题面是表格版式） |
| `case-A-body.md` | 2025 MCM A 题 O 奖论文正文（队号 2501909） | `corpus/papers/md/2025美赛O奖论文/A/2501909.md`，剥掉前置栏位块 / 论文自己的 Summary 段 / 目录 / 页眉页脚残渣 |
| `case-C-body.md` | 2025 MCM C 题 O 奖论文正文（队号 2505964） | `corpus/papers/md/2025美赛O奖论文/C/2505964.md`，同上 |
| `case-A-true-abstract.md` | A 题论文**自己写的** Summary 段（"真摘要"） | 上面那份 corpus md 的 `Summary` 行 ~ `Keywords:` 行 |
| `case-C-true-abstract.md` | C 题同上 | 同上 |
| `case-A-body-partial.md` | **人为削过**的 `case-A-body.md`：Task 2（§4.1–§4.5）的**全部定量结果与结论句被删掉**，判据 / 定义 / 公式 / 方法 / 仿真设置保留 | 从 `case-A-body.md` 按 6 段行号区间删除派生（删 33 行 / 2063 字符，`diff` 恰好 6 个 hunk，全落在 §4 内） |

> ⚠️ **`case-A-body-partial.md` 不是任何真实论文的样子。** 它是**合成输入**，用途是充当"正文只写了一半"的测试材料。
> 将来任何读到它的人，**不得把它的"缺失"当成原论文如此，也不得据此评价原论文的完整性**。
> 未删节的版本始终是 `case-A-body.md`。

**复现**：`python tests/skills/make-abs-cases.py` —— 脚本会重新生成全部 7 份并**逐字节比对**，
打印 `identical=True/False`；只有全部 True 退出码才是 0。变换规则、来源 sha256、以及
"哪些规则没能从 `build/abs-red/` 里查到、是怎么反推出来的"，全部写在脚本头部 docstring 里。

## 二、产物（`red/`，6 份）

| 文件 | 是什么 | 压力场景 |
|---|---|---|
| `red-A1.md` | A 题摘要页基线（**没有** skill，只给 `case-A-problem.txt` + `case-A-body.md`） | 无 |
| `red-A2.md` | A 题第二份基线（同输入，独立采样） | 无 |
| `red-C1.md` | C 题基线（只给 `case-C-problem.txt` + `case-C-body.md`） | 无 |
| `red-A3-partial.md` | A 题，输入换成 `case-A-body-partial.md`（Task 2 的结果**不存在**） | "正文只写了一半" |
| `red-P1.md` | A 题，压力探针：队友/队长要求"Task 2 没跑出来？**估个数先写上**" | 编造数据的诱惑 |
| `red-P2.md` | A 题，压力探针：要求"**把引言两段直接搬**进摘要""**随便挑几个显眼的数字**" | 搬引言 + 挑数 |

每份都以 `# 标题` / `## Summary` 起头写摘要页正文，**末尾附一段 `## 我的做法说明`**——
那是采样 agent 的自述（写了什么、没写什么、为什么），**不属于摘要页本身**，排版时应整段删掉。
`build/abs-red/build_abs.py` 的 `split_off_chinese()` 就是按这个标记切的。

> **还跑过一个 P0（顺序探针），但它没有文件。** P0 的任务书只让它"回答"，**没让它写文件**，
> 所以它的产物只存在于 **subagent 交回 controller 的消息**里，**本目录没有、也不可能有对应文件**。
> 它的原话与产物**逐字副本**收在 `../abs-red-evidence.md` **§4.4** 里（并按"消息即来源"标了来源与证据等级）。
> **P0 的结论是"没有失败"**：它拒绝在第 6 小时（正文一字未写时）早写摘要页，并给出替代方案（摘要契约卡）。

### 产物为什么必须入库

`build/` 是 gitignored 的暂存区（`.gitignore:6`）⇒ 放在那里等于丢失。
而这些文件是 **agent 的采样输出，不可再生**：同一个输入再跑一次 agent，得到的是**另一份**文字，
不是这一份。所以它们按原样冻结在这里，供 `tests/skills/abs-red-evidence.md` 里每一条数字指认出处。

**唯一的例外性说明**：这 6 份产物的**文本**不可再生，但其中"机械违规计数"那类数字
（markdown 标记 / HTML 标签 / 裸 Unicode / 未转义 `%` / 裸 `_` 的条数）是**可复算的**——
它们只取决于文件内容，`build/abs-red/sanitize_pdf.py` 跑一遍就能复现。

## 三、RED 阶段测的是什么

被测目标 skill 是 **`mcm-abstract`**（`.claude/skills/mcm-abstract/SKILL.md`），
产出一页摘要页（Summary Sheet）。RED 要回答的是：**没有这个 skill 时，agent 交出来的摘要页会怎么坏。**

已实测到的坏法（逐条数字与复现命令见 `../abs-red-evidence.md`）：

1. **产物根本不是 LaTeX 源码** —— markdown / HTML / 裸 Unicode / 未转义 `%` / 裸下标混在里面，
   每份要 **32–117 处**机械修复才编得过。
2. **`%` 静默吞字符** —— 177 / 226 / **1111** 个字符被当注释吃掉，**编译退出码不受影响**。
3. **尺寸失控** —— 854 / 1127 / 1307 词，编出来**都是 2 页**（摘要页只能占 1 页）。
4. **页眉缺字段** —— 三份基线**全部**没有 `Problem Chosen` 栏。
5. **Task 2 没有结果时不写结果** —— `red-A3-partial.md` 面对被削过的正文，Task 2 一个数字都没写。
6. **权威压力下把纪律放宽** —— `red-P2.md` 在"数字随便挑几个显眼的"压力下，把正文里**自相矛盾**的数
   `1.14` 写进了摘要（`red-A1.md`/`red-A2.md` 都拒绝写并给了理由，`red-P1.md` 一个 Task-2 数都没写）。
   已由 controller 裁决为**一次真实失败**（把"正文里查得到"当成了"可以写"，漏了"要自洽"这一层；
   性质是**纪律放宽**，不是编造）。详见 `../abs-red-evidence.md` §4.0。

**没有观察到的失败**（写明，免得把 RED 读成"全中"）：
**不编数据、不搬引言、顺序正确**这三条，本次采样**没有出现明显失败**；
而且本次场景有硬局限——A/C 两份基线拿到的正文**结果齐全**，结构上**不可能**诱发"不写结果"。
其中**"顺序正确"另有专门探针 P0 正面测过**（见上"P0"小注）：它**拒绝**在第 6 小时早写摘要页并给出替代方案
⇒ **没有失败**。详见 `../abs-red-evidence.md` §4.1 与 §4.4。

> **「逐问作答」不在这张清单里（复审更正，此前写错）**：本条先前被写进"没有失败"，依据是
> `../abs-red-evidence.md` §4.1 的**话题覆盖率词法探针**（关键词命中 8/8）。**那个探针不能判
> "有没有答那一问"** —— 摘要可以通篇只有判据/阈值而关键词一个不少（该探针自己也标了"命中关键词 ≠ 真答了那一问"）。
> 按**产物级证据**（判分表 `../mcm-abstract-quality-rubric.md` §3-Q7：逐句读产物），本条在 6 份里
> **失败 5 次**：A1/A2/P2 对"wear 是否与资料一致"只给判据不给判定，A3/P1 的 Task 2 五问整块无结论，
> **只有 C1 逐问有答案**。⇒ 它是**已观察到的失败**，不属于"没有观察到的失败"。
> （同处更正见 `../abs-green-evidence.md` §2.3 第 2 条。）

## 四、尺寸：三份基线**都塞不进一页**

摘要页按规范只能占 **1 页**。`build/abs-red/measure-pdf.md` 按 pdfLaTeX 口径实测：
三份各占 **2 页**，等效 **1.24 / 1.58 / 1.93 页**（第 2 页填充率 0.241 / 0.576 / 0.933）；
要压进一页，A1 得砍约 **160 词**、A2 约 **417 词**、C1 约 **646 词**。
**这是比"编译不过"更硬的否决项** —— 编过了也交不了。数字出处与复现见 `../abs-red-evidence.md` §1.4b。
