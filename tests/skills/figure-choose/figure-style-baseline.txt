版本：起点 commit `8c57c6b`；本文件是**口径收敛轮（Task 6 的 Important-2 涟漪）**重跑后的证据
      （§9 登记与修复轮的差异；§2–§8.4 由**同目录**的 `gen-figure-style-baseline.py` 逐条重放命令生成，
      §8.5 由同一脚本的 `2` 相在提交后重放）。
      ⚠️ 旧任务书/旧报告点名的生成器 `.superpowers/sdd/m3-t1-mk-baseline.py` **从未入库**
      （那目录被自己的 `.gitignore` 全挡），且它只能重放出**修复轮之前**那一版
      —— 故本轮换成同目录入库的 `gen-figure-style-baseline.py`（重放式）。

【对捕获输出的唯一加工】
1) 命令一律以仓库相对路径写出（可直接粘进 bash、cwd = 仓根）；
2) 捕获输出里的**仓根绝对路径**与**解释器前缀**剥成相对形式（本仓规定不写绝对路径）；
3) fail-closed 那类块把 stdout 与 stderr 分栏贴出（`[stdout]` / `[stderr]`），栏内逐字。
除这三条外**逐字未改**——每个块尾的 `[exit=..]` 就是该命令的真实退出码。
凡标 `$TEMP` 的路径都在**系统临时目录**里（仓库之外），不入库、收工不残留。

【分母口径声明 · 本文件所有演示一律 6.31 in】
`--textwidth-in` 一律传 **6.31**，即「逐篇正文行宽 p90」的**全局中位**
（侦察读数：tests/figures-recon/b-stats.txt `col_w_in: n=43 ... median=6.310 ...`）。
检查器**不预设**口径——分母一律由参数传入。另一种口径（逐篇 p90 各自作分母）
会给出不同比值，两者结论不同 ⇒ 见 §6，不自行挑一个悄悄用。

【条数】**本条不写死条数**（2026-10-01 订正：原文写「expected.tsv 现为 **21** 条」，与同件
        §2 捕获块里的实际行数不符 ⇒ 散文数 ≠ 同件捕获）——**以本件 §2 捕获块里的
        `MISMATCH 0 / N` 行为准，N 由当场跑出**。
        ⚠️ 这里**连"当时的现值"也不写**（2026-10-01 第 2 轮修复：上一轮此处曾写死 `MISMATCH 0 / 34`，
        `expected.tsv` 一变它就假 —— 正是本条要修的那一类）。
        （选「指针」而不是「带日期的现值」的理由：这个数在 Task 1 之后已经漂过一次 ——
        写死的现值还会再漂第二次；指针则不可能与同件捕获脱节。历史沿革见 §9。）

==============================================================================
§1  本轮修了什么（逐条对应独立评审判定）
==============================================================================

Important-1  PDF 上 F2 直接崩 —— 修：F2 也吃 PDF（第 1 页 `get_pixmap` → `Image.frombytes`）。
             证据：§3.5 的 PDF 对照（旧检查器 rc=1/stdout 空/UnidentifiedImageError ↔ 新检查器判词）；
             入库样本 `ok-05.pdf` / `bad-f2-five-colors.pdf`（§3.1、§2）；变异 M7（§4）。
Important-2  fail-closed 不完整 —— 修：8 条参照缺失路径全部并入 `fail_closed()`（rc=2、不打印判词），
             并把 `--dpi ≤ 0` 与 `--textwidth-in ≤ 0` 同等拒绝。证据：§3.4（8 条逐条）。
Important-3  F3a 没有「它能红」的证明 —— 修：补图注 fixture `caption:6`（缺冒号 ⇒ F3a FAIL，
             钉进 expected.tsv）+ 变异 M8（F3a 谓词取反）。证据：§2、§4。
R-4         `--json` 时末行不再是 `RESULT:` —— 修：JSON 挪到判词行**之前**。证据：§3.3。
R-5         逐格验收把「崩掉的运行」记成 FAIL/OK —— 修：`rc ∉ {0,1}` 或没有 `RESULT:` 行 ⇒ 记 ERROR、
             整轮非零退出。证据：§5（旧/新验收脚本对同一支变异体的 A/B）+ §4 的探针 P1。
R-6         M2 缺前置断言 —— 修：补 `all(b == 'PASS' ...)`（先要求三张合格图本来是绿的）。证据：§4。
R-7         图样本借用的图注带尾句号 ⇒ 每行都混一条无关的 `FAIL（F3c）` —— 修：换不带句号的图注。
             证据：§3.1（图样本行里只剩各自要测的那条）。

命令体（逐字，cwd = 仓根）：

import glob, statistics as st
from PIL import Image
FIGS = sorted(glob.glob('corpus/papers/figures/**/fig-*.png', recursive=True))[::4]
print('sample n =', len(FIGS))
def v1(p):   # A 任务书原样：默认重采样（BICUBIC）
    im = Image.open(p).convert('RGB').resize((320, 320)); tot = 320*320; keep = {}
    for cnt, (r, g, b) in im.getcolors(tot):
        if max(r, g, b) - min(r, g, b) < 24: continue
        k = (r//16, g//16, b//16); keep[k] = keep.get(k, 0) + cnt
    return sum(1 for c in keep.values() if c/tot >= 0.005)
def v2(p):   # B 出厂：NEAREST
    im = Image.open(p).convert('RGB').resize((320, 320), Image.NEAREST); tot = 320*320; keep = {}
    for cnt, (r, g, b) in im.getcolors(tot):
        if max(r, g, b) - min(r, g, b) < 24: continue
        k = (r//16, g//16, b//16); keep[k] = keep.get(k, 0) + cnt
    return sum(1 for c in keep.values() if c/tot >= 0.005)
def v6(p):   # C 侦察仪器：quantize(32, MEDIANCUT)
    im = Image.open(p).convert('RGB').quantize(colors=32, method=Image.MEDIANCUT).convert('RGB')
    tot = im.size[0]*im.size[1]; keep = {}
    for cnt, (r, g, b) in im.getcolors(tot):
        if min(r, g, b) >= 240 or max(r, g, b) <= 40: continue
        if max(r, g, b) - min(r, g, b) <= 24: continue
        k = (r//16, g//16, b//16); keep[k] = keep.get(k, 0) + cnt
    return sum(1 for c in keep.values() if c/tot >= 0.005)
for name, fn in [('A 任务书原样(BICUBIC)', v1), ('B 出厂(NEAREST)', v2), ('C 侦察仪器(quantize32)', v6)]:
    vals = [fn(p) for p in FIGS]; zero = sum(1 for v in vals if v == 0)
    print(f'{name:26} median={st.median(vals):.1f} mean={st.mean(vals):.2f} '
          f'zero%={100*zero/len(vals):.1f} <=4占比={100*sum(1 for v in vals if v <= 4)/len(vals):.1f}%')

⇒ A 与 B 的差 = 重采样是否造色（本检查器出厂用 B）；B 与 C 的差 = 仪器不同，见 §6-2。
