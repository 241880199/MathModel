## ② 参照来源（算式 + 手算）
- **算例**：`min f = (x1−1)² + (x2−2)²`，`s.t. x1 + x2 ≤ 2`，`x1,x2 ≥ 0`。
- **无约束极小**：`(x1,x2) = (1,2)`，`f = 0`；但 `x1+x2 = 3 > 2` ⇒ **越界**，最优必落在边界 `x1+x2 = 2`。
- **边界代入**：令 `x2 = 2 − x1` ⇒ `f(x1) = (x1−1)² + (2−x1−2)² = (x1−1)² + x1² = 2x1² − 2x1 + 1`。
- **驻点**：`df/dx1 = 4x1 − 2 = 0 ⇒ x1 = 0.5`（`≥ 0` 可行）⇒ `x2 = 1.5`，`f = 2·0.25 − 2·0.5 + 1 = 0.5`。
- **KKT 核对**：`∇f = (2(x1−1), 2(x2−2)) = (−1, −1)`；约束梯度 `(1,1)`；`∇f = −λ·∇g ⇒ λ = 1 > 0`（约束**有效**）⇒ 该点是 KKT 点。
- **参照与骨架不同源**：手算走**边界代入 + KKT**；骨架是 `fmincon`（SQP）一段调用。
  ★ **诚实说明**：该参照验证的是**骨架是否算到正确的最优解 / 值**，**不验证"非线性模型对题面是否合适"**。
