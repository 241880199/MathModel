## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— 小序列上**逐步手算前 3 次 NLMS 权重迭代**（期望值写死在本文里），外加**收敛性**（每 pass 的训练 MSE 单调不增）。

## ② 参照来源（算式 + 手算）
- **NLMS 递推**：`xs = [y(t-1), …, y(t-k)]`；`yhat = w·xsᵀ`；`e = y(t) − yhat`；
  `w ← w + μ·e·xs / (‖xs‖² + ε)`。
- **算例**：`y = [10 12 13 15 14 16 17]`、`k = 2`、`μ = 0.5`、`w0 = [0.5, 0.5]`。手算前 3 次：
  - `t=3`：`xs = [12, 10]`、`yhat = 0.5·12 + 0.5·10 = 11`、`e = 13 − 11 = 2`；`‖xs‖² = 244`；
    `w1 = 0.5 + 0.5·2·12/244 = 0.54918033`、`w2 = 0.5 + 0.5·2·10/244 = 0.54098361`。
  - `t=4`：`xs = [13, 12]`、`yhat = 0.54918033·13 + 0.54098361·12 = 13.631148`、`e = 15 − 13.631148 = 1.3688525`；`‖xs‖² = 313`；
    `w1 = 0.54918033 + 0.5·1.3688525·13/313 = 0.57760698`、`w2 = 0.54098361 + 0.5·1.3688525·12/313 = 0.56722359`。
  - `t=5`：`xs = [15, 13]`、`yhat = 0.57760698·15 + 0.56722359·13 = 16.038011`、`e = 14 − 16.038011 = −2.0380113`；`‖xs‖² = 394`；
    `w1 = 0.57760698 + 0.5·(−2.0380113)·15/394 = 0.53881234`、`w2 = 0.56722359 + 0.5·(−2.0380113)·13/394 = 0.53360158`。
- ★ **发散反例（未归一 LMS）**：教科书原始更新 `w ← w + 2μ·e·xs`（Widrow-Hoff，**未按输入能量归一**）对尺度极敏感。
  **实测依据（本机 python 独立复算，非骨架、非 MATLAB）**：对 `y = [10 12 13 15 14]`、`k=2`、`w0=[0.5 0.5]`，
  学习常数取 `0.5 / 0.1 / 0.05 / 0.02 / 0.01` ⇒ **第 1 个 pass（3 次更新）末**权重分别为 `[2.88e6, 2.49e6] / [2.2e4, 1.9e4] / [2616, 2263] / [141, 122] / [13.0, 11.2]`（**首 pass 训练 MSE** 相应为 `1.2e10 / 1.9e7 / 1.1e6 / 2.1e4 / 779`）——
  ★ **标签订正**：这 5 组是**第 1 个 pass 末**的读数，**不是 200 pass 的读数**（原文误标"200 pass 后"）。
  ★★ **长期行为是发散**（这正是本骨架改用 NLMS 的理由）：`μ = 0.5` 时权重在第 41 个 pass 末已达 `~2.5e305`（逼近双精度上限）、随即溢出为 `inf` / `NaN`；`μ` 越小越慢，但**无一收敛**。
  **复算口径（可复跑，逐位复现上列 5 组值与 200-pass 溢出）**：

```bash
python -c "y=[10,12,13,15,14]; k=2
def run(mu,p):
    w=[0.5,0.5]
    for _ in range(p):
        for t in range(k,len(y)):
            xs=[y[t-1-i] for i in range(k)]
            e=y[t]-sum(a*b for a,b in zip(w,xs))
            w=[w[i]+2*mu*e*xs[i] for i in range(k)]
    return w
for mu in (0.5,0.1,0.05,0.02,0.01): print(mu, run(mu,1))
print('200 passes, mu=0.5 ->', run(0.5,200))"
```

  （输出：`0.5 [2876698.5, 2492735.0]` · `0.1 [22076.5, 19117.05]` · `0.05 [2616.05, 2263.36]` · `0.02 [141.34, 121.96]` · `0.01 [13.02, 11.21]` · `200 passes, mu=0.5 -> [nan, nan]`。）
- **参照与骨架不同源**：手算走逐点算术；骨架是 `for` 循环实现。
  ★ **诚实说明**：手算与骨架**用同一套公式**（NLMS 更新）⇒ 该参照验证的是**实现是否算对**（数值），**不验证 `k`/`μ`/`w0` 的选型**。
  ★ **发散反例是另一来源**（python 独立复算），它验证的是**"未归一版本不可用"这一方法判断**，与骨架实现无关。
