## ② 参照来源（算式 + 手算）
- **网络**：源 1、汇 4、需求 4；弧 (cap, cost)：1→2:(3,1) · 1→3:(2,2) · 2→3:(2,1) · 2→4:(2,3) · 3→4:(3,1)。
- **手算（流量变量 + 守恒 + 容量）**：设 `f12,f13,f23,f24,f34`。守恒：`f12+f13 = 4`（源）· `f12 = f23+f24`（点 2）· `f13+f23 = f34`（点 3）· `f24+f34 = 4`（汇）。容量：`f12≤3, f13≤2, f23≤2, f24≤2, f34≤3`。目标 `min = 1·f12 + 2·f13 + 1·f23 + 3·f24 + 1·f34`。
  由 `f12+f13 = 4`、`f12≤3`、`f13≤2` ⇒ `f12 ≥ 2`。分两种情形：
  - `f12=2, f13=2`：`f34 = 2 + f23`，`f24 = 2 − f23` ⇒ 目标 `= 14 − f23`；由 `f34≤3 ⇒ f23≤1` ⇒ 取 `f23=1` 得 **13**。
  - `f12=3, f13=1`：`f34 = 1 + f23`，`f24 = 3 − f23` ⇒ 目标 `= 15 − f23`；由 `f34≤3 ⇒ f23≤2` ⇒ 取 `f23=2` 得 **13**。
- **最优**：min cost = `13`（可行解一：`f12=2, f13=2, f23=1, f24=1, f34=3`，校验守恒：点 2 出 1+1=2 ✓ · 点 3 入 2+1=3 = 出 3 ✓ · 汇入 1+3=4 ✓；费用 `2+4+1+3+3 = 13` ✓）。
- **参照与骨架不同源**：手算走**守恒式枚举**；骨架是 SSP + Bellman-Ford（残量网络最小费用增广）。
  ★ **诚实说明**：手算与骨架不同路径（守恒式 vs 逐次增广），**同结论 13**；独立性来自"手算是人按定义式列式求解、与代码无关"。
