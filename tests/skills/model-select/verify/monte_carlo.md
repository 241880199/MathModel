## ② 参照来源
- 合成分布：`X ~ U(0,1)`，**已知期望 `T = 0.5`**、方差 `1/12`；估计量 `X̄_n` 的**总体标准差 = `1/√(12n)`**（解析给出）。

  ★ **诚实说明**：这条验证的是"**样本均值收敛到已知期望、误差量级 = `1/√n`**"，**不验证**"抽样分布 / 被估量选得对不对"。
