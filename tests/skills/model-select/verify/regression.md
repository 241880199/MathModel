## ① 参照类型
**第 4 类：已知参数的合成数据**（GC6）—— **系数可复原**：造 `y = X·β_true + ε`（固定种子），反估 `β_hat` 并与 `β_true` 比；**核 `R²` 与残差**。

## ② 参照来源
- **真值**：`β_true = [2.0, -3.0, 1.5, 0.5]`（截距 + 3 个自变量），`n = 200`，噪声 `ε ~ N(0, σ²)`，`σ = 0.1`，`seed = 20261004`。
- **系数可复原判据**：`(β_hat − β_true)/se` 应落在 ~`±2`（有限样本的抽样波动；`se` = **系数标准误** `sqrt(diag(s2·inv(XᵀX)))`；`±2` 是标准的 `t ≈ 2` 惯例 ⇒ **标 `[社区]`**）。
- **理论抽样标准误**：`se ≈ σ/√n · (设计矩阵因子)`，量级 `0.1/√200 ≈ 0.00707`（实测与之一致）。
- **`R²`**：因 `σ` 远小于信号，`R²` 应接近 1；**`σ_hat`**（残差标准差）应回到真 `σ = 0.1`。
- **参照与骨架不同源**：真值参数是**已知输入**、`R²`/残差是**可独立算的统计量**（由 `y`、`X` 直接定义），骨架是 `X\y` 的调用。
  ★ **诚实说明**：`β_hat` 的**点估计**与手算 `X\y` 同源（同一公式）；但**"是否回到真值"这一判据**独立于骨架实现（真值来自数据生成，不是骨架算的）。

★ **`mean(resid) = 0` 那一行按构造恒真**：模型含**截距列** ⇒ 最小二乘残差与常数列正交 ⇒ 残差均值必为 0。**不许把它当数值验证引用**；真正有信息的是 `β_hat` 与真值的差、`σ_hat` 与真 `σ` 的差。
★ **本表不是"解析对解析"**：`β_true` 来自**数据生成过程**（是"已知参数"，不是解析式），`β_hat` 是**数值反估** ⇒ 两列是**数值 vs 已知真值**的比对。

**结论**：`β_hat` 回到 `β_true`（各分量差 ≤ `0.0069`，`(β_hat−β_true)/se` 全在 `±2` 内）；`σ_hat = 0.0907` 接近真 `σ = 0.1`；`R² = 0.99916`。**系数可复原**这条成立。
