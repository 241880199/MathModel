## ② 参照来源（算式 + 手算）

- **手算枚举 12 条不同巡回**（固定起点 1，方向对称取一）：
  - `1-2-3-4-5-1` = 2+6+8+5+5 = 26
  - `1-2-3-5-4-1` = 2+6+3+5+10 = 26
  - `1-2-4-3-5-1` = 2+4+8+3+5 = **22**
  - `1-2-4-5-3-1` = 2+4+5+3+9 = 23
  - `1-2-5-3-4-1` = 2+8+3+8+10 = 31
  - `1-2-5-4-3-1` = 2+8+5+8+9 = 32
  - `1-3-2-4-5-1` = 9+6+4+5+5 = 29
  - `1-3-2-5-4-1` = 9+6+8+5+10 = 38
  - `1-3-4-2-5-1` = 9+8+4+8+5 = 34
  - `1-3-5-2-4-1` = 9+3+8+4+10 = 34
  - `1-4-2-3-5-1` = 10+4+6+3+5 = 28
  - `1-4-3-2-5-1` = 10+8+6+8+5 = 37
  ⇒ **最小 = 22**。★ **口径**：固定起点 1、**方向对称取一**（每条巡回只取 `1-2-…`/`1-3-…`/`1-4-…` 中**首个中间点最小**的那个方向）⇒ 恰 **12** 条不同巡回（`(5−1)!/2 = 12`）。
  ★ **订正（2026-10-04 Task 11 复核实测）**：本表**原列 12 行但只有 10 条不同巡回** —— `1-3-4-5-2-1`(= `1-2-5-4-3-1` 反向) 与 `1-3-5-4-2-1`(= `1-2-4-5-3-1` 反向) 是**重复计入**，且**漏了 `1-4-2-3-5-1`(28) 与 `1-4-3-2-5-1`(37)** ⇒ 已换成正确的 12 条。**最优 `22` 不受影响**。
- **最优**：总代价 `22`，巡回 `1-2-4-3-5-1`（其反向 `1-5-3-4-2-1` 等价，亦 22）。
- **参照与骨架不同源**：手算走**逐条枚举**；骨架是 `perms` 全排列穷举实现。
  ★ **诚实说明**：手算与骨架同一穷举 ⇒ **数值穷举核对**；独立性来自"手算是人逐条列出求和、与代码无关"。
