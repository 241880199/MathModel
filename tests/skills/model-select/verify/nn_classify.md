## ② 参照来源
- **已知构造**：类 1 = 内盘 `r ≤ 1.5`（面积均匀采样）、类 2 = 外环 `2.0 ≤ r ≤ 3.2`（面积均匀采样），等点数；两区间**无重叠** ⇒ **径向边界**、无噪声 ⇒ **贝叶斯准确率 = 1.0**。
- **骨架**：内置 `fitcnet`（前馈网，`LayerSizes = [16 8]`，`Standardize = true`），在**独立测试集**上估准确率（`ntrain = 400`、`ntest = 2000`）；网络权重**随机初始化**（`rng(seeds(s)+500)` 固定种子）。
- **对照（同一数据）**：**线性分类器** `fitclinear` —— 对**径向边界**它无法分离。
- 参照与骨架**不同源**：边界是**已知构造**（解析给定的半径区间），准确率是**从合成样本估出的经验值**（测试集计数）。
