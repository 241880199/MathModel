## ① 参照类型
**第 4 类：已知函数的合成数据**（GC6）—— 已知 `f(x) = sin(2x)` + 已知噪声 ⇒ **预测新含噪观测的测试 RMSE 下界 = 噪声标准差 σ = 0.15**。
★ **不许拿 MATLAB 内置 `fitrsvm` 当"独立参照"**（同机同实现）；本骨架**明写** `fitrsvm` **只作实现**。

## ② 参照来源
- **已知构造**：`x ~ U(-3, 3)`，`y = f(x) + N(0, σ²)`，`f(x) = sin(2x)`，`σ = 0.15`；测试点在 `[-3, 3]` 上另取、目标为**新的含噪观测** `yte = f(xte) + N(0, σ²)` ⇒ 测试噪声与训练无关、**不可预测** ⇒ **最优测试 RMSE ≈ σ = 0.15**（噪声底）。
- **骨架**：内置 `fitrsvm`，**RBF 核**（`KernelScale = 'auto'`、`Standardize = true`），在独立测试集上算 RMSE（`ntrain = 400`、`ntest = 1000`）。
- **对照（同一数据）**：**线性核** `fitrsvm`（模型形式对正弦不对）。
- 参照与骨架**不同源**：噪声底 σ 是**构造给定**的，RMSE 是**从合成样本估出的经验值**。

★ **注（★ 这条口径坑，本骨架初版栽过）**：
- **测试目标必须是"新的含噪观测"**，噪声底才是 `σ = 0.15`。★ 若把测试目标换成**无噪声的真函数** `f(xte)`，好的平滑器 RMSE 会**低于 σ**（初版对真函数曾得 `0.034`）—— **σ 只是"预测含噪观测"的下界，不是"预测真函数"的下界**。报告前须写清是哪种。
- **线性行是"对照"，不是独立验证** —— 它与 RBF 行用**同一批数据**；作用是展示"模型形式不对的代价"，**不构成对 RBF 的独立验证**。**本方法的独立数值验证在"RBF RMSE ≈ 噪声底 σ"这一行**。

**结论**：已知 `f(x) = sin(2x)` + 噪声 `σ = 0.15` 上，RBF 核 SVR 测试 RMSE `0.1568 ± 0.0034`（5 种子）
**贴着噪声底 `0.15`**（差 `0.007`，再降不可能）；**线性** SVR `0.6919` 远高于噪声底（模型形式不对）。
★ **本记录验证**"SVR 回归 RMSE 算得对"；**不验证**"该不该用 SVR 建模"（那是建模判断）。
