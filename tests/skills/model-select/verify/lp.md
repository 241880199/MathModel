## ② 参照来源（算式 + 手算）
- **算例**：`max z = 3·x1 + 5·x2`，`s.t. x1 ≤ 4 · 2·x2 ≤ 12 · 3·x1 + 2·x2 ≤ 18 · x1,x2 ≥ 0`。
- **可行域顶点**（约束线两两相交、取第一象限内的点）与目标值：
  - `(0,0)` ⇒ `z = 0`
  - `(4,0)` ⇒ `z = 3·4 = 12`
  - `(0,6)`（由 `2x2=12`）⇒ `z = 5·6 = 30`
  - `(4,3)`（`x1=4` ∩ `3x1+2x2=18`：`12+2x2=18 ⇒ x2=3`）⇒ `z = 3·4+5·3 = 27`
  - `(2,6)`（`x2=6` ∩ `3x1+2x2=18`：`3x1+12=18 ⇒ x1=2`）⇒ `z = 3·2+5·6 = 36`
  - `(4,6)` 不满足 `3·4+2·6 = 24 > 18` ⇒ 不可行。
- **最优**：`z = 36` 于 `(x1,x2) = (2,6)`（在 `x2=6` 与 `3x1+2x2=18` 的交点）。
- **参照与骨架不同源**：手算走**逐顶点算术**；骨架是 `linprog`（单纯形 / 内点）一段调用。
  ★ **诚实说明**：该参照验证的是**骨架是否算出正确的数值最优**，**不验证"线性模型对题面是否合适"**（那是建模判断）。
