## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— 小序列 `x = [10 12 13 15 14]`、窗口 `m = 3`，**逐步手算**简单移动平均与加权移动平均。

## ② 参照来源（算式 + 手算）
- **简单移动平均** `MA_3(t) = (x(t-2)+x(t-1)+x(t))/3`：
  - `t=3`：`(10+12+13)/3 = 35/3 = 11.666667`；
  - `t=4`：`(12+13+15)/3 = 40/3 = 13.333333`；
  - `t=5`：`(13+15+14)/3 = 42/3 = 14`。**一步预测 = 14**。
- **加权移动平均** `w = [1 2 3]`（递增，近点权重大），`Σw = 6`：
  - `t=3`：`(1·10 + 2·12 + 3·13)/6 = 73/6 = 12.166667`；
  - `t=4`：`(1·12 + 2·13 + 3·15)/6 = 83/6 = 13.833333`；
  - `t=5`：`(1·13 + 2·15 + 3·14)/6 = 85/6 = 14.166667`。**一步预测 = 14.166667**。
- **参照与骨架不同源**：手算走逐窗口算术；骨架是 `for` 循环实现。
  ★ **诚实说明**：手算与骨架**用同一套公式** ⇒ 该参照验证的是**实现是否算对**（数值），**不验证窗口 `m` / 权重 `w` 的选型**。
