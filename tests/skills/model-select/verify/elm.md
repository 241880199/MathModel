## ② 参照来源
- **已知构造**：两高斯类、**等协方差** `Sigma = I`、等先验、类均值距 `Δ = 2`（马氏距离）。
  此时**线性判别（LDA）是贝叶斯最优**；理论错误率（教科书级闭式）：`err_bayes = Φ(-Δ/2)`，`Δ = sqrt((m1-m2)' Sigma^{-1} (m1-m2))` ⇒ `Φ(-1) = 0.1587`。
- **骨架**：ELM —— 隐层 `L = 60`、sigmoid 激活、随机权重（`rng(seeds(s)+1000)` 固定种子）、输出权重 `β = (H'H + λI)^{-1} H'T`（`λ = 1e-6`）；在**独立测试集**上估错误率（`ntrain = 600/类`、`ntest = 4000/类`）。
- **对照（同一数据）**：**线性最小二乘分类器**（等价于 ELM 去掉隐层）。
- 参照与骨架**不同源**：`err_bayes` 是**分布性质（解析）**，骨架 / 对照是**从合成样本估出的经验错误率**。

★ **注**：

- **线性 LS 行是"对照"，不是独立验证** —— 它与 ELM 用**同一批数据**；它的作用是确认"等协方差下线性已到贝叶斯、随机隐层买不到额外精度"，**不构成对 ELM 错误率的独立验证**。**本方法的独立数值验证在"ELM 错误率 ≈ 闭式贝叶斯误差"这一行**。
- ELM 的随机性来自**隐层随机权重**（固定种子后逐种子可复现）；据此给分布。
