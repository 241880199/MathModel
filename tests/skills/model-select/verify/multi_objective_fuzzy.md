## ② 参照来源（算式 + 手算）
- **原始矩阵**：`X = [80 90 70; 70 85 95; 90 75 80]`（3 方案 × 3 目标，全效益型）；权重 `w = [0.5, 0.3, 0.2]`。
- ① **相对隶属度（逐列 min-max）** `r = (x − min)/(max − min)`：
  - 目标 1（`[80,70,90]`，`min 70 / max 90 / 极差 20`）：`r₁ = [(80−70)/20, (70−70)/20, (90−70)/20] = [0.5, 0, 1]`；

  - 目标 3（`[70,95,80]`，`min 70 / max 95 / 极差 25`）：`r₃ = [0, 1, 10/25] = [0, 1, 0.4]`。
- ② **加权综合** `B = R·wᵀ`：
  - `B₁ = 0.5·0.5 + 0.3·1 + 0.2·0 = 0.55`；
  - `B₂ = 0.5·0 + 0.3·(10/15) + 0.2·1 = 0.4`；
  - `B₃ = 0.5·1 + 0.3·0 + 0.2·0.4 = 0.58`。
- ③ **排序** `B 降序`：`B₃(0.58) > B₁(0.55) > B₂(0.4)` ⇒ 名次 `[3 1 2]`。
