## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— **3×3 近一致算例**做**主参照**（期望值**手算写死在本文里、并给出算式**），
另附一个 **3×3 完全一致算例**（`lam_max = 3`、`CI = 0`）作边界核对。**含一致性检验** `CR = CI/RI < 0.1`（任务书 B.3）。

## ② 参照来源（算式 + 手算）
- **主算例**：`A = [1 2 5; 1/2 1 3; 1/5 1/3 1]`（3 阶正互反）。
- ① **方根法（几何平均法）**：行几何平均 `g_i = (Π_j a_ij)^(1/3)`：
  - `g₁ = 10^(1/3) = 2.154434690` · `g₂ = 1.5^(1/3) = 1.144714243` · `g₃ = (1/15)^(1/3) = 0.405480133`；`Σg = 3.704629066`。
  - 权重 `w_i = g_i / Σg = [0.581552067, 0.308995644, 0.109452290]`（和 = 1）。
- ② **最大特征值** `lam_max = (1/n) Σ_i (A w)_i / w_i`：
  `Aw = [1.74680448, 0.92812831, 0.32876124]` ⇒ 三个比值均 = `3.003694598` ⇒ `lam_max = 3.003694598`。
- ③ **一致性指标** `CI = (lam_max − n)/(n − 1) = (3.003694598 − 3)/2 = 0.001847299`。
- ④ **RI**：`RI(3) = 0.58`（Saaty 表，**教科书级常识 ⇒ 标 `[社区]`**）。
- ⑤ **一致性比率** `CR = CI / RI = 0.001847299 / 0.58 = 0.003184998 < 0.1` ⇒ **通过**。
- **边界算例**：`A0 = [1 2 3; 1/2 1 3/2; 1/3 2/3 1]`（完全一致）⇒ 行积 `6, 3/4, 2/9`，
  `g0 = [1.817120593, 0.908560296, 0.605706864]`，`w0 = [0.545454545, 0.272727273, 0.181818182] = [6 3 2]/11`；`lam_max = 3`、`CI = 0`。
- **参照与骨架不同源**：手算走**逐格算术**；骨架是一段向量化 MATLAB。
  ★ **诚实说明**：手算与骨架**用同一套公式**（方根法 + `CI/RI`）⇒ 该参照验证的是**实现是否算对**（数值），**不验证公式本身的选型**。

★★ **"方根法 vs 特征向量法"那两行恒等，是 `n = 3` 的一条已知结论**（正互反 3 阶矩阵的方根法向量就是主特征向量）
