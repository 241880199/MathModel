## ① 参照类型
**第 4 类：已知簇结构的合成数据**（GC6）—— `k = 3` 个**中心已知**、等大小的高斯簇 ⇒ 簇分配**还原率**（对标签置换不变）+ **质心误差**；`k` **未知**时用轮廓系数选。
★ **不许拿 MATLAB 内置 `kmeans` / `fcm` 当"独立参照"**（同机同实现）；本骨架**明写**它们**只作实现**。

## ② 参照来源
- **已知构造**：`k = 3` 个簇中心在半径 `sep = 5` 的圆上均匀分布（`C_true` 已知），每簇 `nper = 200` 点、`Σ = I` ⇒ **簇结构已知**。
- **骨架（k 已知）**：内置 `kmeans(X, 3, 'Replicates', 10)`；还原率**对标签置换不变**（枚举 `3!` 种标签映射取最大）；质心按同一映射重排后与 `C_true` 比。
- **k 未知**：`evalclusters(X, 'kmeans', 'silhouette', 'KList', 1:6)` ⇒ 应选回 `k = 3`。
- **模糊 C-means**：内置 `fcm(X, 3, [2,100,1e-5,0])` ⇒ **隶属度**矩阵 `U`；按 `argmax` 估还原率，并给**划分系数** `PC = (1/n) Σ u²`（越接近 1 越硬）。
- 参照与骨架**不同源**：真簇标签是**已知生成结构**，还原率 / 质心误差 / PC 是**从合成样本估出的经验值**。
