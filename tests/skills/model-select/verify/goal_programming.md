## ② 参照来源（算式 + 手算）
- **算例**：`min 2·d1⁻ + 1·d2⁻`
  `硬约束 x1 + x2 ≤ 10`，`x1,x2 ≥ 0`；
  目标1 `x1 + 2·x2 + d1⁻ − d1⁺ = 16`；目标2 `2·x1 + x2 + d2⁻ − d2⁺ = 16`。
- **两目标能否同时精确达成？** 令 `d1⁻=d2⁻=0` ⇒ `x1+2x2 = 16`、`2x1+x2 = 16` ⇒ 相减得 `x1 = x2`、`3x1 = 16 ⇒ x1 = x2 = 16/3 ≈ 5.333`；
  但 `x1+x2 = 10.667 > 10` ⇒ **不可行**。⇒ 至少一个目标要欠。
- **令硬约束取等** `x1 + x2 = 10`（否则可继续增大两目标、代价不会更差），`x2 = 10 − x1`：
  - 目标1 实际值 `x1 + 2(10−x1) = 20 − x1` ⇒ `d1⁻ = max(0, 16 − (20−x1)) = max(0, x1 − 4)`。
  - 目标2 实际值 `2x1 + (10−x1) = 10 + x1` ⇒ `d2⁻ = max(0, 16 − (10+x1)) = max(0, 6 − x1)`。
  - **代价** `C(x1) = 2·max(0, x1−4) + max(0, 6−x1)`，`x1 ∈ [0,10]`：
    - `x1 ≤ 4`：`C = 6 − x1`，在 `x1 = 4` 取最小 `2`；
    - `4 ≤ x1 ≤ 6`：`C = 2(x1−4) + (6−x1) = x1 − 2`，在 `x1 = 4` 取最小 `2`；
    - `x1 ≥ 6`：`C = 2(x1−4) = 2x1 − 8`，在 `x1 = 6` 取最小 `4`。
- **全局最小**：`C = 2` 于 `x1 = 4, x2 = 6`；此时 `d1⁻ = 0`、`d2⁻ = 2`、`d1⁺ = d2⁺ = 0`。
- **参照与骨架不同源**：手算走**分段代价分析**；骨架是 `linprog` 一段调用（把偏差变量摊进 LP）。
  ★ **诚实说明**：该参照验证的是**骨架是否算到正确的最优解 / 偏差 / 代价**，**不验证"权重 2:1 是否合理"**（那是建模选择）。
