## ① 参照类型
**共轭闭式 + MCMC 双路**（GC6）：正态-正态共轭的后验有闭式 ⇒ **MCMC 与闭式对照**（均值/标准差/可信区间）；
另加**内置 `bayeslm`**（diffuse 先验）与**手推闭式**对照。

## ② 参照来源
- **模型 A（正态均值、方差 `sigma^2` 已知）**：由数据与先验直接给闭式后验
  `tau_n^2 = 1 / (1/tau0^2 + n/sigma^2)`，`mu_n = tau_n^2 (mu0/tau0^2 + Σy/sigma^2)`，`95% CI = mu_n ± 1.96 tau_n`。
  - 路径二：**自写随机游走 Metropolis MCMC**（5 条链、各 100000 步、固定种子）。
  - 路径三：`mvnrnd` 从闭式后验**精确抽样**（50000 次）。
- **模型 B（贝叶斯线性回归）**：内置 `bayeslm(…,"diffuse")` 的解析后验摘要
  （`summarize(...).MarginalDistributions`）与手推闭式（OLS 位置 + `t` 尺度、`df = n-p`）对照。
- 参照与骨架**不同源**：闭式公式与 `mvnrnd` 精确抽样独立于自写 MCMC 采样器；`bayeslm` 是 MathWorks 引擎。
