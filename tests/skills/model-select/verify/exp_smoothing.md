## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— 小序列 `x = [10 12 13 15 14]` 上**逐步手算**一次平滑（SES）与二次平滑（Holt），期望值写死在本文里。

## ② 参照来源（算式 + 手算）
- **一次平滑（SES）**，`α = 0.5`：`S(1)=x(1)`；`S(t) = 0.5·x(t) + 0.5·S(t-1)`：
  - `S(1) = 10`；
  - `S(2) = 0.5·12 + 0.5·10 = 11`；
  - `S(3) = 0.5·13 + 0.5·11 = 12`；
  - `S(4) = 0.5·15 + 0.5·12 = 13.5`；
  - `S(5) = 0.5·14 + 0.5·13.5 = 13.75`。**一步预测 = S(5) = 13.75**。
- **二次平滑（Holt）**，`α = 0.5`、`β = 0.3`：`l(1)=x(1)=10`、`b(1)=x(2)−x(1)=2`；
  `l(t) = 0.5·x(t) + 0.5·(l(t-1)+b(t-1))`，`b(t) = 0.3·(l(t)−l(t-1)) + 0.7·b(t-1)`：
  - `t=2`：`l=0.5·12+0.5·(10+2)=12`，`b=0.3·2+0.7·2=2`；
  - `t=3`：`l=0.5·13+0.5·(12+2)=13.5`，`b=0.3·1.5+0.7·2=1.85`；
  - `t=4`：`l=0.5·15+0.5·(13.5+1.85)=15.175`，`b=0.3·1.675+0.7·1.85=1.7975`；
  - `t=5`：`l=0.5·14+0.5·(15.175+1.7975)=15.48625`，`b=0.3·0.31125+0.7·1.7975=1.351625`。
  **一步预测 = l(5) + b(5) = 15.48625 + 1.351625 = 16.837875**。
- **三次（HW 加法）**：骨架在自带季节序列 `[10 14 18 22, 12 16 20 24, 14 18 22 26]`、`L=4` 上运行；
  **本参照不手算 HW**（季节递推较长）—— HW 行**只报骨架读数**、**不声称已手算核对**（诚实说明）。
- **参照与骨架不同源**：手算走逐点递推；骨架是 `for` 循环的向量化实现。
  ★ **诚实说明**：手算与骨架**用同一套公式** ⇒ 该参照验证的是**实现是否算对**（数值），**不验证公式/系数选型**（`α`、`β` 是否最优是另一回事）。

★ **`S(1) = x(1)` 与 `l(1)=x(1)`、`b(1)=x(2)−x(1)` 那几点按构造恒真**（初值就是显式赋的）⇒ **不许把它当数值验证引用**；真正有信息的是**后续递推值**是否与手算对上。
★ **`SES 一步预测 = S(end)`** 是**按定义**取末平滑值 ⇒ 该行**按构造恒真**，不是独立验证。

**结论**：SES 与 Holt 的逐点平滑值、水平、趋势与一步预测均与手算**逐位一致**（本例为有限小数、差为 `0`）；HW 行只作**骨架读数登记**、**本参照不核对**。
