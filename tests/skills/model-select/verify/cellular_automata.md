## ② 参照来源
- 规则：Conway 生命游戏 **B3/S23**（环面）。
- **人工兜底 ①（已知规则的标准图案）**：blinker（水平三连）**周期 = 2**、位移 `[0 0]`；glider（经典五格）**周期 = 4**、每周期位移 `[+1,+1]`。
- **人工兜底 ②（手算第 1 步，可逐格推演）**：blinker 水平三连 `(3,2)(3,3)(3,4)` 的下一时刻 = 竖直三连 `(2,3)(3,3)(4,3)`。
  推导：`(3,3)` 活、邻居 = 2 ⇒ 存活；`(2,3)` / `(4,3)` 死、邻居 = 3 ⇒ 出生；`(3,2)` / `(3,4)` 活、邻居 = 1 ⇒ 死亡 ⇒ 竖直三连。✓
- 参照与骨架**不同源**：手算是逐格算术、周期是图案的**已知性质**；骨架是 `circshift` 邻居计数 + 迭代。★ 但**独立性只有这一层、`MS3` 判不到**。
