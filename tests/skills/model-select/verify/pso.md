## ② 参照来源
- **benchmark**：`f(x) = 3 + (x1−2)² + (x2+1)²`，域 `[-10,10]²`，**已知全局最优 `f* = 3` 于 `(2,−1)`**（**单峰**；人造基准，教科书级 `[社区]`）。
- **随机量的分布**：`seeds = 1..5` 各跑一次（`pop=40`、`maxgen=150`、`w=0.7`、`c1=c2=1.5`），报 `f_best` 的 `mean ± sd`、命中率 `(|f_best − f*| ≤ 1e-4)`、相对差。
- **可复现性**：`rng(seed)` 后跑 ⇒ **跨进程重跑逐位相同**。
- **参照与骨架不同源**：最优 `f*=3` 于 `(2,−1)` 由**算例解析式**给定；PSO 只负责去找它。
  ★ **诚实说明**：该参照验证的是**"PSO 能收敛到已知最优""结果可复现""多次运行有分布"**，**不验证 `w`/`c1`/`c2` 的选型最优**。
