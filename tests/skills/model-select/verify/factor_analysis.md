## ① 参照类型

## ② 参照来源
- 模型：`X = F Λ' + E`，`F ~ N(0, I_k)`，`p = 6` 变量、`k = 2` 因子、`n = 2000`，`rng(0)`。
  已知 `Λ_true = [0.9 0; 0.8 0; 0.7 0.2; 0 0.9; 0 0.8; 0.1 0.7]`。
- ★ **令变量方差 = 1**（取 `Ψ_i = 1 − ‖Λ_i‖²`）：因为内置 `factoran` **内部会标准化**
  （实测 `seed=0`：`factoran(X,…)` 与 `factoran(zscore(X),…)` 结果**至 ~1e-12 量级相同**
  —— `max|diff| = 1.5e-12`（载荷）/ `1.8e-13`（`Psi`），**非逐位相同**（`isequaln = 0`），
  该差随种子在 `1e-12`–`1e-11` 量级浮动），
  令方差 = 1 后这一标准化成为**恒等**，估计出的载荷才直接对得上真值。
- 用内置 `factoran(X, 2, 'rotate', 'none')` 反估；因子解**只定到正交旋转** ⇒ 按两条比：
  (a) **公因子方差（行范数 `‖Λ_i‖²`）旋转不变** ⇒ 直接比；(b) 载荷用**正交旋转对齐**后比。
- 参照与骨架**不同源**：真值载荷是已知生成参数；骨架是 `factoran` 的极大似然估计。
