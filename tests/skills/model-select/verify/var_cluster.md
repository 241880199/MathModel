## ① 参照类型
**第 3/4 类：合成数据（已知变量结构）**（GC6）—— 6 个变量由 **2 个已知隐因子**生成：`v1,v2,v3 = f1 + 小噪声`、`v4,v5,v6 = f2 + 小噪声`（`f1 ⟂ f2`）
⇒ **已知真值**：变量分群 = `{1,2,3}` / `{4,5,6}`。距离 = `1 − |corr|`，`cluster(Z,2)` 割树应**还原**已知变量分组。
★ **链接方式（complete / average）显式**；★ 固定种子、给**逐种子还原率 + 组内/组间平均 |corr|**。

## ② 参照来源
- **人工构造的已知变量分组**：真值 `[1 1 1 2 2 2]'` —— 分群是我们造的、**独立于任何聚类算法**。
- **结构可核的量**：组内平均 `|corr|` 应**高**、组间应**低**（隐因子 `f1 ⟂ f2` ⇒ 组间理论相关 ≈ 0）。
- 参照与骨架**不同源**：变量分组是人工构造、组内/组间相关是**构造成分**；骨架是 `corr` + `linkage` + `cluster`。
  ★ **MATLAB 的 `corr` / `linkage` / `cluster` 只作实现、不作独立参照**（同机同实现不独立）。
  ★ **本记录验证**"距离=1−|corr| 的割树能否还原已知变量分组"；**不验证**"该聚成几组变量"（那是建模决策）。

## ④ 两边读数（`n = 500`, `seeds = 1:20`, `noise = 0.30`）
**① 相关结构（`seeds(1)` 代表样本）**
| 量 | 骨架 | 参照（已知构造） |
| :--- | :--- | :--- |
| 组内平均 `|corr|` | `0.9179` | 高（`f1` 主导 ⇒ 组内强相关） |
| 组间平均 `|corr|` | `0.0383` | ≈ 0（`f1 ⟂ f2`） |

**② 割树成 2 群的还原率（20 种子均值）**
| 链接方式 | 骨架 cut@2 还原 | 参照（已知变量分组） |
| :--- | :--- | :--- |
| complete | `1.000` | `[1 1 1 2 2 2]` |
| average | `1.000` | `[1 1 1 2 2 2]` |

（两种链接方式**都逐种子还原**已知分组 `{v1,v2,v3}` / `{v4,v5,v6}`。）

**结论**：由 2 个已知隐因子生成的 6 个变量，其**组内平均 `|corr| = 0.9179`、组间 `0.0383`**（与构造相符）；
`1 − |corr|` 距离 + `complete`/`average` 链接割成 2 群，**20 个种子全部还原**已知变量分组 `{1,2,3}` / `{4,5,6}`。
