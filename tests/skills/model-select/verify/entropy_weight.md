## ② 参照来源（算式 + 手算）
- **主算例**：`X = [1 2 3; 2 3 4; 3 4 5]`（`m=3` 方案 × 3 指标，全效益型）。
- ① 归一化 `p_ij = x_ij / Σ_i x_ij`（列和 = `6, 9, 12`）⇒
  `p = [1/6 2/9 3/12; 2/6 3/9 4/12; 3/6 4/9 5/12] = [0.166667 0.222222 0.25; 0.333333 0.333333 0.333333; 0.5 0.444444 0.416667]`。
- ② 熵 `e_j = -(1/ln m) Σ_i p_ij ln p_ij`，`ln 3 = 1.098612289`：
  - C1：`Σ p ln p = 1/6·ln(1/6) + 1/3·ln(1/3) + 1/2·ln(1/2) = -0.298627 - 0.366204 - 0.346574 = -1.011404` ⇒ `e₁ = 0.92061984`；
  - C2：`= 2/9·ln(2/9) + 1/3·ln(1/3) + 4/9·ln(4/9) = -0.334239 - 0.366204 - 0.360413 = -1.060857` ⇒ `e₂ = 0.96563361`；
  - C3：`= 1/4·ln(1/4) + 1/3·ln(1/3) + 5/12·ln(5/12) = -0.346574 - 0.366204 - 0.364779 = -1.077556` ⇒ `e₃ = 0.98083404`。
- ③ 差异度 `d_j = 1 - e_j = [0.07938016, 0.03436639, 0.01916596]`，`Σd = 0.13291251`。
- ④ 权重 `w_j = d_j / Σd = [0.59723617, 0.25856400, 0.14419983]`。
- 参照与骨架**不同源**：手算走逐格算术；骨架是一段 `m×n` 向量化实现。
  ★ **诚实说明**：手算与骨架用同一套公式 ⇒ 该参照验证**实现是否算对**（数值），不验证公式选型。

## 边界算例（零值 / 负值处置）
- **零值** `X0 = [0 1 2; 2 3 4; 4 5 6]`：`p₁₁ = 0` ⇒ 按约定 `0·ln0 = 0`（骨架显式置 0，否则得 `NaN`）。
  手算 `e₁ = 0.636514/ln3 = 0.579380`（`Σp ln p = 0 - 0.366204 - 0.270310 = -0.636514`），
  骨架 `e_zero = [0.5793801643, 0.8527924885, 0.9206198357]` ⇒ 第 1 列**一致**；权重 `w_zero = [0.6498994963, 0.2274502519, 0.1226502518]`（**全为有限值，未出 `NaN`**）。
- **负值** `Xn = [1 -1 2; 2 3 1; 3 1 3]`：含负数 ⇒ 骨架**逐列 min-max 归一化到 [0,1]**后计算
  （`[1,2,3]→[0,0.5,1]`、`[-1,3,1]→[0,1,0.5]`、`[2,1,3]→[0.5,0,1]`，每列 `Σ=1.5`）。
  手算每列 `Σp ln p = -0.636514` ⇒ `e = 0.579380`（三列相同）⇒ `d` 相同 ⇒ `w = [1/3, 1/3, 1/3]`；
  骨架 `e_neg = [0.5793801643, 0.5793801643, 0.5793801643]`、`w_neg = [0.3333333333, 0.3333333333, 0.3333333333]` ⇒ **一致**。

**结论**：主算例的 `e`/`d`/`w` 与手算算式**逐位一致**（差 ≲ `1e-8`）；
零值按 `0·ln0=0` 约定处理（权重全为有限值）；负值触发逐列 min-max 归一化、权重全为非负有限值。
