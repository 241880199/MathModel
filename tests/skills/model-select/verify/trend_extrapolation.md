## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— 小序列 `t = 1..5`、`y = [3 5 6 9 10]`，**逐步手算**线性最小二乘与外推 `t = 6`。

## ② 参照来源（算式 + 手算）
- **线性最小二乘** `y = a + b·t`：`t̄ = 3`、`ȳ = 6.6`；
  - `Σ(t−t̄)(y−ȳ) = (-2)(-3.6) + (-1)(-1.6) + 0·(-0.6) + 1·2.4 + 2·3.4 = 7.2 + 1.6 + 0 + 2.4 + 6.8 = 18`；
  - `Σ(t−t̄)² = 4 + 1 + 0 + 1 + 4 = 10`；⇒ `b = 18/10 = 1.8`；`a = 6.6 − 1.8·3 = 1.2`；
  - **外推 `t=6`：`y(6) = 1.2 + 1.8·6 = 12.0`**。
- **其余趋势族**（二次 / 指数 / logistic）**本参照不手算**，只报骨架读数（见 ④），**不声称已核对**（诚实说明）。
- **参照与骨架不同源**：手算走"均值中心化"逐项算术；骨架用 `polyfit`。
  ★ **诚实说明**：手算与骨架**用同一套公式**（线性最小二乘）⇒ 该参照验证的是**实现是否算对**（数值），**不验证趋势族选型**。
