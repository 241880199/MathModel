## ① 参照类型
**第 4 类：已知最优解的小算例 + 固定种子 + 多次运行的分布**（GC6）—— 小 TSP（**已知最优巡回长度**）+ 固定种子 + 5 次运行 + 逐次读数 + `mean ± sd` + 命中率 / 相对差。

## ② 参照来源
- **算例**：**5 城 TSP**，坐标 `C = [0 0; 3 0; 3 4; 0 4; 1.5 2]`（矩形 3×4 四角 + 中心）。
- **已知最优 = 15** —— 由**全排列穷举**（固定起点 0、其余 4 城全排，`4! = 24` 条巡回）独立算出：
  ```
  python -c "import itertools,math
  C=[(0,0),(3,0),(3,4),(0,4),(1.5,2)]; n=len(C)
  d=lambda a,b: math.hypot(C[a][0]-C[b][0],C[a][1]-C[b][1])
  print(min(sum(d(t[i],t[(i+1)%n]) for i in range(n)) for t in ((0,)+p for p in itertools.permutations(range(1,n)))))"
  ```
  **输出：`15.0`**。
- **随机量的分布**：`seeds = 1..5` 各跑一次（`maxit=60`、`nAnts=10`、`α=1`、`β=3`、`ρ=0.5`），报 `L_best` 的 `mean ± sd`、命中率 `(L_best == L*)`、相对差。
- **可复现性**：`rng(seed)` 后跑 ⇒ **跨进程重跑逐位相同**。
- **参照与骨架不同源**：最优 `L* = 15` 由**穷举**（确定性、遍历全部巡回）得出；骨架是**随机**的信息素正反馈启发式。
  ★ **诚实说明**：该参照验证的是**"ACO 能找到已知最优""结果可复现""多次运行有分布"**，**不验证 `α`/`β`/`ρ`/`nAnts` 的选型最优**。
