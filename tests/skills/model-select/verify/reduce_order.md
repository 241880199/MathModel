## ① 参照类型
**第 1 类：解析解 + 收敛阶**（GC6）—— 把二阶方程降成一阶组，用**定步长 RK4** 积分，比逐点误差 + **步长减半看误差按阶下降**。
★ **不许拿 MATLAB 内置 `dsolve` 当"独立参照"**（同机符号实现，不独立）—— 它**只作交叉核对**。

## ② 参照来源
- **算例**：`d2y/dx2 + y = 0`，`y(0) = 1`，`dy/dx(0) = 0` ⇒ **闭式解 `y(x) = cos(x)`**（教科书级）。
- **降阶**：`[y1; y2]' = [y2; -y1]`，初值 `[1; 0]`。
- **收敛阶**：定步长 RK4 是 **4 阶**（`O(h^4)`，步长减半比 ~ `16`）。
- **参照与骨架不同源**：闭式解 `cos(x)` 是纸上解析式；骨架是降阶后的一阶组 + 手写 RK4；`dsolve` 是同机符号实现（只作交叉核对）。
