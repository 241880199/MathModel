## ② 参照来源
- 模型：3 个 agent 在一维线上、状态 `x` 连续，按**行/列双随机**权重矩阵 `W` 更新 `x' = W x`（DeGroot 意见动力学）。
- **人工兜底 ①（2–3 agent 确定性手算小例，可逐步推演）**：
  `W = [0.5 0.5 0; 0.5 0 0.5; 0 0.5 0.5]`，`x0 = [1; 0; 3]`。**第一步手推**：
  `x1(1) = 0.5*1 + 0.5*0 = 0.5`；`x1(2) = 0.5*1 + 0*0 + 0.5*3 = 2.0`；`x1(3) = 0.5*0 + 0.5*3 = 1.5`
  ⇒ `x1 = [0.5; 2.0; 1.5]`。
- **人工兜底 ②（性质检查）**：和守恒（`W` 双随机）/ 收敛到均值 `mean(x0) = 4/3`。
- 参照与骨架**不同源**：手算是逐格算术、性质是代数（`1'W = 1'`）；骨架是矩阵迭代。★ 但**独立性只有这一层、`MS3` 判不到**。

★ **注（两处按构造恒真，必须标明）**：
- **和守恒行是"按构造恒真"** —— `W` 双随机 ⇒ `1'W = 1'` ⇒ `sum(x') = 1'(Wx) = (1'W)x = 1'x = sum(x)`，
  **对任意步数值上必然成立**，**不构成独立数值验证**；
- **收敛到均值行也由构造保证**（双随机 + 连通 ⇒ 迭代收敛到 `(1/n)Σx0`），是一个**性质核对**而非数值验证。
⇒ 本项**真正可手算核对的只有第 1 步行**（一个 3 agent 确定性小例）；**其余两行只做性质核对**。

**结论**：骨架第 1 步与手推**逐位相同**；和守恒与收敛到均值**按构造成立**（非独立验证）。
