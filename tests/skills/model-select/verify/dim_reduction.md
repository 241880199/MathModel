## ② 参照来源
- **人工兜底 ①（已知簇结构的合成流形）**：3 个高斯簇、`d = 10`、每簇 `nper = 90`（共 270 点），
  簇心取 `6·e_j`（`j = 1..3`）、`rng(0)` 固定。
- **人工兜底 ②（邻域保持率 / kNN 一致性，一个可算的量）**：原空间 `k` 近邻里有多少在对偶嵌入里仍是 `k` 近邻。
- **人工兜底 ③（已知簇结构是否被保住）**：在嵌入上做 k-means，看与真簇标签的**纯度**。
- **固定种子 + 多次运行的分布**：实测 `rng(seed)` 后 `tsne` **逐位可复现**（同 `rng(1)` 跑两次 ⇒ `max|diff| = 0`）；
  骨架逐**5 个种子**（`seeds = 0:4`）跑，给 kNN 一致性的**分布**（数据固定、只变 t-SNE 的种子）。
- 参照与骨架**不同源**：真簇标签是已知输入、kNN 一致性是自写度量；骨架是内置 `tsne`。

★ **注（按构造/相对量的说明）**：
- **kNN 一致性 `0.4673`（5 种子均值）是"相对量"** —— t-SNE 会为换取全局结构而重排簇内局部次序，故它**天然 < 1**；
  该值**只作对照记录、不设通过阈值**（设计 §4.1 明列 t-SNE 无 ground truth）。
- **k-means 纯度 `1.0` 不是"按构造恒真"** —— 它是**在嵌入上重新聚类**后与真标签比对的经验结果
  （合成簇虽分离良好，但嵌入若塌缩仍会掉纯度）；它是本项最可读的一条判据。

kNN 一致性 `0.4673 ± 0.0059`（5 种子；**相对量**，记录不设阈值）。
