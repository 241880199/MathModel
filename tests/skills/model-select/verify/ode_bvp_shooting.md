## ① 参照类型
**第 1 类：解析解 + 收敛阶**（GC6）—— 取有闭式解的 BVP，比逐点误差 + **步长减半看误差按阶下降**。
★ **不许拿 MATLAB 内置 `bvp4c` / `ode45` 当"独立参照"**（同机同实现，不独立）。

## ② 参照来源
- **算例**：`d2y/dx2 = -y`，`x ∈ [0, pi/2]`，`y(0) = 0`，`y(pi/2) = 1` ⇒ **闭式解 `y(x) = sin(x)`**（教科书级）。
- **打靶参数**：`s = dy/dx(0)`，解析值 `s* = cos(0) = 1`。
- **收敛阶**：用**固定步长 RK4** 积分（4 阶，`O(h^4)`，比 ~ `16`）。
  ★ **每档网格各自重解 `s`** —— 否则误差被 `s` 的截断误差支配、比值退化（见 ④ 注）。
- **参照与骨架不同源**：闭式解 / 解析 `s*` 是纸上解析式；骨架是打靶（`fzero` 求 `s` + 手写 RK4）。

**更细档（当场复跑）**：误差比 `N=20/40` ⇒ **`15.455285`**（逼近 16）⇒ 确为 **RK4 的 4 阶**。

★ **注（关键）**：若把 `N` 档解出的 `s` **固定**拿去跑 `2N` 档，误差被 `s` 的截断误差支配、比值会**退化到 `2.431`**（当场实测）；**按档重解 `s` 后**才是 `14.721` ⇒ **收敛阶研究必须在每档网格各自重解打靶参数**。

**结论**：逐点误差随步长减半按 `~16` 下降（4 阶）、打靶参数回到解析 `s*=1` 到 `1e-6` ⇒ **"算得对"成立**。
