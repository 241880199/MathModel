## ① 参照类型
**第 3 类：手算标准算例**（GC6）—— 两例：
(A) **4×4 指派**用手算 **Hungarian 归约求下界 + 零匹配**；(B) **0-1 背包**用手算 **全枚举 8 种组合**。

## ② 参照来源（算式 + 手算）
**(A) 4×4 指派**，代价矩阵
```
cost = [9 2 7 8
        6 4 3 7
        5 8 1 8
        7 6 9 4]
```
- **行归约**：行最小 `[2,3,1,4]`（和 `=10`）⇒ 减去后
  `[7 0 5 6; 3 1 0 4; 4 7 0 7; 3 2 5 0]`。
- **列归约**：列最小 `[3,0,0,0]`（和 `=3`）⇒ 减去后
  `[4 0 5 6; 0 1 0 4; 1 7 0 7; 0 2 5 0]`。
- **零匹配**（选 4 个不同行不同列的 0）：`(1,2) (2,1) (3,3) (4,4)` ⇒ 完全匹配。
- **下界 = 行最小和 + 列最小和 = `10 + 3 = 13`**，且由零匹配**可达** ⇒ **最优代价 = 13**（指派 行→列 = `2,1,3,4`，即 `2+6+1+4 = 13`）。

**(B) 0-1 背包**：`max 60·x1 + 100·x2 + 120·x3`，`s.t. 10·x1 + 20·x2 + 30·x3 ≤ 50`，`x ∈ {0,1}³`。
全枚举 8 组合：`(0,0,0)=0` · `(1,0,0)=60` · `(0,1,0)=100` · `(0,0,1)=120` · `(1,1,0)=160` · `(1,0,1)=180` ·
**`(0,1,1)=220`（重量 50 ≤ 50）** · `(1,1,1)=280`（重量 60 > 50 **不可行**）⇒ **最优值 = 220** 于 `x=(0,1,1)`。

- **参照与骨架不同源**：(A) 手算走 Hungarian 归约；(B) 手算走**枚举** —— 骨架 (A) 用 `perms` 穷举、(B) 用 `intlinprog`。
  ★ **诚实说明**：本参照验证**骨架是否算出正确的整数最优**；**(A) 的手算下界与骨架的 `perms` 穷举是两条不同路径**（归约 vs 全枚举），互为佐证。
