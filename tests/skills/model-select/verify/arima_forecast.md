## ① 参照类型
**第 4 类：已知参数的合成数据**（GC6）。**参数可复原 + 预测区间覆盖率**，不是"跟另一段代码对"。

## ② 参照来源
- 真值过程：平稳 AR(2) `y_t = c + a1 y_{t-1} + a2 y_{t-2} + e_t`，`e_t ~ N(0, 1)`，真值 `c = 0.1`、`a = [0.5, 0.2]`。
- **系数反估**：`nlong = 4000`（丢 500 步预热），用内置 `arima(2,0,0)+estimate` 反估 ⇒ 应回到真值。
  有限样本下 AR 估计量的**抽样标准误** `≈ 1/sqrt(n) ≈ 0.016`，故系数差应在 ~2 SE 内。
- **预测区间覆盖率**：样本外一步预测，名义 95% 区间应覆盖约 95%。**二项标准误**
  `sqrt(0.95*0.05/(300*5)) ≈ 0.0056`（每种子 300 次、5 个种子）。
- 参照与骨架**不同源**：真值参数是已知输入、覆盖率是分布性质（理论值 0.95），骨架是 `estimate`/`forecast` 的重复调用。
