## ② 参照来源（算式 + 手算）
- **权重**：准则层 `W = [0.6, 0.4]`；子权重 `W₁ = [0.5, 0.5]`、`W₂ = [0.7, 0.3]`。
- **评语分值**：`V = [100, 80, 60]`（优 / 良 / 差）。
- **隶属度矩阵**：`R₁ = [0.3 0.6 0.1; 0.4 0.4 0.2]`，`R₂ = [0.5 0.4 0.1; 0.2 0.5 0.3]`（**每行和为 1**）。
- ① **一级（`M(·,+)`）**：
  - `B₁ = W₁·R₁ = 0.5·[0.3 0.6 0.1] + 0.5·[0.4 0.4 0.2] = [0.35 0.5 0.15]`；
  - `B₂ = W₂·R₂ = 0.7·[0.5 0.4 0.1] + 0.3·[0.2 0.5 0.3] = [0.41 0.43 0.16]`。
- ② **二级**：`B = W·[B₁; B₂] = 0.6·[0.35 0.5 0.15] + 0.4·[0.41 0.43 0.16] = [0.374 0.472 0.154]`（和 = 1）。
- ③ **综合得分**：`S = B·Vᵀ = 0.374·100 + 0.472·80 + 0.154·60 = 37.4 + 37.76 + 9.24 = 84.4`；**最优等级 = 第 2 级（良）**。
- ④ **算子对照 `M(∧,∨)`**（`b_j = max_i min(w_i, r_ij)`）：
  - `B₁ = [0.4 0.5 0.2]`、`B₂ = [0.5 0.4 0.3]` ⇒ `B = [0.4 0.5 0.3]`（**和 = 1.2，未归一**）。
- **参照与骨架不同源**：手算走逐格算术；骨架是一段 MATLAB 循环 + 矩阵乘。
  ★ **诚实说明**：手算与骨架**用同一套公式**（加权平均合成）⇒ 该参照验证的是**实现是否算对**（数值），**不验证公式/算子选型**。
