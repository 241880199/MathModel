## ① 参照类型
**第 4 类：已知类别边界的合成数据**（GC6）—— (A) **线性可分的等协方差高斯类**（闭式贝叶斯误差）；(B) **XOR 的已知非线性边界**（无噪声 ⇒ 贝叶斯准确率 = 1.0）。
★ **不许拿 MATLAB 内置 `fitcsvm` 当"独立参照"**（同机同实现）；本骨架**明写** `fitcsvm` **只作实现**。

## ② 参照来源
- **(A) 线性边界**：两高斯类、**等协方差** `Sigma = I`、等先验、`Δ = 2`（马氏距离）⇒ 线性判别贝叶斯最优，`err_bayes = Φ(-Δ/2) = 0.1587`（教科书级闭式）。骨架用**线性核** `fitcsvm` 在独立测试集上估错误率（`ntrain = 300/类`、`ntest = 2000/类`）。
- **(B) 非线性边界**：XOR，`y = sign(x1*x2)`（`x ~ N(0, 1.3² I)`）⇒ **已知非线性边界**、无噪声 ⇒ **贝叶斯准确率 = 1.0**。骨架分别用**线性核**与 **RBF 核**（`KernelScale = 'auto'`）`fitcsvm` 估准确率。
- 参照与骨架**不同源**：边界与贝叶斯误差是**已知 / 闭式**，准确率是**从合成样本估出的经验值**（测试集计数）。

★ **注**：

- **(B) 的 RBF 行与线性行是"对照"关系**（同一批数据、只换核），**不是彼此的独立验证**。**本方法两条独立数值验证** = (A) 线性 SVM 错误率 ≈ 闭式贝叶斯 `0.1587`；(B) RBF 核准确率**远高于**线性核（`0.9481` vs `0.5488`），即"**核抓住了已知的非线性边界**"。
- ★ **RBF 行未到 1.0** 的残差（`0.05`）来自 XOR 边界附近的**有限样本 + 核尺度 / 惩罚**，属正常（不是"跑错"）。

**结论**：(A) 线性可分的等协方差高斯类上，线性 SVM 错误率 `0.1672 ± 0.0041` 与**贝叶斯最优** `0.1587` 相差 `0.009`；
(B) XOR 的**已知非线性边界**上，**线性** SVM 仅 `0.5488`（≈ 随机），**RBF** 核 SVM `0.9481` —— 核不是装饰。
