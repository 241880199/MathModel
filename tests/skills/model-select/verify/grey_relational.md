## ② 参照来源
- **手算**（`ρ = 0.5`，用**原始差**、不做归一化以保持可核）：`x0 = [1 2 3 4]`，
  `x1 = [2 4 6 8]` ⇒ `Δ1 = [1 2 3 4]`；`x2 = [1 2 3 3]` ⇒ `Δ2 = [0 0 0 1]`；`x3 = [4 3 2 1]` ⇒ `Δ3 = [3 1 1 3]`。
  `min = 0`、`max = 4` ⇒ `ρ·max = 2` ⇒ `ξ_i(k) = 2 / (Δ_i(k) + 2)`：
  - `ξ1 = 2/[3 4 5 6] = [0.666667 0.5 0.4 0.333333]` ⇒ `r1 = 0.475000`
  - `ξ2 = 2/[2 2 2 3] = [1 1 1 0.666667]` ⇒ `r2 = 0.916667`
  - `ξ3 = 2/[5 3 3 5] = [0.4 0.666667 0.666667 0.4]` ⇒ `r3 = 0.533333`
  ⇒ 排序 `r2 > r3 > r1` ⇒ 因素影响力 **f2 > f3 > f1**。
- 参照与骨架**不同源**：手算是逐格算术（关联系数定义式 `ξ = (min + ρ·max)/(Δ + ρ·max)`）；骨架是同一公式的向量化实现。
  ★ **本算例的手算与骨架走同一公式 ⇒ 属"解析对解析"、是符号核对 + 逐位数值核对，不是"两个独立算法"**；其**独立性来自"手算是人按定义式逐格算、与代码无关"**这一层。
  ★ **本记录验证**"关联系数与关联度算得对"；**不验证**"该选哪些因素 / 归一化怎么选"（那是建模决策）。
