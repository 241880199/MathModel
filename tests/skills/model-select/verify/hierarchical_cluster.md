## ① 参照类型
**第 3/4 类：合成数据（已知簇结构）**（GC6）—— 6 个点 = **2 个已知分群**（`A = (0,0),(1,0),(0,1)` 密集 · `B = (10,10),(11,10),(10,11)` 密集 · 两群远隔）。
核对 **`cluster(Z,2)` 割树得到的组**是否还原已知分组；另对 **4 点直线 `[0 1 3 7]`** 的 **single 链接合并次序**做**手算**核对。
★ **链接方式（single / complete / average）显式**，并核它对结果的影响。

## ② 参照来源
- **人工构造的已知分组**（主例）：真值 `[1 1 1 2 2 2]'` —— 分群是我们造的、**独立于任何聚类算法**。
- **手算合并次序**（直线例）：点 `0 < 1 < 3 < 7`，`single` 链接**逐层手算**：
  最近对 `(0,1)` 距离 `1` ⇒ 并；`{0,1}` 到 `3` 距离 `min(3,2) = 2` ⇒ 并；`{0,1,3}` 到 `7` 距离 `min(7,6,4) = 4` ⇒ 并 ⇒ **合并距离序列 `[1 2 4]`**（可逐位手推）。
- 参照与骨架**不同源**：分组是人工构造、`[1 2 4]` 是逐位手算；骨架是 `linkage` + `cluster`。
  ★ **MATLAB 的 `linkage` / `cluster` 只作实现、不作独立参照**（同机同实现不独立）。
  ★ **本记录验证**"割树能否还原已知分组 / 合并次序"；**不验证**"该分成几群 / 该用哪种链接"（那是建模决策）。

## ④ 两边读数
**① 主例（6 点 · 已知 2 群 · `cluster(Z,2)` 还原率）**
| 链接方式 | 骨架 cut@2 还原 | 参照（已知分组） |
| :--- | :--- | :--- |
| single | `6/6` | `6/6`（两群远隔，最近邻必先并组内） |
| complete | `6/6` | `6/6` |
| average | `6/6` | `6/6` |

**② 合并距离 `Z(:,3)`（各法前三层精确、末层归并两群）**
| 链接方式 | 合并距离序列 |
| :--- | :--- |
| single | `[1, 1, 1, 1, 13.45]` |
| complete | `[1, 1, 1.414, 1.414, 14.87]` |
| average | `[1, 1, 1.207, 1.207, 14.17]` |

（组内合并距离：single 取最近邻 ⇒ 全 `1`；complete 取最远点 ⇒ `sqrt(2)=1.414`；average 居中 ⇒ `1.207` —— **链接方式对组内合并距离的影响可见**，但对**顶层分组**（两群远隔）三者一致。）

**③ 手算核对（4 点直线 `[0 1 3 7]` · single 链接）**
| 量 | 骨架 | 参照（手算） | 是否一致 |
| :--- | :--- | :--- | :--- |
| 合并距离序列 | `[1 2 4]` | `[1 2 4]` | **MATCH** |

**结论**：`single`/`complete`/`average` 三种链接方式割树成 2 群**都还原**已知 2 分组（`6/6`）；
4 点直线的 single 链接合并距离 `[1 2 4]` 与**逐位手算**相同；链接方式只改变**组内**合并距离（`1` / `1.414` / `1.207`），不改变**远隔两群**的顶层分组。
