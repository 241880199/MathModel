## 空集反证（§5.2）—— **任务书第 9 条只列五行，实测"整树空"是六行**

任务书 §"必查项"第 9 条写"把方法目录清空 ⇒ `MS1`/`MS2`/`MS3`/`MS4`/`MS6` 必须全红"。**实测（驱动器先跑两个探针）**：

- **只清空方法库**（`references/` + `assets/`，**留 `SKILL.md`**） ⇒ 红集 = `{MS1,MS3,MS4,MS6}`，**`MS2` 仍绿**（势=3）——
  因为 `SKILL.md` **自身**带 3 条 `corpus/` 反引号路径（`corpus/papers/MODEL_MAP.md` · `corpus/algorithms/src/`
  · `corpus/papers/`），**`MS2` 的抽取面非空**。
- **整棵 skill-dir 清空**（`SKILL.md` 也没了） ⇒ 红集 = **全六条** `{MS1,MS2,MS3,MS4,MS5,MS6}`。

⇒ 设计 §5.2 的"**空树**（零文件 / 零路径 / 零参照 / 零骨架）⇒ 这几条必须真的红"在**整树清空**下成立；
**第 9 条列五行，是因为它列的是"原本平凡真的那五条"**（`MS5` 在空树下**本来就会红**，不在"待修"名单里）。
驱动器把两种切法**都跑的**（`MUT-EMPTY-TREE` 满足第 9 条的"`MS2` 必须红"；`MUT-EMPTY-LIB` 登记"`MS2` 仍绿"这一真读数）。

## 已知边界（**不声称穷尽**）

1. ★★ **"参照与骨架真的不同源"这条机械判据判不了** —— `MS3` **只判"参照记录在场 + 四要素齐"**，
   **不判"参照是否真的独立"**。一个 `verify/` 记录完全可以**四要素齐备、却把骨架自己的输出抄成"参照"**。
   ⇒ **别把 `MS3` 说成"能判不同源"**（那是"声明比事实大"，设计 §5 末已写死）。
   **它的处置分两层（照设计 §4.1/§4.2 与 §H 既有口径）**：
   - **机械层**（`MS3` 判）：四要素齐备；
   - **判断层**（**人工 / 独立复核判**）：**参照是否真的独立** —— 必须由复核员逐条读，且**拿设计 §4 的四类去对**
     （如"手算算例"类必须**给出算式**，不能只给一个数）。
   ★ **本驱动器验的是"机械层能红"**（`MUT-MS3-*`），**验不了判断层** —— 别以为驱动全绿就说明参照都独立。
2. ★ **抽取语法不覆盖**（设计 §5.3 / §5.1 第 4 条）：**裸路径不带反引号 · HTML 链接 · 脚注引用**不在 `MS2` 射程内。
   驱动器只证明了"**反引号内的 `corpus/` / `.claude/` 串**"这一面会红。**其它写法本表未逐条覆盖**。
3. ★ **`MUT-MS2-shorthand` 是"势变化"不是"变红"**：它证明的是"全路径 → 简写 ⇒ 该条**退出抽取面**、
   被 `MS2` 的**势 −1** 暴露（洞不是静默的）"；**它不产生红**。若要它变红，得让被改的那条**仍留在抽取面上**（即另一码事）。
4. ★ **`MS4` 的耗时**：跑 MATLAB（`--scope class --class simulation`，4 个骨架）在**本机约 20–25 秒/次**；
   驱动器共 ~14 次调用 ⇒ 全程**约 5–6 分钟**。★ 本机已知 **MATLAB 退出期自崩**现象见检查器"已知边界"第 5 条；
   驱动器**如实记耗时、不重跑到绿**（若某轮偶发自崩致骨架缺行，`MS4` 会判红，那是**假红**，照实报）。
5. ★ **空集反证只跑了"整树空"与"只清库"两种切法**；**其它中间态**（如只删部分类）**本表未逐条覆盖**。
6. ★ **驱动器不重复跑 `--scope all`**：`all` 的判据集合与 `class` 面相同（都是 `MS1`–`MS6`），
   全库面是**收工门**的事，不进变异循环（省 MATLAB 时间）。
7. ★★ **实测发现：方法文件里的 `corpus/` 串未必落在 `MS2` 抽取面上**。`MS2` 的语法是"反引号内、以
   `corpus/`/`.claude/` 起始"，**但反引号要成对**。`references/simulation/monte_carlo.md` 的正文含一个
   ```` ```matlab ```` 代码围栏 ⇒ **反引号配对被打断**，那两条 `corpus/algorithms/src/…/monte_carro.m`
   **根本没被抽取**（该文件只抽出 `.claude/skills/mcm-table/` 与 `.claude/skills/mcm-figure-choose/`）。
   ⇒ 驱动器首跑把 `MUT-MS2-wrong-path` 打在 `.md` 上时**实测红了 0 条**，据此**改打在骨架 `.m` 上**
   （那条**确实被抽取**）才真红。★ 这是 `MS2` 抽取面**比"人眼看反引号"要小**的事实登记，
   **不是判据缺陷**（设计 §5.1 已声明"抽取语法不声称穷尽"）。
8. ★★ **"判据清单现取"只做了一半（2026-10-04 Task 13 独立复核 Low-1，据实登记）**：
   驱动器**确实现取**清单（`re.match(r"^(PASS|FAIL)\s+(\S+)")`）并用它做 `bad_target` 校验，**但没断言"每条现取判据都被某条变异覆盖"** ⇒
