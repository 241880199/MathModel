  本支的产物是一份**判断文档**（`--output` 必须指向一份具体产物）⇒ **必须存一份 GREEN 产物**。
  ★ **它不造第二份权威**：skill 的权威仍在 `.claude/skills/mcm-topic-select/`；本目录存的是**它的一次产出**，
