# 选题决策 —— 2025 MCM/ICM 六题（A–F）

一支队伍即将开赛，手上是六道题的题面。本文从中挑一道，并说明为什么是它。
下面每题按同一张「形状」写一节，末尾给**一个带推翻条件的推荐**。

**口径与免责（先读）**

- **L1 / L2** 是我自建的两级分类：**L1 = 建模范式**（这类题在回答什么性质的问题），**L2 = 具体模型族**（用什么工具回答）。
- **数据形态枚举值**（本题集只用到三个）：`D0 无官方数据·须自采或自建`、`D1 官方提供结构化数据集`、`D2 官方提供多源/半结构化数据`。
- **【可核：高/中/低】** = 该轴上我这条判断**可被核实到什么程度**。高 = 题面一句话即可核；中 = 需要我做一步推理但有据可查；低 = 依赖历史参与度等难以外部核实的量。
- **「历史」两行的数字是我离线凭记忆对 2016–2025 同型题的估计，不声称穷尽**，也不是对语料的普查结果；真要落笔进论文或做统计，须回语料复核。
- 六题均为 2025 年题面；下表按题面文件的 A–F 顺序。

## 题 A — 磨损反演

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **机理建模 · 反问题/参数辨识** | *"可观测的只有磨损剖面，要反推的是踩踏过程（频次、方向、并行人数）——观测量是过程的时间积分，本质是反问题。"* |
| `附带` **统计推断 · 不确定性量化** | *"年龄估计的可靠性、材料来源的置信度，都要求把结论表达成带区间的推断而非点值。"* |

- 历史：组合 `机理建模 · 反问题/参数辨识` × `D0 无官方数据`，出现约 3 次
- 历史：题 `2016 A`（Hot Bath）用过模型 `热传导方程 + 参数估计`，其后 `2017 A`、`2024 A` 同族，合计约 3 题
- 轴 1 · 数据可得性【可核：高】：题面无数据集；但题面**明文允许** archaeologist 现场获取"非破坏、低成本、小团队、少工具"可得的任何测量——测量方案本身是交付物，风险可控，不同于"数据不可得"。
- 轴 2 · 建模核清晰度/方法成熟度【可核：中】：核是"磨损剖面 = 踩踏分布的时间积分"，可走磨蚀律/接触力学 + 反演；反问题、贝叶斯推断、不确定性量化都是成熟工具，但要自证并守住物理假设。
- 轴 3 · 区分度 vs 拥挤度【可核：低】：MCM A 是传统"连续/机理"赛道；相比 C 题拥挤度中低，且"是否有人并行上下"这类观测量新颖，原创亮点空间大。
- 轴 4 · 交付负担与翻车风险【可核：中】：无数据清洗、无 one-page memo；但"无外部真值"意味着结论难被外部验证，必须内置"能测什么/测不准什么"的诚实边界，否则易被评委质疑空谈。

## 题 B — 可持续旅游

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **优化决策 · 多目标规划/系统动力学** | *"在游客数、收入、拥挤与环境成本之间做多目标权衡，并让支出反馈回模型形成闭环。"* |
| `附带` **政策评价 · 敏感性分析** | *"各类限流/征税措施的效果排序，以及最敏感因素的识别。"* |

- 历史：组合 `优化决策 · 多目标规划` × `D0 无官方数据`，出现约 4 次
- 历史：题 `2023 B`（Reimagining Maasai Mara）用过模型 `生态旅游承载量/多目标优化`，`2022 B`（Colorado 河水电）同族，合计约 4 题
- 轴 1 · 数据可得性【可核：高】：题面未提供数据集；Juneau 的客流/财政须从题面给的 4 条链接及公开报告自采，自采负担中等。
- 轴 2 · 建模核清晰度/方法成熟度【可核：中】：可做系统动力学或多目标规划；但"可持续"定义宽泛，容易滑向指标堆砌而失焦。
- 轴 3 · 区分度 vs 拥挤度【可核：低】：B 题传统政策/优化赛道，拥挤度中；真正的亮点在"支出去向 → 反馈闭环"这段，多数队伍会偷懒跳过。
- 轴 4 · 交付负担与翻车风险【可核：中】：需 one-page memo + 敏感性分析；模型主观性强，缺硬数据支撑时易被评委追打。

## 题 C — 奖牌预测

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **数据驱动预测 · 统计回归/区间预测** | *"用历届奖牌 + 项目设置 + 选手数据预测 2028 洛杉矶，并按题面要求给出预测区间。"* |
| `附带` **效应识别 · 模型评估** | *"'名帅效应'的证据强度、主场新增项目的影响，以及模型外推的精度评估。"* |

- 历史：组合 `数据驱动预测 · 回归/区间预测` × `D1 官方数据集`，出现约 8 次
- 历史：题 `2023 C`（Wordle）用过模型 `回归/时间序列预测`，`2022 C`（交易策略）、`2024 C`（网球动量）同族，合计约 8 题
- 轴 1 · 数据可得性【可核：高】：官方 5 个 CSV（1896–2032，含选手级结果、项目数、东道主），六题里数据风险最低。
- 轴 2 · 建模核清晰度/方法成熟度【可核：中】：预测 + 区间 + 评估的工具链很成熟；真正的难点是"名帅效应"属因果识别，不是普通回归能糊过去的。
- 轴 3 · 区分度 vs 拥挤度【可核：低】：MCM C 历来最拥挤，大量队伍会交线性回归基线 ⇒ 平庸解扎堆；想冲 O 奖必须把不确定性量化与因果识别做深。
- 轴 4 · 交付负担与翻车风险【可核：中】：无 memo；但数据清洗是隐形工作量（国家更名、`Germany-1` 这类 Team 细分、记录异常），题面已明示"如何处理数据是建模的一部分"。

- 轴 3 · 区分度 vs 拥挤度【可核：低】：ICM E 环境赛道；懂生物动力学建模的队伍相对少，原创空间大。

## 推荐

- **推荐：题 A（Testing Time: The Constant Wear On Stairs）。**
  在六题里，A 的**数据风险最低**（自采/自建、且测量方案本身就是交付物，不受"数据拿不到"掣肘）、**建模天花板最高**（磨损→人流是真反问题，不是套回归）、**拥挤度低于 C**（C 题基线解扎堆），而交付面最干净（无 memo、无数据集清洗）。
  一句话：**A 把"难"压在建模这一件你最该强的事上，把风险压在自己可控的范围内；C 的"稳"是用拥挤换来的，D 的"强"是用 GIS 翻车风险换来的。**
  若只求"稳交"，C 是次优；若求"冲奖且队伍物理/微分方程功底硬"，A 是首选。

- **推翻条件（出现任一条，即改选）：**
  1. **队伍无 ODE / 物理建模 / 反问题经验**，或抵触"自证假设" ⇒ 改选 **C**（官方数据、题面自带的区间预测就是标准答案，允许稳扎稳打拿完整分）。
  2. **队伍强在 GIS / 图论 / 网络分析**，且愿意接受脏数据清洗 ⇒ 改选 **D**（数据管够，网络模型能直接展示功力）。
  3. **队伍量化能力弱但写作与政策分析强** ⇒ 改选 **B** 或 **F**（这两题价值主要在论证与 memo/letter，而非复杂模型）。
  4. **开赛 2–3 小时内仍无法把磨损剖面写成任何可解的反演式**（即核心假设立不起来）⇒ 立即切 **C** 止损，不要在 A 上空转。
