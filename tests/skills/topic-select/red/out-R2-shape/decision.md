# 选题决策 —— 2025 MCM/ICM 六题评估与推荐

## 口径与声明（读前必看）

本文件按给定「中性形态」逐题一节填写。形态里的几个词在本文件中的含义先钉死，以免各节口径漂移：

- **L1（问题范式，即题目要你"做"什么）** 枚举：`预测` / `优化` / `评价` / `反演` / `机理-动力学` / `因果-政策`。
- **L2（建模范式，即主力模型族）** 枚举：`统计回归` / `时间序列` / `微分-差分方程` / `图-网络` / `数学规划` / `多准则评分` / `仿真-多主体` / `机理-经验混合`。
- **数据形态** 枚举：`时间序列` / `面板` / `网络` / `截面` / `文本` / `无给定数据`。
- **可核性** 枚举：`可核`（题面或给定文件一步可核实） / `半可核`（需外部知识或判断） / `不可核`（本次材料内无依据）。

**历史计数口径（重要）**：本文件**没有历史语料**，只有六份题面。下面每条「历史」行里的 `<N>` 是**自有知识下的近似**，一律标 `自报·未核`，**既不声称穷尽、也不声称精确**。若要把它变成可核的数，须按一条固定协议重跑：*在 2016–2026 MCM/ICM 全集内，按同一 `L1·L2` 组合与数据形态检索、逐条登记篇数*。本文件只给近似值 + 可核的题号锚点。

**依据范围**：仅 `brief.md`、`problems/A.md`–`F.md`、`neutral-shape.md` 三处。

## 题 A — 台阶磨损

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **反演 · 机理-经验混合** | *"题目核心是'从一组台阶的磨损形态倒推人流量、方向偏好与并行人数'，这是由结果反推成因的反问题。"* |
| `附带` **预测 · 统计回归** | *"再借年龄估计与磨损量做回归，检验磨损是否与已知史料相容，并给出日均人次量级。"* |

- 历史：组合 `反演 · 机理-经验混合` × `无给定数据`，出现 ≈4 次（`自报·未核`）
- 历史：题 `2021 A`（真菌分解）用过模型 `Logistic/分解动力学 ODE`，≈N 篇（`自报·未核`；无语料，仅自有知识锚点）
- 轴 1 · 数据可得性【可核】：题面**明写无数据文件**，要求团队自行设计**非破坏、低成本、小队伍**的测量方案（如剖面扫描/深度尺）——数据自建，门槛在测量设计而非清洗。
- 轴 2 · 建模风险【半可核】：磨损—人流关系没有标准本构，需自定磨损累积假设（线性/Weibull 等）并做敏感性；方向偏好只能从剖面不对称性弱信号推断，易被指"假设过强"。
- 轴 3 · 评判友好度【半可核】：题面给出 3 个"基本预测"子问 + 5 个"更难"子问 + 明确要求写明所需测量——给分点密、偏好评。
- 轴 4 · 同型密集度【不可核】：无投稿分布语料可依；就题面观感，"考古+磨损"属少见对象，偏蓝海但需说服评委接受自建本构。

## 推荐

- **推荐**：**题 C（奥运奖牌表）**。理由是它同时满足三条最稀缺的条件：(1) **数据封闭全给**——五份 csv 覆盖 1896–2024 并含 2028 programme，解可完全复现、无需外部采集；(2) **子问分层且可给分**——预测区间、首金国家概率、项目-奖牌关系、名帅效应、原创洞见，每一条都对应一个可交付物；(3) **明写不确定性要求**——预测区间与性能度量会把"拍脑袋"挡在门外，对训练有素的队伍是加分项。代价：C 题历来最拥挤（红海），且须处理跨届口径断裂与"名帅效应"这一弱因果问题（后者宜**降调为探索性、明确标注不可识别**，不要过度声称）。
- **备选**：若队伍强项在数据清洗 + 网络建模，选 **题 D**（同样数据全给，但清洗与建网工作量更大）；若想规避红海且机理表达强，选 **题 E**（无数据但参数可由文献锚定，深度可控）。
- **推翻条件**（任一条成立即改选）：
  1. **开赛时 C 题实际未提供题面所列数据文件**（或文件残缺、口径不可修复）——立即改选 **D**（六题中唯一另一道给全数据的题）。
  2. **队伍不具备统计/区间估计能力**（只能做确定性模型）——C 的核心分（预测区间）拿不到，改选 **D** 或 **E**。
  3. **队伍以"规避红海、追求差异化"为首要目标**且机理建模强——改选 **E**。
  4. **队伍数据采集与文本处理强、且能接受结论定性化**——在 F 冷门上有差异化空间，可作为次要备选（但风险最高，不建议首选）。
