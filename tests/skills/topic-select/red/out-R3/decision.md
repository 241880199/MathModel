# 选题决策：2025 MCM/ICM 六题择一

> 输入：六道题的题面（`problems/A.md` – `F.md`）。
> 本文件只依据这六份题面作出，未使用数据包、未联网。

## 结论（先给）

**选 Problem C —— Models for Olympic Medal Tables。**

一句话理由：**六道题里只有 C 和 D 的必需数据是随题给全的，而 C 的执行门槛（表格统计）显著低于 D（地理网络），所以 C 是"下限最高"的那一道；同时 C 明确要求预测区间与不确定性量化，天花板并没有被牺牲。**

**唯一能推翻它的条件**：队伍里没有一个人能熟练用 pandas/numpy 处理十万行级的表格数据。如果"数据这一关"就过不去，C 的优势反转为劣势，此时改选 **E**（见第 5 节决策规则）。

## 1. 六题速览

| 题 | 类别 | 一句话 | 必需数据是否随题 | 额外交付物 | 最大风险 |
|---|---|---|---|---|---|
| **A** | MCM·连续/物理 | 由石阶/木阶的磨损反推人流量、方向偏好、并行人数、年代、修缮史 | **否**（自行设计非破坏性测量） | 无 | 无数据、无极值验证；物理建模难度最高 |

## 2. 四轴评分

我按四个轴给每道题打分（0–5，分越高越好；"执行风险"轴越**低**越好，已在下表按此方向折算）：

| 题 | ①数据确定性 | ②任务有界性 | ③上限（强队拉开差距的空间） | ④执行风险（低=好） | 合计 |
|---|---|---|---|---|---|
| A | 1 | 3 | **5** | 1 | 10 |
| B | 2 | 4 | 3 | 3 | 12 |
| **C** | **5** | **4** | 4 | **4** | **17** |
| D | **5** | **4** | 4 | 2 | 15 |
| E | 2 | 4 | 4 | 4 | 14 |
| F | 1 | 3 | 3 | 1 | 8 |

各轴口径：

- **①数据确定性**：必需数据有多少是随题给全的、拿不到会不会直接卡死。**这是 96 小时里最常见的死法**，给最高权重。C/D 满分，A/F 因为"数据要自己想办法"而垫底。
- **②任务有界性**：题面把要做的事切得多清楚、能不能直接映射成论文章节。C/D/E 都有分点列举的明确任务，A 的三问其实边界很模糊。
- **③上限**：一支强队能在此题上做出别人做不出的东西的空间。A 最高（真做接触力学磨损模型的门槛极高，一旦做成即是降维打击），C/E/D 次之。
- **④执行风险**：工具链、技能栈、时间分配上的翻车概率，取反后计入。

**关于"题目拥挤度"的说明（重要）**：很多人选难题时会躲 C，理由是"选 C 的人最多"。但 MCM/ICM 的奖项是**按题池分别按比例分配**的，选 C 的人多，分给 C 的 Outstanding/Finalist 名额也同比多。**拥挤度对你的获奖概率近乎中性**，它影响的是"你和邻座想法撞车"的观感，不是名额。因此我没有把拥挤度当作独立的一轴来压分；真正的差别只在"强队在小题池里更容易显出来"，这一点我在第 5 节作为推翻条件处理。

## 3. 为什么是 C

1. **数据风险归零——这是决定性的一条。**
   题面白纸黑字："Your models and data analysis must ONLY use the provided data sets." 五个 CSV 覆盖 1896–2024 全部夏季奥运会的奖牌表、主办国、按项目的赛事数、以及每一位选手的逐条成绩。这意味着开赛后**不需要任何检索、爬取、下载、授权**，第 0 小时就能开始建模。A/B/E/F 四题都要靠队伍自己在赛中把数据凑出来，而赛中最贵的就是时间。这一条就把 C 与半数题目区分开了。

2. **任务边界清晰，直接可拆成章节。**
   题面分了三个明确的大 bullet：①奖牌数预测模型（含 2028 洛杉矶预测、首牌国家、项目数与奖牌关系）；②"名帅效应"；③其他原创洞见。每一条都能直接落成一章，便于在开赛头两小时内分工到人。

3. **天花板没有被牺牲。**
   题面明确要求"estimates of the uncertainty/precision"和"prediction intervals for all results"——**它把"要不确定性量化"写死在要求里，却不告诉你怎么做**。这正是强队拉开差距的地方：分层/贝叶斯模型、留一届奥运的交叉验证（backtesting）、正则化、以及对"项目数—奖牌数"关系的面板分析，都是普通回归做不出来的。一个扎实的不确定性框架，比一个点估计高 0.9 相关更能打动评委。

4. **执行门槛低，工具链普通。**
   全程 Python + pandas + 统计库，没有 GIS、没有仿真平台、没有必须安装的重型工具。第④轴给 4 分是实打实的：C 最坏的翻车也就是"表格读进来慢一点"，不是"数据根本用不了"。

5. **下限最高。**
   因为队伍构成未知，我优先选**最坏情况最好**的那道。C 的最坏情况是"用基础回归交了一份平庸但完整、结构正确的答卷"；D 的最坏情况是"GIS 工具链没搞定，网络图出不来，全盘皆输"。**在信息不全时，选下限高的，同时用第 3 条保住上限。**

## 4. 我对 C 的顾虑（诚实列出，不藏）

- **"名帅效应"是因果推断陷阱。** 用观测数据说"换教练→拿牌多"极易把归因搞反（是强国请好教练，不是好教练造就强国）。**处置建议：把这一节降级为"描述性观察 + 反事实讨论 + 明确的局限声明"，不要硬做因果结论。** 宁可少拿一点分，也不要用一个站不住的因果论断把整篇的可信度拖低。
- **题目最"热"，想法容易撞车。** 如第 2 节所述，这对**名额分配**近乎中性，但确实要求队伍在方法上（而非选题上）做出区分度。缓解办法就是第 3 条第 3 点：把重心放在不确定性与验证，而不是又一份"用 GDP/人口预测奖牌"的回归。
- **数据自带坑。** 题面已自曝：国家称谓随届次变化、部分项目（网球/乒乓/沙滩排球）的"Team"字段带 `Germany-1` 这类后缀。**开赛第一小时应先把这些清洗规则写死并记入假设**，别等到写论文时才发现。

## 5. 决策规则：什么时候该推翻上面这个推荐

本推荐建立在"队伍构成未知"之上。**一旦你知道队伍构成，请按下面的规则覆盖它——规则优先级高于我的默认推荐。**

| 如果队伍…… | 改选 | 理由 |
|---|---|---|
| 没人能熟练处理表格数据（pandas/numpy） | **E** | E 的数据风险最低（可自设假设，无需外部数据），ODE 建模自足，且题池相对没那么挤 |
| 运筹/网络强，且有 GIS 或 osmnx 经验 | **D** | D 的数据同样是给全的，且网络+公平性分析的天花板比 C 更具区分度；拥挤度也更低 |
| 微分方程/生态/动力系统是强项 | **E** | 稳定性、分岔、季节性、阶段结构分析是 E 的真正得分点；竞争小、上限高 |
| 物理/材料背景过硬，愿意押高方差 | **A** | A 的上限全六题最高（真做出磨损力学模型=降维打击），但无数据、无验证，方差极大，只在队伍极强时才押 |
| 有真实的政策/多目标优化经验，且赛前就有数据储备 | **B** | B 的本质是多目标优化 + 系统动力学，没有数据储备会沦为空谈；有储备则可行 |
| 有成熟的自主数据搜集与清洗能力 | **F 可选，但我仍不建议** | 题面亲自警告数据"veracity and completeness"存疑；搜集失败即全盘失败，性价比最低 |

**总原则**：数据是 96 小时里的硬约束，先按"数据能不能到手"筛，再按"强项匹配"选。

## 6. 选 C 之后的头 24 小时落地清单

1. **0–2h**：五张表全部读入，打印行列数、年份跨度、缺失情况；把"国家称谓变迁""Team 后缀"两条清洗规则写死并存档（题面已点名，别踩）。
2. **2–4h**：明确三章的分工：①预测模型与不确定性、②名帅效应、③原创洞见；指定一人专责数据清洗与结果复现（跨届交叉验证的骨架先搭起来）。
3. **4–10h**：先把"奖牌数—历史奖牌—项目数—主办国效应"的基线模型跑通，**并立刻配套做留一届交叉验证**，拿到可信度的第一组数字。
4. **10–18h**：做分层/贝叶斯或正则化模型，产出 2028 的**预测区间**（题面硬要求）；同批处理"零奖牌国家何时首牌"的概率问题。
5. **18–24h**：名帅效应按第 4 节的"描述 + 反事实 + 局限"三件套推进，**明确不宣称因果**；开始起草"项目数—奖牌"关系的面板分析。

## 7. 我拿不准的地方

- **队伍构成未知**是本决策最大的不确定性来源。第 5 节的规则就是为对冲它而写的；若你能告诉我队伍强项，我可以给出唯一确定的答案而不是这份带条件的推荐。
- **我没有拿到数据包**，因此 C 和 D 的"数据确定性 = 5"是基于题面对数据清单的描述（数据文件名、年份范围、字段），**不是**基于我核验过的数据质量。实际 CSV 是否干净、是否真的覆盖 1896–2024 全部届次，需要开赛后第一时间抽查。
- **奖项按题池比例分配**这一假设如果被现实推翻（例如某些题的 Outstanding 名额比例明显不同），第 2 节"拥挤度中性"的判断会变，届时 C 的相对优势需重新评估。
