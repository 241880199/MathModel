# 2025 MCM/ICM 选题决策：六题里挑哪一道

> 依据：本目录 `brief.md` + `problems/A.md`–`F.md` 六份题面。
> **结论：选 C（Models for Olympic Medal Tables）。**
> 这是一份"决策 + 证据"文档，不是解题方案；所有打分都是我基于题面给出的判断，不是事实断言。

## 0. 一页结论

| | |
|---|---|
| **推荐** | **C 题（Models for Olympic Medal Tables）** |
| **一句话理由** | 六题里唯一同时满足"数据现成且干净、建模主线成熟可回测、子问题可切块保底、且不强制附加件"的一题。 |

## 1. 我用来比较的四把尺子（四轴）

每轴 1–5 分，**5 = 对参赛队最有利**。四个轴都是"风险调节后"的实用指标，不衡量题目"高级不高级"。

| 轴 | 代号 | 问的是什么 | 高分意味着 |
|---|---|---|---|
| **数据** | D | 题面给不给数据？数据干净吗？ | 拿到就能开工，不用自己去找/造，不会被"数据不可得"卡死 |
| **建模** | M | 有没有一条能落地、还能被自己验证的建模主线？ | 主流程清楚（如回归/优化/ODE/图论），且能给出可检验的输出 |
| **交付** | W | 强制附加件与写作负担重不重？ | 负担轻（无 memo/letter、无需自采数据的"来源说明"章节） |
| **风险** | R | 卡死概率、被判"空谈"的概率、差异化空间 | 低卡死、结论可证伪、有余地做出区分度 |

> 说明：W 轴是"负担反向"——分越高负担越轻。四轴等权求和，仅用于排序，不是精确度量。**不声称这套权重是唯一合理的**。

## 2. 逐题档案（A–F）

每题给出：题族分类 · 题面到底问什么 · 数据 · 可走主线 · 主要坑 · 同型历史 · 四轴评级。

### A — Testing Time: The Constant Wear On Stairs
- **题族 / 语料口径**：连续型 + 物理机理（MCM **A** 的传统槽位）。
- **题面要什么**：从一组楼梯的磨损，反推 (1) 使用频率；(2) 是否有方向偏好；(3) 是否有人并排走（同时通过人数）。进阶：磨损与史料是否自洽、年代估计及其可靠性、修缮史、石材/木材来源是否与假定一致、日客流是"短时大流"还是"长时小流"。**测量必须无损、低成本、小队伍、少工具。**
- **数据**：**不提供任何数据**；题面要求队伍自己设计测量方案（这本身是考点）。
- **可走主线**：磨损力学（磨损率 ∝ 接触载荷 × 通行次数 × 走行路径分布）+ 人流随机过程（方向、单人/并排宽度）+ **反问题**（由磨损剖面反演使用史），Monte Carlo + 贝叶斯反演是自然手法。
- **主要坑**：没有任何实测数据可供校验；材料硬度、步态载荷、磨损系数全靠文献假设 → 极易被评"这些数哪来的"。"年代估计的可靠性"在原理上就难以验证。
- **同型历史（2016–2026，凭记忆，未逐条核对，不声称穷尽）**：A 槽常年是"机理 + 连续 + 少数据"——2016 热水浴、2017 赞比西河坝、2018 短波多跳传播、2019 龙生态、2020 鱼类北迁、2021 真菌食物网、2022 太阳能板、2023 干旱植物群落、2024 性别比与资源。**规律：A 几乎从不给数据，考的是"自己搭物理模型"。**
- **四轴**：数据 **2** / 建模 **3** / 交付 **5**（无附加件）/ 风险 **2** → **12**

### B — Managing Sustainable Tourism（Juneau）
- **题族 / 语料口径**：离散优化 + 系统动力学 + 政策（MCM **B** 传统槽位）。
- **题面要什么**：建"可持续旅游"模型并**明确说清在优化什么、什么是约束**；给出额外收入的支出计划并说明其如何**反馈**回模型；敏感性分析；迁移到另一个被过度旅游影响的目的地；**一页 memo** 给 Juneau 旅游委员会。
- **数据**：**不给数据包**；题面正文给了几个锚点数字（约 3 万居民、2023 年 160 万邮轮客、约 3.75 亿美元收入等）和 4 条参考链接。
- **可走主线**：多目标优化 / 系统动力学（承载容量，税、费、限流三根杠杆），可做 SD 仿真 + Pareto 前沿 + 敏感性。
- **主要坑**："可持续"的目标函数要自己立，立不好就是拍脑袋；缺少可信参数，反馈环容易画成定性图而没有数。
- **同型历史（同上，记忆，不声称穷尽）**：2016 太空垃圾、2017 收费站合流、2018 语言数量、2019 无人机配送、2020 沙堡、2021 无人机灭山火、2022 水电共享、2023 马赛马拉、2024 潜水器搜寻。**规律：B 是"离散/优化 + 决策建议 + 常带 memo"。**
- **四轴**：数据 **2** / 建模 **4** / 交付 **3**（memo）/ 风险 **3** → **12**

### C — Models for Olympic Medal Tables ★（推荐）
- **题族 / 语料口径**：数据洞察 + 统计预测（MCM **C** 传统槽位）。
- **题面要什么**（可切块，逐块有交付）：
  1. 建各国奖牌数模型（**至少**金 + 总），给出**不确定性/精度**与性能度量；
  2. 预测 2028 洛杉矶奖牌榜，**给出预测区间**，指出谁上升谁下滑；
  3. 尚未得过奖牌的国家**何时首牌**、给出概率；
  4. 项目（数量/类型）与奖牌的**关系**：各国靠哪些项目、东道主选项目的影响；
  5. 用数据找"**名帅效应**"证据、估计其贡献，并为三个国家各选一个项目给出投资建议；
  6. 其他原创洞见。
- **数据**：**明确提供 5 个 CSV**——`summerOly_athletes`（选手-项目-年份-名次）、`summerOly_medal_counts`（1896–2024 全表）、`summerOly_hosts`（含 2032）、`summerOly_programs`（1896–2032 各项目事件数）、`data_dictionary`。**规定只能使用所给数据做建模与分析。**
- **可走主线**：泊松/NegBin GLM → 分层/部分汇聚（国家随机效应、收缩）→ 时间序列/状态空间 → 东道主效应与项目协变量 → **回测**（用 2016 年前数据训练，预测 2020/2024 再对比）。"不确定性"是题面硬要求，天然可做区间。
- **主要坑**：(a) 报名量最大、同质化最重，差异化落在"不确定性刻画 + 事件/项目协变量 + 严格回测"；(b) "名帅效应"是**因果**问题，观测数据只能给相关证据——必须显式承认识别局限，别把相关说成因果；(c) 国家/代表队口径会变（如 `Germany-1`、历史上苏联/独联体等），需自定并写明合并规则。
- **同型历史（同上，记忆，不声称穷尽）**：2016 Goodgrant 资助、2017 自动驾驶协同、2018 能源结构、2019 阿片危机、2020 电商评论、2021 大黄蜂分布、2022 金/比特币交易、2023 Wordle 预测、2024 网球动量。**规律：C 给数据、要预测/推断、要不确定性与性能度量。**
- **四轴**：数据 **5** / 建模 **5** / 交付 **5**（无 memo/letter）/ 风险 **4** → **19**

### D — A Roadmap to a Better City（Baltimore 交通）
- **题族 / 语料口径**：网络 / 运筹 + GIS（ICM **D** 传统槽位）。
- **题面要什么**：建网络模型；评估 (1) 桥塌/重建、(2) 公交或人行项目 的影响，且都要"照顾到各方主体"；(3) 推荐一个最优项目并说清对居民的好处、对其他主体的影响、以及它**打断**了哪些别的生活；回答"安全"这一议题；**一页 memo** 给市长。强调**多主体权衡**。
- **数据**：**提供 9 个 CSV**（OSM 节点/边 all 与 drive、公交线、公交站、AADT 车流量、带节点路名、数据字典），题面明说**真实数据很脏**（如一条路既有编号又有会变化的路名），清洗与假设是过程的一部分。
- **可走主线**：图论最短路/容量/可达性 + 情景对比（有桥 vs 无桥）+ 多目标权衡。
- **主要坑**：数据工程量大（OSM 清洗、路名归并）；题面范围极广（4 个议题 + 安全 + memo），最容易"样样浅"；缺可靠基线（如绕行时长增量）时结论站不住。
- **同型历史（同上，记忆，不声称穷尽）**：D 槽常年是"网络 + 多主体 + 给数据"。2023 UN 可持续发展目标排序、2024 五大湖水位等属资源分配/网络家族（具体年度归属我这版记忆不确定，仅作方向参考）。
- **四轴**：数据 **4** / 建模 **3** / 交付 **3** / 风险 **3** → **13**

### E — Making Room for Agriculture（森林→农田）
- **题族 / 语料口径**：环境 / 生态系统动力学（ICM **E** 传统槽位）。
- **题面要什么**：建食物网模型（生产者/消费者 + 农事周期的季节性 + 除草剂/杀虫剂对作物、昆虫、蝙蝠、鸟类与系统稳定性的影响）；纳入两种回归物种；撤除草剂后报告稳定性、再引入蝙蝠（食虫 + 传粉）并**另选一个受益物种做对比**；分析有机农业不同成分情景对整体与各分量的影响（病虫害、作物健康、传粉、生物多样性、长期可持续、成本）；**一页给农民的信**。
- **数据**：**不给数据包**；可自行假设建模，也可用真实历史案例。
- **可走主线**：Lotka–Volterra / 扩展食物网 ODE + 季节性强迫 + 情景切换 + 稳定性/分岔分析。
- **主要坑**：几乎所有参数（捕食率、农药半致死浓度、繁殖率）都无数据支撑 → 容易产出"漂亮的 ODE 图但没人信"；情景 + 信件写作量大。
- **同型历史（同上，记忆，不声称穷尽）**：2016 水危机、2017 可持续城市、2018 气候变化与区域不稳定、2019 生态退化/生态系统服务、2020 塑料污染、2022 林业碳汇、2023 光污染、2024 财产保险可持续性。
- **四轴**：数据 **2** / 建模 **3** / 交付 **3** / 风险 **2** → **10**

### F — Cyber Strong?（国家网安政策）
- **题族 / 语料口径**：政策 / 数据驱动治理（ICM **F** 传统槽位）。
- **题面要什么**：提出"什么算强网安政策"的**理论**并用数据支持；刻画网络犯罪全球分布（高发、得手、被挫败、被报案、被起诉）；把各国公开政策与犯罪分布对比，找出**有效/无效的条款**；找人口统计相关（上网、财富、教育）；自陈数据局限；**一页给 ITU 峰会政策者的 memo**。题面明确**不许自造新指标**（已有 ITU GCI）。
- **数据**：**不给数据**，明确要求自己收集（VERIS/VCDB、ITU GCI 等），且要自评来源可信度与完整度。
- **可走主线**：跨国面板回归 / 相关分析 + 政策文本编码 + 理论构建。
- **主要坑**：跨国网安与网络犯罪数据缺失严重、口径不一、报案偏差大 → 因果识别几乎不可能；最典型结局是"通篇相关、没有结论"；评委对数据质量自陈的要求很高。**六题里失败概率最高。**
- **同型历史（同上，记忆，不声称穷尽）**：2016 难民移民政策、2017 火星移民、2018 大数据与隐私、2023 绿色 GDP、2024 非法野生物贸易。**规律：F 不给数据、要自采、偏政策与定性。**
- **四轴**：数据 **1** / 建模 **2** / 交付 **3** / 风险 **1** → **7**

## 4. 为什么是 C

1. **数据闸门 = 零**。唯一一道既给数据、数据又结构化干净（纯表格、字段明确、含数据字典）的题。A/B/E/F 都得自采或自造数据；D 的数据虽给但脏且是 GIS。对刚开赛、时间以小时计的队伍，"拿到就能跑通基线"是最大的确定性来源。
2. **主流程成熟、可自证**。GLM/泊松 → 分层收缩 → 回测（拿历史奥运会做留出验证）是一条评委熟悉、自己也验证得动的路径。与记忆里"判据声明必须有一次真的红"同一精神：C 天然允许你**用历史数据当场证明模型行不行**，而 A/E/F 的结论几乎无法在赛内被证伪。
3. **子问题可切块保底**。题面 6 个子问各自独立成章（预测 2028 / 首牌国家 / 项目效应 / 东道主 / 名帅 / 原创洞见）。即使"名帅效应"这一最硬的因果块做浅了，其余五块仍能撑起完整论文——**部分解被明确接受**，容错率高。
4. **不确定性是硬要求，而这点正是区分度所在**。题面反复要求 prediction intervals、performance measures、odds。多数队伍会糊弄过去；把区间、覆盖率、校准讲清楚就能拉开差距。
5. **交付负担最轻**。B/D/E/F 都强制一页 memo/letter（非技术写作 + 受众转换，另加一档风险）；C 只要求正文 + 参考文献 + AI 报告。
6. **和团队工具链契合**：C 产出大量数值结果，天然适合出图、出表、写摘要页——这正好是已建/在建的写作与绘图技能能补强的部分。

### 正面回应它的最强反对意见
> "C 报名最多、最卷，容易同质化。"

成立，但这是**差异化风险**，不是**失败风险**。同质化伤的是奖项档位，不是"交不出东西"。相比之下 A/E/F 的数据缺口伤的是**能否做完整**。按"先把及格线锁死、再搏区分度"的顺序，C 是风险收益比最高的：底线（有数据、有主线、有保底块）它最高，上限（不确定性 + 因果谨慎 + 回测）也足够高。

## 5. 推翻条件：什么情况下改选别的

推荐是**有条件的**。下列任一条件成立，就应当改选：

- **改选 D**，当且仅当：队伍有人熟练 GIS/`osmnx`/图算法，且愿意把前 6–8 小时投在数据清洗上。D 的上限（网络 + 多主体权衡）高于 C，但数据工程是硬门槛；门槛不过，D 会当场崩。
- **改选 B**，当且仅当：队伍偏爱优化/仿真、有人能做系统动力学，且擅长写决策 memo。B 与 C 分数接近，差别在"自采参数 vs 现成数据"——若队伍更自信于立假设、而非清洗表格，B 可反超。
- **改选 A**，当且仅当：队伍物理/力学背景强、能把"无损测量方案"本身写成亮点。注意 A 的真实难点不是建模而是**勘测设计 + 参数溯源**，A 的风险轴只有 2。
- **改选 E**，当且仅当：队伍有生态学/动力系统背景，且接受"参数靠文献、结论偏定性"。E 的差异化来自稳定性分析与情景刻画，不是数值精度。
- **改选 F**，当且仅当：队伍极强于文献整合与政策文本编码，且愿意承担数据自采。**默认不推荐**——数据轴 1、风险轴 1，是六题里最容易写成空谈的。
- **若以上都不满足**（如队伍统计/编程都偏弱）：不应硬选任何一题，而应**先按 C 起步**（它的数据与基线最容易在 2–3 小时内跑通），把是否切换的决策点定在"第一个基线跑通之后"。

> **推翻本推荐的量化信号**（开赛后 2–3 小时内观察）：若 C 的数据字典/字段与题面描述严重不符、或队伍无法在 3 小时内跑出任何一个可回测的基线，则考虑切到 D（若有人熟 GIS）或退到 B。

## 6. 若确实选 C：开赛头两三个小时的落点（可选）

1. **先读 `data_dictionary`，再定国家口径**：把代表队名（`Germany-1`、历史合并/更名）整理成"参赛主体-年份"映射并写进假设；这一步做错，后面所有预测都歪。
2. **拼面板**：国家 × 年份 ×（金/银/铜/总），并联入东道主与项目数。
3. **跑最笨的基线**：泊松/NegBin 回归 + 国家固定效应，**留出 2020/2024 做回测**，先拿到"差多少"这个数。
4. **再决定是否上分层/状态空间**：只有基线的回测误差讲清楚了，复杂模型才有意义；不要一上来做贝叶斯。
5. 全程把"不确定性"当一等公民：区间、覆盖率、校准图，而不是事后补一句。

## 7. 我拿不准的地方（诚实清单）

1. **没有队伍画像**。题面只给六道题，没给人数、专业、技能。§4 的结论建立在"中等偏上统计/编程队伍"这一假设上；§5 是给这一缺口准备的补偿机制。
2. **没有真正读到数据文件**。本目录只有六份 `.md` 题面，C/D 声称的数据包（zip/CSV）**不在**此处；我对 C/D 数据"干净/脏"的判断来自题面自述，未核实。
3. **2016–2026 同型历史源自离线记忆**，未联网、未逐条核对：年度-题目对应可能有误，且**不声称穷尽**。它只用于判断"这类题是否反复出现"，不作为事实引用。另外 2026 年题面不在本次给定范围内，未纳入。
4. **四轴打分是我自己的判断**，权重未做敏感性；换一套权重（例如把"差异化空间"单列并加重），D 有可能超过 C。
5. **"名帅效应"的可做性存疑**：题面给的是观测数据，因果识别很可能做不实——我把它列为 C 的主要坑，但若评委对这块要求极高，C 的优势会被削弱。
