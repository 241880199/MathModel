# 2025 MCM/ICM 选题决策（六选一）

> **口径说明**
> - **L1（建模范式）**：机理 / 预测 / 优化 / 评价 / 网络 / 统计推断 / 决策。
> - **L2**：该范式下的子类，见各节。
> - **数据形态枚举**：`无附数据` / `附表·结构化CSV` / `附表·网络地理` / `须自采·文本·政策`。
> - **可核性**：【可核】＝所给题面可直接核；【半可核】＝题面＋常识可推断，但需额外假设；【不可核】＝经验判断，无题面证据。
> - **诚实声明**：两条「历史」行里的年份、字母与篇数一律来自离线记忆。本流程未附任何语料可供核验，故它们**只作量级参考、不声称穷尽**，可被任一年表一秒推翻；年份与字母本身也可能记错。凡涉及"出现过几次/多少篇"的，请按存疑读数对待。

## 题 A — 台阶磨损（Testing Time）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **机理 · 反问题（磨损正演 → 反演使用史）** | *"把磨损当成几何/接触的物理过程建正演模型，再由观测到的磨损形态反推人流、方向、同时人数与年代。"* |
| `附带` **统计推断 · 参数与不确定性估计** | *"题面直接追问年代估计有多可靠、磨损是否与已知史料自洽，本质是带噪声反演的置信度问题。"* |

- 历史：组合 `机理 · 反问题` × `无附数据`，出现 ≈2 次（记忆估计·未核）
- 历史：题 `2018 A`（多跳短波传播）用过模型 `物理正演/波动传播`，≈ 数十篇（记忆估计·未核）
- 轴 1 · 数据可得性【可核】：题面明说测量由团队自行设计、须无损且低成本，**不随题附任何数据**；可得性取决于能否现场量测。
- 轴 2 · 方法成熟度【半可核】：磨损正演＋反演有套路（几何/接触模型、贝叶斯或优化反演），但没有可照抄的标准公式，属中高难。
- 轴 3 · 区分度上限【不可核】：无数据、纯开放建模，天花板高、易出彩；同样易被判"空谈、不可核"。
- 轴 4 · 翻车风险【不可核】：主要失败模式＝测量方案不具体、正演模型无参数锚点、反演不可辨识（同一磨损对应多组使用史）。

## 题 B — 可持续旅游（Managing Sustainable Tourism）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **优化 · 多目标/约束优化** | *"题面要求说清在优化什么、什么当约束，并把税收收入的支出计划做成反馈闭环——典型的多目标约束优化。"* |
| `附带` **机理 · 系统动力学（反馈回路）** | *"问题把'支出→基建与保护→承载力与体验→游客量→收入'写成回路，需要系统动力学式的反馈建模。"* |

- 历史：组合 `优化 · 多目标/约束优化` × `无附数据`，出现 ≈3 次（记忆估计·未核）
- 历史：题 `2017 E`（Sustainable Cities）用过模型 `多目标优化/系统动力学`，≈ 数十篇（记忆估计·未核）
- 轴 1 · 数据可得性【可核】：不随题附数据；题面给了 4 条参考链接，游客量/收入/税基需自采 → 中等。
- 轴 2 · 方法成熟度【半可核】：多目标优化、系统动力学、敏感性分析套路成熟，且题面明确要求"迁移到另一目的地"，可迁移性强。
- 轴 3 · 区分度上限【不可核】：可持续/旅游母题反复出现，易同质化；出彩点在于反馈闭合与支出方案的具体化。
- 轴 4 · 翻车风险【不可核】：失败模式＝把"可持续"写成口号、目标函数与约束含混、缺反馈与敏感性分析、利益相关方只写一方。

## 题 C — 奥运奖牌榜预测（Models for Olympic Medal Tables）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **预测 · 点预测＋区间预测** | *"题面点名要 2028 奖牌榜的点预测与预测区间、并给首金国家的概率，落在带不确定性的预测范式里。"* |
| `附带` **统计推断 · 效应归因（事件/东道国/教练）** | *"事件数与奖牌的关系、东道国效应、'伟大教练'效应都是找证据做归因，属于统计推断而非纯预测。"* |

- 历史：组合 `预测 · 点预测＋区间预测` × `附表·结构化CSV`，出现 ≈5 次（记忆估计·未核）
- 历史：题 `2023 C`（Wordle 预测）用过模型 `时间序列/回归预测`，≈ 数十篇（记忆估计·未核）
- 轴 1 · 数据可得性【可核】：题面明确随题附 5 个 CSV（1896–2024 全量、含运动员级），并限定"只能用所给数据"→ 六题里数据风险最低。
- 轴 2 · 方法成熟度【半可核】：层次贝叶斯/泊松-负二项/区间预测/面板回归成熟，事件-奖牌结构可做，技术路径清晰；难在不确定性量化做扎实。
- 轴 3 · 区分度上限【不可核】：中低——C 历来是参赛最密集的题之一，点预测高度同质；出彩点＝区间与概率校准、首金概率、事件结构、东道国、教练效应的因果辨析。
- 轴 4 · 翻车风险【不可核】：失败模式＝只给点预测无区间、越过"只用所给数据"的硬约束去引外源、把教练效应从相关读成因果。

## 题 D — 更好的城市交通（A Roadmap to a Better City）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **网络 · 最短路/可达性/网络流** | *"题面要求为 Baltimore 或其某片区域建网络模型，并用它评估桥塌、公交与步道项目的影响——核心是网络的流量与可达性分析。"* |
| `附带` **决策 · 多利益相关方权衡与项目排序** | *"题面反复要求指出项目对各利益相关方（居民/通勤/游客/货运）的利弊，并推荐'最改善居民生活'的项目，落点多准则决策。"* |

- 历史：组合 `网络 · 最短路/可达性` × `附表·网络地理`，出现 ≈2 次（记忆估计·未核）
- 历史：题 `2017 D`（机场安检吞吐）用过模型 `排队论/仿真优化`，≈ 数十篇（记忆估计·未核）
- 轴 1 · 数据可得性【可核】：随题附 9 个文件（OSM 节点/边、公交线/站、AADT 等），但题面自己警告"messy"，需清洗＋GIS 处理 → 数据在，但工程量大。
- 轴 2 · 方法成熟度【半可核】：最短路/网络流/可达性＋GIS 是成熟栈；门槛不在数学而在 OSM 数据清洗与图构建。
- 轴 3 · 区分度上限【不可核】：高——网络可视化＋多利益相关方分析＋具体项目建议，容易做出与 C 明显不同的辨识度。
- 轴 4 · 翻车风险【不可核】：失败模式＝卡在数据清洗、网络被简化成玩具图、项目建议与网络证据脱节、只讲收益不讲对他人与安全的伤害。

## 题 E — 为农业腾出空间（Making Room for Agriculture）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **机理 · 食物网/种群动力学** | *"题面要求建'新农生系统'的食物网并跟踪它随季节与人工作用的演化，是典型的多物种动力学建模。"* |
| `附带` **决策 · 情景分析（去化学化/有机）** | *"除草剂移除、引入蝙蝠等天敌、逐级有机化，都是拿干预当情景、比较其对生态系统稳定性与成本的影响。"* |

- 历史：组合 `机理 · 食物网/种群动力学` × `无附数据`，出现 ≈3 次（记忆估计·未核）
- 历史：题 `2021 A`（Fungi 分解）用过模型 `种群/分解动力学（ODE）`，≈ 数十篇（记忆估计·未核）
- 轴 1 · 数据可得性【可核】：不随题附数据，题面允许自设情景或引用真实案例 → 参数全靠假设或自采，可得性中低。
- 轴 2 · 方法成熟度【半可核】：Lotka-Volterra/多房室模型＋季节驱动＋干预是成熟套路；难点是参数要有依据。
- 轴 3 · 区分度上限【不可核】：中高——物种交互（蝙蝠同时当昆虫天敌与传粉者）与有机情景有创新空间，但生态参数难落地。
- 轴 4 · 翻车风险【不可核】：失败模式＝参数无来源、稳定性结论对初值/参数极敏感、情景与模型两张皮、忽略经济与政策维度。

## 题 F — 网络就强了吗（Cyber Strong?）

| L1 · L2 | 支撑句 |
| :-- | :-- |
| `核心` **统计推断 · 跨国政策效应识别** | *"题面要求提出'强网安政策'的理论并用数据驱动分析支撑它，实质是把政策特征与网安结果做跨国面板或效应识别。"* |
| `附带` **评价 · 理论与判据构建（不自造总分）** | *"既要建立'何为强政策'的判据，又被明确禁止另造总指标、只能借 GCI/VERIS 等验证，属评价框架搭建。"* |

- 历史：组合 `统计推断 · 跨国政策效应` × `须自采·文本·政策`，出现 ≈1–2 次（记忆估计·未核）
- 历史：题 `2019 C`（阿片危机，数据驱动政策情景）用过模型 `传播动力学/统计推断`，≈ 数十篇（跨域类比·记忆估计·未核）
- 轴 1 · 数据可得性【可核】：题面不附任何数据，要求团队自采政策文本与网安指标（GCI/VERIS/VCDB）→ 数据风险最高。
- 轴 2 · 方法成熟度【半可核】：面板回归/政策文本编码/固定效应/双重差分是成熟方法，但结论质量完全取决于自采数据的可比性。
- 轴 3 · 区分度上限【不可核】：中高——"政策文本量化＋效应识别"的组合少人做深，有差异空间；但上限受数据可得性压制。
- 轴 4 · 翻车风险【不可核】：失败模式＝数据来源不可靠或不可比、把相关当因果、违反"不自造指标"的硬约束、政策编码主观且不可复现。

## 推荐

- 推荐：**选 C（2025 MCM Problem C，Olympic medal tables）**。默认画像（题面未给队伍信息，此为假设）：数理与编程均衡、希望"风险可控又不被同质化拖死"。理由：六题中唯一"随题附数据、且被限定只用所给数据"的低风险量化题（轴 1 最硬）；交付物（点预测＋预测区间＋首金概率）好坏可判、难以写空；子问留有真区分度（事件结构、东道国、教练效应、首金国），且高风险的"教练效应"子问只求部分解。次选 D：同为附数据，区分度更高，但 GIS 工程量与翻车概率也更高。
- 推翻条件：① 队伍统计/编程薄弱、写不动回归与区间 → 转 D（若会 GIS）或 A；② 队伍强项是物理/连续建模、要的是"高上限叙事" → 转 A；③ 队伍有强生态动力学背景 → 转 E；④ 队伍有强文本/政策分析能力且能接受自采数据的高风险 → 转 F。以上任一成立，对 C 的推荐即让位。
