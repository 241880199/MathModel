# `mcm-code` 判据样例（`CD1`–`CD6`）

**一对一条**：`samples/<判据号>/{comply,violate}/` —— **目录名即判据号**，一动就是一整对。
每对含一个**代码目录** `code/`（`<代码目录>` 靶子 —— 内含代码文件 + `result-manifest.md` 结果清单）
与一个**论文文件** `appendix.md`（`--appendix` 靶子）。
驱动器 `tests/skills/code/mutate-code.py` 逐对跑
`check-code.py --scope artifact <此对>/code --appendix <此对>/appendix.md`，
断言 **合规侧全绿、违规侧只红它自己那条**。

★ 下表的"压的是什么失效"**不声称穷尽**同类失效 —— 每对只钉一种、且只让它自己那条红。
★ 夹具**是交付件**（不是临时件），随 `tests/skills/code/` 入库；一律 LF。

---

## ★ `CD1` / `CD2` 的两侧语言覆盖（设计 §0.3 的多语言惯用法）

`CD1` 与 `CD2` 是**多语言惯用法**判据 ⇒ **每对的 `code/` 里同时放 MATLAB（`solve.m`）与 Python（`solve.py`）两份代码**，
**两侧都被压到**（不是只测一种语言）：

* `CD1/comply/code/`：`solve.m`（`rng(seed,'twister')` + `rand`）**与** `solve.py`（`np.random.default_rng(seed)`）都合规。
* `CD1/violate/code/`：`solve.m`（`rand` 无 `rng`）**与** `solve.py`（`np.random.rand` 无播种）都违规。
* `CD2/comply/code/`：`solve.m`（`writetable`）**与** `solve.py`（`np.savetxt`）都落盘。
* `CD2/violate/code/`：`solve.m`（只有 `disp`）**与** `solve.py`（只有 `print`）都只打印。

⇒ 任一语言的惯用法漏认（把 MATLAB 或 Python 那一侧写成恒绿 / 恒红），断言 ①② 会当场红。

## `CD1` —— 求解入口固定随机源（`[社区]`）

* 判法（**per-file 启发式**）：**凡用到随机性的代码文件，必须同处有固定随机源惯用法**
  （MATLAB `rng(`；Python `default_rng` / `.seed(`）。**完全不含随机性的文件不判**
  （确定性模型没有"随机源"可固定 ⇒ 不强制）。
* `comply/`：两侧都"用随机且固定了种子" ⇒ 绿。
* `violate/`：两侧都"用了随机却没固定种子" ⇒ 红。
  ★ 压的是"求解跑的是随机实验、却没钉死随机源 ⇒ 别人重跑复现不了"这一失效。

## `CD2` —— 结果落盘，且不只有 `disp` / `print`（`[社区]`）

* 判法（**per-file 启发式**）：有打印（`disp`/`fprintf`/`print`）**却无任何落盘惯用法** ⇒ 该文件"只打印" ⇒ 红；
  另：整个代码集**无一处落盘惯用法** ⇒ 红（空集不许判绿）。
* `comply/`：两侧都用落盘惯用法把结果写到磁盘 ⇒ 绿。
* `violate/`：两侧都只有打印、结果不落盘 ⇒ 红。
  ★ 压的是"结果只出现在终端里 ⇒ 关了窗口就没了、进不了论文"这一失效。

## `CD3` —— 结果文件名带论文编号，与正文 图 X / 表 Y / 式 Z 对得上（`[社区]`）

* 判法（**与 `references/numbering.md` 一致**）：结果清单每行 —— 从 `结果文件` 文件名里抽出 `(类型, 编号)`
  （`figure-1-*` / `table-2-*` / `eq-3-*`，也认中文名），与 `对应正文编号` 列的 `(类型, 编号)` 必须**相等**。
* `comply/`：`figure-1` ↔ `图 1`、`table-1` ↔ `表 1`，逐行对得上 ⇒ 绿。
* `violate/`：某行文件名是 `table-2-estimate.csv`、正文编号却是 `表 1` ⇒ 红。
  ★ 压的是"改了图序 / 表序却忘了改名 ⇒ 文件与正文对不上"这一失效。
  ★ **边界**：本判据只判"文件名编号 ↔ 清单编号"的**对应**；**不查文件是否真的落盘**、**不读正文散文**核对图号。

## `CD4` —— 论文附录里不含程序正文（`[官方]` `corpus/official/instructions.html:1227` 与 `corpus/official/instructions.html:1305`）

* 判法（**启发式 · 两层强信号**）：给了 `--appendix` 时 ——
  ① **无歧义信号**（**代码块标记** `\begin{verbatim}` / `\begin{lstlisting}` / `\begin{minted}` / Markdown 围栏 ```；
  或**代码专属语法** `#include <` / `from X import Y` / `import X as Y`）⇒ **单命中即判**；
  ② **定义行**（`function ` / `def ` / `class ` / 整行 `import X`）⇒ **须有代码体佐证**才判
  （定义行不以句尾标点收束 ∧ 其紧邻窗口内出现代码语句）。
  **不给 `--appendix` ⇒ 判 `N/A`**（与 `mcm-data` 的 `DA2 --refs` 同型）。
* `comply/`：附录是文字说明（方法 / 复现信息 / 结果对应）⇒ 绿。
* `violate/`：附录里贴了程序全文 ⇒ 红。
  ★ 压的是"把源码随论文提交"这一**官方明文禁止**的失效（本 skill **唯一的 `[官方]`** 依据）。
  ★ **边界 · 漏判面**：**纯文字描述的伪代码**、包在自定义环境里的源码、或**孤立一行、无代码体佐证的定义行**可能漏判。
  ★ **边界 · 假阳性面（重要）**：本判据是**启发式**；**以 `class 词:` / `function 词(` 起首的散文行**
  仍有可能被误判为程序正文 —— **命中时请人工确认再改**（误判会叫人删合法散文，代价高于别的判据）。

## `CD5` —— 可执行语句内没有写死的机器绝对路径；注释内不算（`[社区]`）

* 判法（**启发式**）：逐行先**剥掉注释**（MATLAB `%`、Python `#`，按引号态判定）**再**找
  `[A-Za-z]:[\\/]` 或 `/Users/`；注释里的路径**不判**。
* `comply/`：★ **两侧各放一条"注释里含绝对路径但判绿"的反例** ——
  `solve.m` 有 `% ... C:\Users\alice\...` 注释、`solve.py` 有 `# ... /Users/alice/...` 注释，
  可执行语句全部用相对路径 ⇒ 绿（这正是压住 `P5` 假阳性面的那一对）。
* `violate/`：`solve.m` 的可执行语句写死 `D:\Projects\...`、`solve.py` 写死 `C:\Users\...` ⇒ 红。
  ★ 压的是"路径写死在自己机器上 ⇒ 换台机器就跑不了"这一失效。
  ★ **边界**：判定是启发式（只看 `C:\` / `D:\` / `/Users/` 形态）—— **匹配到不一定是违规，没匹配到也不保证没有别的写死形态**。

## `CD6` —— ★ 结果清单在场、五列非空，且 `代码来自=AI` 的行已核（`[社区]`，`P6` 的核心）

* `comply/`：清单一行 `代码来自=AI` + `确认=已核（李四,2027-02-16）` ⇒ 绿。
* `violate/`：**同结构，只把该 AI 行的 `确认` 改成 `待核`** ⇒ 红。
  ★ 这一对**必须真的分得开** —— 它是设计 §1.2 那句边界话（"凡由 AI 写的代码，队员必须自己跑通并核对结果后方可采信"）
  的**机械落地**；判不开，整支就退化成一堆提醒。
  ★ **本条不是官方要求**：官方只把「辅助写代码」列在建议谨慎侧 `[官方]`；
  "AI 写码行必须有跑过记录"是本套件自订口径（约定件 §6.1）。
  ★ **边界（`代码来自` 比对前先【规范化】）**：去首尾空白 + 反引号 + 大小写不敏感 + **允许 `AI` 前缀** ——
  `ai` / `AI写` / `AI 生成` 都**算 AI 行**。若不规范化会**假绿**（见驱动器 `CTRL-CD6-NORM-PREFIX`）。
  ★ **配套（fail-closed）**：判"清单列齐"时一并判 `代码来自` 的取值域**只许** `本人` / `AI` ——
  出现第三种取值 ⇒ 红（见驱动器 `CTRL-CD6-THIRD-VALUE`）。

## 驱动器覆盖（`mutate-code.py`）

三条断言：① 违规侧每条判据至少红一次 ② 合规侧每条判据确实绿 ③ 判据总数 == `samples/`
下一级目录数（两边**现取**、集合相等）。另设**控制项**压 `N/A` 三分 + **第四态**
（目标缺失 / 节不在 / 节在但零行 / 节在但表头不符）、目录在场但零代码文件、
模板守卫（`assets/` 下的模板不许当靶子）、`CD4` 的 `N/A` 出口、`CD6` 的**规范化**与**取值域 fail-closed**、
以及内检 `--scope self` 三条的从失败方向证明。
**此清单不声称穷尽**驱动器覆盖的失效；逐条读 `tests/skills/code/mutate-code.py` 头部。
