# `mcm-data` 判据样例（`DA1`–`DA5`）

**一对一条**：`samples/<判据号>/{comply,violate}/` —— **目录名即判据号**，一动就是一整对。
每对的 `data-sources.md` = 来源表产物（**用户产物的替代品**），`paper.md` = `--refs` 的论文文件。
驱动器 `tests/skills/data/mutate-data.py` 逐对跑 `check-data.py --scope artifact <表> --refs <论文>`，
断言 **合规侧全绿、违规侧只红它自己那条**。

★ 下表的"压的是什么失效"**不声称穷尽**同类失效 —— 每对只钉一种、且只让它自己那条红。
★ 夹具**是交付件**（不是临时件），随 `tests/skills/data/` 入库。

---

## `DA1` —— 来源表在场 + 五列每行非空（`[社区]`）

* `comply/`：两行数据齐全（`出处`/`口径`/`局限`/`获取日期`/`取数方` 全非空）⇒ 全绿。
* `violate/`：**列在但值空** —— 第一行的 `口径` 单元格留空（**不是"表不在"**：表不在是 `N/A`，不是红）。
  ★ 压的是"表搭起来了、某列却漏填"这一失效；`DA1` 只判**列内非空**，**不判内容对错**。
  ★ 除列内非空，`DA1` 还判 `取数方` 的**取值**（规范化后）**只许** `本人` / `AI` —— 出现第三种取值 ⇒ 红（**fail-closed**，不静默放过；配套见 `DA4` 段）。

## `DA2` —— **非自主来源**须引用（`[官方]` `corpus/official/instructions.html:1121`）

* `comply/`：三行的 `出处`（世界银行 URL + 题面附件名 + 保留值 `本队自产`）—— 前两行**都能在
  `paper.md` 里被搜到**；第三行是**自产来源**（`本队自产` **刻意不出现在** `paper.md` 里）⇒ 仍全绿。
* `violate/`：第一行 `出处` = `https://example.com/private-dataset`，**`paper.md` 里搜不到** ⇒ 红。
  ★ 压的是"用了**外部**来源却没把来源写进论文引用"这一失效。★ **在本模块这五条判据内**，唯一的
  `[官方]` 是 `DA2`（`CD4` 也是 `[官方]`，故**不写作"全仓唯一"**）。
  ★ **边界（保留值 `本队自产` = 自产来源）**：`出处` 取**保留值 `本队自产`** 的行**豁免 `DA2` 与 `DA3`**
  —— 自产数据既没有"外部引用"、也没有"外部可信度层级"（`DA2` 不必在 `--refs` 里搜到；`DA3` 的
  `可信度层级` 列填保留记号 `—`）；该行仍须满足 `DA1` 非空 / `DA4` 确认闸。**样例集现已覆盖这两条豁免**
  （即上面 `comply/` 的第三行：`出处 = 本队自产`、`可信度层级 = —`）。
  ★ 不给 `--refs` 时 `DA2` 判 `N/A`（见驱动器 `CTRL-DA2-NOREFS`），**不是绿也不是红**。

## `DA3` —— `可信度层级` 每行非空且在五级内（`[社区]`）

* `comply/`：层级取 `2 国际组织与学术` / `3 开放数据平台`（五级内）⇒ 绿。
* `violate/`：第一行取 `9 自媒体` —— **不在设计 §3.3 的五级内** ⇒ 红。
  ★ 压的是"层级列填了、但填的不是本套件那五级"（例如随手写了个自造档位）。
  ★ `DA3` 只判"层级标了没有、在不在五级内"，**不判层级选得对不对**（那要交叉验证，归队员）。
  ★ **边界（保留值豁免，与 `DA2` 同一裁定）**：`出处` 取**保留值 `本队自产`** 的行**豁免本判据** ——
  自产数据没有"外部可信度层级"，该行 `可信度层级` 填 `—`（保留记号），`DA3` 不查该列；样例覆盖见 `DA2` 段。

## `DA4` —— ★ `取数方=AI` 的行必须「已核」+ 确认人 + 日期（`[社区]`，`P6` 的核心）

* `comply/`：一行 `取数方=AI` + `确认=已核（张三,2027-02-15）` ⇒ 绿。
* `violate/`：**同结构，只把 `确认` 改成 `待核`** ⇒ 红（`<<< 第1行；仍为「待核」`）。
  ★ 这一对**必须真的分得开** —— 它是设计 §1.2 那句边界话（"凡由 AI 检索到的数据，队员必须逐条
  确认可靠性后方可引用"）的**机械落地**；判不开，整支就退化成一堆提醒。
  ★ **本条不是官方要求**：官方只把「解释数据与模型结果」列在建议谨慎侧 `[官方]`；
  "AI 取数行必须有确认栏"是本套件自订口径。
  ★ **边界（`取数方` 比对前先【规范化】）**：去首尾空白 + 反引号 + 大小写不敏感 + **允许 `AI` 前缀** ——
  `ai` / `AI检索` / `AI 检索` 都**算 AI 行**。若不规范化会**假绿**：写成变体的 AI 行不被认出 ⇒ `势=0` ⇒ 判 `PASS`。
  ★ **配套（`DA1` fail-closed）**：`DA1` 判 `取数方` 的取值**只许** `本人` / `AI`（规范化后），
  出现第三种取值 ⇒ `DA1` 判红。

## `DA5` —— 清洗与口径对齐步骤有记录、且每步可重跑（`[社区]`）

* `comply/`：`## 清洗步骤` 三项，每项都带**脚本/命令标记**（`work/stepN_*.py`）⇒ 绿。
* `violate/`：两步都**没有**任何脚本/命令标记（"凭经验删""让数据看起来合理"）⇒ 红。
  ★ 压的是"清洗做了却没记成可重跑的步骤"这一失效（每步要能再现）。
  ★ "可重跑"是**启发式**（认脚本/命令标记）；措辞里不含标记的手写步骤会**假红**（见 `check-data.py` 已知边界）。

## 驱动器覆盖（`mutate-data.py`）

三条断言：① 违规侧每条判据至少红一次 ② 合规侧每条判据确实绿 ③ 判据总数 == `samples/`
下一级目录数（两边**现取**、集合相等）。另设控制项压 `N/A` 三分（目标缺失 / 节不在 / 节在但零行）、
**第四态**（节在但表头与 §1.1 不符 ⇒ `DA1`–`DA4` 判 `FAIL`）、
模板守卫（`assets/` 下的模板不许当靶子）、`DA2` 的 `N/A` 出口与内检 `--scope self`。
**此清单不声称穷尽**驱动器覆盖的失效；逐条读 `tests/skills/data/mutate-data.py` 头部。
