### ★ `probe_2` 那行的 `2>` 口径（**实测，不是抄来的**）

`probe_2` 的**进度写去 stderr**（`sys.stderr.write("  ... %d/%d\r")`）⇒ 必须 `2>/dev/null`，
否则 `\r` 会被 `gen-evidence.py` 归一成换行、灌进入库件。
★ **实测（2026-10-03 当场跑）**：把三台探针的 stderr **单独重定向**后量字节数 ——
```
python tests/m3-schematic-recon/probe_0_inventory.py > build/m3-schematic-recon/raw_probe_0.txt 2> build/m3-schematic-recon/se_0.txt
wc -c < build/m3-schematic-recon/se_0.txt        # probe_0 / probe_1 / probe_3 ⇒ 均 0
```
⇒ `probe_0` / `probe_1` / `probe_3` 的 stderr **各 0 字节** ⇒ 那三行接 `2>&1` 无副作用
（保留先例写法）。**`probe_2` 除外**（它的 stderr 有进度行，必须 `2>/dev/null`）。

### 幂等

★ **实测（2026-10-03 当场跑）**：`gen-evidence.py` 连跑两次，四份 `out-*.txt` 的 md5 **逐对相同**
（`md5sum tests/m3-schematic-recon/out-*.txt` 两次输出 diff 为空）。机制上亦确定：本文件不含
时间戳/随机数。`probe_2` 的输出亦确定
（`corpus` 固定、抽样用 `sample_index` 系统抽样、无人眼表外的随机性）。

## ★ 骨架表定稿规则（**明文降级**，本任务的核心产物之一）

### 为什么没做成机械定稿（**不许把"我挑的"说成"读数挑的"**）

硬要求 7 要求"按读数 6 的频次降序 + 一个当场算出的入选阈值"。**做不到**，原因是读数 6 本身：

1. 可分类的只有 10.0% 的图（其余是位图，且我**不假装**能从像素可靠分出示意图）；
2. 就算只看那 10.0%，特征也不可分（多个单特征精度 ≈ 基线）。

⇒ 按计划 P1 的**明文降级路径**办：**起步五份 + 一名一句的理由**，并**明确登记这是判断**。

### 人眼抽样给出的频次（**判断，不是读数**；n=96 → 27 张示意图）

把 27 张示意图按形态归类（`sample-labels.tsv` 的 `form` 列；**不声称穷尽**）：

| 形态（映射到起步骨架） | 张数 |
| :--- | ---: |
| `model-layered`（分层 / 结构 / 框架 — 合并 `layered` 7 + `structure` 11） | **18** |
| `mechanism-block`（机理块 / 储罐-流 / 耦合箭头） | 4 |
| `pipeline-linear`（纯线性链） | 2 |
| `pipeline-branch`（分支 + 汇合） | 2 |
| `loop-feedback`（反馈环） | 1 |

### ★ 阈值敏感性（**当场算的**，正因为它不稳，才降级）

"入选线 = 一个当场算出的阈值"，把这个规则**真算一遍**：

| 规则 | 算出来的入选集合 | 成员数 |
| :--- | :--- | ---: |
| 降序取"**最大相对落差**"处切（18,4,2,2,1 → 落差 4.5 / 2.0 / 1.0 / 2.0，最大 4.5 在 18→4） | 只留 `model-layered` | **1** |
| 绝对线 **≥3 张** | `model-layered` + `mechanism-block` | **2** |
| 绝对线 **≥2 张** | 再加 `pipeline-linear` + `pipeline-branch` | **4** |
| 绝对线 **≥1 张**（出现即入选） | 起步五份全留 | **5** |

★ **同一份标签上，换一条同样"机械"的定线规则，成员数在 1 / 2 / 4 / 5 之间跳。**
⇒ 这个样本（27 张、且标签是人眼判断）**撑不起一条机械入选线** —— 这就是"没做成机械定稿"的**量化理由**，
不是"懒得做"。

### 起步五份的**逐个去向**（不许沉默）

| 骨架 | 去向 | 一句理由（**判断**） |
| :--- | :--- | :--- |
| `model-layered` | **入选** | 抽样里**最主导**的形态（18/27），也是"框架 / 结构图"的通用底座。 |
| `mechanism-block` | **入选** | 4/27；机理块（储罐-流-耦合箭头）在机理示意图类里稳定出现。 |
