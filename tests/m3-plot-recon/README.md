# `tests/m3-plot-recon/` —— `mcm-plot-python` 的**侦察快照目录**

本目录是 **2026-09-29 侦察期**的一次性取证现场，**不是**一套常跑测试。它记录"在
`mcm-plot-python` 建出来之前，这个绘图底座在本机到底是什么样"。

## 两类文件，纪律不同

| 类别 | 文件 | 纪律 |
| :--- | :--- | :--- |
| **探针脚本** | `a1_*.py` `a2_*.py` `a3_*.py` `a4_*.py` `b567_*.py` `c10_*.py` `c89_*.py` `d11_*.py` `d12_*.py` `d13_*.py` `d14_*.py` `e15_*.py` | **可运行源码**。改它 = 改探针本身（要留痕、要重跑）。 |
| **输出的捕获** | `out-*.txt` | **逐字的 stdout 捕获，自带年代指纹**（内嵌当时的"真仓扫到 N 个 skill""MUT: N/N""绘图家族 N 个"等读数）。 |

## 关于 `out-*.txt`：**手改 = 造伪**

`out-*.txt` 是**某个时点**的 stdout 原文（很多行甚至是探针逐字打印的"当时读数"）。
它们**内嵌的数字随家族落地而变**，**但那些数字正是它们的价值所在**——它们是"那天读到的
这个数"的证据。**手改一处 = 把证据伪造成它从未产生的样子。**

⇒ 若某份捕获与今天的事实不一致，**唯一正确的做法**是：**重跑该目录下产出它的 `*.py`，
并在同一批里重新捕获**（让文件重新携带**今天**的年代指纹），**不是**去改 `out-*.txt` 里的字面量。
**更新 = 重跑 + 重捕获，绝不是编辑。**

这条纪律覆盖（至少）：

- `out-m43-m46-today.txt`（其中 `MUT: … 红（合计）` 那一行的**总数是当天**的变异合计；今天该数已变，
  但**本文件不改**——它证的是"M43 那天在真仓那个总数下 RED-OK"）；
- `out-e15-m43-prealchor.txt`（`M43` 前置锚在"真家族 ≥1"下的探针捕获，同为当天的读数）；
- 本目录内其余每一份 `out-*.txt`。

## 为什么 `e15_m43_preanchor.py` 的**末行措辞**与它的捕获对不上

`e15_m43_preanchor.py` 末尾那行读数**曾经写死裸总数**（一个具体整数）。那是**可运行源码里的字面量**，
与快照不同——它每次跑都原样打印，**是个活的过期数**。⇒ 已把它**去掉**、改成不写死计数的措辞
（同一理由见 `d11_red_loop.py` 等探针头部：**计数现读，不手写**）。
因此这些**源码**与它**早期的** `out-*.txt` 捕获会不一致——**这是对的**：捕获停在捕获那天，
源码活在今天。要消除差异，**重跑并重捕获**。

## 复跑

各探针头部都写了它的复跑命令（形如 `python tests/m3-plot-recon/<x>.py …`），从**仓根**执行。
本目录的产物落在 `build/m3-plot-recon/`（**已 gitignore**，不入库）。

**本文件不复述任何规范数值**——数字一律以现场命令的输出为准。
