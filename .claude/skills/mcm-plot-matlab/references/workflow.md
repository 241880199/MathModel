# mcm-plot-matlab · 出图流程

本文件是 `SKILL.md` 的流程正文。**本文件与 `SKILL.md` 一样，不复述任何规范数值**（含用中文数词写的规范值）；
文中出现的数字**只有规则编号 `H<n>`**（指针型 ID，不是数值），**没有别的数字字面量** ——
规范的阈值 / 占比 / 样本读数一律回 `references/house-style.md` 去说，口径与复跑命令回 `provenance.md`。

流程：**读规范 → 套样式 → 出图 → 机械层验 → 亲眼看图**。
最后一步与前几步一样是**固定环节**，不许省。

## 读规范

先打开 `references/house-style.md`，按这次的**图型与数据关系**找到相关的那几条规则。
每条规则的数值、口径与验证状态都在那份文件里，**本文件与 `SKILL.md` 都不重述**。
要复核某个数的分母、样本范围与已知偏差，读 `provenance.md`。

## 套样式

```matlab
M   = mcmplot();
fig = M.figure(tw_in);              % tw_in = 正文栏宽分母(in)，由调用方给
ax  = axes(fig);
plot(ax, x, y, 'LineWidth', M.style.line_width);
xlabel(ax, 'Slope (deg)');          % ← 轴标签带单位 = 调用方纪律（MATLAB 侧无设置项）
M.apply(fig);                       % 上 house style（浅色主题 / 白底 / 色序 / 框线刻度 / 字体）
```

`M.figure()` 建的就是**浅色主题**的 figure —— MATLAB 出厂主题是**深色**，故每张 figure 必须显式上浅色。
若要给一个**已有**的 figure 补主题，用 `theme(fig, 'light')` —— **必须带 figure 句柄**。

**用法禁忌（可被一条命令推翻）**：**别写不带句柄的 `theme('light')`。**
本仓产物级实测它是**静默空操作**：调用**返回成功**（不报错），而图仍是深色 —— 这就是
"看起来设上了、实际没设"的那一类。判它是**深色不是浅色**的机械判据是出货检查器的**底色那一条**：
把产物送进 `check-figure-style.py`，若它判红 ⇒ 本条即被坐实；若深色产物能过 ⇒ 本条即被证伪。

`M.apply()` 必须在**建图后、导出前**调，把白底 / 色序 / 字体 / 框线刻度一次套齐。
**字体**：`M` 从表里的候选族取**本机可用的那一档**（含系统 `Times New Roman`）；
一档都不在时退回表里最后一档。

## 出图

```matlab
wh   = M.size(tw_in);        % 该落在哪个图幅（宽×高，英寸）
band = M.fontsize(body_pt);  % 图内字号的允许带（下限 上限，pt）
M.save(fig, out_path, dpi);  % PNG：dpi 必给；PDF：不需要 dpi
```

- `tw_in`：**正文栏宽分母**，单位英寸。它是**该用户论文的属性**，必须由调用方传入；
  本 skill 与出货检查器**都不预设**它的默认值。换口径会给出不同的图宽比读数。
- `body_pt`：**正文 pt**，同样由调用方传（正文 pt 是论文的属性）。
- 导出走 `print` 家族：`.png` 跟 `PaperPosition`、`.pdf` 跟 `PaperSize`（`M.figure()` 把两条设成同一图幅）。
  **别用 `exportgraphics` 当权威交付**：它的宽是**轴内容包围盒**的函数、不可控 ——
  只在需要"按内容裁"时用它，且证据里要写明用的是哪条口径。
- `dpi`：保存时用哪个，送进检查器时就传哪个 —— **两处必须逐字一致**（见下节）。

## 机械层验（与判据的契约）

图出好后，**原样**调出货检查器（本 skill **不改它**，也不重实现它）：

```
python tests/skills/figure-choose/check-figure-style.py     --fig <产物路径> --caption <图注文本，或 @<文件>>     --textwidth-in <float> --dpi <int>
```

三条契约：

- **`--textwidth-in` 与脚本侧逐字同名同义**：就是 `M.figure()` / `M.size()` 的那个分母。
  检查器**不预设**它的默认值，必须由调用方给出；给的口径要与出图时用的**同一个**。
  口径不写明，读数就不可比。
- **`--dpi` 必须与 `M.save(fig, path, dpi)` 里的 `dpi` 一致**：PNG **必给** `--dpi`（不给则检查器报错退出）；
  PDF 走页盒、**不需要** `--dpi`。两处不一致，检查器量到的图宽比就不是你交的那张图。
- **`--fig` 与 `--caption` 都是必填**：图注可以给文本，也可以给 `@<文件>` 形式。

判词怎么读（末行恒为 `RESULT:` 那一条）：全绿 ⇒ 机械层过；判红 ⇒ 逐条按判词改，改完重跑；
**参数或参照缺失** ⇒ 检查器**不产生任何判词**、直接报错退出 —— 那时要修的是**输入**，不是图。

## 亲眼看图（**固定一节，不许省**）

机械层判的只是**能机械化的那几层**：图宽比、彩色主色数、底色、色序、字体族、图注形态。它**判不了**：

- 这张图**有没有把要说的事说清**（重点有没有被读出来、有没有被别的元素抢走）；
- 刻度与图例**读起来对不对**（单位、量纲、正负号、双轴对不对得上）；
- 图注与图**说的是不是同一件事**；
- 中文与符号**有没有缺字形**（缺字形时图上会留空白框）。

⇒ 所以**出图之后，agent 必须自己把产物看一遍**，并写下**从这张图读到了什么**。
这一步不许省、也不许只贴判词来代替。

**这一节的操作内容（不是口号）**：

- **谁看**：**出图的 agent 自己先看**（不是"交给用户看"就算数）；agent 看完，再把路径交给控制者与用户复核。
- **看什么**（本支这几点必看 —— 有判据兜住的、也有判据射程之外的）：
  ① **底色是不是浅色** —— MATLAB 出厂是深色，本支的 motivating case 就是"深色底也能过机械判据的其它几条"；
  ② **顶 / 右框线在不在、刻度朝内还是朝外** —— 本支的 `H10`，判据端只有产物级回读；
  ③ **线画上了没有、轴标签有没有把单位写全**（轴标签带单位是调用方纪律，载体侧无设置项）。
- **路径怎么给**：产物写到仓内一个**固定产物目录**（`build/` 下一个本模块的子目录；该目录被 git 忽略，
  不进提交），把**仓内相对路径**连同"从这张图读到了什么"的一句话一起交给控制者与用户。

**为什么这一步不可省**：机械判据判不了判断层。本模块的载体选择有一条硬口径 ——
**以 agent 能否看见产物为准**：产物是 PNG / PDF，agent 能直接打开来看，所以"亲眼看图"
不是附加礼节，而是这条口径的直接兑现。判断层的这一层，正是判据射程之外的那一层。
