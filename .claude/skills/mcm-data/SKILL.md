# mcm-data —— 数据获取与交代（三条路决策树）

**一句话**：赛期的数据只有三种处境 —— **题面给了附件**、**题面没给（要自己找）**、**找不到（要降级）**；本 skill 按**赛期实际动作顺序**给三跳，每跳只说"该干什么 + 该看哪份 `references/`"，**不复述**其中的内容。

## ★★ 边界声明（必读）

> **本 skill 给出数据来源与代码规范；最终判断与结论由队员负责。**

> **凡由 AI 检索到的数据，队员必须逐条确认可靠性后方可引用** —— 依据 corpus/official/INDEX.md §2.4，官方把「解释数据与模型结果」列在建议谨慎侧。

★ 这两句不是口号：来源表里 `取数方 = AI` 的**每一行**，`确认` 列都必须记「已核（人 + 日期）」。

## 什么时候用 / 不用

- **用**：赛期要**收集数据**（题面没给的自己找）、要**读题面附件**、要把来源**统一落成一张来源表**、要判断一个来源**该不该交叉验证**、要给论文写**数据引用**时。
- **不用（边界，各归各）**：
  - **选模型 / 建模方法** ⇒ M4 的 `mcm-model-select`；
  - **写求解代码、种子 / 落盘 / 编号** ⇒ M5 的 `mcm-code`；
  - **出图 / 出表 / 示意图** ⇒ M3 的绘图类 skill；
  - **写论文正文某一节** ⇒ M2 的 `mcm-section-writer`；
  - **选题 / 全稿合规** ⇒ M1 的 `mcm-topic-select` / `mcm-selfreview`。

## 三条路（**按赛期实际动作顺序**）

| 路 | 触发（赛期你看到的） | 指向 |
| :--- | :--- | :--- |
| **①** | **题面给了附件**（C/D/E 题常见：`.csv` / `.xlsx` / 附件表） | `references/cleaning.md` —— 怎么读、口径怎么记、清洗步骤怎么落 |
| **②** ★ | **题面没给 / 只给一半**（A 题、各题的补充数据）—— **主路** | `references/finding-data.md` —— 分层找源 + 可得性三角 |
| **③** | **找不到**（想要的粒度上确实没有） | `references/finding-data.md` 的**降级**段（换代理 / 换粒度 / 换时窗） |

★★ **②是主路**：**题目未提供、需自行获取的数据**是赛期**主路**（用户 2026-10-04 明确："部分数据在题目中不会提供，需要自行获取"）。题面附件那条路是**并列的一支，不是主线**。

★ **三条路都落到同一张来源表**（`assets/data-source-table.md`）：路① 的附件、路② 的外部来源、路③ 的代理指标，**一律逐条进表**（`出处` / `口径` / `局限` / `获取日期` / `可信度层级` / `取数方` / `确认` 七列）。

## 口径与不做（**用本 skill 前先读**）

| # | 口径 |
| :--- | :--- |
| ① | **"没找到" ≠ "不存在"**：说某个粒度找不到数据时，必须写出**搜了什么、在哪个层面搜的**；判据只能证明"没记来源"，**证明不了"数据不存在"**。 |
| ② | **可信度层级不是"能不能用"，是"要不要交叉验证"** —— 四级及以下**要求至少一个独立来源交叉**（★ 这是**提示**，不是判据；判据只查"层级标了没有"）。 |
| ③ | **本 skill 的官方依据只有一条**：一切非自主来源须引用（`corpus/official/instructions.html:1121`，`[官方]`）。**其余条文（来源表 / 清洗步骤 / 五级 / 确认闸）都是本套件自订的工程口径 `[社区]`**，**不许写成官方要求**。 |
| ④ | **本 skill 不声称"数据是对的"** —— 它只查来源表与确认记录**是否在场**，不查 URL 里是否真有那个数、口径选得对不对。 |
