# source-credibility —— 可信度五级

**上位**：`SKILL.md` 的口径②；来源表 `可信度层级` 列的取值即本文件的**五级之一**（★ 例外：`出处 = 本队自产` 的自产行填 `—`）。

★ **依据标注**：**五级是本套件自订的工程口径 `[社区]`** —— 官方（`corpus/official/`）**没有任何**类似分级；**不许写成官方要求**。

---

## 五级（**从强到弱**）

| 层级 | 是什么 | 例 |
| :--- | :--- | :--- |
| **1 官方统计口** | 政府部门 / 统计局 / 央行 / 监管机构 | 国家统计局、美联储、Eurostat |
| **2 国际组织与学术** | World Bank / UN / WHO / 学会 / 期刊数据集 | World Bank Open Data、UN Comtrade |
| **3 开放数据平台** | 政府开放数据 / Kaggle / 公开 GitHub 数据集 | `data.gov`、Kaggle Datasets |
| **4 商业与行业报告** | 咨询公司 / 企业财报 / 行业协会 | 行研报告、公司年报 |
| **5 媒体与转引** | 新闻 / 二手转引 | 新闻稿、社交媒体转引 |

★ **"例"列不声称穷尽**，只帮助定位层级。

---

## ★ 层级不是"能不能用"，是"要不要交叉验证"

- **五级都能用** —— 层级判的**不是可用性**，是**你要不要拿第二个独立来源去核它**。
- ★ **四级及以下要求至少一个独立来源交叉**（★ 这是**提示**，**不是判据**：判据只查"层级标了没有"）。
- **交叉 = 独立来源**：同一条新闻被十家媒体转载，**不算**十个来源；要两个**互相独立**的源头。

---

## 怎么填这一列（`可信度层级`）

- 一行一个来源，**只填层级号或名**（如 `2 国际组织`）；★ **例外**：`出处 = 本队自产` 的**自产行填 `—`**（自产数据没有"外部可信度层级"，不适用本文件五级）。
- 拿不准**从严**：宁可按**更弱**的层级填、并去交叉。
- **层级由来源本身定，不由"用它的人"定** —— AI 取来的官方口径数，层级仍是 `1`；但**确认那一步照走**（来源表 `确认` 列，见 `references/citation.md`）。
