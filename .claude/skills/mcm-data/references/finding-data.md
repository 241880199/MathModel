# finding-data —— 自行获取数据（★ **主路**）

**上位**：`SKILL.md` 的**第二条路**（题面没给 / 只给一半）把题指到本文件。
**本文件给三件东西**：① 分层找源；② 可得性三角；③ 降级。**这是本 skill 的主路。**

★ **依据标注**：本文件的**找源次序、三角、降级全是本套件自订的工程口径 `[社区]`**；本文件涉及的**唯一 `[官方]` 事实**是"一切非自主来源须引用"（`corpus/official/instructions.html:1121`，写法见 `references/citation.md`）。

---

## 1 分层找源（**从近到远，逐层降**）

排序原则：**先找"最可能被认可、也最省事"的**，找不到再往下走一层。

1. **题面点名的来源** —— 题面若点了机构 / 报告 / 数据库名，**先找那个**（最省事，也最不可能被质疑）。
2. **官方统计口** —— 政府部门 / 统计局 / 央行 / 监管机构。
3. **国际组织与学术** —— World Bank / UN / WHO / 各学会 / 期刊附带数据集。
4. **开放数据平台** —— `data.gov` / Kaggle / 公开 GitHub 数据集。
5. **商业与行业报告** —— 咨询公司 / 企业财报 / 行业协会。
6. **文献与新闻** —— 论文里的数、新闻转引（**最易失真**，见 `references/source-credibility.md`）。

★ **本清单不声称穷尽**。层次越往下，**越要交叉验证**（见 `references/source-credibility.md`）。
★ **一层里可能有多个来源** —— 都记下来，进来源表时**逐条列**。

---

## 2 可得性三角（**时间跨度 × 地理粒度 × 口径**）

**同一个指标，三样通常凑不齐** —— 常见的是"口径严的没几年、年份长的没细分、细分到城市的换了口径"。
**三者不能同时满足是常态，不是失败**；关键是**取舍有记录**。

| 你要的 | 常撞的墙 | 取舍怎么写 |
| :--- | :--- | :--- |
| 长**时间跨度** | 早年的只有全国汇总 | 早年用粗口径、近年用细口径，**在论文里分段说明** |
| 细**地理粒度** | 细到城市就只有近 5 年 | 要么收短时窗、要么降粒度，**二选一并写清** |
| 严**口径** | 严口径往往只有一两个来源 | 接受交叉验证，或改用**能对齐的代理**（见 §3） |

★ **取舍写两处**：来源表的 `局限` 列（这一行的数据缺什么）+ 论文的假设 / 局限段（为什么可以这样取舍）。

---

## 3 降级（**找不到就换，换完写局限**）

三条降级路，**按代价从低到高**：

1. **换代理指标** —— 拿一个**能代表**目标量的可得指标替代（例：用"夜间灯光"代理经济活跃度）；写清**代理的理由与失真方向**。
2. **换粒度** —— 地理或时间粒度放宽 / 收紧（省 → 市、年 → 季）；换完在 `口径` 列写明**换了什么**。
3. **换时窗** —— 用可得年份替代目标年份；写清**外推的假设**。

★ **三步都要落到来源表**：降级后的来源**照样逐条进表**（`出处` / `口径` / `局限` / …），并在 `局限` 列注明"这是降级项"。
★ **降级不等于放弃**：局限**写进论文**（假设段 / 灵敏度段）比假装数据齐全更安全。
★ **本 skill 不替你判"这个代理能不能接受"** —— 那是队员的判断；本 skill 只要求**降级这件事被写下来**。
