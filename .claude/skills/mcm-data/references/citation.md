## 官方规则（**本 skill 唯一的 `[官方]`**）

> `[官方]` **一切非自主来源都要引用。**
>
> 原文（`corpus/official/instructions.html:1121`）：
> *"Teams may use any inanimate source of data, materials, computers, software, references, websites, books, etc. Teams should reference all sources used using footnotes, endnotes, or in-line documentation, and include an associated reference list citing all sources."*
>
> 即：**能用任何非人来源的数据**，但**用过的都要引** —— 脚注 / 尾注 / 行内标注皆可，并附一份**参考文献表**列出**全部**来源。★ **本套件口径**：此处"全部来源"限定为**全部非自主来源**（自产数据不由这条管）。

★ 这条就是"**非自主来源必须有对应引用**"的**官方依据**（`corpus/official/instructions.html:1121`）。

## 来源表怎么填（**七列 · 逐列**）

| 列 | 填什么 |
| :--- | :--- |
| `出处` | **URL / 题面附件名 / 保留值 `本队自产`**（写全，别简写） |
| `口径` | 这个指标**是怎么定义的**（同一名词不同机构口径不同） |
| `局限` | 已知偏差 / 覆盖缺口 / 时点问题 / **降级项** |
| `获取日期` | 外部来源**必须**记（网页会变，不记日子就不可复现） |
| `可信度层级` | `references/source-credibility.md` 的五级之一（`出处 = 本队自产` 的自产行填 `—`） |
| `取数方` | `本人` / `AI` |
| `确认` | `已核（人 + 日期）` / `待核` |

★ **保留值 `本队自产` 须【逐字】**：就写这**四个字**，**不得加后缀 / 括注 / 说明**（如 `本队自产（附录A）`）。理由：检查器按**精确等值**认这个保留值；多一个字它就不是保留值了 ⇒ 该行**落回 `DA2` 的 `--refs` 搜索**（要求"本队自产（附录A）"这串在论文里出现）⇒ **潜在假红**。自产行的**补充说明**写进 `局限` 列（如"自采、非外部来源"），**别挂在 `出处` 上**。

★ **`确认` 列的理由**：官方把「解释数据与模型结果」列在**建议谨慎**侧 `[官方]`（`corpus/official/INDEX.md` §2.4）⇒ **由 AI 取来的条目必须过队员的手**：`取数方 = AI` 的行，`确认` 必须记「已核（人 + 日期）」。

## 论文里怎么写（**与来源表一致**）

- **正文每处用数**：行内标注或脚注给出**来源**，能指到来源表那一行最好。
- **参考文献表**：列出**全部非自主**来源（`corpus/official/instructions.html:1121`）。
- **与来源表不打架**：论文里出现的来源，来源表里要有同一行；数字对得上。
- **图表来源**：图 / 表若引自外部数据，**图注 / 表注**注明来源（**排版归 M3，来源归本 skill**）。

★ **本文件不判"引用格式对不对"** —— 只要求"**非自主来源有对应引用**"；格式与美观是队员的判断。
