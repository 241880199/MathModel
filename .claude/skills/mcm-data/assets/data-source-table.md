# 数据来源表（模板 · **可直接复制**）

> **用法**：把下面**两节**整段复制进你的来源表文件（如 `data-sources.md`），**列头逐字保留、不要改**。
> 行数自定 —— 但**零行不算合格**：表在场就必须有数据行（空集不许判绿）。

## 来源表

| 出处 | 口径 | 局限 | 获取日期 | 可信度层级 | 取数方 | 确认 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |

★ **七列填什么**（**不声称穷尽**，逐列口径见 `references/citation.md`）：

- `出处` —— URL / 题面附件名 / 保留值 `本队自产`（★ **保留值须逐字、不得加后缀 / 括注**：多一个字就不是保留值了、会被当外部来源要求写进引用；详见 `references/citation.md`）；
- `口径` —— 这个指标**是怎么定义的**（同一名词不同机构口径不同）；
- `局限` —— 已知偏差 / 覆盖缺口 / 时点问题 / 降级项；
- `获取日期` —— 外部来源**必须**记（网页会变，不记日子就不可复现）；
- `可信度层级` —— `references/source-credibility.md` 的五级之一（`出处 = 本队自产` 的自产行填 `—`）；
- `取数方` —— `本人` / `AI`；
- `确认` —— `已核（人 + 日期）` / `待核`。

## 清洗步骤

> 逐条记你**实际做过**的清洗与口径对齐动作。每条要**能重跑**：写清对**哪个文件 / 哪一列**、做了**什么**、**依据什么**。行数自定。

★ **下列三条为示例，落地时替换为你实际做过的清洗动作**。

1. 取数：从 `<附件名 / URL>` 取 `<指标>`，记下**单位 / 时点 / 缺失值处理**。
2. 口径对齐：把 `<来源 A>` 与 `<来源 B>` 的同名指标按 `<统一口径>` 折算，写出折算公式。
3. 可重跑：注明用哪个脚本 / 哪条命令能再现这一步（脚本路径 + 命令）。
