# mcm-plot-python · 出图流程

本文件是 `SKILL.md` 的流程正文。**本文件与 `SKILL.md` 一样，不复述任何规范数值**（含用中文数词写的规范值），也都**一个阿拉伯数字都没有**——
规范的阈值 / 占比 / 样本读数一律回 `references/house-style.md` 去说，口径与复跑命令回 `provenance.md`。

流程：**读规范 → 套样式 → 出图 → 机械层验 → 亲眼看图**。
最后一步与前几步一样是**固定环节**，不许省。

## 读规范

先打开 `references/house-style.md`，按这次的**图型与数据关系**找到相关的那几条规则。
每条规则的数值、口径与验证状态都在那份文件里，**本文件与 `SKILL.md` 都不重述**。
要复核某个数的分母、样本范围与已知偏差，读 `references/provenance.md`。

## 套样式

```python
import mcmplot

mcmplot.apply_style()          # 先调它，再建图
```

`apply_style()` 做三件事：注册**随本 skill 入库**的字体、叠上底座样式、再叠本 skill 的 rcParams。
**前置依赖**是第三方样式包 **SciencePlots**（底座 = `science` 与 `no-latex` 两套样式）。
**本 skill 不自动安装它**：`import scienceplots` 失败时，请先把它装进当前环境。
字体不依赖 TeX Live 的字体路径 —— 入库的字体由 `apply_style()` 自己注册。

## 出图

```python
fig, ax = plt.subplots(figsize=mcmplot.figsize_for(textwidth_in))
# … 画 …
mcmplot.save(fig, out_path, dpi)
```

- `textwidth_in`：**正文栏宽分母**，单位英寸。它是**该用户论文的属性**，必须由调用方传入；
  本 skill 与出货检查器**都不预设**它的默认值。换口径会给出不同的图宽比读数。
- `dpi`：保存时用哪个，送进检查器时就传哪个 —— **两处必须逐字一致**（见下节）。

## 机械层验（与判据的契约）

图出好后，**原样**调出货检查器（本 skill **不改它**，也不重实现它）：

```
python tests/skills/figure-choose/check-figure-style.py \
    --fig <产物路径> --caption <图注文本，或 @<文件>> \
    --textwidth-in <float> --dpi <int>
```

三条契约：

- **`--textwidth-in` 与脚本侧逐字同名同义**：就是 `figsize_for()` 的那个分母。
  检查器**不预设**它的默认值，必须由调用方给出；给的口径要与出图时用的**同一个**。
  口径不写明，读数就不可比。
- **`--dpi` 必须与 `save(fig, path, dpi)` 里的 `dpi` 一致**：同一个值在两个地方各写一次，
  是本契约唯一的失败点 —— 两处不一致，检查器量到的图宽比就不是你交的那张图。
- **`--fig` 与 `--caption` 都是必填**：图注可以给文本，也可以给 `@<文件>` 形式。

判词怎么读（末行恒为 `RESULT:` 那一条）：全绿 ⇒ 机械层过；判红 ⇒ 逐条按判词改，改完重跑；
**参数或参照缺失** ⇒ 检查器**不产生任何判词**、直接报错退出 —— 那时要修的是**输入**，不是图。

## 亲眼看图（**固定一节，不许省**）

机械层判的只是**能机械化的那几层**：图宽比、彩色主色数、图注形态。它**判不了**：

- 这张图**有没有把要说的事说清**（重点有没有被读出来、有没有被别的元素抢走）；
- 刻度与图例**读起来对不对**（单位、量纲、正负号、双轴对不对得上）；
- 图注与图**说的是不是同一件事**；
- 中文与符号**有没有缺字形**（缺字形时图上会留空白框）。

⇒ 所以**出图之后，agent 必须自己把产物看一遍**，并写下**从这张图读到了什么**。
这一步不许省、也不许只贴判词来代替。

**为什么这一步不可省**：机械判据判不了判断层。本模块的载体选择有一条硬口径 ——
**以 agent 能否看见产物为准**：产物是 PNG / PDF，agent 能直接打开来看，所以"亲眼看图"
不是附加礼节，而是这条口径的直接兑现。判断层的这一层，正是判据射程之外的那一层。
