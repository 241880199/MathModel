# mcm-section-writer —— 逐节写作范式

**只回答一件事**：给你 **题面** + **你正在写哪一节** + **该节要点清单** + **已定稿的图表与结果** →
产出一份**该节 `.tex` 片段** + **该节的按节自查单**。

★ **它是逐节工具，不是整篇工具**。跨节一致性由 `纪律 B6` 管辖，落点在 `references/section-edges.md`
（本文件只给指针）。**不向用户要"论文全文"。**

## 什么时候用 / 不用

**用**：手上有了要点清单，要把**这一节**组织成合格的论文正文时。

**不用（边界六条，逐条写死）**：

- **不排版**（骨架 / 页眉 / `\documentclass`）⇒ `mcm-latex-format`；
- **不写摘要页** ⇒ `mcm-abstract`；
- **不出图 / 表 / 示意图** ⇒ M3 的绘图类 skill（`mcm-figure-choose` → `mcm-plot-*` / `mcm-table` / `mcm-schematic`）；
- **不做全稿提交前合规**（一票否决那一组）⇒ `mcm-selfreview`；
- **不做页数预算** ⇒ `mcm-paper-architecture`（**已决定不做 ⇒ 明写「未建」**）；
- ★ **不判"这段是不是 AI 生成的"** —— `judge.md:133` / `:244` / `:240` 三处都写着它**证明不了、不能下判定**，故本 skill **不承接这一问**。

## 节路由表（你写哪一节 → 读哪一段 → 盯哪几条纪律）

**正文 8 节**（`目录` 与 `参考文献` 是机械件，不在本 skill，见 `references/sections.md` §0）。

| # | 你写这一节 | 读 `references/sections.md` | 该节 ③ 格挂的纪律**条号**（★ 规则原文只在 `docs/mcm-writing-discipline.md`） |
| :-- | :-- | :-- | :-- |
| 1 | 问题重述 | §1 | `纪律 B1` · `纪律 B2` · `纪律 C1` |
| 2 | 假设及其论证 | §2 | `纪律 A1` · `纪律 B1` · `纪律 B3` · `纪律 B4` |
| 3 | 问题的分析 | §3 | `纪律 B1` · `纪律 B2` · `纪律 C1` |
| 4 | 模型建立 | §4 | `纪律 A1` · `纪律 A2` · `纪律 A5` · `纪律 B1` · `纪律 B3` · `纪律 B4` |
| 5 | 求解与结果 | §5 | `纪律 A2` · `纪律 A5` · `纪律 B1` · `纪律 B4` |
| 6 | 灵敏度 / 误差 / 稳定性 | §6 | `纪律 A3` · `纪律 B1` · `纪律 B4` |

每条各配一句「**怎么查**」的具名动作，落在 `references/sections.md` 各节的 ③ 格。

## 输入契约（照设计 §1；四样，缺一样就先向用户要）

1. **题面**；
2. **你正在写哪一节**（上表 8 节之一）；
3. **该节的要点清单** —— 形态照 `tests/skills/arch-cases/brief-S1.md`：**一条条要点、不成句**，
   措辞 / 段落组织 / 过渡 / "公式怎么引出来"**由你决定**；
4. **已定稿的图表与结果**（若该节要引用图表；没有就说没有）。

## 输出契约（每次都交齐这两样）

1. **该节 `.tex` 片段** —— 可直接粘进全文；**不带** `\documentclass` / 页眉 / 页码；
2. **该节的按节自查单** —— 把本节 ① 格的 `自查 B<n>` 逐条打勾，并跑下面的检查器。

## 检查器（可机器执行；`check-section.py`，判据 `SW1–SW8`）

```
python check-section.py <节文件> --section <8 节之一> [--input <要点清单>]
```

★ **射程不许夸大**：判据覆盖 `SW1–SW8` **八项**；**硬失败（`FAIL`）只有三处：`SW1`、`SW2`（与 `SW1` 同一合取口径）、
`EMPTY`（本节无可检正文）**；其余 **`SW3–SW8` 六项一律只出"提请复核"（`WARN`）**。
★ **"检查器 PASS" ≠ "这一节写好了"** —— 它只判形式与可机判的那几项；
`纪律 A3/A4/A5/B2/B4/B5/B6` 等条目**仍靠人工逐条**（同 `mcm-abstract` 的口径：工具只判形式）。
★ **判据口径与它的四条边界**（阈值不可复算 · 词表先自测 · 压力臂做不到 · 明令不用的四项）**见 `references/metrics.md`**，本文件不重复。

## 指针（唯一权威）

- **逐节范式（本 skill 的主体）** —— 8 节 × 五格（① 必须回答的问题 · ② 结构骨架 · ③ 最易犯的纪律条目 · ④ 节边界 · ⑤ 反面实例）+ **每节的证据强度标注**：`references/sections.md`。
- **节边界表** —— 每节「不写什么、留给哪一节」· `自查 B6`（正文只放推导摘要）的跨节落点 · **符号表**（`纪律 B3` 一节之内 / `纪律 B6` 跨节对齐）：`references/section-edges.md`。
- **检查器各判据的口径 + 它的四条边界**：`references/metrics.md`。
- **纪律的权威表述**（14 条，三层有序）：`docs/mcm-writing-discipline.md` —— **本 skill 只给条号，不复述规则原文**。
- **官方内容清单的镜像**（`自查 B1–B11`）：`.claude/skills/mcm-selfreview/SKILL.md`。
