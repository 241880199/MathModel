# `references/sections.md` —— 逐节范式（**8 节 × 五格**）

**本文件是 `mcm-section-writer` 的主体。** 8 个正文节，每节五格：
**① 必须回答的问题 · ② 结构骨架 · ③ 该节最易犯的纪律条目 · ④ 节边界 · ⑤ 反面实例**。

★ **③ 格的写法（本文件的硬规矩）**：凡引纪律，**只给条号 + 一句「怎么查」的具名动作**，
**绝不复述规则原文** —— 规则原文是 `docs/mcm-writing-discipline.md` 的**唯一权威表述**（`docs/mcm-suite-lessons.md` 4.8：
同一句话写两处，必有一处忘改）。同理，① 格**只给 `自查 B<n>` 条号 + 一句话**，不复述官方原文。

## ★★ 证据强度标注（每节携带；读法先看这一段）

- `[实测对照]` = 该节有**真实产物的反面实例**可引。★ **不等于**"该节的范式已被验证有效"。
- `[仅规格来源]` = 只有官方内容清单的镜像（`自查 B1–B11`）与规格，**未跑过任何对照**。

★★ **`[实测对照]` 的含义（不许放大）** —— 只有 **两节案例**有 RED/GREEN 对照：

1. **S1** = 模型建立节（`tests/skills/arch-cases/` 的 `out-S1*.md`）；
2. **S2** = 优缺点 + 结论两节，**由同一个产物覆盖**（`out-S2*.md`）。

且这几条限定**必须与标注同读**：

- **GREEN 侧每节各 1 个产物**（`out-S1-g.md` / `out-S2-g.md`；`judge-green.md:263`）；
- **GREEN 侧没有压力臂**（`judge-green.md:265`）—— ★ 但**"没有压力臂"只对 GREEN 侧成立**：
  **RED 侧有压力臂** `out-S2-p.md`（`tests/skills/arch-cases/README.md:34`：*"S2 压力臂（队长要求'缺点别写太狠'）"*）；
- ★ **只有 S2 那一对是干净的单变量对照**（`judge-green.md:264`）；**S1 那一对混了产物形态**
  （RED 是 markdown、GREEN 是 LaTeX 源码）⇒ **S1 上的改善不能全归给纪律 / skill**；
- ★ **结论节（§8）的 `[实测对照]` 只覆盖文风层**：它对应的官方项 `自查 B9`「明确报告结果」
  **RED 轮自认测不到** —— `tests/skills/arch-cases/README.md` §三.2 记该论文结论节**零数字**、
  **无法观测**写手会不会在结论里复述关键数值（`judge.md:247` 同记）。

★ **关于"两节"与"三处"**：两节**案例**（S1、S2）中，**S2 一个产物同时覆盖 §7 与 §8 两节**。
⇒ 说"**两节**"是**按案例计**；本文件末的**标注计数表按节计，故出现三处 `[实测对照]`（§4 / §7 / §8）**。
两者不矛盾，**但"三处"里 §7 与 §8 共用同一个 S2 产物**，不是两份独立证据。

★ **不得**把 S1/S2 的读数写成"该节的普遍规律"；**不得**把 S1 上的改善整个归给纪律（P8）。

## §4 模型建立　`[实测对照] = S1`

- **① 必须回答的问题**：`自查 B7` 前半 —— 把模型真正**建起来**（设计 + 推导）。
- **② 结构骨架**（★ **依 S1 对照产物 `tests/skills/arch-cases/out-S1.md` 组织**）：
  - 本节任务（把测量到的量与待求量连起来）；
  - 离散化对象（把连续面切成格 / 单元，为什么要这么做）；
  - 待测量的量（逐个记号的含义）；
  - **核心关系式**（必须出现）；
  - 这个式子的**物理动因**（别只丢公式）；
  - 参数**如何确定**（引一条理论 / 一个来源）；
  - 参数**不是常数**时怎么处理；
  - 群体 / 总体量怎么加权；
  - 可调性（哪些量可按本地数据换）；
  - 导出一个**平均量**；
  - 反解收尾（要问的两个量互相解出）。
- **③ 该节最易犯的纪律条目**：
  - `纪律 A1`（怎么查：表 / 图 / 数字**逐项**指到出处，指不到就补来源或标 `assumed` —— 机判 = `SW1` / `SW2`）；
  - `纪律 A2`（怎么查：每个数字回要点清单 / 结果台账找来源，逐个记下"追到 / 追不到"）；
  - `纪律 A5`（怎么查：同一处的陈述与紧邻句**逐句比对**，看有没有互相打架）；
  - `纪律 B1` · `纪律 B3` · `纪律 B4`（怎么查分别同上述三格的具名动作）。
- **④ 节边界**：见 `references/section-edges.md` 的「§4」行。
- **⑤ 反面实例**：`tests/skills/arch-cases/out-S1.md:65–77`（WHO 表那一段）——
