# `references/metrics.md` —— `check-section.py` 各判据的口径 **与它的边界**

**它是什么**：对**一份节文本**（`.tex` 或 `.md`）跑一组检查，报告 `PASS` / `WARN` / `FAIL`。
★ **只有 `FAIL` 是硬失败** —— 判据名一律 `SW*`（`SW` = section-writer），**不许用 `D*`**（那已被别处占用）。

```
python check-section.py <节文件> --section <8 节之一> [--input <要点清单>]
```

- `--section` 取值**必须是** `references/sections.md` 那 8 个节名之一；**给不认识的值 ⇒ fail-closed 红**（不许静默绿）。
- `--input` = 写手输入（★ **设计 §1 的输入契约**：**题面 + 哪一节 + 该节要点清单 + 已定稿的图表与结果** ——
  本 CLI 里 `--input` 收其中**要点清单 + 已定稿的图表与结果**两项；"哪一节"走 `--section`）；
  `SW1`/`SW2` 要回它搜数字；**缺失时 `SW1` 报"无法判定"，不许报 `PASS`**。

★ **`SW9` 的口径与阈值来历**（★ 必须与上表同读；本项**无判词出处**）：
  - **量什么**：**正文**里**行内加粗**的处数 ÷ **`SW9` 自己的正文词数** × 1000（`‰`，每千词）；Markdown `**…**` 与
    LaTeX `\textbf{}` / `\bfseries` **两种格式都认**。
    ★ **分母是 `SW9` 自己那层正文词数，不是抬头那行 `正文词数=`**（★ 必须说清，否则读者会当成同一个数）：
      抬头 `正文词数` 取自 `prose_paragraphs()`（**已 `clean_math`、并过"散文段 `<5` 词"门**）；
      `SW9` 的分母取自 `sw9_body_lines()`（**不做**"纯公式行"过滤、**不剔**短行）⇒ **两者不同源、数值会差**。
      实测 RED-S1 上两者差约 19%（抬头 `1313` 词 vs `SW9` 行 `1627` 词，`SW9` 的分母把公式 token 也算进去了）。
      ★ 阈值 `5.0‰` 是在**同一个分母（`sw9_body_lines` 词数）上标定**的、内部自洽 ⇒ **不许**把分母换成抬头那个数
        （动了分母就得重标阈值、并重跑 43 份人写样本）。工具 `SW9` 行打出的就是这一分母、当场可复算。
  - **"正文"怎么切**：先剥掉（a）参考件包壳（`===== BEGIN VERBATIM` 之前）与（b）末尾那段
    **`## 我的做法说明` 起**的自述（仓库口径：说明段不计入正文统计，见 `tests/skills/arch-cases/judge.md`）；
    再逐行剔除**标题行**、**表格行**、**表 / 图题标签行**、**整行加粗行**。★ **"整行加粗 = 标签"两种格式对等豁免**：
    Markdown `**…**` 独占一行与 LaTeX `\textbf{…}` 独占一行**同样不计**（复核 Minor-1：同一视觉构造不许两种格式判定相反）。
    ⇒ 只有"**嵌在散文句里的加粗**"才计入 —— 这正是 `纪律 §③` 允许（标签位）与要压（行内强调）的分界。
  - **阈值 `5.0‰` 怎么来的**：当场量三组 —— RED `out-S1.md` = **7.38**、GREEN `out-S1-g.md` = **0.00**、
    真值 `true-S1/S2` = **0.00 / 0.00**、43 份人写 O 奖论文**最大 4.28**（中位 0）⇒ 取 `5.0‰`
    （**> 人写最大值、< RED**）。
  - **为什么仍只 `WARN`**：它是**文风层**代理量、且红侧只有一个样本 ⇒ 提请复核、绝不判死。
    ★ 与 `SW3`–`SW8` 的**一处不同**：本项阈值**可复算**（对每件跑本工具、读它打出的 `SW9` 行即可）。
  - ★ **已知局限（不声称穷尽）**：① **整行加粗被当"标签"排除** ⇒ 一份把**整段**都写成 `**…**`（或 `\textbf{…}`）的产物会被漏计；
    ② 它是**密度**线 ⇒ 一份**长**正文里**少量**领起式加粗压不住（实测 `out-S2.md` = 5 处 / 1192 词 = **4.19‰ < 5.0**，**不** WARN）
    —— 本项压的是**成规模**的行内加粗，不是"出现一处就报"；
    ③ **跨行的 Markdown `**…**` 不计**（`RE_MD_BOLD` 无 `re.S`）⇒ 一处**跨行**加粗会被漏计。
      ★ **裁定（复核 Minor-1 附条）**：**非漏、按可接受的已知局限登记、不动正则** ——
      理由：⑴ 本仓语料里的**行内强调**绝大多数是**单行**的（Markdown 段落单行长行；跨行者见 ⑵）；
      ⑵ 对 `corpus/papers/md/2025美赛O奖论文/**` 全部 43 份逐件扫"`\*\*` 跨行成对"，**至少 1 处真实跨行加粗**：
        `corpus/papers/md/2025美赛O奖论文/C/2505964.md:1393–1394` 的段内软换行
        `**Investment Recommen-` / `dations**`（CommonMark 下确会渲成粗体）；其余跨行命中多为回归表显著性星号
        （如 `** p<0.01`）与公式 / 页眉残片 —— 扫描命中项**不声称穷尽**；
      ⑶ 但那 1 处算进去也只让 `C/2505964` 的 `SW9` 由 **37 处 / 8648 词 = 4.28‰** 变 **38 处 = 约 4.39‰**，
        仍 **`< 5.0‰`、不改任何判词**；而加 `re.S` 会改变 `RE_MD_BOLD` 语义、并与"整行加粗 = 标签"豁免交互
        ⇒ 须重标阈值、重跑 43 份，代价与收益不成比。**如实登记为局限，不声称已覆盖。**

★★ **`SW1`/`SW2` 与 `SW3–SW9` 的**报告级别不同**：前者是**硬失败（`FAIL`）**，后者**一律只出"提请复核"（`WARN`）**。
**绝不判死**。★ **硬失败（`FAIL`）共三处**：`SW1`、`SW2`（合取口径，见上）、**`EMPTY`**（本节
**无散文行、无表** —— ★ **"只有公式行、无散文无表"同样算无正文**、fail-closed）。**"检查器 PASS" ≠ "这一节写好了"** —— `纪律 A3/A4/A5/B2/B4/B5/B6` 等条目**仍靠人工逐条**。

★ **`EMPTY` 的"纯公式行"判法**（同一口径也写在工具头部与 `README`）：一行经 `_mask_block_math` 掩掉**块级数学**
（`$$…$$` / `\[…\]` / 列出的数学环境）、再经 `RE_INLINE_MATH` 抹掉**行内公式**后，若**残留里没有一个字母（中英文均可）**
⇒ 判该行为**纯公式行**（不算正文）。⇒ `$$ E=mc^2 $$.` 的残留只有 `.`（无字母）**仍判公式行**；
而 `We obtain $T = 18743$ from the fit.` 残留含字母 ⇒ **仍是正文**（不许误伤含行内公式的散文行）。

★ **数学环境清单不声称穷尽（已知局限）**：本工具只认**它列出的**那些环境
（`equation`/`align`/`alignat`/`flalign`/`gather`/`multline`/`eqnarray`/`displaymath`/`math`/`split`/`cases`/`array`，
及 `$$…$$` / `\[…\]`）；**自定义 / 未列出的环境可能不被识别** ⇒ 那一行可能被当成正文（**漏判 `EMPTY`**）。

## 2. ★★ 四条边界（必须与上表**同读**；这几条也会被工具头部的静态自检盯住）

### 边界 1 —— 阈值或出自判词、或为本项目 `[社区]` 自订（**两类皆不可重跑、不可复算**），**只出"提请复核"，不许读成"达标线"**

`SW3–SW8` 的阈值（`90%` / `15%` 之类）**或出自判词、或为本项目 `[社区]` 自订**（逐条见上表）；出自判词那几档依据的**两轮度量脚本都没落盘**
（`docs/mcm-writing-discipline.md:10` · `tests/skills/arch-green-evidence.md:157` · `judge-green.md:10`），
自订那几档本就是本项目软线 ⇒ **两类都不可重跑、不可复算** ⇒ 一律输出**"提请复核"**，**绝不判死**。
**不许**把它们读成"达标线" —— `judge-green.md:270` 明记：*"**0 与 0 之间无法定阈**"*。
★ **`SW9` 不在此列**：它的阈值是**本项目当场量的分布**定的（RED 7.38 / GREEN 0.00 / 43 份 O 奖论文最大 4.28
⇒ 取 `5.0‰`），**可复算**；但仍属文风层、只出**"提请复核"**（来历见本文件 §1 的 `SW9` 块与工具头部 docstring）。

### 边界 2 —— 词表判据**必须先用真值自测**

`judge.md:238` 明令：*"任何词表判据在使用前必须先在 `true-*` 上跑一遍。"*
⇒ 工具**内置**这条：`SW5`（对比式 + 强调式）等**任何词表判据**，**每次运行先拿
`tests/skills/arch-cases/true-S1.md` / `true-S2.md` 跑一遍**；
**词表在真值上命中 ⇒ 输出"词表不可用：真值命中 N 处"，把该项降级为"不可判"，不报产物有罪。**

### 边界 3 —— 压力臂与自由臂**必须分别设阈**；★ **本工具做不到**

`judge.md:239` 要求：**压力臂与自由臂必须分别设阈**。★ **本工具做不到** ——
**节片段里没有"压力臂"这个概念**。
★ 而 **RED 轮是分臂测的**：`out-S2.md`（自由臂）vs `out-S2-p.md`（压力臂，队长要求"缺点别写太狠"，`tests/skills/arch-cases/README.md:34`）
⇒ **本工具放弃的正是 RED 那一半的控制手段**。
**这是本工具的明确局限，不是"已覆盖"。**

### 边界 4 —— **明令不用的四项**不许出现

`judge-green.md:202-208` 明令**不用**这四项判据（实测被推翻）：

- **句长 CV**（方向不稳定、对分句实现敏感，同一份读数相差约 15%）；
- **root-TTR 词汇多样性**（长度混杂、方向上不稳定）；
- **Flesch 可读性**（区间完全重叠，零分辨力）；
- **模板化过渡词表**（五份文件合计命中 1 次，根本没有量）。

⇒ 工具**源码 / 输出里出现这四项任一即 `FAIL`**（工具自带一条**盯它自己**的静态自检：四项禁用在场即红）。
