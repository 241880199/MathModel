# `references/section-edges.md` —— 节边界表（**一处集中**）

**为什么集中在一处**：节边界是**跨节**的事 —— 散在各节里必然漂移。本文件是**唯一的边界表述**，
`references/sections.md` 的每节 ④ 格**只给指向这里的指针**。

★ 与前两份 references 同一条硬规矩：凡引纪律**只给条号 + 「怎么查」的具名动作**，
规则原文只在 `docs/mcm-writing-discipline.md`。

## 2. 一条**跨节**取舍规则：`自查 B6`

`自查 B6`（**正文只放推导 / 计算摘要，冗长部分入附录**）**不是某一节的格**，是**跨节的取舍规则**。

- **怎么查**：逐段问"这一段是**摘要**还是**完整推导 / 完整数据**？" —— 完整的那一部分该不该挪附录；
- **落点**：它**不属任何单节**，故**只在本文件出现**（设计 §2.1 明确：不单列节）。
- ★ 与之配套：`自查 B6` 的**页数后果**见 `mcm-selfreview`（页码计入 25 页上限）；**页数预算**不在本 skill（`mcm-paper-architecture` 未建）。

## 3. ★★ 符号表：`纪律 B3` 管一节之内，跨节对齐归 `纪律 B6`

**这是 GREEN 轮没修好的那一条的正对落点**（先说结论，再说它的**边界**）。

| 层级 | 归谁 | 管什么 | **怎么查** |
| :-- | :-- | :-- | :-- |
| **一节之内** | `纪律 B3` | 本节内符号与正文 / 符号表一致、术语首现给定义 | 在**本节内**把每个 `$...$` 与缩写抽出来，看**首次出现处**有没有定义 |
