# 表格规范（`mcm-table/references/table-style.md`）

**本文件是表格规范的唯一权威。** 每条规则都带**出处**（实测读数 / 惯例），并**与出处同时写明边界**。
**读数来源**：`tests/m3-table-recon/`（侦察证据，已入库）。复跑配方见该目录 `README.md`；
本文件只**引用**读数，不复述其口径。

---

## 0. 射程（**不声称穷尽**）

- **覆盖**：普通三线表 · 合并单元格 / 多级表头 · 表注 · 表内公式。
- **不做**（**已裁**）：长表跨页、显著性标记（星号 / 上下标）。
- **"表"不含伪代码框**：侦察在"表区"里检出 **6.2%（36 张）** 其实是 `Algorithm N` 伪代码框，
  而获奖论文作者**自己的口径就不统一** ⇒ 本规范**不算它们**，该 6.2% **如实记在读数旁**。
- 本文件列出的规则**不声称穷尽**表格排版的一切；未被本文件写到的写法属规范未覆盖面。

---

## 1. 由语料读数推出的三条（**每条与它的边界同时读**）

### `T1` 表型 —— 默认三线表

**规则**：默认**三线表** —— `\toprule` / `\midrule` / `\bottomrule`，**不画竖线**。

**出处（读数 4 / 读数 5）**：

- 读数 4：**恰 3 条横线 = 78.6%（456/580）**；
- 读数 5：**纯三线 = 69.0%**；
- 复跑：`python tests/m3-table-recon/probe_2_corpus.py`（全量 ≈ 4 分 10 秒）→ `out-2-corpus.txt`。

**★ 同时写明的边界**：

1. **21.4%** 不是 3 条线（4/5/6/7/8/9 条各有）；
2. **31.0%（180/580）有长竖线** ⇒ **"不画竖线"是本规范的选择，不是"获奖论文都这样"**；
3. `580` 读作**上界**（探针的假阳性只把分母逼到"未量化"，没有把表数**抬**上去的偏差）；
4. 含 **6.2% 伪代码框未扣**（见 §0）。

### `T2` 表宽 —— 不拉伸

**规则**：默认取 `tabular` 的**自然宽度**，**上限 = 版心宽**；超了就**缩**（缩字号 / `\resizebox`），
**不许溢出**。

**出处（读数 2）**：n=580 · min **0.505** · p10 **0.626** · **中位 0.893** · p90 **1.022** · max **1.429**。
复跑：同上（读数 2）。

**★ 同时写明的边界**：

1. **15.9%（92 张）的获奖论文表超版心，其中只 1 张被页框裁掉**
   ⇒ 这句是**"我们选的做法"**，不是"获奖论文都这样"；
2. **版心是推出来的**（文本行 x 的 2%/98% 分位，两遍迭代），**未与 PDF 自身页边距对照**
   ⇒ 分母误差**未量化**。本 skill 的**判据**不用这个推出来的分母，改用**编译时的 `\textwidth`**（见 §3.3）。
3. ★ **`\resizebox` 在本 skill 里落不了地**：自带模板 **没有载 `graphicx`** ⇒ 任何带 `\resizebox`
   的表在判据 `C1` 上**编不过**（判红），且判据量的是**未缩放的自然宽**。⇒ **超宽时请缩字号**
   （如外层 `{\small …}`），**不要**写 `\resizebox`；要支持它需给模板加 `graphicx`（**未实现**，
   登记 `docs/mcm-suite-todo.md` §H.2）。

### `T3` 表题位置 —— 默认在表上方

**规则**：表题默认在表**上方**（`\caption` 在 `tabular` **之前**）。

**出处（读数 3）**：**上 57.8%** · 下 12.9% · **未定 29.3%**。复跑：同上（读数 3）。

**★ 同时写明的边界**：**29.3% 未定**（未标号的表；探针 `CAPTION_RE` 只认 `Table/表 + 编号`，
**不硬塞**）⇒ **不许把那 29.3% 读成"上"**。

**读数只用于立规则的语境、不当作规则值**：读数 1（普及度 **132/164 = 80.5%**）与读数 6
（论文层 **164/164 全部可量**）用于说明"**表格在获奖论文里普遍存在、且语料可量**"。
⚠️ 读数 1 **强依赖写死的阈值**（长线 ≥ 版心宽 ×0.50 / 对齐容差 2pt / ≥3 条），
**未做阈值敏感性分析** ⇒ **80.5% 不是"与判据无关的事实"**，引用时必须带这句。

## 2. 惯例层（**标"惯例"，不冒充实测**）

> **编号从 `D4` 起**：`D1`–`D3` 是草案里最初的"表题位置 / 三线表 / 表宽"三条，
> 它们**有语料读数支撑**，已**升格为上表的 `T1`–`T3`** ⇒ 这里不重复编号，也不留空号占位。

| 代号 | 默认 | 说明 |
| :--- | :--- | :--- |
| `D4` | **同列同精度**：同一列小数位数一致 | **不替你决定有效数字**（那是你模型的判断） |
| `D5` | **单位进列头**（`Temperature (K)`），不在每格重复 | |
| `D6` | **缺失值写 `--`** | |
| `D7` | **默认不加粗**；你点名"哪个数是答案"才加粗 | |
| `D8` | 数值列用 **`siunitx` 的 `S` 列**（小数点对齐） | 覆盖法 = "别用 siunitx" ⇒ 降级成右对齐 |

**这五条为何不标"实测"**：它们是**排版惯例**（书上有答案），量了也是同一个答案。
本仓规矩是**不许把惯例冒充实测**，故如实标"惯例"。

★ **默认 ⊆ 可覆盖**：§2 里**每一条都有一句覆盖法**（自然语言即可）——
"表题放下面"（**写法见 §3.1**） · "第 3 列 4 位小数" · "要竖线" · "别用 siunitx" · "把第 2 列最大的加粗"。
**写不出覆盖法的默认不许进规范。**

## 3. 产物契约

### 3.1 交齐这几样（对应设计 §4）

| # | 产物 | 说明 |
| :--- | :--- | :--- |
| 1 | **LaTeX 代码** | 可直接粘的 `\begin{table}…\end{table}` |
| 2 | **需要的宏包清单** | 一行 `\usepackage{…}`（`booktabs` / `siunitx` / …）。★ **论文骨架里一个都没有**（实测）⇒ **必须给** |
| 3 | **来源回显** | 每个数取自哪里（格式见 §3.2） |
| 4 | **验收记录** | 编译读数 + 看图的"从这张表读到了什么" |

★ **覆盖「表题默认在上」（`T3`）时要写一行声明**：把表题放到 `tabular` **之下**是**合法覆盖**，
但判据 `C3` **只认一行注释**（默认位不写任何东西）。**要把表题放下面，就在 `\begin{table}` 之前**
加这一行：

```
% mcm-table-caption: below
```

**可直接粘的例子**：

```
% mcm-table-caption: below
\begin{table}[htbp]
  \centering
  \begin{tabular}{l l}
    \toprule
    Item & Value \\
    \midrule
    A & 1 \\
    \bottomrule
  \end{tabular}
  \caption{表题在表下（声明了覆盖，判据 `C3` 认这行）。}
\end{table}
```

★ **只认这一行**：表题在下、却**没有**这行注释 ⇒ `C3` **判红**。★ **不许**用别的措辞代替
（判据的这行格式由判据自己钉死）。其余默认条的覆盖（如"不要 siunitx"）是自然语言、由写手按本
skill 执行，**不进判据**。

### 3.2 来源回显的格式（**钉死**）

在 `\begin{table}` **之前**放**一行或多行**注释，形如：

```
% mcm-table-src: r3c2 <- pasted:r3c2
% mcm-table-src: r3c2 <- file:data/x.csv#row5:slope
```

- **左端** = 表内坐标 `r<行>c<列>`（行含表头行，从 1 起）；
- **右端** = 来源：**粘贴入口**写 `pasted:r<行>c<列>`；**文件入口**写 `file:<路径>#row<行>:<列名>`。
- **覆盖要求**：**每一格**都要有对应的 `r<行>c<列>` 出现在**某一行**注释的**左端**。
  ⇒ 出货判据 8 判的就是"这组注释存在、且覆盖到每一格"。

### 3.3 版心宽从哪来（**判据的分母**）

判据"编译后实测表宽 ≤ 版心宽"里的**版心宽**取**编译时**的 `\textwidth`，**不取** §1 `T2` 边界里
那个**推出来的**读数。做法：在模板 / 骨架里插一句

```
\typeout{MCMLAYOUT textwidth=\the\textwidth}
```

解析 log 里的 `MCMLAYOUT textwidth=<pt>` 得到 pt 值，再换算英寸。**这是确定的数**（LaTeX 自己算的）。

★ **判据 `C4` 的分母恒取自自带模板**（`assets/table-template.tex` **编译时**的 `\textwidth`）——
**`--skeleton` 不参与 `C4`**。把分母换成**给定骨架的那份** `\textwidth` **未实现**（**登记**：
`docs/mcm-suite-todo.md` §H.2；`--skeleton` 只报 `rc` / 错误数 / `Overfull \hbox` 计数 /
未定义控制序列名单，**不做宽度比较**）。**默认链**（自带模板自证 + 编译时 `\textwidth`）**不受影响**。

⚠️ **注意**：`siunitx` 的 `S` 列里放非数值（如缺失值 `--`）必须写成 `{--}`（花括号包起来），
否则编不过。这是 `D8` 与 `D6` 在实现上的耦合点 —— **生成器自己处理，不留给用户**。

## 4. 环境与边界（**如实登记**）

- **需要本机 PATH 里有 `pdflatex`**（本机 TeX Live 2026 实测在：pdfTeX 3.141592653-2.6-1.40.29）
  ⇒ **干净检出复跑不相容**；
- **网页端未验**（以本机为准）；
- **跨机未验**；
- ⚠️ 路径含空格 / 非 ASCII 时**不能把路径直接塞给 pdflatex** ⇒ 走临时目录；
- **PDF 不可字节比**（每次重编带新时间戳）⇒ 判据一律基于文本 / 几何读数。
