# mcm-table —— 把数据落成规范的 LaTeX 表格

**只回答一件事**：数据与列名在手，**怎么排成一张能直接粘进论文的规范表** —— 表型怎么定、
宽度怎么控、精度怎么取、表注与表内公式怎么放、生成之后怎么编译、怎么自查。

**不回答**：**该用哪种表**（选型属决策层，本支说到"这张表怎么排"为止）；
**规范里每条规则的具体数值**（表的规范在 `references/table-style.md`，图的规范在
`mcm-figure-choose/references/house-style.md`，**本 skill 一个都不重述**）。
**不产** Python / MATLAB / Origin 代码；也不出"这张表合规吗"的终审判词（判词在出货检查器的出口）。

## 什么时候用

- 数据与列名已经在手，要落成一段能直接粘进论文的 LaTeX 表格代码；
- 已经排出来了，但出货检查器判红（三线结构 / 表宽 / 表题位置 / 来源回显 里的某几条），要按规范重排；
- 要把一篇论文里的表统一到同一套外观（表型、精度、单位、缺失值写法）。

**不用**：

- 只问"这份数据该画成图还是排成表 / 该用哪种表" ⇒ 属决策层，本支不选型；
- 只问某条规范的具体数值或口径 ⇒ 直接读 `references/table-style.md`（本 skill 不重述数值）；
- 要出图 ⇒ 走绘图家族的其余支；图与表的**样式**主张分家：图看
  `mcm-figure-choose/references/house-style.md`，表看本支的 `references/table-style.md`。

## 怎么用

**前置条件（照实）**：本 skill 的"看"这一步要**把生成的表编译出来**、渲成图、agent 自己看一眼
⇒ **需要本机 PATH 里有 `pdflatex`**（本机为 TeX Live）。**本 skill 不自动安装**任何 TeX 发行版、
也不代管宏包。**网页端未验**、**跨机未验**：本封装只在本机一版 TeX Live 上验过。
★ **路径含空格或非 ASCII 时不要把路径直接塞给 `pdflatex`**（先例：本仓 `mcm-abstract` 的检查器
记过这个坑）⇒ 先复制进系统临时目录再编。

流程（**给数 → 定列与精度 → 生成 → 编译 → 渲图看一眼 → 交付**）见 `references/workflow.md`。
本文件只讲怎么用，不复述规范数值。

## 输出契约（每次都交齐这几样）

- **一段 LaTeX 代码**：可直接粘的 `\begin{table}…\end{table}`；
- **需要的宏包清单**：一行 `\usepackage{…}`。★ **论文骨架里一个表格宏包都没有** ⇒ **必须给**；
- **来源回显**：每个数取自哪里，按 `references/table-style.md`「产物契约」一节钉死的格式写；
- **机械层读数**：把表送进编译与出货检查器后的原始输出，判词逐条贴；
- **亲眼看表的一句话**：从这张表读到了什么 —— 见 `references/workflow.md` 那一节。

## 边界

- **不重述任何规范数值**：阈值 / 占比 / 样本读数一律在 `references/table-style.md`。
  本文件**一个阿拉伯数字都没有**（规则编号也写成不带数字的 `T<n>` / `D<n>` 形态）。
- **不选表型**：见「什么时候用」。
- **不做长表跨页、不做显著性标记**（星号 / 上下标）：本轮**已裁**不做 ⇒ 如实说，不假装能做。
- **不编"看着像样的假法子"**：规范里凡本机落不了地的条目，一律如实标，不糊一条假路径。
- **机械层过了不等于表对了**：机械判据判不了"这张表讲没讲清" ⇒ "亲眼看表"是必经，不是礼节
  （见 `references/workflow.md` 的调用方纪律）。
- **不自动装依赖**：见「怎么用」的前置条件。

## 指针（唯一权威）

- **表格规范正文**（表型 / 表宽 / 表题 / 惯例层 / 产物契约）：`references/table-style.md`
  —— 本 skill 对表格样式的主张以它为准，本文件不复述其中任何一个数。
- **图的规范**（图通常长什么样）：`mcm-figure-choose/references/house-style.md` —— 图的样式回那边，
  本 skill **不复述它**。
- **本 skill 的流程正文**：`references/workflow.md`
- **侦察证据**（每个读数的出处与复跑命令）：见 `references/table-style.md` 里每条规则下的出处标注
