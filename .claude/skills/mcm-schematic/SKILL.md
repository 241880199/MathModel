# mcm-schematic —— 把"过程 / 结构 / 机理"落成规范的 TikZ 示意图

**只回答一件事**：手里有一段关于**过程 / 结构 / 机理**的文字描述，**怎么把它落成一段能直接编进论文的 TikZ 源码**
—— 归哪一类、挑哪份骨架、改哪儿、怎么编译、怎么自查。

**不回答**：**该画哪种图**（那是决策层，本支只在"示意图"这三类内部报一句类别）；
**规范里每条规则的具体数值**（示意图的规范在 `references/schematic-style.md`，
图的规范在 `mcm-figure-choose/references/house-style.md`，**本 skill 一个都不重述**）；
也**不管"图里说的话对不对"**（那是你的模型的事）。
**不产** Python / MATLAB / Origin 代码 —— 本支只产 TikZ。

## 什么时候用

- 有"先做什么再做什么 / 在哪一步分叉"的过程，要落成**技术路线图**；
- 有"储罐 / 流 / 耦合 / 场"这类实体结构，要落成**机理示意图**；
- 有"输入层 / 隐藏层 / 输出层"或"模块并列"这类组成，要落成**模型结构图**；
- 已经画出来了，但出货检查器判红（图宽 / 配色 / 色序 / 图注 / 底色 / 字体 里的某几条），要按规范重画；
- 要把一篇论文里的示意图统一到同一套视觉标准。

**不用**：

- 只问"这份数据该画成哪种图 / 该用哪种表" ⇒ 属决策层，走 `mcm-figure-choose`，本支不选型；
- 只问某条规范的具体数值或口径 ⇒ 直接读 `references/schematic-style.md`（本 skill 不重述数值）；
- 要出**数据图**（坐标轴 / 曲线 / 散点）⇒ 走 `mcm-plot-python` / `mcm-plot-matlab` / `mcm-plot-origin`；
- 要排**表** ⇒ 走 `mcm-table`。

## 怎么用

**前置条件（照实）**：本 skill 的"看"这一步要**把生成的图编译出来**、渲成图、agent 自己看一眼
⇒ **需要本机 PATH 里有 `pdflatex`**（本机为 TeX Live）。**本 skill 不自动安装**任何 TeX 发行版、
也不代管宏包。**网页端未验**、**跨机未验**：本封装只在本机一版 TeX Live 上验过。
★ **路径含空格或非 ASCII 时不要把路径直接塞给 `pdflatex`** ⇒ 先复制进仓内被 git 忽略的 `build/` 再编。

流程（**定类别 → 挑骨架并说出为什么 → 改 → 编译 → 渲图看一眼 → 交付**）见 `references/workflow.md`。
本文件只讲怎么用，不复述规范数值。

## 输出契约（每次都交齐这几样）

- **一段 TikZ 源码**：可直接粘的 `tikzpicture`，**含 `\input` 样式层那一行**；
- **需要的宏包清单**：`\usepackage{tikz}` ＋ 用到的 `\usetikzlibrary` 名单。
  ★ **论文骨架里一个 TikZ 宏包都没有** ⇒ **必须给**，否则粘进论文编不过；
- **选型回显**：用了哪份骨架 / 归哪一类、**为什么挑它**；回落原语时**明说**；
- **机械层读数**：编译读数（`rc` / 错误行 / 溢出行计数）＋ 出货检查器的判词，逐条贴
  （★ **判示意图要带 `--schematic`**，否则检查器只走数据图那条默认路径、拿不到示意图特有的那几条判词；
  怎么调见 `references/workflow.md` 的验收记录那一步）；
- **亲眼看图的一句话**：从这张图读到了什么 —— 见 `references/workflow.md` 那一节。

## 边界

- **不重述任何规范数值**：尺寸 / 配色 / 线型 / 分层上限一律在 `references/schematic-style.md` 与
  `assets/schematic-style.tex`，本文件**一个阿拉伯数字都没有**。
- **样式只有一个来源**：产物样式 = `assets/schematic-style.tex`；骨架一律 `\input` 它，
  **骨架自身不带样式字面量**。
- ★ **不复述图的规范，也**不把 `house-style.md` 说成"它也管示意图"：那份文件里**多数条目是为数据图写的**
  （坐标轴 / 刻度 / 图例 / 信息密度 / 多面板）⇒ **对示意图不适用**。哪几条适用、哪几条不适用，
  **逐条列在** `references/schematic-style.md` 的「不适用清单」那一节。
- **不选图型**：见「什么时候用」。
- **机械层过了不等于图对了**：图宽 / 配色 / 图注 / 底色 / 色序 / 字体之外，
  机械判据**只兜得住一部分**（节点框重叠 / 文字越页框 / 线宽）；**箭头有没有戳进框里、
  标注有没有落到画外、字有没有被压成几行 —— 只能靠眼睛** ⇒ "亲眼看图"是必经，不是礼节
  （逐条射程见 `references/schematic-style.md` 的「已知缺口」节与 `references/workflow.md` 的调用方纪律）。
- **不编"看着像样的假法子"**：规范里凡本机落不了地的条目，一律如实标，不糊一条假路径。
- **不自动装依赖**：见「怎么用」的前置条件。

## 指针（唯一权威）

- **示意图规范正文**（复用层 / `S` 条 / 不适用清单 / 已知缺口）：`references/schematic-style.md`
  —— 本 skill 对示意图样式的主张以它为准，本文件不复述其中任何一个数。
- **产物样式层**（颜色 / 线宽 / 圆角 / 间距 / 箭头与节点宏）：`assets/schematic-style.tex`。
- **骨架族**（各自完整可编译，都带「改哪儿」对照表）：`assets/skeletons/`。
- **图的规范**（图通常长什么样）：`mcm-figure-choose/references/house-style.md` —— 图的样式回那边，
  本 skill **不复述它**。
- **本 skill 的流程正文**：`references/workflow.md`。
- **侦察证据**（骨架族怎么定下来的、每个读数的出处与复跑命令）：见 `references/schematic-style.md`
  引的那份侦察件（路径写在规范正文里，本文件不复述带编号的路径）。
