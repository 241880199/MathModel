## ① 适用判据

- **用**：要**对总体参数 / 分布下判断**（均值是否等于某值、两组是否有差异、分布是否合某形状）；样本量中小、要**显著性**结论；非正态时用**非参数**版本。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **比较三个以上组** ⇒ 走 `anova`（多做两两 t 检验会**膨胀第一类错误**，多重比较要校正）。
  2. **有先验、要给后验 / 可信区间** ⇒ 走 `bayesian`。
  3. **只看"相不相关 / 谁影响大"** ⇒ 走 `grey_relational`（灰关联不判显著性）。
  4. **样本不独立 / 违背检验前提仍硬套** ⇒ `p` 值失真（凭经验）。
  5. **把 `p` 当效应大小**：`p` 小只说明"证据强"，**不等于效应大**（凭经验）。

## ② 标准建模步骤

1. **定假设**：原假设 `H0`（如均值 = `mu0`）+ 备择假设；定**显著性水平** `alpha`（常 0.05）。
2. **选检验**：单样本 / 双样本 t（正态、方差已知/未知）；非正态用小样本符号秩 / 秩和；分布拟合用 χ²。
3. **查前提**：独立性、正态性（或大样本）、方差齐性 —— 不满足则换非参数。
4. **算检验统计量与 `p` 值**：`p < alpha` ⇒ 拒绝 `H0`。
5. **多重比较**：涉及多组时用 Bonferroni / FDR 等**校正** `p`。
6. **数值验证**（★ 见 ⑥）：对**已知参数**的合成数据核**拒绝率**。
7. **报告**：检验量、`p` 值、结论 + 前提检验结果。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 样本（单 / 双样本）· `H0` 参数值 · 显著性水平 `alpha` · 检验类型 |
| **输出** | 检验统计量 · `p` 值 · 是否拒绝 `H0` |

**显式假设（必须写进论文）**：
1. **样本独立**（同一对象不重复计）。
2. **t 检验前提**：正态（或大样本 CLT）；非正态用小样本非参数检验。
3. **`H0` 为真时第一类错误率 = `alpha`**：`alpha = 0.05` 只控制"误拒"。
4. **多重比较须校正**：做 `m` 次检验，不校正则族错误率上升。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿"跑通"当"算对"**：拒绝率对不对要拿**已知真值**核。**实测**（本骨架，`alpha = 0.05`，5 种子 × 2000 次）：`H0` 为真时经验拒绝率 `0.0495 / 0.0538 / 0.0494`（≈ 名义 `0.05`）；见 `verify/hypothesis_test.md`。
2. ★ **拿 MATLAB 内置当"独立参照"**：`ttest`/`signrank` 是内置、**不独立**（任务书 B）—— 参照是**名义水平 / 理论功效**。
3. **多重比较不校正**：两两 t 做很多次 ⇒ 假阳性暴涨（凭经验）。
4. **把 `p` 当效应量**：大样本下微小差异也"显著"（凭经验）。
5. **前提不查就套 t**：正态性 / 方差齐性不满足时结论不可靠（凭经验）。
