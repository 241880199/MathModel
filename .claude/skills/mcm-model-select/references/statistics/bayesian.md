## ① 适用判据

- **用**：**有先验知识 / 小样本**、要**后验分布 + 可信区间**（不是 `p` 值）；参数有不确定性、要**逐层更新**；要**把先验与数据显式合成**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **没有先验、也不想要主观性** ⇒ 走频率派检验 / 回归（`hypothesis_test` / `regression`）。
  2. **只要一个点估计** ⇒ 走 `regression`（贝叶斯的价值在后验分布，不只点估计）。
  3. **先验选得随意、还不做敏感性分析** ⇒ 结论被先验主导（凭经验）。
  4. **MCMC 不查收敛就报后验** ⇒ 链没收敛时数字全错（凭经验）。
  5. **把"可信区间"当"置信区间"** ⇒ 两者语义不同（贝叶斯：参数的概率；频率：重复抽样的覆盖）。

## ② 标准建模步骤

1. **定模型**：似然 + 各参数先验（共轭优先，如正态-正态、Beta-Binomial）。
2. **求后验**：共轭 ⇒ 闭式；否则 MCMC（Metropolis-Hastings / Gibbs）。
3. **MCMC 设置**：链数、步长、预热（burn-in）、固定种子；**查收敛**（`R̂` / 迹图）。
4. **算摘要**：后验均值 / 标准差 / **95% 可信区间**。
5. **敏感性**：换先验看后验变多少。
6. **数值验证**（★ 见 ⑥）：**共轭闭式 vs MCMC / 精确抽样**多路对照。
7. **报告**：后验分布图 + 摘要表（均值 / 区间）+ 先验与收敛诊断。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 数据 · 似然模型 · **先验分布及超参数** · MCMC 设置（链数 / 步数 / 预热 / 种子） |
| **输出** | 后验均值 / 标准差 · 可信区间 · 收敛诊断 |

**显式假设（必须写进论文）**：
1. **先验必须写明**：超参数是谁定的、依据什么（★ 这是贝叶斯最需要交代的一条）。
2. **似然模型**：数据生成假设（如正态、Poisson）。
3. **MCMC 收敛**：链混合良好、`R̂` 接近 1；否则后验数不可用。
4. **可信区间的语义**：95% 可信区间 = "参数落此区间的后验概率 0.95"（不是频率覆盖）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿"跑通"当"算对"**：MCMC 必出数，对不对要拿**闭式后验**核。**实测**（本骨架）：模型 A 的 MCMC / `mvnrnd` 精确抽样 / 闭式后验三者后验均值一致到 `~4e-4`；见 `verify/bayesian.md`。
2. ★ **拿 MATLAB 内置当"独立参照"**：`bayeslm` 是内置、**不独立**（任务书 B）—— 参照是**共轭闭式公式**（且本骨架明写 `bayeslm` 与手推闭式那两行属**解析对解析、符号核对**）。
3. ★ **MCMC 不看收敛**：预热不足 / 步长过小 ⇒ 链未混合，后验数全错（凭经验）。
4. **先验不写明 / 不做敏感性**：结论被先验主导还看不出来（凭经验）。
5. **可信区间与置信区间混用**：语义不同，别互相冒充（凭经验）。
