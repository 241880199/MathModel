# 变量聚类 / R 型聚类（`var_cluster.m`）

> **要把指标（变量）分群、看变量间相关结构时用**：对变量两两相似度（如 `1 − |corr|`）做层次聚类，把**高度相关的一批指标归成一组**（组内信息冗余、可择一代表）。

**归属**：类索引 `references/statistics.md` · 骨架 `assets/matlab/statistics/var_cluster.m` · 参照 `tests/skills/model-select/verify/var_cluster.md`。
★ **与相邻方法的边界（★ 类索引去重口径）**：本方法聚的是**变量**（R 型聚类，输入**相关阵**）；`references/statistics/hierarchical_cluster.md` 聚的是**样本**（Q 型聚类，输入 n×p 数据）。
两者**共用** `linkage`/`cluster`，但**输入对象不同**（变量 vs 样本）—— 这是最容易互相冒充的一对。

## ① 适用判据

- **用**：**指标太多且彼此相关**，要**把冗余指标归组**（每组选一个代表指标）；建评价体系前**去共线**；要看**变量间的块状相关结构**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要聚样本**（把对象分群）⇒ 走 `hierarchical_cluster`（Q 型），别用相关阵聚变量。
  2. **要对变量降维成综合指标** ⇒ 走 `pca`（PCA 给主成分；变量聚类只给"哪几个变量是一伙的"）。
  3. **变量数太少**（p 很小）⇒ 相关阵不稳定、分群无意义（凭经验）。
  4. **只看相关、忽略变量方向 / 量纲** ⇒ 距离失真（凭经验）。
  5. **样本量小**（n 小）⇒ 相关系数抖动 ⇒ 变量分群不稳（凭经验）。

## ② 标准建模步骤

1. **列变量、算相关阵** `R`（p×p），用 `|corr|` 去掉正负号（相关性强弱）。
2. **定距离**：常用 `d = 1 − |corr|`（本骨架）；对称、对角 0。
3. **选链接方式**（`complete` / `average`），对**距离向量**做层次聚类 ⇒ 树 `Z`。
4. **割树**成 `k` 组（`cluster(Z,k)`）⇒ 得到**变量分组**。
5. **核结构**：检查**组内相关高、组间相关低**（本骨架对**已知隐因子**生成的变量核分组还原）。
6. **报告**：变量分组表 + 组内 / 组间平均 `|corr|` + 树状图。
7. **数值验证**（★ 见 ⑥）：对**已知变量结构**的合成数据核分组还原。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 变量相关阵（或原始数据，由 `corr` 算）· 距离定义（如 `1 − |corr|`）· 链接方式 · 组数 `k` |
| **输出** | 变量分组 · 组内 / 组间平均 `|corr|` · 树状图 |

**显式假设（必须写进论文）**：
1. **相似 = `|corr|`**：用相关系数代表变量接近程度（去掉符号 —— ★ 若需区分正/负相关，改 `1 − corr`）。
2. **链接方式**：`complete`/`average` **会改变**结果，须写清。
3. **线性相关**：相关阵只刻画**线性**关系。
4. **样本代表总体**：`n` 太小时相关阵不稳。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把"聚变量"与"聚样本"混写**：同一批数据、同一函数，输入若是相关阵就是**变量聚类**，若直接喂数据就是**样本聚类**。**实测**（本骨架，2 隐因子 6 变量）：喂相关阵 ⇒ 还原变量分组 `{1,2,3}/{4,5,6}`、组内 `|corr| = 0.9179` 组间 `0.0383`；见 `verify/var_cluster.md`。
2. ★ **拿 MATLAB 内置当"独立参照"**：`corr`/`linkage`/`cluster` 同为内置、**不独立**（任务书 B）—— 本骨架参照是**已知隐因子构造**。
3. **去掉 `|corr|` 的符号**：`1 − |corr|` 会把强**负**相关也当"接近"（正面：抓冗余；负面：若想看方向则失真），须写明（凭经验）。
4. **不处理相关阵的对角**：对角须置 0（`1 − 1 = 0`），否则距离阵非法（本骨架显式 `D(1:p+1:end)=0`）。
5. **变量太少仍强行分组**：p 小时相关阵噪声大（凭经验）。

- **变量分组表**（组号 × 成员变量）+ **组内 / 组间平均 `|corr|`** + **树状图**。
- 表 → `mcm-table`（`.claude/skills/mcm-table/`）；树状图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）。

## ⑥ 代码骨架

**路径**：`assets/matlab/statistics/var_cluster.m`（**零参可跑**，自带算例：2 已知隐因子 × 6 变量，`complete`/`average` 两链接）。

关键片段（**不整份复制**）：
```matlab
R = corr(Xv);                 % 变量相关阵
D = 1 - abs(R);  D(1:p+1:end) = 0;      % 距离 = 1 - |corr|，对角置 0
Z = linkage(squareform(D), method);     % method ∈ {complete, average}
lab = cluster(Z, 2);          % 割树成 2 组
```
