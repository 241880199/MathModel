# 方差分析（`anova.m`）

> **要比较三个以上组的均值是否有差异时用**：把总变异分解为"组间"与"组内"，用 `F` 检验判断组均值是否齐；单因素 / 双因素。

**归属**：类索引 `references/statistics.md` · 骨架 `assets/matlab/statistics/anova.m` · 参照 `tests/skills/model-select/verify/anova.md`。
★ **骨架与参照由本模块 Task 2 产出**（`statistics` 类的 `补` 项）—— **本文件只写六格，不重做骨架 / 参照**。
★ **与相邻方法的边界**：**两组**比较用 t 检验 ⇒ `references/statistics/hypothesis_test.md`；要看**哪个因素影响大**（无 `p` 值）⇒ `references/statistics/grey_relational.md`。

## ① 适用判据

- **用**：要**比较三个以上组的均值**（如三种工艺、四个地区）；因素可**单因素**（一个自变量）或**多因素**（含交互）；关心"组间差异是否显著"。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **只有两组** ⇒ 用 t 检验（ANOVA 对两组与 t 检验等价，但直接 t 更简洁）。
  2. **要判断哪个因素影响更大而无 `p` 值** ⇒ 走 `grey_relational`。
  3. **组内不独立 / 方差不齐** ⇒ `F` 失真，应用 Welch ANOVA / 非参数（Kruskal-Wallis）（凭经验）。
  4. **数据严重非正态且样本小** ⇒ 用非参数方差分析（凭经验）。
  5. **配对 / 重复测量** ⇒ 用重复测量 ANOVA，别用独立样本版（凭经验）。

## ② 标准建模步骤

1. **定因素与水平**：单因素（`k` 组）或多因素（因素 A × 因素 B）；每组样本数。
2. **查前提**：正态、方差齐、独立。
3. **算平方和**：`SSB = Σ_i n_i (x̄_i − x̄)^2`、`SSW = Σ_i Σ_j (x_ij − x̄_i)^2`；`F = (SSB/(k−1)) / (SSW/(N−k))`。
4. **求 `p`**：`p = 1 − F_cdf(F; k−1, N−k)`；`p < alpha` ⇒ 拒绝"各组均值齐"。
5. **事后多重比较**：显著后做 `multcompare` 找**哪几组**不同（并校正）。
6. **数值验证**（★ 见 ⑥）：对**已知组均值**的合成数据核**拒绝率** + `F` 与手算平方和分解对照。
7. **报告**：ANOVA 表（`SS`/`df`/`MS`/`F`/`p`）+ 组均值图 + 事后比较。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 观测值 · 分组标签 · 因素个数 · 显著性水平 `alpha` |
| **输出** | `SSB`/`SSW`/`F`/`p` · 组均值 · 事后比较结果 |

**显式假设（必须写进论文）**：
1. **独立性**：观测相互独立。
2. **正态性**：各组内近似正态（或大样本）。
3. **方差齐性**：各组方差近似相等。
4. **`H0`**：各组**真均值相等**；`F` 检验是**单侧**（方差比）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿"跑通"当"算对"**：`F` 对不对要拿**手算平方和**核。**实测**（本骨架）：`anova1` 返回 `F = 0.451395878` 与手算 `SSB/SSW` 分解**逐位相同**；见 `verify/anova.md`。
2. ★ **拿 MATLAB 内置当"独立参照"**：`anova1`/`anova2` 是内置、**不独立**（任务书 B）—— 参照是**名义拒绝率 + 手算平方和定义式**。
3. **只做 ANOVA 不做事后比较**：拒绝 `H0` 只说明"至少有两组不同"，**没说哪两组**（凭经验）。
4. **方差不齐 / 非正态仍套**：`F` 检验前提破 ⇒ 结论不可靠（凭经验）。
5. **把"不显著"当"相等"**：`p > alpha` 只是"证据不足"，不是"证明了相等"（凭经验）。
