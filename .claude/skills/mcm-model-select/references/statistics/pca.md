# 主成分分析 PCA（`pca.m`）

> **多变量降维、只看主要变异方向时用**：把 p 个相关变量线性组合成少数几个**互不相关**的主成分，用前几个解释绝大部分方差；常作降维 / 去相关 / 综合排序的前置。

**归属**：类索引 `references/statistics.md` · 骨架 `assets/matlab/statistics/pca.m` · 参照 `tests/skills/model-select/verify/pca.md`。
★ **与相邻方法的边界**：要**保留可解释的因子结构**（有隐因子假设）⇒ `references/ml/factor_analysis.md`；要**做非线性降维**（t-SNE）⇒ `references/ml/dim_reduction.md`；要**按组分类**⇒ `references/ml/clustering.md`。

## ① 适用判据

- **用**：**变量多且彼此相关**、要**压缩成少数综合指标**；要**看哪几个方向承载主要变异**；要把相关变量**去相关**后再喂给回归 / 评价模型；指标之间存在共线、想要**客观的维度结构**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要外推未来值** ⇒ 走 `prediction`（PCA 是描述性降维，不做预测）。
  2. **要有明确物理意义的少数因子** ⇒ 走 `factor_analysis`（PCA 的主成分是数据驱动的组合，**未必可解释**）。
  3. **变量量纲差异大而不标准化** ⇒ 方差大的量纲**垄断**主成分（应先 z-score，凭经验）。
  4. **样本量太小**（`n` 与 `p` 相当或更小） ⇒ 主方向不稳定、易过拟合（凭经验）。
  5. **变量与主成分是非线性关系** ⇒ 线性 PCA 抓不住（改用核 PCA / t-SNE，凭经验）。

## ② 标准建模步骤

1. **选变量、定方向**：列出相关变量；各变量**同向化**（成本型先取负）。
2. **标准化**：逐列 `z-score`（`(x − x̄)/s`）—— ★ 量纲不一必须做。
3. **算相关 / 协方差矩阵**，对其做**特征分解**（或 `svd`）。
4. **排序**：按特征值**降序**排；取前 `k` 个主成分说明解释方差比。
5. **定 `k`**：累计解释方差比 ≥ 阈值（如 85%）或 Kaiser 准则（特征值 > 1）。
6. **算载荷 / 得分**：`载荷 = 特征向量 × sqrt(特征值)`；得分 = 标准化数据投影到主成分。
7. **数值验证**（★ 见 ⑥）：对**已知主方向 / 已知特征值**的合成数据，核样本特征分解能否还原。
8. **报告**：解释方差比表 + 载荷表 + 主成分得分（供下一步排序 / 回归用）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 数据矩阵 `X`（n 样本 × p 变量，须同向、数值）· 是否标准化 · 选取主成分个数 `k` 的准则 |
| **输出** | 特征值 · 解释方差比（+ 累计）· 载荷矩阵 · 主成分得分 |

**显式假设（必须写进论文）**：
1. **线性**：主成分是原始变量的**线性**组合。
2. **方差大 = 信息多**：用方差大小代表重要性（这条假设本身可被质疑）。
3. **标准化**：量纲不一必须 z-score —— ★ **这改变结果**，须与"不标准化"区分说明。
4. **特征向量符号任意**：整体取反仍是同一主方向；**重根时子空间不定**（方向不唯一）。
5. **样本代表总体**：主方向由样本估计，`n` 太小时不稳。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿"跑通"当"算对"**：特征分解必出结果，但方向对不对要拿参照核。**实测**（本骨架，`n = 5000`，20 种子）：对**已知主方向 30 deg**的合成数据，还原夹角误差 **< 0.5 deg**、`|cos| = 0.99995`；见 `verify/pca.md`。
2. ★★ **不标准化**：量纲大的变量垄断主成分（凭经验；本骨架算例两个变量同量纲，故未标准化也不致错，但实战常翻车）。
3. ★ **特征向量符号弄反 / 重根下方向跳**：符号是任意的，别把它当"算错"；重根时**方向本就不唯一**（实测：本骨架对 v1 做**符号规范化**后再算夹角）。
4. **主成分的命名过度解读**：主成分是数据驱动的组合，**未必有物理意义**（凭经验；想要可解释性走 factor_analysis）。
5. **拿 MATLAB 内置 `pca` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架的参照是**已知构造**（`verify/pca.md` 明写内置只作实现一致性对照）。
6. **只看前几个主成分、丢了尾部结构**：可能是噪声，也可能是关键小方差方向（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/statistics/pca.m`（**零参可跑**，自带算例：已知主方向 30 deg、已知特征值 `[4 1]` 的合成数据，20 种子）。

关键片段（**不整份复制**）：
```matlab
v1 = [cosd(theta); sind(theta)];  V = [v1, [-sind(theta); cosd(theta)]];
Sigma = V * diag(L_true) * V';    C = chol(Sigma);   X = Z * C;   % 已知总体协方差
S = cov(X);  [Vh, D] = eig(S);    lam = diag(D);
[lam, ord] = sort(lam, 'descend');  Vh = Vh(:, ord);  % ★ 排序 + 符号规范化
```
