# 神经网络分类（BP / LVQ / PNN）（`nn_classify.m`）

> **关系强非线性、类别边界写不出解析式时用**：用前馈网（BP）从特征矩阵里学一个**非线性判别边界**，输出**类别标签**。代价是**结果随初值随机**、要**固定种子 + 给多次运行的分布**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/nn_classify.m` · 参照 `tests/skills/model-select/verify/nn_classify.md`。
★ **与 `prediction` 的边界（类索引写死）**：本方法是**类别判别**（输出**类别**，管「分到哪一类」）；`references/prediction/nn_forecast.md` 的**神经网络预测**管「**序列 / 函数预测**」（输出**连续值**）—— 两处互不越界。★ **要外推未来值 ⇒ 走 `prediction`**。
★ **与相邻方法的边界**：线性可分的边界、要**可解释的系数** ⇒ `references/statistics/` 或 `references/ml/discriminant.md`（判别分析给显式判别函数）；要**最大间隔 / 小样本** ⇒ `references/ml/svm_classify.md`；要**单隐层极快训练** ⇒ `references/ml/elm.md`。

## ① 适用判据

- **用**：特征到类别的映射**强非线性**（如**径向、异或、流形**型边界），解析判别式难设；样本量**较大**（相对参数量）；允许**黑箱**、只要**分类准**而不强调解释；多类问题（一对多 / softmax 输出）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要外推未来值 / 预测序列** ⇒ 走 `prediction`（`nn_forecast`），本方法只给类别。
  2. **样本很少**（几十个点）⇒ 过拟合、结果不可靠（凭经验）。
  3. **类别边界本就是线性的、且要可解释** ⇒ 用判别分析 / 逻辑回归（凭经验；本骨架实测：在**线性**可分的等协方差类上，线性 LS 分类器已到贝叶斯（见 `verify/elm.md` 的线性对照），网络买不到额外精度却丢掉可解释性）。
  4. **类别极不平衡而不处置** ⇒ 网络偏向多数类（凭经验）。
  5. **不做标准化 / 不固定种子就报数** ⇒ 结果逐次不同、不可复现（凭经验；网络权重的随机初始化会改变结果）。

## ② 标准建模步骤

1. **定任务**：确认是**分类**（离散标签）不是回归 / 预测；列出**特征矩阵**与**类别标签**。
2. **预处理**：特征**标准化 / 归一化**；类别做 **one-hot**；**划分训练 / 验证 / 测试**。
3. **定结构**：隐层数 / 每层神经元数（小样本宜浅）；激活（隐层 `tanh`/`ReLU`，输出 `softmax`）。
4. **训练**：反向传播类优化（本骨架用内置 `fitcnet`）；**固定随机种子**。
5. **早停 / 正则**：按验证集误差早停，或加权衰减，防过拟合。
6. **评估**：在**独立测试集**上算**准确率 / 混淆矩阵**；★ 与**已知边界**或线性基线对比。
7. **数值验证**（★ 见 ⑥）：对**已知类别边界**的合成数据核准确率是否达到理论水平。
8. **报告**：准确率 + 混淆矩阵 + 网络结构 + 种子（可复现性）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 特征矩阵 `X`（n 样本 × p 特征，须预处理）· 标签 `Y`（多类）· 网络结构（隐层 / 神经元数）· 训练轮数 |
| **输出** | 预测类别 · 各类概率 · 准确率 / 混淆矩阵 |

**显式假设（必须写进论文）**：
1. **样本独立同分布**，训练 / 测试同分布。
2. **特征已标准化**（否则量纲大的变量主导梯度）。
3. **边界可由网络表示**（足够宽的网络理论上能逼近任意连续边界，但**有限样本下不保证**）。
4. **随机初始化**：结果**依赖种子** ⇒ 必须**固定种子**并给**多次运行的分布**。
5. **类别标签的语义**由人给定，网络只学映射，**不解释"为什么"**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿线性模型去套非线性边界**：**实测**（本骨架，2 维**径向边界**：内盘 `r ≤ 1.5` vs 外环 `2.0..3.2`）：网络测试准确率 **`0.9999 ± 0.0002`**（5 种子），而**线性分类器**（`fitclinear`）只有 **`0.6113`**（见 `verify/nn_classify.md`）。差异 = 边界形态。
2. ★ **不固定种子就报数**：结果逐次不同（权重随机初始化）。**实测**：本骨架对 `seeds = 1:5` 逐种子给读数并给 `mean ± sd`（不是跑一次）。
3. ★★ **拿 MATLAB 内置 `fitcnet` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写** `fitcnet` **只作实现**，参照是**已知径向边界**（`verify/nn_classify.md`）。
4. **样本少 → 过拟合**：网络参数量远超样本量时，训练准确率高而测试差（凭经验）。
5. **不做标准化**：特征量纲差异大时训练慢、易陷局部极小（凭经验）。
6. **把类别概率当"置信度"过度解读**：未校准的 softmax 输出**不是概率**（凭经验）。
