# 降维：t-SNE / UMAP（`dim_reduction.m`）

> **要把高维数据压到 2 维、只看"谁和谁挨着"时用**：t-SNE 保**局部邻域**、把点摊到低维便于**可视化**；UMAP 是它的近似替代（**MATLAB 无内置**）。代价是**非确定性、无 ground-truth 输出**（"看上去分开了"不是判据）。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/dim_reduction.m` · 参照 `tests/skills/model-select/verify/dim_reduction.md`（**承接 Task 3，读数一致**）。
★ **低使用度提示（类索引 + P5 · 不许写成"常用"）**：`t-SNE` / `UMAP` 在 2025 O 奖语料里 **0 命中** ⇒ **本方法属低使用度**、照补是为**覆盖面**，**不是高频需求**。
★ **与相邻方法的边界**：要**线性、可解释的降维 / 去相关** ⇒ `references/statistics/pca.md`；要**找隐因子**（有因子模型假设）⇒ `references/ml/factor_analysis.md`；要**分簇**（不只要看）⇒ `references/ml/clustering.md`。

## ① 适用判据

- **用**：高维数据的**可视化**（摊到 2 维看**局部邻域 / 分群**）；探索性分析、给聚类 / 分类作**前置观察**；t-SNE 对**非线性流形**较好。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要可解释的坐标 / 要拿去喂下游模型** ⇒ 用 **PCA**（t-SNE 轴**无物理意义**、坐标不可复用）（凭经验）。
  2. **要把降维结果当特征** ⇒ t-SNE **不保全局结构**（簇间距离别解读）（凭经验）。
  3. **样本很多**（上万）⇒ t-SNE `O(n²)` 很慢（凭经验）。
  4. **想要"稳定复现"** ⇒ t-SNE **非确定性** ⇒ 必须**固定种子**并给多次运行（凭经验；本骨架对 5 个种子给分布）。
  5. **要 UMAP** ⇒ **MATLAB 无内置**（`which('umap')` 实测为空）⇒ 需外部包（本骨架**只给 t-SNE**，**不假装有 UMAP**）。

## ② 标准建模步骤

1. **定任务**：确认是**可视化 / 探索**（不是要可解释特征）。
2. **预处理**：特征标准化；高维先 **PCA 降噪**再喂 t-SNE（常见做法，凭经验）。
3. **定困惑度 `Perplexity`**：近似"邻域大小"（常用 5–50）；★ 显式声明。
4. **跑嵌入**：`tsne(X, 'NumDimensions', 2, 'Perplexity', p)`（★ **固定种子**）。
5. **多次运行**：换种子看嵌入**是否稳定**（给分布）。
6. **评估**：★ **无 ground-truth** ⇒ 用**替代量**：**邻域保持率（kNN 一致性）**、已知簇的**纯度 / 轮廓系数**（**替代品，不是等价物**）。
7. **报告**：2 维散点 + 种子 + 困惑度 +（已知簇时）纯度。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 高维数据 `X`（n×p，须标准化）· 目标维度 · 困惑度 `Perplexity` · 随机种子 |
| **输出** | 低维嵌入 `Y`（n×2）·（替代量）kNN 一致性 / 纯度 / 轮廓系数 |

**显式假设（必须写进论文）**：
1. **局部邻域比全局结构更重要**（t-SNE 的目标函数）。
2. **困惑度是外生选择**（改变嵌入形态）。
3. **嵌入非确定性**：必须固定种子；否则不可复现。
4. **低维坐标无度量意义**：轴无物理含义、簇间距离别解读。
5. **无 ground-truth**：本方法**没有"对的嵌入"**（见 ④）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **把"看上去分开了"当"算对了"**：t-SNE **没有 ground-truth 输出** ⇒ 不能声称"已验证"（设计 §4.1）。**实测**（本骨架，3 簇合成流形，`d = 10`、`k = 10`、`perp = 30`）：**kNN 一致性 `0.4673 ± 0.0059`**（5 种子）—— 这是**相对量**（t-SNE 为换全局结构会重排簇内次序，**天然 < 1**），**只作对照、不设通过阈值**。
2. ★ **不固定种子就报图**：嵌入逐次不同。**实测**：`rng(seed)` 后 `tsne` **逐位可复现**（同种子跑两次 `max|diff| = 0`）；本骨架逐 5 个种子给分布。
3. ★ **把降维结果当特征喂模型 / 解读簇间距离**：t-SNE **不保全局结构**（凭经验）。
4. ★★ **本项参照是"人工兜底"，不是"已验证"**：**明写** —— 参照走 **已知簇结构 + 邻域保持率（kNN 一致性）**（设计 §4.1 的兜底）；**邻域保持率是替代品、不是等价物**（它量的是"局部相对保序"，不是"t-SNE 对不对"）。
5. **样本多就慢**：`O(n²)` 的邻域计算（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/ml/dim_reduction.m`（**零参可跑**，自带算例：3 个高斯簇、`d = 10`、每簇 90 点、簇心 `6·e_j`；逐 5 种子给 kNN 一致性分布；**承接 Task 3，不重做**）。

关键片段（**不整份复制**）：
```matlab
rng(seeds(s));                       % ★ t-SNE 非确定性 ⇒ 固定种子
Y = tsne(X, 'NumDimensions', 2, 'Perplexity', perp, 'Verbose', 0);
% 邻域保持率（kNN 一致性）：原空间 k 近邻有多少在对偶嵌入里仍是 k 近邻
c = 0; for i = 1:size(X,1); c = c + numel(intersect(idxX(i,:), idxY(i,:))) / k; end
```
