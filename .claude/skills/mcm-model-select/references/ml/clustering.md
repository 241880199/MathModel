# 聚类（K-means / 模糊 C-means）（`clustering.m`）

> **要把样本分成若干簇、但**没有标签**时用**：K-means 迭代重心把点分到最近的簇；模糊 C-means 给每个点一个**隶属度**（柔性地属于各簇）。代价是**要预设簇数 `k`**（K-means）或**给隶属度阈值**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/clustering.m` · 参照 `tests/skills/model-select/verify/clustering.md`。
★★ **去重口径（类索引写死）**：**层次聚类不列本类** —— 它的正条目在 `references/statistics/hierarchical_cluster.md`（自底向上合并、不必预设 `k`、给树状图）。**本类「聚类」= K-means / 模糊 C-means**（**要预设 `k`、迭代重心**）。
★ **另一条边界**：要**找观测变量背后的潜在因子**（解释协方差结构）⇒ `references/ml/factor_analysis.md`；要**非线性降维可视化** ⇒ `references/ml/dim_reduction.md`；**有标签**的归类 ⇒ `references/ml/discriminant.md`。

## ① 适用判据

- **用**：**无标签**、要按"相似性"把样本**分成若干簇**；要**簇数与簇心**；样本量中大（K-means 快）；**允许一个点到某簇是"程度"而非"硬归属"** ⇒ 模糊 C-means（给隶属度）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **不预设 `k`、要看层次 / 嵌套结构** ⇒ `references/statistics/hierarchical_cluster.md`（本类要预设 `k`）。
  2. **要聚的是"变量"**（看指标间相关结构，R 型）⇒ `references/statistics/var_cluster.md`。
  3. **有标签、要归类规则** ⇒ 判别分析（本方法是**无监督**）。
  4. **簇非凸 / 环状 / 密度不均** ⇒ K-means 假设**球形等大小簇**，会切错（凭经验；改密度聚类 / 谱聚类）。
  5. **不标准化** ⇒ 量纲大的特征主导欧氏距离（凭经验）。
  6. **`k` 乱定**：K-means 的 `k` 是**外生选择**，定错则结果无意义（凭经验）。

## ② 标准建模步骤

1. **定任务**：确认**无标签**、聚类对象是**样本**（Q 型）。
2. **预处理**：**标准化**特征（量纲不一必须做）；必要时去离群点。
3. **定簇数**：K-means 要预设 `k` —— 用**轮廓系数 / 肘部法 / 领域知识**；★ **`k` 已知**与**`k` 未知**是两种情形，分开报。
4. **算法**：K-means（迭代重心）或模糊 C-means（隶属度，给**划分系数**）。
5. **多次重启**：K-means 对初值敏感 ⇒ **多重复制**取最优（本骨架 `'Replicates', 10`）。
6. **评估**：若**真簇已知**（合成）⇒ **还原率（对标签置换不变）+ 质心误差**；否则 ⇒ 轮廓系数 / 簇内平方和。
7. **数值验证**（★ 见 ⑥）：对**已知簇结构**的合成数据核还原率与质心。
8. **报告**：簇成员表 + 各簇中心 + 簇数选择依据（+ 模糊情形给隶属度）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 样本矩阵 `X`（n×p，须标准化）· 簇数 `k` ·（FCM）模糊指数 `m` · 距离度量 |
| **输出** | 簇标签（K-means）· 簇中心 ·（FCM）隶属度矩阵 `U` |

**显式假设（必须写进论文）**：
1. **簇数 `k` 已知或已定**（K-means 的外生输入；`k` 未知须另择法）。
2. **簇近似球形、大小相近**（K-means 的几何前提；否则会误分）。
3. **特征已标准化**，距离度量已选定。
4. **距离能代表"相似"**（选错度量则分群无意义）。
5. **FCM 的模糊指数 `m`**（软硬程度）是**外生选择**；隶属度**不是概率**（凭经验）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **不预设 `k`、直接跑 K-means**：`k` 是外生输入。**实测**（本骨架，`K = 3` 已知高斯簇，`sep = 5`）：`k` **未知**时用**轮廓系数**在 `k = 1..6` 上选，5 种子**全部选回 `k = 3`**（`verify/clustering.md`）—— 即"`k` 未知"要靠选择准则补，不能白得。
2. ★ **`k` 已知时看还原率**：**实测**：K-means 簇分配**还原率 `1.0000`**（5 种子全对，对标签置换不变），**匹配后质心最大误差 `0.1255`**；FCM 还原率同为 `1.0000`。
3. ★ **模糊 C-means 只看硬标签、丢隶属度**：**实测**：FCM 在已知 3 簇上**划分系数 `PC = 0.9058`**（5 种子；`PC = (1/n) Σ u²`，越接近 1 越硬）—— 隶属度**是一个可读的量**，别只取 `argmax`。
4. ★★ **拿 MATLAB 内置 `kmeans` / `fcm` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写**它们**只作实现**，参照是**已知簇结构**（`verify/clustering.md`）。
5. **初值敏感**：单次 K-means 可能陷局部最优 ⇒ 用多重复制（本骨架 `Replicates = 10`，凭经验）。
6. **不标准化**：量纲大的特征主导欧氏距离（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/ml/clustering.m`（**零参可跑**，自带算例：`K = 3` 个**中心已知**、等大小的高斯簇（`sep = 5`），K-means 与 FCM 各跑，`k` 未知用轮廓系数在 `k = 1..6` 上选；5 种子）。

关键片段（**不整份复制**）：
```matlab
[lab, C] = kmeans(X, K, 'Replicates', 10);          % ★ k 已知
ev = evalclusters(X, 'kmeans', 'silhouette', 'KList', 1:6);   % ★ k 未知：轮廓系数选 k
[~, U] = fcm(X, K, [2, 100, 1e-5, 0]);              % FCM 隶属度 U（c×n，列和为 1）
pc = sum(U(:).^2) / size(X, 1);                     % 划分系数（越接近 1 越硬）
```
