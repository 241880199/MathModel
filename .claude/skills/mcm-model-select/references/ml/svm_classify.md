# SVM 分类（`svm_classify.m`）

> **要"最大间隔"、样本中小、边界可能非线性时用**：找一个**间隔最大**的分界（线性）或用**核函数**把它升到高维再线性分（非线性），对**高维、小样本**稳健。代价是**要调核与惩罚系数**、结果**可解释性弱**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/svm_classify.m` · 参照 `tests/skills/model-select/verify/svm_classify.md`。
★ **与相邻方法的边界**：因变量是**连续值**（回归）⇒ `references/ml/svm_regress.md`；要**可解释的显式判别函数** ⇒ `references/ml/discriminant.md`；样本**很大**且只要准 ⇒ 神经网络 / 集成树（凭经验）；要**外推未来** ⇒ `prediction`。

## ① 适用判据

- **用**：**二分类**（或多类拆二）；特征维度**高**、样本**中小**；边界**可能非线性**（用核）；要**泛化好**、容忍**黑箱**；类别**近似可分**（允许少量越界点，靠惩罚系数 `C` 权衡）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要外推未来值** ⇒ `prediction`（本方法只做判别）。
  2. **要可解释的判别式 / 概率** ⇒ 判别分析（`discriminant`）给显式线性 / 二次判别函数（凭经验）。
  3. **样本极多**（上万 × 高维）⇒ 核方法训练代价高，改线性模型或神经网络（凭经验）。
  4. **类别严重重叠、无间隔可言** ⇒ 最大间隔假设失效，须靠软间隔 + 交叉验证，且未必优于其它法（凭经验）。
  5. **不做标准化就用核** ⇒ 特征尺度主导核距离（凭经验）。

## ② 标准建模步骤

1. **定任务**：确认**二分类**；列出特征矩阵与标签（`±1` / 两类）。
2. **预处理**：特征**标准化**；类别编码。
3. **选核**：线性可分 ⇒ 线性核；非线性 ⇒ **RBF 核**（把数据映到无穷维）。
4. **定超参**：惩罚系数 `C`（间隔软硬）、核尺度 `σ`（RBF 带宽）；用**交叉验证**选。
5. **训练**：解二次规划 / SMO（本骨架用内置 `fitcsvm`）。
6. **评估**：**独立测试集**准确率 / 混淆矩阵；★ 与**已知边界**或线性基线对比。
7. **数值验证**（★ 见 ⑥）：对有**已知边界**的合成数据核准确率。
8. **报告**：准确率 / 混淆矩阵 + 核与超参 + 支持向量数。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 特征矩阵 `X`（须标准化）· 标签 `Y`（二类）· 核函数 · 惩罚系数 `C` · 核尺度 |
| **输出** | 预测标签 · 决策函数值 · 支持向量 · 准确率 |

**显式假设（必须写进论文）**：
1. **类别近似可分**：允许少量越界（软间隔）。
2. **核已选对**：核形状是**外生选择**，选错等于模型设定错。
3. **特征已标准化**（核距离对尺度敏感）。
4. **超参由交叉验证定**，不是拍脑袋（`C` 与核尺度）。
5. **二分类**：多类须**拆一对多 / 一对一**，本骨架只做二分类。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **拿线性 SVM 去分非线性边界**：**实测**（本骨架，XOR：`y = sign(x1*x2)` 的**已知非线性边界**，无噪声 ⇒ 贝叶斯准确率 = 1.0）：**线性** SVM 准确率 **`0.5488`**（≈ 随机），**RBF** 核 SVM **`0.9481`**（5 种子）。核不是可有可无的。
2. ★ **不标准化就用 RBF 核**：特征尺度差异会被核距离放大（凭经验）。
3. ★ **超参不调**：`C` / 核尺度凭默认易欠拟合或过拟合（凭经验；本骨架用 `KernelScale = 'auto'` 作默认示范）。
4. ★★ **拿 MATLAB 内置 `fitcsvm` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写** `fitcsvm` **只作实现**，参照是**已知边界 / 闭式贝叶斯误差**（`verify/svm_classify.md`）。
5. **只报准确率、不看类别不平衡**：少数类被牺牲时准确率仍高（凭经验；应看查全 / 混淆矩阵）。
