# 因子分析（`factor_analysis.m`）

> **要找一堆相关观测变量背后的少数**潜在因子**时用**：假设 `X = F Λ' + E`，用少数公共因子 + 各自独特噪声解释变量间的相关结构。代价是**因子解只定到旋转**、**因子个数要选**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/factor_analysis.m` · 参照 `tests/skills/model-select/verify/factor_analysis.md`（**承接 Task 3，读数一致**）。
★ **与相邻方法的边界**：只要**方差最大的综合方向**（不假设隐因子）⇒ `references/statistics/pca.md`；要**把样本分簇** ⇒ `references/ml/clustering.md`；要**非线性降维可视化** ⇒ `references/ml/dim_reduction.md`；要**有标签的归类** ⇒ `references/ml/discriminant.md`。

## ① 适用判据

- **用**：多个观测变量**彼此相关**、假设背后有**少数公共因子**；要**解释变量的相关结构 / 结构效度**；要**降维且想给因子命名**（旋转后载荷可解释）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **只要降维、不要隐因子解释** ⇒ **PCA** 更直接（PCA 是主成分，因子分析**有因子模型假设**）（凭经验）。
  2. **变量数与样本数不匹配**（`n` 太小相对 `p`）⇒ 载荷不稳、需大样本（本骨架用 `n = 2000` 才稳，凭经验）。
  3. **变量基本不相关** ⇒ 无公共因子可提取（凭经验）。
  4. **要唯一的因子解** ⇒ **因子解只定到正交 / 斜交旋转**（本骨架明写"不假装唯一"）。
  5. **要外推未来值** ⇒ `prediction`（本方法是描述性结构分析）。

## ② 标准建模步骤

1. **定任务**：确认要找**潜因子**、变量间**相关**。
2. **预处理**：标准化（本骨架令**变量方差 = 1**，使内置 `factoran` 的内部标准化成为恒等，载荷才直接对得上真值）。
3. **选因子数 `k`**：按累计方差 / 特征值 / 平行分析；★ **显式声明**。
4. **估载荷**：极大似然 / 主因子法（本骨架用内置 `factoran`）。
5. **旋转**：正交（varimax）或斜交 ⇒ **给可解释的载荷**；★ 说明旋转方式。
6. **评估**：**公因子方差**（行范数 `‖Λ_i‖²`，**旋转不变**）+ 载荷（旋转对齐后比）。
7. **数值验证**（★ 见 ⑥）：对**已知载荷**的合成数据核载荷 / 公因子方差能否复原。
8. **报告**：载荷表 + 公因子方差 + 因子命名 + 旋转说明。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 数据矩阵 `X`（n×p，须标准化）· 因子数 `k` · 旋转方式 |
| **输出** | 载荷 `Λ` · 公因子方差 · 唯一性 `Ψ` · 因子得分 |

**显式假设（必须写进论文）**：
1. **线性因子模型** `X = F Λ' + E`（公共因子 + 独特噪声）。
2. **公共因子** `F ~ N(0, I_k)`、**独特噪声** `E` 互不相关、且与 `F` 不相关。
3. **因子数 `k`** 外生选择。
4. **因子解只定到旋转**：载荷不唯一，只有**旋转不变量**（公因子方差）才有唯一意义。
5. **标准化**：量纲不一必须做（本骨架令方差 = 1）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把载荷当唯一解**：因子解**只定到旋转**。**实测**（本骨架，`p = 6`、`k = 2`、`n = 2000`）：**公因子方差**（旋转不变）5 种子 `max|diff| = 0.0335 ± 0.0119`（`seed = 0` 时 `0.0252`），而**载荷**必须**旋转对齐**后才比（`0.0289 ± 0.0061`）—— 且对齐行只是**一致性核对**，**独立验证在公因子方差行**（`verify/factor_analysis.md`）。
2. ★ **不令方差 = 1 就比载荷**：内置 `factoran` **内部会标准化**（实测：`factoran(X,…)` 与 `factoran(zscore(X),…)` 至 `~1e-12` 量级相同、**非逐位相同**）⇒ 令方差 = 1 后这一标准化成为恒等，公因子方差才降到 `~0.03`（初版非单位方差曾到 `0.14`）（`verify/factor_analysis.md`）。
3. ★★ **拿 MATLAB 内置 `factoran` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写** `factoran` **只作实现**，参照是**已知载荷**（`verify/factor_analysis.md`）。
4. **因子数选错**：`k` 太大过拟合、太小漏结构（凭经验）。
5. **给因子过度命名**：旋转后的载荷才有可解释性，且命名是**主观**的（凭经验）。

## ⑤ 输出模板

- 表 → `mcm-table`（`.claude/skills/mcm-table/`）；载荷热图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）。
