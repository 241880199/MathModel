# 极限学习机 ELM（`elm.m`）

> **要一个单隐层、训练极快的非线性分类 / 回归器时用**：隐层权重**随机给定不训练**，只解输出层的**线性最小二乘**（本骨架用岭回归），一次闭式求解就完事。代价是**随机隐层未优化** ⇒ 要多试隐层规模、给多次运行的分布。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/elm.m` · 参照 `tests/skills/model-select/verify/elm.md`。
★ **与相邻方法的边界**：要**用 BP 迭代训练**、隐层可学 ⇒ `references/ml/nn_classify.md`；要**最大间隔 / 小样本** ⇒ `references/ml/svm_classify.md`；要**显式可解释判别式** ⇒ `references/ml/discriminant.md`；要**外推未来** ⇒ `prediction`。

## ① 适用判据

- **用**：关系**非线性**、要**极快训练**（无迭代，一次线性求解）；样本量中 / 大；单隐层够用（配合随机特征近似任意连续边界）；同一数据要**反复重训**（如交叉验证 / 集成）时省时间。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要隐层表达可学 / 要最低误差** ⇒ 常规 BP 网络或 SVM（隐层随机、未优化，理论上限低于可学网络）（凭经验）。
  2. **样本很少** ⇒ 随机隐层方差大、结果不稳（凭经验）。
  3. **要可解释** ⇒ 随机投影**几乎不可解释**（凭经验）。
  4. **极端非线性 / 复杂流形** ⇒ 单隐层随机特征数需要很大才能逼近（凭经验）。
  5. **要外推未来值 / 序列预测** ⇒ `prediction`（本方法是判别 / 函数回归）。

## ② 标准建模步骤

1. **定任务**：确认是**分类**（本骨架）或**回归**（同类做法，输出层换线性）。
2. **预处理**：特征**标准化**；类别做 **one-hot**。
3. **定隐层规模 `L`**：隐层神经元数（超参，靠验证集 / 多次试验定）。
4. **随机隐层**：`H = g(X·W + b)`，`W, b` **随机给定且不训练**（★ 固定种子）。
5. **解输出权重**：`β = (HᵀH + λI)⁻¹ Hᵀ T`（岭回归，`λ` 防奇异）。
6. **评估**：**独立测试集**准确率（或回归 RMSE）；★ 与**已知边界**对比。
7. **数值验证**（★ 见 ⑥）：对**已知类别边界 / 已知贝叶斯误差**的合成数据核达标。
8. **报告**：准确率 + 隐层规模 `L` + 种子（可复现性）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 特征矩阵 `X`（须标准化）· 标签 `T`（one-hot）· 隐层规模 `L` · 岭系数 `λ` · 激活函数 |
| **输出** | 预测类别 · 隐层输出 `H` · 输出权重 `β` · 准确率 |

**显式假设（必须写进论文）**：
1. **随机隐层足以表达边界**（随机特征近似；`L` 越大越接近，但**有限 `L` 不保证**）。
2. **隐层权重不需要训练**（ELM 的核心假设；也是它的**局限**）。
3. **输出层线性可分**（在随机特征空间里）。
4. **`λ` 处置病态**（`HᵀH` 奇异时的岭正则）。
5. **特征已标准化**、类别已 one-hot。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **随机隐层 → 结果随种子变**：**实测**（本骨架，两等协方差高斯类、`Δ = 2`、`ntrain = 600/类`）：ELM 测试误差 **`0.1629 ± 0.0063`**（5 种子）—— 与贝叶斯最优 `0.1587` 同量级，但**逐种子有散布** ⇒ 必须给分布。
2. ★★ **拿"跑通"当"算对"**：ELM 必出结果（一次线性求解），但隐层随机、可能欠拟合。**实测**：本骨架用**线性最小二乘分类器**作独立对照（同一数据），得 `0.1588`（≈ 贝叶斯），与 ELM 的 `0.1629` 同量级 ⇒ 证明数据可解、ELM 没跑偏（`verify/elm.md`）。
3. ★ **隐层规模 `L` 不调**：太小欠拟合、太大过拟合 + 解 `β` 变病态（凭经验；`λ` 需配合）。
4. **不标准化**：随机隐层对尺度敏感（凭经验）。
5. **拿内置 / 自写当"独立"**：本骨架**自写 ELM**（MATLAB 无 `elm` 内置，`exist('elm') = 0`）—— 参照是**已知贝叶斯误差**，不是另一份代码（任务书 B）。

关键片段（**不整份复制**）：

```matlab
rng(seeds(s) + 1000);                       % ★ 隐层随机权重（固定种子，独立流）
W = randn(size(Xtr,2), L);  b = randn(1, L);
Htr = 1 ./ (1 + exp(-(Xtr*W + b)));         % sigmoid 隐层
beta = (Htr'*Htr + lambda*eye(L)) \ (Htr'*Ttr);   % ★ 一次闭式求解，无迭代
[~, yp] = max(Hte*beta, [], 2);             % 测试集判别
```
