# SVM 回归（`svm_regress.m`）

> **要拟合一个非线性、且不想过拟合的连续关系时用**：用 **ε-不敏感损失 + 核函数**做回归，只顾"误差超过 ε 的点"，对离群点与高维较稳健。代价是**要调核与 ε / C**、**可解释性弱**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/svm_regress.m` · 参照 `tests/skills/model-select/verify/svm_regress.md`。
★ **与相邻方法的边界**：因变量是**类别**（离散）⇒ `references/ml/svm_classify.md`；要**显式回归方程 / 可解释系数** ⇒ `references/prediction/regression.md`；要**外推未来时间点** ⇒ `prediction` 的序列方法（灰色 / 平滑 / ARIMA）。

## ① 适用判据

- **用**：**连续因变量**、与自变量**非线性**；样本中小；要**稳健**（ε-不敏感损失会**忽略小误差**，对离群点不敏感）；高维特征。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要外推未来时间点** ⇒ `prediction` 的序列方法（本方法是**输入→输出的函数回归**，不作时间外推）。
  2. **要显式、可解释的回归方程**（论文要报系数与显著性）⇒ 线性 / 广义线性回归（`prediction/regression`）（凭经验）。
  3. **关系本就线性、且要快** ⇒ 线性回归更简单（凭经验；本骨架实测：线性 SVR 对 **正弦**函数误差 `0.692`，远高于 RBF 的 `0.157` —— 但那是**模型形式不对**的代价，不是 SVR 本身的问题）。
  4. **不做标准化、不调 ε / C** ⇒ 结果对尺度与超参敏感（凭经验）。
  5. **样本极多**（上万）⇒ 核 SVR 训练代价高（凭经验）。

## ② 标准建模步骤

1. **定任务**：确认因变量**连续**、是**函数回归**不是时间外推。
2. **预处理**：自变量 / 因变量**标准化**。
3. **选核**：非线性 ⇒ **RBF**；近线性 ⇒ 线性核。
4. **定超参**：不敏感带 `ε`、惩罚系数 `C`、核尺度 `σ`；交叉验证选。
5. **训练**：解 SVR 对偶问题（本骨架用内置 `fitrsvm`）。
6. **评估**：**独立测试集**上算 **RMSE / MAE**；★ 与预期噪声底或线性基线对比。
7. **数值验证**（★ 见 ⑥）：对**已知函数**的合成数据核 RMSE 是否接近**噪声底**。
8. **报告**：RMSE / MAE + 散点-拟合图 + 核与超参。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 自变量 `X`（须标准化）· 因变量 `y`（连续）· 核函数 · `ε` · `C` · 核尺度 |
| **输出** | 预测值 · 支持向量 · RMSE / MAE |

**显式假设（必须写进论文）**：
1. **响应是输入的函数**（同一 `x` 对应一个分布），**不是时间序列**。
2. **ε-不敏感损失恰当**：小于 `ε` 的误差被忽略，是**建模选择**。
3. **核形状外生**：核与超参由人 / 交叉验证定。
4. **特征已标准化**。
5. **误差同方差近似**（异方差时须加权，凭经验）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把噪声底当"还能再降"**：**实测**（本骨架，已知 `f(x) = sin(2x)` + 噪声 `σ = 0.15`，测试目标是**新的含噪观测**）：RBF SVR 测试 RMSE **`0.1568 ± 0.0034`**（5 种子），**贴着噪声底 `0.15`** —— 再降**不可能**（测试噪声不可预测）。★ **另一型口径错**：若把测试目标换成**无噪声真函数**，好的平滑器 RMSE 会**低于 σ**（本骨架初版就栽在这：对真函数 RMSE 曾到 `0.034`）⇒ **报告前必须写清"RMSE 是对含噪观测还是对真函数"**。
2. ★★ **拿 MATLAB 内置 `fitrsvm` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写** `fitrsvm` **只作实现**，参照是**已知函数 + 噪声底**（`verify/svm_regress.md`）。
3. ★ **用错模型形式**：**实测**：线性 SVR 拟正弦 ⇒ RMSE `0.692`（≈ 3 倍标准差），远超 RBF 的 `0.157`；核选择不是装饰。
4. **不标准化**：尺度差异主导核距离（凭经验）。
5. **`ε` / `C` 不调**：过小 `ε` → 过拟合；过大 → 欠拟合（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/ml/svm_regress.m`（**零参可跑**，自带算例：已知 `f(x) = sin(2x)`，`x ∈ [-3,3]`，噪声 `σ = 0.15`；测试目标是**新的含噪观测** ⇒ 噪声底 `σ = 0.15`；5 种子）。

关键片段（**不整份复制**）：
```matlab
x  = -3 + 6*rand(ntrain,1);  y = sin(2*x) + sigma*randn(ntrain,1);
xte = -3 + 6*rand(ntest,1);  yte = sin(2*xte) + sigma*randn(ntest,1);   % ★ 新的含噪观测
mR = fitrsvm(x, y, 'KernelFunction','rbf', 'KernelScale','auto', 'Standardize',true);
mL = fitrsvm(x, y);                                   % 线性核对照
rmse = @(m) sqrt(mean((predict(m, xte) - yte).^2));
```
★ **撞名提醒**：本名字**无**顶层 `@svm_regress` 类目录撞名（实测 ⇒ 0）；`exist('svm_regress')` 实测 = 0（MATLAB 无同名内置）。
**独立参照**：`tests/skills/model-select/verify/svm_regress.md`（**第 4 类：已知函数的合成数据** —— RBF SVR RMSE `0.1568 ± 0.0034` vs 噪声底 `0.15`；线性对照 `0.6919`）。
