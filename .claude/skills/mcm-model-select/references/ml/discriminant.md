# 判别分析（`discriminant.m`）

> **有标签、要一个**显式判别规则**把新样本归类时用**：在已知类别上估**判别函数**（线性 LDA / 二次 QDA），直接给出归类规则与错误率。代价是**有分布假设**（高斯）、**要对协方差结构做选择**。

**归属**：类索引 `references/ml.md` · 骨架 `assets/matlab/ml/discriminant.m` · 参照 `tests/skills/model-select/verify/discriminant.md`（**承接 Task 3，读数一致**）。
★ **与相邻方法的边界**：要**最大间隔 / 小样本**、不假设分布 ⇒ `references/ml/svm_classify.md`；要**隐因子结构** ⇒ `references/ml/factor_analysis.md`；要**无标签分簇** ⇒ `references/ml/clustering.md`；要**测试组间差异** ⇒ `references/statistics/anova.md` / `hypothesis_test.md`（凭经验）。

## ① 适用判据

- **用**：**有标签**的分类 / 归类；要**显式、可解释的判别规则**（哪几个变量、什么方向）；各类**近似高斯**；线性判别（LDA）在**等协方差**下是**贝叶斯最优**；要给**错误率**的可信估计。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **类别边界强非线性、要最大间隔** ⇒ `references/ml/svm_classify.md` 或神经网络（凭经验）。
  2. **各类协方差差异大** ⇒ 用**二次判别（QDA）**而非线性（本骨架实测：等协方差下二次 ≈ 线性，`0.1661` vs `0.1658`；**这才是"该用线性"的证据**，`verify/discriminant.md`）。
  3. **样本量小相对变量数** ⇒ 协方差估计病态，需正则化 / 降维（凭经验）。
  4. **要外推未来值** ⇒ `prediction`。
  5. **类别极不平衡 / 先验差异大** ⇒ 须设先验，否则偏向多数类（凭经验）。

## ② 标准建模步骤

1. **定任务**：确认**有标签**、要**归类规则**。
2. **预处理**：**标准化**；检查各类**协方差是否相近**（决定线性 / 二次）。
3. **设先验**：按样本比例或领域知识。
4. **估判别**：线性（LDA，共享协方差）或二次（QDA，各自协方差）；本骨架用内置 `classify`。
5. **评估**：**独立测试集**错误率 / 混淆矩阵；★ 与**贝叶斯最优**比较。
6. **核选择**：等协方差 ⇒ 线性；否则二次。
7. **数值验证**（★ 见 ⑥）：对**已知类别 / 已知协方差**的合成数据核错误率是否对上贝叶斯。
8. **报告**：判别规则（线性系数 / 二次项）+ 错误率 / 混淆矩阵 + 先验。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 特征矩阵 `X`（n×p）· 类别 `Y` · 判别类型（线性 / 二次）· 先验 |
| **输出** | 判别规则（系数）· 预测类别 · 错误率 / 混淆矩阵 |

**显式假设（必须写进论文）**：
1. **各类近似高斯分布**（LDA/QDA 的分布前提）。
2. **线性判别假设共享协方差**（等协方差下 LDA 最优）；否则用二次。
3. **先验已知 / 由样本比例估**。
4. **样本独立同分布**。
5. **变量已被正确测量 / 标准化**；协方差估计需要足够样本。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **协方差结构选错**：**实测**（本骨架，两**等协方差**高斯类，`Δ = 2`、`d = 2`、`ntrain = 200/类`、`ntest = 2000/类`）：**线性**判别错误率 `0.1658 ± 0.0046`、**二次**判别 `0.1661` —— 等协方差下**二次不优于线性**（差异 `0.0003`），这**正是"该用线性"的证据**（`verify/discriminant.md`）。
2. ★★ **拿"跑通"当"算对"**：**实测**：线性判别错误率 `0.1658` 与**贝叶斯最优** `Φ(-Δ/2) = 0.1587` 相差 `0.007`（量级符合 `ntrain = 200/类` 的估计误差）—— 有**独立理论值**对照才叫算对。
3. ★★ **拿 MATLAB 内置 `classify` 当"独立参照"**：同机同实现**不独立**（任务书 B）—— 本骨架**明写** `classify` **只作实现**，参照是**闭式贝叶斯误差**（`verify/discriminant.md`）。
4. **样本量不足估协方差**：`p` 大时 LDA/QDA 协方差矩阵病态（凭经验）。
5. **先验照搬假设**：先验错则决策偏（凭经验）。
