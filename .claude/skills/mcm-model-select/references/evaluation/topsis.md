# TOPSIS（`topsis.m`）

> **按"离理想解的距离"排序**：把每个对象放到多指标空间里，谁离**正理想解**最近、离**负理想解**最远，谁最优。**不显式主观定权**（权重可等权、可外部给，常与熵权连用）。

**归属**：类索引 `references/evaluation.md` · 骨架 `assets/matlab/evaluation/topsis.m` · 参照 `tests/skills/model-select/verify/topsis.md`。
★ **骨架与参照由本模块 Task 2 产出**（`evaluation` 类的 `补` 项）—— **本文件只写六格，不重做骨架 / 参照**。

## ① 适用判据

- **用**：**多对象 × 多指标**、指标**可测数值**、既要排序又要**效益型/成本型混合**；或已有**客观权重**（熵权）想接一个排序器（EWM-TOPSIS）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **必须要主观/专家权重** ⇒ 走 AHP `references/evaluation/ahp.md`（或 AHP 定权 + TOPSIS 排序）。
  2. **指标高度相关** ⇒ 距离会被**重复计权**放大，应先**降维/去相关**（`statistics` 的 PCA）或换方法。
  3. **要"绝对水平"而非"相对排序"** ⇒ TOPSIS 只给**相对贴近度**，不能当绝对分。
  4. **指标数 ≫ 对象数**：贴近度会**挤向 0.5**、区分度差（凭经验）。

## ② 标准建模步骤

1. 建**决策矩阵 `X`**（m 对象 × n 指标），标各指标 benefit / cost。
2. **向量归一化**：`r_ij = x_ij / sqrt(Σ_i x_ij²)`（**须写明用的哪种归一化**）。
3. **加权**：`v_ij = w_j · r_ij`。
4. 定**正 / 负理想解** `v⁺, v⁻`（效益型取列 max/min，成本型反之）。
5. 算**欧氏距离** `D⁺_i = ‖v_i − v⁺‖`，`D⁻_i = ‖v_i − v⁻‖`。
6. **贴近度** `C_i = D⁻_i / (D⁺_i + D⁻_i)`，`C` 越大越优 ⇒ 排序。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 决策矩阵 `X`（m×n）· 权重 `w`（1×n，归一）· 各指标类型 `benefit` |
| **输出** | 归一化矩阵 `R` · 加权矩阵 `V` · 理想解 · 距离 `D±` · 贴近度 `C` · 排序 |

**显式假设（必须写进论文）**：
1. **归一化方式**已选定（向量归一 or min-max）—— 不同方式**结果不同**。
2. 距离用**欧氏距离**、各指标**等权独立**（加权后仍可加性）。
3. 权重 `Σw = 1`（骨架内自动归一）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. **归一化方式混用/不写明**：向量归一 ≠ min-max，换一种排序可能变（凭经验）。
2. **成本型指标忘取反**：`v⁺/v⁻` 会取错方向。本骨架对每个指标读 `benefit(j)` 分支处理（`evaluation/topsis.m`）。
3. **贴近度两极化**：指标或对象少时 `C` 会挤到接近 1 或 0，区分度低（凭经验）。
4. **权重含 0 或负值**：负权重无意义、0 权重等于删指标 —— 须先确认权重合法（凭经验）。
5. **把 `C` 当绝对得分**：`C` 是**相对贴近度**，不同数据集之间不可比（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/evaluation/topsis.m`（**零参可跑**，自带三方案三指标标准算例）。
★ **MATLAB 本无 `topsis`**（`which topsis` 找不到）⇒ 骨架自写。

关键片段（**不整份复制**）：
```matlab
R = X ./ sqrt(sum(X.^2, 1));        % 向量归一化
V = R .* w;                         % 加权
D_pos = sqrt(sum((V - v_pos).^2, 2));
D_neg = sqrt(sum((V - v_neg).^2, 2));
C = D_neg ./ (D_pos + D_neg);       % 贴近度
```
