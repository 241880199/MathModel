# 熵权法（`entropy_weight.m`）

> **靠数据自身的离散度定权**：某指标在各对象间**差异越大**，它携带的信息越多、**熵越小**、**权重越大**；反之差异小（都差不多）则权重小。

**归属**：类索引 `references/evaluation.md` · 骨架 `assets/matlab/evaluation/entropy_weight.m` · 参照 `tests/skills/model-select/verify/entropy_weight.md`。
★ **骨架与参照由本模块 Task 2 产出**（`evaluation` 类的 `补` 项）—— **本文件只写六格，不重做骨架 / 参照**。

## ① 适用判据

- **用**：指标**是完整数值**、希望权重**不带主观**、由数据决定；常作**客观权重**去驱动 TOPSIS / 模糊综合评价（`references/evaluation/topsis.md`）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **样本量小** ⇒ 熵估计**不可靠**，权重会抖动（凭经验）。
  2. **指标强相关** ⇒ 权重被**重复计入**（凭经验）。
  3. **某指标离散度小但业务上很关键**（如"安全性"大家都接近满分）⇒ 熵权会**压低**它，与业务直觉相反 ⇒ 应改用**主观权重或主客观组合赋权**。
  4. **要判断"谁更好"的排序** ⇒ 熵权只给**权重**，排序还要接一个排序器（TOPSIS / 综合评分）。

## ② 标准建模步骤

1. 取**决策矩阵 `X`**（m 对象 × n 指标）；对成本型先**正向化**。
2. 保证**非负**：含负值 ⇒ 逐列 **min-max 归一化到 [0,1]**（信息熵要求非负）。
3. 算**比重** `p_ij = x_ij / Σ_i x_ij`。
4. 算**熵** `e_j = −(1/ln m) Σ_i p_ij ln p_ij`（约定 `0·ln0 = 0`）。
5. 算**差异度** `d_j = 1 − e_j`。
6. **权重** `w_j = d_j / Σ_j d_j`。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 决策矩阵 `X`（m×n，须非负）· 各指标类型 `benefit` |
| **输出** | 熵 `e` · 差异度 `d` · 权重 `w` |

**显式假设（必须写进论文）**：
1. **信息熵以"差异"代表"重要性"**（这条假设本身可被质疑，见 ①反面-3）。
2. `m` 为方案数（`1/ln m` 归一常数）。
3. 含负值时**先做 min-max 归一化**——★ 这会**改变权重**，须与"直接用法"区分说明。
4. 约定 `0·ln0 = 0`（否则 MATLAB 直接算得 `NaN`）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **零值 / 负值处置**（熵权法最常见的翻车点，**实测依据 = 本骨架 `entropy_weight.m`**）：
   - **零值**：`p_ij = 0` 时按 `0·ln0 = 0` 约定置 0（骨架显式 `term(p==0)=0`），否则得 `NaN`；
   - **负值**：信息熵要求非负 ⇒ 骨架自动**逐列 min-max 归一化到 [0,1]** 并打印注记（**这会改变权重**）；
   - **常量指标列**（各对象同值）：熵 `e_j = 1` ⇒ 差异度 0 ⇒ **权重 0**。
2. **忘记正向化成本型指标** ⇒ 熵的计算方向错（凭经验）。
3. **与 AHP 之争**：客观（熵权）vs 主观（AHP）各有短长，**常做主客观组合赋权**；别把熵权结果说成"客观所以更对"（凭经验）。
4. **归一化方式影响权重**：min-max 与比重法（`p_ij`）是两回事，须写明（凭经验）。

## ⑤ 输出模板

- **权重向量 `w`**（+ 各指标熵 `e` / 差异度 `d`）；常作为**下一步排序器（TOPSIS）的输入**。
- 权重表 → `mcm-table`（`.claude/skills/mcm-table/`）；权重条形图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）。
- ★ **不复述这两个 skill 的排版规则**。

## ⑥ 代码骨架

**路径**：`assets/matlab/evaluation/entropy_weight.m`（**零参可跑**，自带主算例 + 零值算例 + 负值算例）。

关键片段（**不整份复制**）：
```matlab
if min(Xn(:)) < 0                    % 负值 ⇒ 逐列 min-max 到 [0,1]
    for j = 1:n; lo = min(Xn(:,j)); hi = max(Xn(:,j));
        if hi > lo; Xn(:,j) = (Xn(:,j)-lo)/(hi-lo); else; Xn(:,j) = zeros(m,1); end; end
end
p = Xn ./ sum(Xn, 1);                % 比重
term = p .* log(p); term(p == 0) = 0;   % 约定 0·ln0 = 0
e = -sum(term, 1) / log(m);          % 熵
d = 1 - e; w = d / sum(d);           % 差异度 → 权重
```
