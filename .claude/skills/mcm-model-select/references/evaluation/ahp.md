# AHP 层次分析法（`ahp.m`）

> **层次化地给主观权重**：把决策分解成 目标层 → 准则层 →（子准则）→ 方案层，靠**两两比较**把定性判断转成数，再用**一致性检验**卡住"自相矛盾"的判断矩阵。

**归属**：类索引 `references/evaluation.md` · 骨架 `assets/matlab/evaluation/ahp.m` · 参照 `tests/skills/model-select/verify/ahp.md`。

## ① 适用判据

- **用**：题面要给**若干指标定权重 / 多准则排序**，而指标**难以直接量化**（"安全性""舒适度"），但**有专家可做两两比较**；或指标**分层**、需要把下层权重**逐层汇总**到总目标。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **指标本身是完整数值、样本充足** ⇒ 应走**客观赋权**（熵权法 `references/evaluation/entropy_weight.md`），AHP 的主观权重会引入不必要的争议。
  2. **只要求"离理想解多近"的排序、不要求显式权重** ⇒ 用 TOPSIS `references/evaluation/topsis.md`（可配合客观权重）。
  3. **专家意见严重不一致、判断矩阵反复不过一致性检验** ⇒ 不是"换个 RI 阈值"能解决的，应改**群决策 / Delphi** 或换方法。
  4. **指标数很大（经验上 n ≳ 9）** ⇒ 一个 n 阶矩阵有 n(n−1)/2 个两两判断，负担与不一致风险陡增 ⇒ 应**分层降维**或改客观赋权。

## ② 标准建模步骤

1. 建**层次结构**：目标层 → 准则层 →（子准则层）→ 方案层。
2. 自下而上构造**正互反判断矩阵** `A`（元素取 Saaty 1–9 标度，`a_ji = 1/a_ij`）。
3. 求**优先权向量** `w`（本骨架用**方根法 / 几何平均法**；特征向量法为等价替代，见 ④-4）。
4. 算 `lam_max`：`CI = (lam_max − n)/(n − 1)`，`CR = CI / RI(n)`；**判据 `CR < 0.1` 才通过**；不过 ⇒ 回步骤 2 修正判断矩阵。
5. **层次总排序**：把子准则权重逐层乘以所隶属准则的权重，得到方案层对总目标的权重。
6. ★ **总排序也要做一致性检验**（用各层的 CI/RI 加权求和得 `CR_total`，仍须 `< 0.1`）。
7. 出排序 / 选优。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 判断矩阵 `A`（正互反）；标度语义（Saaty 1–9）；`RI` 表 |
| **输出** | 权向量 `w`、`lam_max`、`CI`、`CR`、一致性是否通过 |

**显式假设（必须写进论文）**：
1. 层次里的**元素可分解、互不重叠**（同一层元素相对上层是并列的）。
2. 专家两两判断**相容**（否则一致性检验会拒）。
3. Saaty 1–9 标度的语义被受访者**统一理解**。
4. 权重**加性可组合**（总排序用加权和，而非 max-min 之类）。

**默认取值**：方法 = 方根法；`RI` 用 Saaty 表（见 ④-1）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. **`RI` 的取值要有出处**：`n = 1..10` 时 `RI = 0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45, 1.49`（Saaty 表，**教科书级常识 ⇒ 标 `[社区]`**）。`n ≤ 2` 时 `RI = 0` ⇒ 无一致性检验必要（`CI` 分母为 0）。
2. **忘了总排序的一致性检验**（只做了单层，凭经验——美赛里常见）。
3. **特征向量法取错特征向量**：`eig` 返回的特征值未排序，且可能是复数。**实测**（本骨架 `ahp.m`）：须取**实部最大者**对应的特征向量（代码里显式 `max(real(ev))`）。
4. ★ **`n = 3` 时方根法与特征向量法恒等**（正互反 3 阶矩阵的一条已知结论）⇒ 拿"两法结果一致"当**独立验证**是**按构造恒真的**、不构成证据（**骨架里两法读数逐位相同，即为这条恒真性的体现**，不是巧合）。
5. **把 0.1 判据悄悄放宽到 0.2** 来"让矩阵通过"——判据就是 `0.1`，放宽要**明写并说明理由**。
6. **原始数值指标硬转标度**：如果某指标本就是可测数值，硬压成 1–9 标度会**丢掉可复现性**（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/evaluation/ahp.m`（**零参可跑**，自带标准算例）。

关键片段（**不整份复制**；完整实现见上述路径）：
```matlab
g = prod(A, 2) .^ (1 / n);          % 方根法：行几何平均
w = (g / sum(g)).';                 % 权向量（归一）
lam_max = mean((A * w.') ./ w.');   % 最大特征值估计
CI = (lam_max - n) / (n - 1);
CR = CI / RI;                       % RI 查 Saaty 表；CR < 0.1 判通过
```
