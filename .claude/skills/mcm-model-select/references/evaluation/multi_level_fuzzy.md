# 模糊综合评价（多层次）（`multi_level_fuzzy.m`）

> **给"分不清等级"的评价合成一个结论**：评价指标**分层**（准则 → 子准则），每个底层指标对"优/良/中/差"这类**模糊等级**给一个**隶属度**，再**逐层合成**成一个综合隶属度 / 得分。

**归属**：类索引 `references/evaluation.md` · 骨架 `assets/matlab/evaluation/multi_level_fuzzy.m` · 参照 `tests/skills/model-select/verify/multi_level_fuzzy.md`。

## ① 适用判据

- **用**：题面的评价体系**有层级**；评语是**模糊等级**（优/良/中/差、达标/基本达标/不达标）；底层指标**多为定性**（"环境友好度"），很难给硬分数，但**能给"属于某等级的程度"**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **指标全是可测数值、要客观权重** ⇒ 熵权法 + TOPSIS（`references/evaluation/entropy_weight.md` · `references/evaluation/topsis.md`）更可复现。
  2. **没有层级、只是并列的多个目标** ⇒ 用 **多目标模糊综合评价** `references/evaluation/multi_objective_fuzzy.md`。
  3. **要找"最优决策变量"** ⇒ 那是优化（`optimization`），不是评价。
  4. **层级过深（经验上 > 2–3 层）或指标过多** ⇒ 逐层合成**误差累积**，且权重来源难自洽（凭经验）。

## ② 标准建模步骤

1. 定**因素集 `U`**（分层：准则 → 子准则）与**评语集 `V`**（等级 + 分值向量 `V`，如 `[100 80 60]`）。
2. 定**权重**：准则层权重 `W`、各准则下子权重 `Wk`（来源可为 AHP `references/evaluation/ahp.md`、熵权、专家）。
3. 对**每个底层指标**做**单因素评判** ⇒ 隶属度向量（由隶属函数或专家打分并归一化）。
4. 把同一准则下的隶属度向量摞成**模糊评判矩阵 `Rk`**（行 = 子指标，列 = 等级）。
5. ★ **选合成算子**（写进论文）：**加权平均 `M(·,+)`** 或 **最大最小 `M(∧,∨)`**。
6. **逐层合成**：一级 `Bk = Wk ∘ Rk`；把 `Bk` 摞成上层 `R`，二级 `B = W ∘ R`。
7. 结论：**最大隶属度**对应等级，或**加权得分 `S = B · Vᵀ`**。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `W`（1×K）· 各准则 `Wk` · 各准则 `Rk` · `V` · 算子 |
| **输出** | 各准则 `Bk` · 综合 `B` · 得分 `S` · 最优等级 |

**显式假设（必须写进论文）**：
1. 权重已归一（`ΣW = 1`、每个 `ΣWk = 1`）。
2. 每个指标的隶属度向量**已归一**（行和为 1）。
3. 评语等级**互斥且完备**（覆盖所有可能）。
4. ★ **算子的选择是一条显式假设**：取 `M(·,+)` 隐含"各因素贡献**可加**"；取 `M(∧,∨)` 隐含"由主导因素决定"（见 ④-1）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **算子不写明 ⇒ 结果不可复现**。**实测**（本骨架同组数据，`multi_level_fuzzy.m`）：
   - `M(·,+)`：`B = [0.374 0.472 0.154]`（**Σ = 1**，归一）；
   - `M(∧,∨)`：`B = [0.4 0.5 0.3]`（**Σ = 1.2，未归一**）。
   两算子给的综合等级**未必相同** ⇒ 论文里必须**指明算子**（这也是本骨架把两种都算出来对照的原因）。
2. **隶属度未归一**就合成（行和 ≠ 1）⇒ 上层 `B` 不可比。
3. **最大隶属度接近**时不能只报"最优等级"：当 `B` 的相邻两项很接近（如 `0.472 vs 0.374`）应同时报**加权得分 `S`** 或做**灵敏度分析**（凭经验）。
4. **权重与层次结构错配**：子权重 `Wk` 的长度与 `Rk` 行数不一致 —— 本骨架对此下了 `assert` 直接报错，别静默跑错。
5. **把"模糊综合"当成"客观评价"**：权重仍是主观的（除非改用熵权）。别把结果说成"客观分数"（凭经验）。

## ⑤ 输出模板

- **综合隶属度向量** `B` + **综合得分 `S`** + （如需要）各准则 `Bk`。
- 隶属度 / 得分表 → `mcm-table`（`.claude/skills/mcm-table/`）；层次结构图 / 隶属度对比图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）。
- ★ **不复述这两个 skill 的排版规则**（三线表 / 图宽比 / 图注合规等一律以它们为准）。

## ⑥ 代码骨架

**路径**：`assets/matlab/evaluation/multi_level_fuzzy.m`（**零参可跑**，自带 2 准则 × 各 2 子指标 × 3 等级算例，并打印 `M(·,+)` 与 `M(∧,∨)` 对照）。

关键片段（**不整份复制**）：
```matlab
for k = 1:K
    B_k(k, :) = Wk{k} * Rk{k};        % 一级：M(·,+) 加权平均
end
B = W * B_k;                          % 二级
score = B * V.';                      % 加权得分
```
**独立参照**：`tests/skills/model-select/verify/multi_level_fuzzy.md`（第 3 类：手算标准算例）。
