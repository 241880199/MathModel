# 非线性规划（`nlp.m`）

> **目标或约束里出现非线性时用**：乘积、平方、指数、比值、三角函数等使可行域/等值面弯了 ⇒ 最优解**不再一定落在顶点**，要用 KKT / 梯度类算法求**局部**最优（凸问题才是全局）。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/nlp.m` · 参照 `tests/skills/model-select/verify/nlp.md`。
★ **与 `lp`/`ilp` 的边界**：全线性 ⇒ `references/optimization/lp.md` / `ilp_assignment.md`（有全局最优保证）。

## ① 适用判据

- **用**：目标或约束**含非线性项**（`x²`、`x·y`、`e^x`、`1/x`、间距/能量/方差类目标）；变量连续；能给出**初值**；问题规模中等。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **其实全线性** ⇒ 上 NLP 是"杀鸡用牛刀"，且**失去全局最优保证** ⇒ 用 `references/optimization/lp.md`。
  2. **非凸、要求全局最优** ⇒ `fmincon` 之类的**局部**算法会卡在局部极小；要么多初值重启、要么用全局优化器，且**必须说明得到的只是局部解**（凭经验——最常见的越界声明）。
  3. **目标不可微 / 黑箱** ⇒ 梯度法失效 ⇒ 用无导数 / 启发式（`references/optimization/ga.md` / `pso.md`）。
  4. **只要近似可行解、规模大** ⇒ 精确 NLP 可能不收敛或极慢，考虑启发式并注明近似。

## ② 标准建模步骤

1. **定连续变量 + 非线性目标 / 约束**，写成标准形 `min f(x) s.t. g_i(x) ≤ 0, h_j(x) = 0`。
2. **判凸性**（能判就判）：凸 ⇒ 局部最优 = 全局最优；非凸 ⇒ 注明只是局部。
3. **给初值 `x0`**（NLP 对初值敏感——这是必写的一步）。
4. **求解**：SQP / 内点（MATLAB `fmincon`）。
5. **验 KKT / 可行性**：残差、约束满足度、`exitflag`。
6. **多初值重启**：换若干 `x0` 看最优值是否一致（一致性 = 全局性的证据）。
7. **灵敏度 / 解释**：参数扰动下最优解怎么变。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `fun`（目标）· `x0`（初值）· `A,b,Aeq,beq`（线性约束）· 非线性约束函数 · `lb,ub` |
| **输出** | 最优 `x*`、`f*`、`exitflag`、迭代/可行性信息 |

**显式假设（必须写进论文）**：
1. **目标 / 约束可微**（否则梯度类算法不适用）。
2. **凸性**（若声称全局最优，必须证明或说明凸性假设）。
3. **初值合理**（NLP 收敛到哪个局部解依赖初值）。
4. **连续变量**（无整数性）。
5. **约束的规范化**：`≤0` 形式、等式约束的独立数 ≤ 变量数（否则约束相容性存疑）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把局部最优当全局最优宣称**：非凸问题里 `fmincon` 只保证局部（凭经验——评审常抓）。
2. **初值给得太差 ⇒ 不收敛 / 落到坏局部解**：本骨架**实测**：`min (x1-1)²+(x2-2)² s.t. x1+x2≤2, x≥0`，无约束极小 `(1,2)` 越界（`1+2=3>2`），取边界后最优 `(0.5,1.5)`、`f*=0.5`（骨架读数 `x*=[0.5000000014 1.499999999]`、`f*=0.5`）。
3. **忘了写变量下界**：`x` 跑成负数（凭经验）。
4. **把非线性约束线性化过头**：近似 RHS/系数会**挪动最优解**（凭经验）。
5. ★ **拿 `fmincon` 当"独立参照"**：它只是**实现**，同机同实现**不独立**（任务书 B）；参照走**手算 KKT**（见 ⑥ 与参照件）。
6. **目标尺度悬殊不做归一**：`f` 各项量纲差异大时收敛慢（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/nlp.m`（**零参可跑**，自带算例 `min (x1-1)²+(x2-2)² s.t. x1+x2≤2, x≥0`）。

关键片段（**不整份复制**）：
```matlab
fun = @(x) (x(1) - 1)^2 + (x(2) - 2)^2;
[x, fval, exitflag] = fmincon(fun, [0 0], [1 1], 2, [], [], [0 0], [], [], ...
                              optimoptions('fmincon', 'Display', 'off', 'Algorithm', 'sqp'));
```
