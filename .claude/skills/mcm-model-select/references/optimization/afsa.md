# 人工鱼群（`afsa.m`）

> **要"聚群 / 追尾 / 觅食"三类行为协作时用**：每条"人工鱼"在视野内按**聚群**（向邻居中心）、**追尾**（向邻居最优）、**觅食**（随机试探）三种行为移动，并记忆全局最优。适合连续 / 多峰寻优；代价同族：**结果随随机数变**，固定种子 + 多运行。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/afsa.m` · 参照 `tests/skills/model-select/verify/afsa.md`。
★ **与相邻方法的边界**：要"粒子速度 + `gbest` 牵引" ⇒ `references/optimization/pso.md`；要"克隆选择" ⇒ `references/optimization/immune.md`。

## ① 适用判据

- **用**：**连续**变量、**多峰**或黑箱目标的全局寻优；想用"三种行为"同时做**局部精细搜索（聚群/追尾）+ 全局探索（觅食）**；参数解释直观（视野 `visual`、步长 `step`、拥挤度 `crowd`）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **离散 / 排列问题** ⇒ 欧氏邻域不自然 ⇒ 用 `references/optimization/ga.md` / `aco.md`（凭经验）。
  2. **要求精确最优** ⇒ 启发式给近似解（凭经验）。
  3. **参数 / 预算（`visual`/`step`/`crowd`/`nfish`/`maxgen`）不当** ⇒ 收敛慢或早熟——**实测**：同一**单峰基准上、缩预算**（`nfish` 40→30、`maxgen` 300→100）后命中率可从 `5/5` 掉到 `0/5`（见 ④-1 与 ④-3）。
  4. **只跑一次就报结果** ⇒ 结果不可复现（本类纪律核心，见 ④-1）。

## ② 标准建模步骤

1. **初始化鱼群**（本骨架 `nfish=40`，域 `[-10,10]^2`）。
2. **评估**适应度，记全局最优。
3. **对每条鱼**依次尝试：
   - **聚群**：邻居中心更优且不拥挤 ⇒ 向中心移动；
   - **追尾**：邻居中最优者更优 ⇒ 向其移动；
   - **觅食**：视野内随机试探，遇更优则前移；
   - 都不成 ⇒ **随机行为**。
4. **收缩**视野 / 步长（本骨架随代数线性收缩）。
5. **更新全局最优**。
6. ★ **固定种子 + 多次运行**：报**逐次最优 + mean±sd + 命中率 / 相对差**。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 目标函数 · `nfish` · `maxgen` · 视野 `visual` · 步长 `step` · 拥挤度 `crowd` · 试探次数 `try_n` · 域 · 种子 |
| **输出** | 逐次最优 `f_best` / `x_best` · `mean ± sd` · 命中率 · 相对差 |

**显式假设（必须写进论文）**：
1. **搜索空间连续**、**有界**。
2. **邻域用欧氏距离**定义（视野是球）。
3. ★ **结果是随机变量**：报固定种子可复现值 + 多种子分布；**单次读数不能当性能**。
4. **`visual`/`step`/`crowd`/`nfish`/`maxgen` 是显式超参** —— 收敛精度**强依赖**它们（见 ④-3）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**：**实测**（本骨架 `afsa.m`，单峰 `f(x)=3+(x1-2)²+(x2+1)²`、`f*=3`、`nfish=40`、`maxgen=300`、`visual=2, step=0.7`）：5 个种子的 `f_best` 全 = `3`，**mean ± sd = `3 ± 4.0714219e-11`**，**命中率 `5/5`**。
2. ★ **可复现性**：**实测**（两次独立 `matlab -batch`）：本骨架整段输出**逐字节一致**（`diff` 为空）。
3. ★★ **收敛精度强依赖算力/参数（实测）**：同一骨架、同一参数、**只把 `nfish=30, maxgen=100, visual=1, step=0.6` 缩一档**，5 种子的 `f_best` 就落到 `3.0011 ~ 3.0030`（**相对差 `1e-4 ~ 1e-3`、命中率 `0/5`**）；恢复到 `nfish=40, maxgen=300` 才回到 `3 ± 4e-11`（`5/5`）。⇒ **报读数必须带清参数与预算**，否则"达标"不可复现。
4. **视野/步长不收缩** ⇒ 后期在最优点附近乱跳（凭经验——本骨架让它们随代数收缩）。
5. **聚群把鱼吸进局部盆地** ⇒ 多峰函数上早熟（凭经验）。
6. **拿工具箱 / 内置当"独立参照"**：同机同实现**不独立**（任务书 B）；参照走**已知最优算例 + 独立参照件**。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/afsa.m`（**零参可跑**，5 种子分布 + 可复现）。

关键片段（**不整份复制**）：
```matlab
for s = 1:numel(seeds)
    rng(seeds(s));                                   % ★ 固定种子
    X = lo + (hi - lo) .* rand(nfish, D); fX = fit(X);
    for it = 1:maxgen
        visual = visual0*(1 - it/maxgen) + 0.05;     % 视野/步长随代数收缩
        step   = step0  *(1 - it/maxgen) + 0.02;
        for i = 1:nfish
            d = sqrt(sum((X - X(i,:)).^2, 2)); nb = find(d > 0 & d < visual);
            % 聚群 → 追尾 → 觅食 → 随机（依次尝试）
        end
    end
    fbest(s) = bestf; xbest(s,:) = bestx;            % 多次运行给分布
end
```
