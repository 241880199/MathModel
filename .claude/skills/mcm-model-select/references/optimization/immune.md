# 免疫优化（`immune.m`）

> **要"克隆选择 + 亲和度成熟"时用**：模拟免疫系统——**优的抗体多克隆**，克隆体按亲和度高低做**幅度反比**的变异（越好变异越小），再择优**记忆**。兼具探索与开发；代价同族：**结果随随机数变**，固定种子 + 多运行。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/immune.m` · 参照 `tests/skills/model-select/verify/immune.md`。
★ **与相邻方法的边界**：要"群体协作、连续搜索" ⇒ `references/optimization/pso.md`；要"以概率接受劣解" ⇒ `references/optimization/sa.md`。

## ① 适用判据

- **用**：连续 / 混合变量的全局寻优；想借**克隆扩增 + 亲和度成熟**在**多峰**地形里兼顾探索与精细开发；需要**记忆细胞**保留历史最优。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **目标可微且凸** ⇒ 梯度法更快更准（凭经验）。
  2. **要求精确最优** ⇒ 免疫优化是启发式、给近似解（凭经验）。
  3. **参数（克隆规模 `q`、变异幅度）没调好** ⇒ 要么早熟、要么退化成随机搜索（凭经验）。
  4. **只跑一次就报结果** ⇒ 结果不可复现（本类纪律核心，见 ④-1）。

## ② 标准建模步骤

1. **初始化抗体群**（本骨架 `pop=40`，域 `[-10,10]^2`）。
2. **评估亲和度**（= 适应度，越小越好）。
3. **选择**前 `q` 个最优抗体（本骨架 `q=10`）。
4. **克隆**：克隆数与排名成正比（越优克隆越多）。
5. **变异（亲和度成熟）**：变异幅度与排名**反比**（越优变异越小）。
6. **择优**：原抗体 + 克隆体里选回 `pop` 个（精英保留）。
7. ★ **固定种子 + 多次运行**：报**逐次最优 + mean±sd + 命中率 / 相对差**。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 目标函数 · `pop` · `maxgen` · `q`（克隆选择数）· 变异幅度规则 · 域 · 种子 |
| **输出** | 逐次最优 `f_best` / `x_best` · `mean ± sd` · 命中率 · 相对差 |

**显式假设（必须写进论文）**：
1. **亲和度能反映优劣**（即适应度函数选对）。
2. **克隆 / 变异算子保持解在域内**。
3. ★ **结果是随机变量**：报固定种子可复现值 + 多种子分布；**单次读数不能当性能**。
4. **`q`、克隆规模、变异规则是显式超参**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**：**实测**（本骨架 `immune.m`，单峰 `f(x)=3+(x1-2)²+(x2+1)²`、`f*=3`、`pop=40`、`maxgen=150`、`q=10`）：5 个种子的 `f_best` = `3.0000027 / 3.0000001 / 3.0000013 / 3.0000017 / 3.0000004`，**mean ± sd = `3.0000012 ± 1.0304197e-06`**，**命中率 `5/5`**。
2. ★ **可复现性**：**实测**（两次独立 `matlab -batch`）：本骨架整段输出**逐字节一致**（`diff` 为空）。
3. ★ **拿工具箱 / 内置当"独立参照"**：同机同实现**不独立**（任务书 B）；参照走**已知最优算例 + 独立参照件**。
4. **变异幅度不与排名反比** ⇒ 优抗体被大扰动打散、退化成随机搜索（凭经验）。
5. **克隆数不设上限** ⇒ 计算量爆炸（凭经验——本骨架按比例分配总数 `pop`）。
6. **只保留克隆体、丢掉原抗体** ⇒ 丢失已收敛的好解（凭经验——本骨架做精英合并）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/immune.m`（**零参可跑**，5 种子分布 + 可复现）。

关键片段（**不整份复制**）：
```matlab
for s = 1:numel(seeds)
    rng(seeds(s));                                   % ★ 固定种子
    Ab = lo + (hi - lo) .* rand(pop, D); fAb = fit(Ab);
    for it = 1:maxgen
        [fs, order] = sort(fAb); Ab = Ab(order,:); fAb = fs;
        pool = Ab; fpool = fAb;                      % 精英保留
        for i = 1:q
            nc = max(1, round(pop * (q - i + 1) / q));   % 越优克隆越多
            sigma = 0.05 + 0.4 * (i / q);                % 越优变异越小
            c = min(max(repmat(Ab(i,:), nc, 1) + sigma*randn(nc, D), lo), hi);
            pool = [pool; c]; fpool = [fpool; fit(c)];
        end
        [fs2, order2] = sort(fpool); Ab = pool(order2(1:pop),:); fAb = fs2(1:pop);
    end
    [fbest(s), im] = min(fAb); xbest(s,:) = Ab(im,:);    % 多次运行给分布
end
```
