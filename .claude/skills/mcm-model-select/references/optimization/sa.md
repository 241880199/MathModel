# 模拟退火（`sa.m`）

> **要"以一定概率接受变差解、慢慢降温"时用**：从一个解出发做邻域扰动，**劣解按 `exp(−Δ/T)` 概率接受**，温度徐徐下降 ⇒ 既能跳出局部极小、又能收敛。代价同 GA：**结果随随机数变**，必须固定种子 + 多运行。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/sa.m` · 参照 `tests/skills/model-select/verify/sa.md`。
★ **与相邻方法的边界**：要"群体进化" ⇒ `references/optimization/ga.md`；要"信息素正反馈" ⇒ `references/optimization/aco.md`。

## ① 适用判据

- **用**：**组合优化**（TSP、调度、布局）或连续函数的**全局**寻优；有**自然的邻域扰动**（换两城市、微调坐标）；可接受近似解。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **目标可微、要精确解** ⇒ 用梯度法 / 精确算法（凭经验）。
  2. **降温表随手定** ⇒ 太快 ⇒ 早熟（退化成局部搜索）；太慢 ⇒ 跑不完（凭经验——SA 最需调参处）。
  3. **没有合适邻域结构** ⇒ 扰动要么太粗（乱跳）要么太细（卡住）（凭经验）。
  4. **只跑一次就报结果** ⇒ 结果不可复现（本类纪律核心，见 ④-1）。

## ② 标准建模步骤

1. **表示解**：如 TSP 用城市排列。
2. **定义邻域**：如 2-opt（反转一段路径）。
3. **定能量 = 目标值** `L`。
4. **初始温度 `T0` + 降温表**：本骨架几何降温 `T ← αT`（`α=0.995`）。
5. **主循环**：扰动 → 若更优接受；否则以 `exp(−Δ/T)` 概率接受 → 降温。
6. **记忆最优**：全程记录遇见的最优解。
7. ★ **固定种子 + 多次运行**：报**逐次最优 + mean±sd + 命中率 / 相对差**。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 数据（如城市坐标）· `T0` · `α` · `maxit`（迭代上限）· 邻域算子 · 种子 |
| **输出** | 逐次最优 `L_best` / 最优解 · `mean ± sd` · 命中率 · 相对差 |

**显式假设（必须写进论文）**：
1. **邻域连通**：从任一解经有限步邻域可达最优（否则搜不到）。
2. **降温足够慢**：理论全局收敛需 `T→0` 且降温无穷慢；实践中只能近似（要注明）。
3. ★ **结果是随机变量**：报固定种子可复现值 + 多种子分布；**单次读数不能当性能**。
4. **`T0`/`α`/`maxit` 是显式超参**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**：**实测**（本骨架 `sa.m`，5 城 TSP `C=[0 0;3 0;3 4;0 4;1.5 2]`，**已知最优 `L*=15`**、`maxit=3000`、`T0=5`、`α=0.995`）：5 个种子的 `L_best` = `15 / 15 / 15 / 15 / 15`，**mean ± sd = `15 ± 0`**，**命中率 `5/5`**；相对差全为 `0`。
2. ★ **可复现性**：**实测**（两次独立 `matlab -batch`）：本骨架整段输出**逐字节一致**（`diff` 为空）。
3. ★ **拿工具箱 / 内置当"独立参照"**：同机同实现**不独立**（任务书 B）；参照走**独立穷举出的已知最优**（见 ⑥ 与参照件）。
4. **降温太快 ⇒ 早熟**：`α` 取太小会退化成局部搜索（凭经验）。
5. **不记录历史最优** ⇒ 最后温度低时反而可能停在差解上（凭经验——本骨架用"全局最优记忆"规避）。
6. **接受概率数值下溢**：`exp(−Δ/T)` 在 `Δ/T` 很大时 `→0`，需用 `max(T,eps)` 防除零（本骨架已处理）。

## ⑤ 输出模板

- **分布表**（各 `seed` 的 `L_best` + `mean ± sd` + 命中率）+ **降温 / 能量曲线** + 最优解（巡回）。
- 降温曲线 / 最优巡回图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）；分布表 → `mcm-table`（`.claude/skills/mcm-table/`）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/sa.m`（**零参可跑**，5 城 TSP，5 种子分布 + 可复现）。

关键片段（**不整份复制**）：
```matlab
tour = randperm(n); L = tourlen(tour, Dm); T = T0;
for k = 1:maxit
    [i,j] = deal_sorted(randi(n,1,2));
    cand = [tour(1:i-1), fliplr(tour(i:j)), tour(j+1:end)];   % 2-opt
    Lc = tourlen(cand, Dm);
    if Lc < L || rand < exp(-(Lc - L)/max(T, eps))            % Metropolis
        tour = cand; L = Lc;
    end
    T = max(T * alpha, 1e-6);                                 % 几何降温
end
```
**独立参照**：`tests/skills/model-select/verify/sa.md`（**第 4 类：已知最优小算例 + 固定种子 + 多次运行的分布** —— `L*=15` 由全排列穷举独立得出）。
