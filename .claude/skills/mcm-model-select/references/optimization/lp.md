# 线性规划（`lp.m`）

> **目标与约束都是线性时用**：决策变量连续、目标函数与约束全是**一次式** ⇒ 最优解落在**可行域顶点**，可用单纯形 / 内点法求到**全局最优**（不是近似）。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/lp.m` · 参照 `tests/skills/model-select/verify/lp.md`。
★ **与相邻方法的边界**：含**整数 / 0-1** 变量 ⇒ `references/optimization/ilp_assignment.md`；目标或约束**非线性** ⇒ `references/optimization/nlp.md`；**多目标权衡** ⇒ `references/optimization/goal_programming.md`。

## ① 适用判据

- **用**：题面有**连续决策变量**、**线性目标**（max/min 一个线性式）、**线性约束**（≤ / ≥ / = 的资源、容量、配比、平衡式）；规模可大可小；要求**全局最优 + 可解释的对偶/影子价格**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **变量必须是整数 / 0-1**（人数、车辆数、开关）⇒ 线性松弛会把 `x=2.5 辆车` 当可行解 ⇒ 走整数规划 / 指派（`references/optimization/ilp_assignment.md`）。
  2. **目标或约束非线性**（乘积、平方、比值、对数）⇒ 用线性式硬近似会**改掉最优解的位置** ⇒ 走 `references/optimization/nlp.md`。
  3. **多个目标要分优先级让步** ⇒ 单目标 LP 不能用权重代替"层次让步"，走 `references/optimization/goal_programming.md`。
  4. **问题不可微 / 组合爆炸（TSP、调度、选址）** ⇒ 线性模型要么写不出、要么规模爆炸 ⇒ 走上启发式（`references/optimization/ga.md` 等）。

## ② 标准建模步骤

1. **定决策变量** `x_j ≥ 0`（或自由变量拆成正负两部分）。
2. **写目标**：`max z = Σ c_j x_j`（骨架统一转 `min −cᵀx`）。
3. **写约束**：`A x ≤ b`（≥ 转号、= 单列），标出上/下界。
4. **求解**：单纯形 / 内点法（MATLAB `linprog`）。
5. **读解**：最优点、最优值、**松弛量 / 剩余量**、**对偶变量（影子价格）**。
6. **灵敏度**：目标系数与右端项**在多大范围变化最优基不变**（比赛里常被评委问）。
7. **可解释性**：把对偶变量翻译回"每多一单位资源的边际价值"。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `c`（目标系数）· `A, b`（不等式约束）· `Aeq, beq`（等式约束）· `lb, ub`（变量界） |
| **输出** | 最优 `x*`、最优值 `z*`、`exitflag`、对偶变量 / 松弛量 |

**显式假设（必须写进论文）**：
1. **线性性**：投入产出关系是常数比例（规模报酬不变、无可变系数）。
2. **可加性**：各变量对目标/约束的贡献可直接相加（无交互项）。
3. **连续性**：决策变量允许取分数（若不允许 ⇒ 见 ①反面 1）。
4. **确定性**：系数 `c, A, b` 是已知常数（不含随机）。
5. **可行域非空且有界**（否则 `linprog` 会报无界 / 不可行 —— 要在论文里说明如何保证）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. **`max` 与 `min` 口径搞反**：MATLAB `linprog` 只解 `min`。**实测**（本骨架 `lp.m`）：`max 3x1+5x2` 须传 `c = -[3 5]`，再把 `fval` 取负 ⇒ 得 `z*=36`；若忘了取负会报出 `-36`。
2. **`A x ≤ b` 的方向写反**：`≥` 约束必须整体乘 `−1` 后并入 `A`，否则可行域变成补集（凭经验——LP 最常见的翻车点）。
3. **无界 / 不可行不检查 `exitflag`**：`exitflag < 0` 时 `x*` 是无意义的（凭经验）；本骨架实测 `exitflag = 1`。
4. **把整数问题当 LP 解**（见 ①反面 1）：松弛解非整数时**不能四舍五入**——可能不可行或非最优（凭经验）。
5. ★ **拿 `linprog` 当"独立参照"**：它只是**实现**；同一台机器的同一套实现**不构成独立验证**（任务书 B）。本方法的参照走**手算顶点枚举**（见 ⑥ 与参照件）。
6. **变量界的省略**：物理量（产量、时间）通常非负，漏掉 `lb = 0` 会得到负产量（凭经验）。

## ⑤ 输出模板

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/lp.m`（**零参可跑**，自带算例 `max 3x1+5x2`，`s.t. x1≤4, 2x2≤12, 3x1+2x2≤18, x≥0`）。

关键片段（**不整份复制**）：
```matlab
c = -[3 5];                       % ★ max ⇔ min 取负
A = [1 0; 0 2; 3 2];  b = [4; 12; 18];
[x, fval, exitflag] = linprog(c, A, b, [], [], [0 0], [], ...
                              optimoptions('linprog', 'Display', 'off'));
z = -fval;                        % ★ 转回 max 口径
```
**独立参照**：`tests/skills/model-select/verify/lp.md`（**第 3 类：手算顶点枚举** —— 期望值 `(2,6), z=36` 手算写死、给出逐顶点算式）。
