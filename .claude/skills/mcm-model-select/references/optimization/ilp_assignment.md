# 整数规划 / 指派问题（`ilp_assignment.m`）

> **决策变量必须取整（或 0-1）时用**：人数 / 车辆数 / 台数 / 开关状态不能是分数，指派问题还要"一人一岗、一岗一人"。代价是**不能只解线性松弛**（松弛解通常非整数），要用分支定界 / 全排列穷举（小规模）求整数最优。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/ilp_assignment.m` · 参照 `tests/skills/model-select/verify/ilp_assignment.md`。
★ **与 `lp` 的边界**：变量允许连续 ⇒ 用 `references/optimization/lp.md`（更简单、有对偶）；**含整数性**才用本方法。

## ① 适用判据

- **用**：决策变量**必须整数**（人数、件数、车型数）或 **0-1**（选/不选、开/关、派/不派）；或题目是**指派 / 匹配**结构（n 任务 × n 人，一岗一人）；规模使得分支定界 / 穷举可行。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **变量本质连续**（流量、产量、浓度）⇒ 强加整数性会**虚增代价、甚至无解** ⇒ 用 `references/optimization/lp.md`。
  2. **变量数很大（组合爆炸）** ⇒ 精确分支定界可能超时 ⇒ 用启发式（`references/optimization/ga.md` / `aco.md`），并**明说得到的是近似解**。
  3. **目标/约束非线性** ⇒ 整数非线性规划更难，先考虑能否线性化，或走 `references/optimization/nlp.md`。
  4. **只要"比例分配"、不要求整数** ⇒ 别上 ILP（凭经验——过度整数化是常见误用）。

## ② 标准建模步骤

1. **定整数 / 0-1 变量**（`x_j ∈ ℤ` 或 `∈ {0,1}`）。
2. **写线性目标与约束**（同 LP，但变量带整数性）。
3. **加结构约束**：指派问题加"每行和 = 1、每列和 = 1"。
4. **求解**：分支定界（`intlinprog`）或小规模**全排列穷举**（精确）。
5. **验证整数性**：检查解确为整数，且**可行**（不能把 LP 松弛解四舍五入）。
6. **读解 + 上界比较**：报整数最优，并与 LP 松弛值比较（给出 gap 的大小）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 目标系数 `f` · 约束 `A, b` · 变量类型（整数 / 0-1）· 界 |
| **输出** | 整数最优 `x*`、最优值、`exitflag`；指派问题另给**指派方案** |

**显式假设（必须写进论文）**：
1. **线性性 + 可加性**（同 LP）。
2. **整数性来源明确**：是"物理不可分"还是"人为取整"（后者要说明代价）。
3. **0-1 变量的语义**（选/不选）与约束的**互斥 / 蕴含**关系写清。
4. **规模可控**：精确解法要求问题规模在可解范围内；否则须改用启发式并**注明近似**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把 LP 松弛解四舍五入**：非整数松弛解取整后**可能不可行或非最优**（凭经验——ILP 最经典的错）。
2. **指派问题忘了"一岗一人"约束**：只写"每行选一个"会允许同一列被多人占用（凭经验）。
3. **`perms` 穷举只适合小 n**：**实测**（本骨架 `ilp_assignment.m`）：4×4 指派 `perms(1:4)` 只枚举 **24 个**排列、代价最小 = **13**（指派 `行→列 = [2 1 3 4]`）；**n 一大（如 n≥10）就是 3628800 个**，必须换 `intlinprog`（凭经验）。
4. **0-1 背包的容量方向写反**：`Σ w x ≤ cap` 而非 `≥`（凭经验）；本骨架实测最优值 `220`（`x=[0 1 1]`）。
5. ★ **拿 `intlinprog` 当"独立参照"**：它只是**实现**，同机同实现**不独立**（任务书 B）；参照走**手算 / 全排列穷举**。
6. **`intlinprog` 的 `intcon` 漏项**：忘了声明哪些变量是整数 ⇒ 退化成 LP（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/ilp_assignment.m`（**零参可跑**；含 (A) 4×4 指派·全排列穷举 (B) 0-1 背包·`intlinprog` 两例）。

关键片段（**不整份复制**）：
```matlab
% (A) 指派：n 小 ⇒ 全排列穷举（精确）
P = perms(1:n);
for k = 1:size(P,1); vals(k) = sum(cost(sub2ind(size(cost), (1:n).', P(k,:).'))); end
[cost_min, imin] = min(vals);  assign = P(imin, :);
% (B) 0-1 背包：intlinprog（max ⇔ min 取负）
[x, fval] = intlinprog(-v(:), 1:nI, w(:).', cap, [], [], zeros(nI,1), ones(nI,1), ...
                       optimoptions('intlinprog','Display','off'));
```
