# 遗传算法（`ga.m`）

> **目标不可微 / 组合爆炸 / 黑箱时用**：把解编码成"个体"，靠**选择 + 交叉 + 变异**并行搜索，不依赖梯度。代价是**结果随随机数变** —— 必须**固定种子 + 多次运行给分布**。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/ga.m` · 参照 `tests/skills/model-select/verify/ga.md`。
★ **与相邻方法的边界**：多种群 / 量子 / 混合变体 ⇒ `references/optimization/ga_variants.md`；要"按温度退火接受" ⇒ `references/optimization/sa.md`。
★ **撞名提醒**：MATLAB Global Optimization Toolbox 有同名函数 `ga`；`addpath` 本目录后**路径文件胜出**（本骨架优先）。

## ① 适用判据

- **用**：**组合 / 离散**问题（调度、选址、TSP）或**不可微 / 黑箱**目标；解空间大、梯度难求；能构造"编码 + 交叉 + 变异"；允许**近似解**、有多余算力跑多次。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **目标可微且凸** ⇒ 用梯度法 / `fmincon`（更快、有最优性保证）；GA 是浪费（凭经验）。
  2. **要求全局最优保证** ⇒ GA 只保证**概率意义**下的好解，不给最优性证书（凭经验——常见的过度宣称）。
  3. **变量少、规模小** ⇒ 精确算法（枚举 / 动态规划）反而更快更准（凭经验）。
  4. **只跑一次就报结果** ⇒ 忽略随机性、结果不可复现 ⇒ 必须**固定种子 + 多运行**（本类纪律核心，见 ④-1）。
  5. **约束极紧** ⇒ 惩罚函数权重难调、可能只得到不可行解（凭经验）。

## ② 标准建模步骤

1. **编码**：实数编码（连续）/ 排列编码（路径）/ 二进制（选择）。
2. **定适应度**：目标函数（+ 惩罚项处理约束）。
3. **初始化种群**：`N` 个体（本骨架 `pop=40`，域 `[-10,10]^2`）。
4. **选择**：锦标赛 / 轮盘赌（本骨架锦标赛规模 2）。
5. **交叉 / 变异**：混合交叉（`pc=0.9`）+ 高斯变异（`pm=0.1`，步长随代数收缩）。
6. **精英保留**：留住历史最优，防退化。
7. ★ **固定种子 + 多次运行**：`rng(seed)` 各跑一次，报**逐次最优 + mean±sd + 命中率 / 相对差**。
8. **停止**：达到代数上限 / 收敛。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 目标函数 · 编码 · `pop` · `maxgen` · `pc` · `pm` · 种子 · 域 |
| **输出** | 逐次最优 `f_best` / `x_best` · `mean ± sd` · 命中率 · 相对差 |

**显式假设（必须写进论文）**：
1. **解可编码**且**交叉/变异算子能保持可行性**（或惩罚能引导回可行域）。
2. **适应度能反映优劣**（含约束处理方式）。
3. ★ **结果是随机变量**：必须报**固定种子下的可复现值** + **多种子的分布**；**单次跑的 `f_best` 不能当性能**。
4. **参数（`pop`/`pc`/`pm`/代数）是显式超参**，影响收敛。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**（本方法**最常犯**的错）：结果随 RNG 变。**实测**（本骨架 `ga.m`，单峰 `f(x)=3+(x1-2)²+(x2+1)²`、`f*=3`、`pop=40`、`maxgen=150`）：5 个种子的 `f_best` = `3 / 3.0000295 / 3 / 3 / 3.0000001`，**mean ± sd = `3.0000059 ± 1.3191647e-05`**；**命中率 `5/5`**（`|f−f*| ≤ 1e-4`）。
2. ★ **可复现性**：固定 `rng(seed)` 后**跨进程重跑逐位相同**。**实测**（两次独立 `matlab -batch`）：本骨架整段输出**逐字节一致**（`diff` 为空）。
3. ★ **拿 `ga`（工具箱 / 内置）当"独立参照"**：同机同实现**不独立**（任务书 B）；参照走**已知最优算例 + 独立参照件**。
4. **变异步长不随代数收缩** ⇒ 后期在最优点附近乱跳、精度上不去（凭经验）。
5. **种群太小 / 代数太少** ⇒ 早熟收敛；太大 / 太多 ⇒ 慢（凭经验）。
6. **约束只靠惩罚、不检查可行性** ⇒ 可能报出不可行"最优解"（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/ga.m`（**零参可跑**，5 种子分布 + 可复现）。

关键片段（**不整份复制**）：
```matlab
for s = 1:numel(seeds)
    rng(seeds(s));                                   % ★ 固定种子
    P = lo + (hi - lo) .* rand(pop, D); fv = fit(P);
    for gen = 1:maxgen
        % 锦标赛选择 → 混合交叉 → 高斯变异（步长收缩）→ 精英保留
    end
    [fbest(s), im] = min(fv); xbest(s,:) = P(im,:);  % 多次运行给分布
end
```
