# 蚁群 ACO（`aco.m`）

> **路径 / 组合类问题、要"信息素正反馈"时用**：一群"蚂蚁"按**信息素 × 启发式**的概率逐点构建路径，走得好（路径短）的多留信息素，信息素又指引下一代；**正反馈**收敛到好路径。代价同族：**结果随随机数变**，固定种子 + 多运行。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/aco.m` · 参照 `tests/skills/model-select/verify/aco.md`。
★ **与相邻方法的边界**：要"群体进化" ⇒ `references/optimization/ga.md`；TSP 也可用 2-opt 的 `references/optimization/sa.md`。

## ① 适用判据

- **用**：**图上路径 / 组合**问题（TSP、路由、车辆调度、路径规划——本题材的经典落点）；能定义"边的代价 + 启发式（如 `1/d`）"；可接受近似解。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **连续无结构变量** ⇒ ACO 的"路径构建"不自然 ⇒ 用 `references/optimization/pso.md` / `afsa.md`（凭经验）。
  2. **要求精确最优** ⇒ ACO 给近似解（凭经验）。
  3. **信息素参数失配**：挥发率 `ρ` 太大 ⇒ 记忆丢光；太小 ⇒ 早熟（凭经验）。
  4. **只跑一次就报结果** ⇒ 结果不可复现（本类纪律核心，见 ④-1）。
  5. **规模极小时** ⇒ 精确枚举反而更快更准（凭经验）。

## ② 标准建模步骤

1. **建图**：节点 + 边 + 边代价矩阵 `D`，启发式 `η = 1/D`。
2. **初始化信息素** `τ`（本骨架全 1）。
3. **每代**：每只蚂蚁从随机起点，按概率 `τ^α · η^β`（避开已访问）逐步构建路径。
4. **挥发 + 沉积**：`τ ← (1−ρ)τ`，再按路径长度沉积 `Q/L`。
5. **记忆最优**：记录全程最短路径。
6. ★ **固定种子 + 多次运行**：报**逐次最优 + mean±sd + 命中率 / 相对差**。
7. **调参**：`α, β, ρ, nAnts, maxit`。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 城市 / 节点坐标 · `nAnts` · `maxit` · `α`（信息素权重）· `β`（启发式权重）· `ρ`（挥发率）· 种子 |
| **输出** | 逐次最优 `L_best` / 最优解 · `mean ± sd` · 命中率 · 相对差 |

**显式假设（必须写进论文）**：
1. **问题可表示成"图上的路径构建"**，且**边代价可加**。
2. **信息素模型**（本骨架用 ant system：按路径长度沉积）。
3. ★ **结果是随机变量**：报固定种子可复现值 + 多种子分布；**单次读数不能当性能**。
4. **`α, β, ρ, nAnts, maxit` 是显式超参**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**：**实测**（本骨架 `aco.m`，5 城 TSP `C=[0 0;3 0;3 4;0 4;1.5 2]`，**已知最优 `L*=15`**、`nAnts=10`、`maxit=60`、`α=1, β=3, ρ=0.5`）：5 个种子的 `L_best` = `15 / 15 / 15 / 15 / 15`，**mean ± sd = `15 ± 0`**，**命中率 `5/5`**，相对差全 `0`。
2. ★ **可复现性**：**实测**（两次独立 `matlab -batch`）：本骨架整段输出**逐字节一致**（`diff` 为空）。
3. ★ **拿工具箱 / 内置当"独立参照"**：同机同实现**不独立**（任务书 B）；参照走**独立穷举出的已知最优**（见 ⑥ 与参照件）。
4. **概率全零导致构建失败**：某步所有未访问边概率为 0 时须随机选（本骨架已处理：`if sum(prob)<=0`）。
5. **不挥发 / 不遗忘** ⇒ 早期次优路径的信息素锁死搜索（凭经验——`ρ` 的作用）。
6. **`β` 太大** ⇒ 退化成贪心最近邻、丢多样性（凭经验）。

## ⑤ 输出模板

- 最优路径图 / 收敛曲线 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）；分布表 → `mcm-table`（`.claude/skills/mcm-table/`）。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/aco.m`（**零参可跑**，5 城 TSP，5 种子分布 + 可复现）。

关键片段（**不整份复制**）：
```matlab
for s = 1:numel(seeds)
    rng(seeds(s)); Tau = ones(n);                    % ★ 固定种子
    for it = 1:maxit
        for a = 1:nAnts
            % 按 (Tau.^alpha).*(Eta.^beta) 概率逐步构建路径（避开 tabu）
        end
        Tau = (1 - rho) * Tau;                       % 挥发
        for a = 1:nAnts; for k = 1:n                 % 按长度沉积 Q/L
            Tau(Tours(a,k), Tours(a,mod(k,n)+1)) = Tau(...) + Qc / Ls(a);
        end; end
    end
    Lbest(s) = bL; tourbest(s,:) = bt;               % 多次运行给分布
end
```
**独立参照**：`tests/skills/model-select/verify/aco.md`（**第 4 类：已知最优小算例 + 固定种子 + 多次运行的分布** —— `L*=15` 由全排列穷举独立得出）。
