# 目标规划（`goal_programming.m`）

> **多个目标互相打架、要"尽量都满足"时用**：不给目标定硬指标，而是给每个目标一个**期望值**，引入**正/负偏差变量**，最小化（加权或分层的）偏差 ⇒ 得到"最不让谁失望"的折中方案。

**归属**：类索引 `references/optimization.md` · 骨架 `assets/matlab/optimization/goal_programming.m` · 参照 `tests/skills/model-select/verify/goal_programming.md`。
★ **与 `nlp` / 多目标优化的边界**：目标规划是**把多目标转成单目标 LP**（偏差最小化），可**分层让步**；若要的是**一整条 Pareto 前沿**，那是多目标优化（`references/optimization/ga_variants.md` 的 NSGA-II 一族）。

## ① 适用判据

- **用**：题面有**多个目标**、彼此**不能同时最优**，但可以给每个目标一个**期望值 / 目标值**；各目标**量纲/优先级不同**（需要加权或分层）；希望得到"权衡后可解释"的方案。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **只有一个目标** ⇒ 直接 LP/NLP，不必引入偏差变量（凭经验——多余建模）。
  2. **目标间可公度、就是要加总** ⇒ 直接加权求和即可，目标规划是"含不可达期望值的加权和"（凭经验）。
  3. **要完整权衡曲线（Pareto 前沿）** ⇒ 目标规划只给**一个**折中点 ⇒ 用多目标优化（`references/optimization/ga_variants.md`）。
  4. **硬约束其实可以违反** ⇒ 那是"软目标"，应放进目标（偏差项）而不是硬约束，否则会**无解**（凭经验——最常见的翻车）。

## ② 标准建模步骤

1. **定决策变量** `x`。
2. **给每个目标写期望值** `g_k`，引入**偏差变量** `d_k⁻, d_k⁺ ≥ 0`：`(目标式) + d_k⁻ − d_k⁺ = g_k`。
3. **区分硬约束与软目标**：不可违反的写硬约束；可折中的写偏差式。
4. **定优先级 / 权重**：加权式给权重 `w_k`；分层式按优先级**逐轮求解**（后轮不得恶化前轮）。
5. **求解**：加权式 = 一个 LP（`linprog`）；分层式 = 多轮 LP。
6. **读解**：哪些目标达成、哪些欠/超，各偏差数值。
7. **解释**：把偏差翻译回"哪个目标让步了多少"。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 决策变量 · 各目标式与期望值 · 偏差权重（或优先级）· 硬约束 |
| **输出** | 最优 `x*`、各偏差 `d⁻/d⁺`、总偏差代价 |

**显式假设（必须写进论文）**：
1. **线性性**：目标式与硬约束都是线性的（加权式因此可当 LP 解）。
2. **期望值 / 优先级来自题意或决策者**（不是算法自定——要写明出处）。
3. **权重的口径**（加权式）：权重反映"可接受的让步比"；**不同权重给不同解**。
4. **分层式的支配性**：前一层未优化到最优前，不得进入下一层（lexicographic 语义）。
5. **偏差变量非负**且**同一目标 `d⁻` 与 `d⁺` 至少一个为 0**（LP 最优会自动满足，不必显式加约束）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **把软目标写进硬约束 ⇒ 无解**：期望值往往**本来就不可达**（这正是要"规划"的原因），一旦当硬约束就矛盾（凭经验——最典型）。
2. **权重/优先级没交代出处**：评审会问"凭什么是这个权重"（凭经验）；要写明是题意、专家还是敏感性分析取的。
3. **忘了 `d⁻, d⁺` 两个都要有**：只放一个方向会锁死"只能欠、不能超"（凭经验）。
4. **本骨架实测**：算例 `min 2·d1⁻ + 1·d2⁻`（硬约束 `x1+x2 ≤ 10`；目标1 `x1+2x2 → 16`；目标2 `2x1+x2 → 16`）
   ⇒ 手算与骨架**逐位一致**：最优 `(x1,x2) = (4,6)`、`d1⁻=0`、`d2⁻=2`、**总代价 = 2**。
5. **分层式误用成加权式**：把"优先级"当"权重"并入一个目标，会**允许低优先级目标换来高优先级恶化**（凭经验）。
6. **拿 `linprog` 当"独立参照"**：它只是**实现**，同机同实现**不独立**（任务书 B）；参照走**手算**。

## ⑥ 代码骨架

**路径**：`assets/matlab/optimization/goal_programming.m`（**零参可跑**，自带上述算例；变量 `z = [x1 x2 d1⁻ d1⁺ d2⁻ d2⁺]`）。

关键片段（**不整份复制**）：
```matlab
c    = [0 0 w1 0 w2 0];              % 目标：加权偏差最小
A_ub = [1 1 0 0 0 0];  b_ub = 10;    % 硬约束 x1+x2 <= 10
A_eq = [1 2 1 -1 0 0; 2 1 0 0 1 -1]; b_eq = [16; 16];   % 目标1 / 目标2（含偏差变量）
[z, cost] = linprog(c, A_ub, b_ub, A_eq, b_eq, zeros(1,6), [], ...
                    optimoptions('linprog','Display','off'));
```
