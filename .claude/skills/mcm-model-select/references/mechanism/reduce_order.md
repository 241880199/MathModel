# 降阶 / 解析解法（`reduce_order.m`）

> **给"高阶方程要化成一阶组"或"能拿闭式解"的题用**：把 n 阶 ODE 降成 n 个一阶方程的组（好交给数值积分），或用分离变量 / 齐次 / 常数变易等**解析手法**直接求出通解或特解。

**归属**：类索引 `references/mechanism.md` · 骨架 `assets/matlab/mechanism/reduce_order.m` · 参照 `tests/skills/model-select/verify/reduce_order.md`。
★ **与相邻方法的边界**：**只要数值轨迹、不在乎闭式** ⇒ 直接初值问题（`references/mechanism/ode_ivp.md`）；**两端给条件** ⇒ `references/mechanism/ode_bvp_shooting.md`；**离散时间步**（`x_{k+1}=f(x_k)`，那是**差分**降阶 / 递推）⇒ `references/mechanism/difference_equations.md`；**非线性系统要长期稳定性** ⇒ `references/mechanism/param_id_stability.md`（线性化 / 特征值）。

## ① 适用判据

- **用**：方程**阶数 ≥ 2**、需要**降成一阶组**以便数值求解；或方程属于**可解析求通解的型**（可分离变量 `g(y)dy=f(x)dx`、齐次 / 可化为齐次、形如 `y^(n)=f(x)` 的逐次积分、常系数线性方程的常微分算子分解）；或题面**要通解 / 解的族结构 / 参数在解里的显式关系**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **只要数值轨迹**：降阶后还得靠 `ode_ivp` 积分——**降阶只是第 1 步**，别把"降成一阶组"当成"解完了"（见 `references/mechanism/ode_ivp.md`）。
  2. **方程不能解析求通解**（非线性、变系数）⇒ 硬套"分离变量"会**写出错的通解** ⇒ 老实走数值法。
  3. **`dsolve` 给不出闭式**（返回 `RootOf` / 空）⇒ 说明该方程**无初等闭式解**，别把符号输出当解析解（凭经验）。
  4. **题面的"降阶"其实指降维 / 降复杂度**（如 PDE 减维、模型简化）⇒ 那是另一回事，属 `references/mechanism/pde_numerical.md` 或建模简化，不是本方法的 ODE 降阶。
  5. ★ **把 `dsolve` 当"独立参照"**：它只是**同机的符号实现**（任务书 B / GC6）——本方法的真参照是**教科书闭式解 + 收敛阶**。

## ② 标准建模步骤

1. **判型**：先看方程属于哪一类（可分离 / 齐次 / 线性常系数 / `y^(n)=f(x)`）—— 类别决定用哪种解析手法。
2. **降阶（数值路线）**：引入 `y1=y, y2=y', …, yn=y^(n-1)`，得**一阶组** `y' = F(x, y)`；初值由原问题的 `y(a), y'(a), …` 给出。
3. **解析路线（能求出时）**：
   - **可分离**：`∫g(y)dy = ∫f(x)dx + C`，再用初值定 `C`。
   - **齐次 / 可化为齐次**：令 `u=y/x`，化为可分离。
   - **`y^(n)=f(x)`**：逐次积分 n 次，带 n 个积分常数。
   - **线性常系数**：特征方程 `P(r)=0` 求根，按重根 / 复根写通解。
4. **定常数**：用初值 / 边值定积分常数（通解 → 特解）。
5. **数值验证**（★ 见 ⑥）：对有闭式解的算例，用降阶后的一阶组做定步长 RK4，比逐点误差 + **步长减半看误差按阶下降**（~16）。
6. **报告**：闭式解（若有）+ 轨迹图 + 收敛阶读数。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 高阶方程（或其一阶组形式）· 初值 / 边值 · 步长（数值路线）或符号工具（解析路线） |
| **输出** | 一阶组 `y'=F` · 通解 / 特解（闭式）· 轨迹 · 收敛阶读数 |

**显式假设（必须写进论文）**：
1. **阶数已知**，且降阶成一阶组的变量代入是**恒等变换**（不改变方程）。
2. **解析求解的适用域**：分母不为零、开方取定符号、对数参数为正等（如齐次的 `u=y/x` 要求 `x≠0`）。
3. **积分常数由初值/边值唯一确定**（初值个数 = 阶数）。
4. **闭式解的奇点 / 分支**写清（如 `y'=y^2` 的解在有限时间爆破）。
5. **数值路线**的步长 / 容差与 `ode_ivp` 同口径。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **降阶后当"解完了"**：降成一阶组只是**预处理**，还要积分 + 验证"算得对"。**实测**（本骨架）：`d2y/dx2 + y = 0, y(0)=1, dy/dx(0)=0 ⇒ y=cos x`，降阶后 RK4 步长减半误差比 `16.238`（N=20/40）· `16.213`（N=40/80）⇒ 才见 4 阶。
2. **解析求解丢根 / 丢常数**：分离变量积分常数、线性方程的重根与复根、`tan` 的分支——漏一个就是**错解**（凭经验）。
3. **齐次代换的条件没写**：`u=y/x` 要求 `x≠0`；`y^(n)=f(x)` 逐次积分要带 n 个常数（凭经验）。
4. ★ **把 `dsolve` 输出当"独立参照"**：符号解是**同机实现**（本骨架实测 `dsolve` 返回 `cos(x)`，与手写闭式一致 ⇒ **只作交叉核对、非独立参照**）。
5. **数值与解析"同公式"却宣称独立**：若手算与骨架用**同一公式**（如都写 `cos(x)`），那是**符号核对、非数值验证** —— 必须另给**逐点数值误差 + 收敛阶**（本骨架的硬核在误差比 `16.238`）。
6. **爆破解没做步长控制**：`y'=y^2` 这类有限时间爆破，固定步长会**跨过奇点**给出垃圾（凭经验）。

```matlab
% 降阶：d2y/dx2 + y = 0  ⇒  一阶组 z' = [z2; -z1]，初值 [y(0); dy/dx(0)] = [1; 0]
f  = @(z) [z(2); -z(1)];
y0 = [1; 0];
order_ratio = y_err_N / y_err_2N;     % ~ 16（RK4 定步长，4 阶）
% dsolve 仅作同机符号交叉核对（非独立参照）
sol = dsolve(diff(y,x,2)+y==0, y(0)==1, subs(diff(y,x),x,0)==0);   % ⇒ cos(x)
```
