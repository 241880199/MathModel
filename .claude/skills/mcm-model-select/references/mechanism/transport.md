# 输运方程（热传导 / 扩散 / 波动）（`transport.m`）

> **给"通量守恒"的一维演化题用**：平流 `u_t + c u_x = 0`（随流搬运）· 扩散 / 热传导 `u_t = D u_xx`（抹平梯度）· 波动 `u_tt = c² u_xx`（往返振荡）—— 用显式有限差分逐拍推进。

## ① 适用判据

- **用**：方程是一维**守恒律 / 输运**：**平流**（`u_t + c u_x = 0`）、**扩散 / 热传导**（`u_t = D u_xx`）、**波动**（`u_tt = c² u_xx`）；重点在**格式选型与 CFL / 稳定域**，且要**整场演化**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **一般 PDE、用内置 `pdepe`/`ode15s` 即可**（不必讲格式细节）⇒ 走 `references/mechanism/pde_numerical.md`。
  2. **反应是主角**（行波前、斑图）⇒ 走 `references/mechanism/reaction_diffusion.md`。
  3. **多维 / 复杂几何**⇒ 有限差分直接法退化，需有限元 / 商用求解器（凭经验）。
  4. **只关心稳态**（不是演化）⇒ 属椭圆型，走 `references/mechanism/pde_numerical.md`。
  5. **拿它当"任意 PDE 的通用解"**：平流 / 扩散 / 波动的格式与稳定条件**各不相同**，不能一套格式打天下。

## ② 标准建模步骤

1. **定子形态**：平流 / 扩散 / 波动（决定方程与格式）。
2. **定域与边界**：本骨架用**周期域** `(0,1)`；其他边界（Dirichlet / Neumann）另设。
3. **空间离散**：平流用迎风（`c>0` 用 FTBS）；扩散用中心差分 FTCS；波动拆成 `u_t = v, v_t = c² u_xx`。
4. **定时间步**：平流核 **CFL** `c dt/dx`（迎风稳定 `≤1`，取 `=1` 甚至精确）；扩散核 `r = D dt/dx² ≤ 0.5`。
5. **逐拍推进**得整场。
6. **数值验证**（★ 见 ⑥）：对有**闭式解**的初值（正弦）比逐点误差 + 衰减率。
7. **报告**：时空图 / 多时刻剖面 + 格式与 CFL / 稳定域。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **平流不取 CFL=1 时有数值耗散 / 色散**：迎风 FTBS 在 `CFL=1` 时**精确**（整格平移）。**实测**（Task 1）：`max|u-u_exact|=7.772e-16`（机器精度）；`CFL≠1` 会有 `O(dx)` 数值扩散。
2. ★ **扩散衰减率与解析对不"逐位"**：显式 FTCS 是空间二阶、时间一阶 ⇒ 衰减率有 `O(dt)` 偏差。**实测**（Task 1）：数值衰减率 `3.94966147` vs 解析 `D(2 pi)^2=3.94784176`，差 `1.8e-03`；`max|u-u_exact|=1.263e-04`（`O(dx²)`）。
3. **扩散显式格式越稳定域**：`r = D dt/dx² > 0.5` 会振荡发散（凭经验 + von Neumann 分析）。
4. **波动方程当成一阶处理**：`u_tt` 要拆成两个一阶方程（`u, v`），否则格式写错（凭经验）。
5. ★ **拿 `ode45`/`pdepe` 当"独立参照"**：真参照是**闭式解**（正弦平流 / 扩散解析衰减）。
6. **"薄"语料当成"厚"**：本方法的**热传导 / 波动子形态无语料背书**，只有"扩散"这一薄支有（见下）。别把它写成"常用"。

**路径**：`assets/matlab/mechanism/transport.m`（**零参可跑**，自带算例 `c=1, D=0.1, N=100, T=0.5`，周期域）。

关键片段（**不整份复制**）：
```matlab
% 平流：迎风 FTBS，CFL=1 时精确
um = circshift(u, 1);  u = u - cfl*(u - um);
% 扩散：中心差分 FTCS（稳定需 r <= 0.5）
wp = circshift(w,-1); wm = circshift(w,1);  w = w + r*(wp - 2*w + wm);
```
