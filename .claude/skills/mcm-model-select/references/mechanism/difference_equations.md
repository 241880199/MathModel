# 差分方程（离散动力系统 · 稳定性判据）（`difference_equations.m`）

> **给"按离散步演化"的题用**：状态只在离散时刻更新（`x_{k+1} = f(x_k)` 或 `x_{k+1} = A x_k`），要**逐期递推、判稳定、找平衡**。

**归属**：类索引 `references/mechanism.md` · 骨架 `assets/matlab/mechanism/difference_equations.m` · 参照 `tests/skills/model-select/verify/difference_equations.md`（**Task 1 已交付、已过独立复核**）。
★ **与相邻方法的边界**：**自变量连续**（`dy/dt=f`）⇒ `references/mechanism/ode_ivp.md`；**离散但每步带随机** ⇒ `simulation` 类（`references/simulation/monte_carlo.md`）；**多期数据要外推预测** ⇒ `prediction` 类（`references/prediction/trend_extrapolation.md`）。

## ① 适用判据

- **用**：状态演化是**离散时间步**（`x_{k+1}=f(x_k)`，或线性 `x_{k+1}=A x_k`）；要**逐期递推**、**求平衡点**、**判长期稳定 / 收敛 / 振荡**；或题目天然按"年 / 月 / 代"离散更新（种群代际、库存周转、马尔可夫链、递推经济模型）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **过程本是连续时间**（物理演化、连续增长）却离散化 ⇒ 步长影响**动力学性质**（可能把稳定系统算成不稳定）⇒ 走 `references/mechanism/ode_ivp.md` 更稳。
  2. **有随机扰动逐期叠加**（`x_{k+1}=f(x_k)+噪声`）⇒ 那是随机过程 / 仿真（`references/simulation/monte_carlo.md`）。
  3. **只是想按趋势外推已有时间序列**，不追究递推机理 ⇒ 走 `prediction` 类（`references/prediction/moving_average.md` 等）。
  4. **把它与微分方程混为一谈**：`differential equation` 的语料**不能**给差分方程背书信（离散 ≠ 连续，Task 1 已裁）。

## ② 标准建模步骤

1. **写状态与更新规则**：定状态向量 `x_k` 与映射 `x_{k+1}=f(x_k)`（或矩阵 `A`）。
2. **定初值 `x_0`**。
3. **逐项递推**：`for k=1..N` 更新，得轨线 `x_k`。
4. **求平衡点**：解 `x*=f(x*)`（线性时 `(I-A)x*=0`）。
5. **判稳定**：标量判据 `|a|<1`；向量判据**谱半径** `ρ(A)=max|eig(A)|<1`。
6. **数值验证**（★ 见 ⑥）：标量递推比**闭式解** `x_n=a^n x_0`；稳定性比解析判据。
7. **报告**：轨线图 + 平衡点 + 稳定性结论（收敛 / 振荡 / 发散）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 更新映射 `f` 或矩阵 `A` · 初值 `x_0` · 步数 `N` |
| **输出** | 轨线 `x_k` · 闭式解（标量）· 谱半径 · 稳定 / 不稳定 |

**显式假设（必须写进论文）**：
1. **离散时间步长已定**（"一年一步"等），且步长选择不改变所关心的结论。
2. **映射 `f` / 矩阵 `A` 已知且定常**（不随 `k` 变；时变另论）。
3. **线性系统的稳定性 ⟺ 谱半径 < 1**（这是谱半径判据的适用前提）。
4. **初值 `x_0` 的物理含义与量纲**写清。
5. **递推不发散到非物理值**（种群不取负等，必要时加约束）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **用连续语料给离散方法背书**：`differential equation` 的命中**不能**算作差分方程的证据（离散 ≠ 连续）。**实测**（Task 1）：`difference equation` 在 `corpus/papers/MODEL_MAP.md` **0 命中** ⇒ 本方法标 `[社区]`。
2. **稳定性只看单个特征值**：多变量系统必须看**谱半径**（`max|eig(A)|`），只看对角元 / 单系数会漏（凭经验）。
3. **递推发散不报警**：`|a|>1` 时数值会溢出，要**先判稳定性再算长轨线**（凭经验）。
4. ★ **谱半径行的"符号核对"要标清**：骨架与参照**同用 `eig`** ⇒ 该行是**符号核对、非数值验证**；本方法的**数值验证在 `x_10` 行**（逐项迭代 vs 闭式解 `a^N x_0`，逐位相同）。**实测**（Task 1）：`x_10=0.0009765625`（两侧同）、谱半径 `0.8`。
5. **离散步长与"事件"错位**：更新发生在期初还是期末、状态是存量还是流量，写反会让结果差一期（凭经验）。

% 标量递推：数值迭代 vs 闭式解
x = x0;  for n = 1:N; x = a * x; end
x_closed = a^N * x0;                 % 闭式解

rho = max(abs(eig(A)));              % 稳定 ⟺ rho < 1
