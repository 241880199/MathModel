# 参数辨识 / 稳定性分析（`param_id_stability.m`）

> **给"方程形态已知、参数未知"或"要看长期稳定性"的题用**：动力学方程（如 logistic `dN/dt=rN(1-N/K)`）写得出，但参数 `(r,K)` 要从观测数据**反推**；或要判**平衡点稳不稳**（线性化特征值）。

**归属**：类索引 `references/mechanism.md` · 骨架 `assets/matlab/mechanism/param_id_stability.m` · 参照 `tests/skills/model-select/verify/param_id_stability.md`（**Task 1 已交付、已过独立复核**）。
★★ **与相邻类的边界（类索引已定，必须逐字落实）**：
- **与 `statistics`（估计）的边界**：本方法做的是**机理模型内部参数的辨识**（先有动力学方程，再反推它的参数）；`statistics` 的**假设检验 / 方差分析 / 贝叶斯推断**做的是**从数据推断总体性质 / 检验假设**（不预设动力学方程）。**若题面没有机理方程、只要"这两组数有没有差别" ⇒ 属 `statistics`**（`references/statistics/hypothesis_test.md` 等）。
- **与 `optimization`（拟合）的边界**：本方法把"反推参数"化成一个**最小二乘**问题并用优化器求解（本骨架用 `fminsearch`）——**优化只是手段（fitting）**；`optimization` 类的方法（`references/optimization/nlp.md` 等）关注的是**一般约束最优的模型选择**。**若题面的核心是"在约束下求最优决策"、参数不是从动力学反推 ⇒ 属 `optimization`**。
- **与 `ml` 的边界**：`ml` 的回归 / 神经网络是**纯数据驱动**（不假设方程）；本方法是**机理约束下的参数估计**。

## ① 适用判据

- **用**：题面**已给定（或可写出）动力学方程形态**、但**参数未知**，要从观测 / 实验数据**估计参数**；或给出方程与参数、要**判平衡点稳定性 / 长期行为**（特征值符号、`R0`、Hopf 分岔）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **没有机理方程**、只有数据 ⇒ 走 `statistics`（回归 / 检验 / 贝叶斯）或 `ml`（数据驱动）。
  2. **核心是约束最优决策**（不是反推机理参数）⇒ 走 `optimization` 类。
  3. **方程形态也未知**（要在多个候选模型间选）⇒ 那是**模型选择**本身，先做 AIC/BIC 比较，别硬拟合一个错的形态。
  4. **参数不可辨识**（不同参数组合给同样的输出）⇒ 拟合会给出**一族解**；要先做**可辨识性分析**（敏感性 / 剖面似然），不能只报一个点估计（凭经验）。
  5. **数据含噪却报"精确等于真值"**：加噪数据只会在**噪水平内**回到真值（见 ④）。

## ② 标准建模步骤

1. **写机理方程**（含待估参数 `θ`）。
2. **收集 / 生成观测数据** `d_i = model(t_i; θ) + 噪声`。
3. **构造目标**：最小二乘 `J(θ) = Σ (model(t_i;θ) - d_i)²`（常取对数参数化 `θ=exp(p)` 保证正性）。
4. **优化**求解 `θ̂ = argmin J`（`fminsearch`/`lsqcurvefit`）。
5. **稳定性分析**：求平衡点，算线性化 Jacobi 的特征值 / 导数符号 ⇒ 判稳（实部 <0 稳定）。
6. **可辨识性 / 敏感性检查**：扰动参数看输出变化；不敏感 ⇒ 不可辨识。
7. **数值验证**（★ 见 ⑥）：**造真值参数** ⇒ 反演回来要对得上（无噪精确、加噪在噪水平内）。
8. **报告**：参数点估计 + 置信区间 / 分布 + 稳定性结论。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 机理方程 · 观测数据（或真值参数造合成数据）· 优化初值 · 噪声水平 |
| **输出** | 参数估计 `θ̂` · 稳定性结论（特征值 / 符号）· 敏感性 |

**显式假设（必须写进论文）**：
1. **方程形态正确**（这是本方法的前提；形态错了，参数估得再准也没用）。
2. **参数定常**（不随时间变）。
3. **噪声模型**写清（本骨架加高斯噪声、固定种子 `rng(0)`）。
4. **可辨识性**成立（否则给**参数分布 / 区间**，不给单点）。
5. **优化收敛到全局最优**（多初值重启防局部极小；凭经验）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **加噪数据报"精确等于真值"**：只会在**噪水平内**回到真值。**实测**（Task 1）：真值 `(r,K)=(0.5,10)`；无噪反演相对差 `(1.885e-13, 1.659e-13)`；**2% 噪声（种子 0）**反演 `(0.515433946183, 9.94436625891)`，相对差 `(3.087e-02, 5.563e-03)`。
2. ★ **稳定性行的"符号核对"要标清**：骨架与参照**同用真值写 `±r`** ⇒ 该行是**符号核对、非数值验证**。**实测**（Task 1）：`N*=0: f'=+0.5`（不稳定）、`N*=K: f'=-0.5`（稳定）。
3. **只报点估计、不做可辨识性**：多参数模型常有**参数相关**（`r` 与 `K` 在数据不充分时强耦合）⇒ 必须给区间 / 敏感性（凭经验）。
4. **优化初值 / 参数化不当**：直接优化 `K` 可能跑到负值 ⇒ 用 `exp` 参数化保证正（本骨架做法）（凭经验）。
5. **把"拟合残差小"当"模型对"**：残差小只说明**在该数据上拟合好**，不说明方程形态对（凭经验）。
6. **★★ 越界到 statistics / optimization**：这是本方法**最易混淆**处——见上方"与相邻类的边界"逐条对；**别把"从数据估总体"（statistics）或"约束最优决策"（optimization）写成参数辨识**。
