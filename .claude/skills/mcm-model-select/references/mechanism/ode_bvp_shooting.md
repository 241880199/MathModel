# ODE 边值问题（打靶法）（`ode_bvp_shooting.m`）

> **给"两端各给一个条件"的连续时间系统用**：方程 `d2y/dx2 = f(x, y, dy/dx)` 已知，但**边界条件在两端**（如 `y(0)=0`、`y(L)=1`）⇒ 把缺的那个**初值当未知量**，反复"打靶"直到右端条件满足。

**归属**：类索引 `references/mechanism.md` · 骨架 `assets/matlab/mechanism/ode_bvp_shooting.m` · 参照 `tests/skills/model-select/verify/ode_bvp_shooting.md`。
★ **与相邻方法的边界**：**两端条件都是初始侧（给初值）** ⇒ 初值问题（`references/mechanism/ode_ivp.md`）；**含空间维度、两端是空间边界** ⇒ `references/mechanism/pde_numerical.md`（那才用 `bvp4c`/有限差分整场求）；**参数未知** ⇒ `references/mechanism/param_id_stability.md`。

## ① 适用判据

- **用**：方程 `d2y/dx2 = f(x, y, dy/dx)`（或高阶化成一阶组）**在两端各给一个条件**（一端定函数值、另一端定函数值或导数值）；要**整条解曲线**（不是向前演化轨迹）。典型：梁的挠度（两端固定/简支）、稳态一维温度（两端定温）、管流（进出口各一条件）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **两端条件其实都是初值**（`y(0)`、`dy/dx(0)` 都给）⇒ 直接积分（`references/mechanism/ode_ivp.md`），**不必打靶**。
  2. **有天然时间方向、只给初始状态** ⇒ 那是初值问题，把它当边值问题会**凭空多出一个约束**。
  3. **含空间维度 / 偏微分**（二维稳态温度等）⇒ 打靶法退化（要打的是边界函数）⇒ 走 `references/mechanism/pde_numerical.md`（有限差分 / `bvp4c`）。
  4. **方程在未知初值附近极敏感 / 非线性强**⇒ 单打靶**发散**（初值微扰被指数放大）⇒ 需多重打靶、或换配点法 / `bvp4c`（凭经验）。
  5. ★ **把 `bvp4c` 当"独立参照"**：它只是**实现**（同机同实现不独立，任务书 B / GC6）——本方法的真参照是**有闭式解的算例 + 收敛阶**。

## ② 标准建模步骤

1. **化成一阶组**：`y''=f` ⇒ `[y1;y2]' = [y2; f(x,y1,y2)]`。
2. **点数边界条件**：一端 2 个、另一端 2 个，共 4 个 ⇒ 一阶组两变量正好需要 2 个初始值，故**缺几个初值就设几个打靶未知量**（这里是 `s = y'(左端)`）。
3. **写打靶残差**：`φ(s) = y_右端(s) - 目标值`。
4. **解 `φ(s)=0`**：线性问题 `φ` 是 `s` 的一次函数（一步解出）；非线性问题用 `fzero`（标量）/ `fsolve`（向量）。
5. **用求得的 `s` 积分出整条解曲线**。
6. **数值验证**（★ 见 ⑥）：对**有闭式解的算例**逐点比 + **步长减半看误差按阶下降**（RK4 定步长 ~16）。
   ★ **收敛阶研究必须在每一档网格上各自重解 `s`** —— 否则误差被 `s` 的截断误差支配、比值退化成 ~2（本骨架已如此实现）。
7. **报告**：解曲线 + 打靶参数 `s`（可回译成物理量，如端点斜率）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 右端 `f` · 区间 `[a,b]` · 两端边界值 · 打靶未知量初值 · 步长 / 积分容差 |
| **输出** | 打靶参数 `s` · 解曲线 `y(x)` · （定步长）收敛阶读数 |

**显式假设（必须写进论文）**：
1. **解存在唯一**：边值问题良定（对应线性问题的系数矩阵非奇异 / 非线性问题的 Jacobi 非奇异）。
2. **初值问题在打靶过程中可反复求解**：即内层 `y'=f` 的初值问题在迭代中不发散（否则单打靶失效，见 ① 反面 4）。
3. **打靶未知量的个数 = 缺失的初始条件个数**（不能多设也不能少设）。
4. **边界条件类型写清**：Dirichlet（定值）/ Neumann（定导）/ 混合；本骨架是 Dirichlet + Dirichlet。
5. **积分器与步长**：定步长 RK4 或自适应；收敛阶研究要按档重解打靶参数。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **收敛阶研究里"把粗网格解出的打靶参数拿去跑细网格"**：误差被 `s` 的截断误差支配，比值**退化**。**实测**（本骨架）：固定 `s` 时比值 `2.431`；**按档重解 `s` 后** `14.721`（N=10/20）、`15.455`（N=20/40）⇒ 才是 RK4 的 4 阶。**这一型最隐蔽**。
2. **打靶未知量设置错**：设了不该设的（把已知边界当未知）、或漏设 ⇒ 残差方程个数对不上（凭经验）。
3. **`fzero`/`fsolve` 初值给得离根太远**⇒ 收敛到别的根 / 不收敛；**同一 BVP 可有多个解**（非线性时）（凭经验）。
4. **端点误差看错对象**：打靶解在**右端点**被残差方程"钉住"（那里误差 ~0），**最大误差在内部** ⇒ 要报**网格上的最大误差**，不是端点误差（实测：本骨架报 `max|y-sin(x)|`）。
5. ★ **拿 `bvp4c` / `ode45` 当"独立参照"**：同机同实现**不独立**（任务书 B）。真参照是有闭式解的算例（如 `y''=-y, y(0)=0, y(π/2)=1 ⇒ y=sin x`）。
6. **线性 BVP 明明能一步解出却用迭代法**：线性打靶 `φ(s)` 是一次式，`s` 可直接由两端值算出（见起点素材 `lineshoot.m` 的做法），不必迭代（凭经验）。

% 每档网格各自解 s（★ 收敛阶研究的关键）
fzopt = optimset('TolX', 1e-14);
s_N   = fzero(@(s) shoot_final(s, xr, yl, N)   - yr, 1.0, fzopt);
s_2N  = fzero(@(s) shoot_final(s, xr, yl, 2*N) - yr, 1.0, fzopt);
order_ratio = y_err_N / y_err_2N;     % ~ 16（RK4 定步长，4 阶）
