# 插值（数据补全 / 网格化）（`interpolation.m`）

> **在已知采样点之间"补点"**：给定若干离散采样，构造一条**穿过所有已知点**的曲线，用它求**未采样位置**的值 —— 用于**数据补全、网格加密、等距化**，不是为了"预测未来"。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/interpolation.m` · 参照 `tests/skills/model-select/verify/interpolation.md`。

## ① 适用判据

- **用**：要的是**补全缺失点 / 把稀疏网格加密 / 把不等距数据等距化**（类索引问 3 专门指到这里）；采样点**较密、在采样范围内**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **要"采样范围之外"的值（外推）** ⇒ 插值**不负责外推**，越界用多项式会剧烈发散 ⇒ 用趋势外推（`references/prediction/trend_extrapolation.md`）。
  2. **数据含噪声** ⇒ 插值**穿过每个噪声点**会把噪声也插进去 ⇒ 用**平滑 / 拟合**（`references/prediction/exp_smoothing.md` · `references/prediction/regression.md`）。
  3. **采样点很少、又要求光滑** ⇒ 高阶多项式会**Runge 振荡**；应改用样条 / 分段（见 ④-2）。
  4. **高维、点稀疏** ⇒ 一维插值不够，须用 Kriging / 径向基等（`corpus/algorithms/src/Interpolation（目标规划、多元分析与插值的相关例子）/` 是起点素材，**不作独立参照**）。

## ② 标准建模步骤

1. 定**采样点 `(xt, yt)`** 与**待求点 `xq`**（应落在 `[min(xt), max(xt)]` 内）。
2. 选**插值方法**：`linear`（稳、低阶）、`spline`（三次样条，光滑、收敛快）、`pchip`（保形、不过冲）。
3. **插值** `yq = interp1(xt, yt, xq, method)`。
4. **核验**：把 `xq` 取在已知函数的**更细网格**上，比较插值值与真值 ⇒ 误差应随网格加密下降。
5. 输出补全 / 加密后的序列。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `xt`（采样点，须**互异且单调**）· `yt` · `xq`（待求点）· `method` |
| **输出** | `yq`（插值值）· 误差诊断 |

**显式假设（必须写进论文）**：
1. **被插值函数足够光滑**（样条假设二阶连续；`pchip` 假设单调性保持）。
2. **`xq` 落在采样范围内**（内插）；越界即外推，需另行说明。
3. **采样点无噪声**（否则插值会拟合噪声；有噪声应改拟合）。
4. **`method` 是显式选择**（不同方法结果不同）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **方法的收敛阶不同**：`spline` 是四阶（误差 ~ `h⁴`）、`linear` 是二阶（~ `h²`）。**实测**（本骨架 `interpolation.m`，`f(x)=sin(2πx)`）最大绝对误差：

   | n（节点数） | 5 | 9 | 17 | 33 | 65 |
   | :--- | :--- | :--- | :--- | :--- | :--- |
   | `linear` | `0.2105` | `0.07038` | `0.01885` | `0.004792` | `0.001203` |
   | `spline` | `0.1808` | `0.007749` | `0.0002643` | `8.439e-06` | `2.651e-07` |
   | `pchip` | `0.09289` | `0.03339` | `0.005619` | `0.001422` | `0.0003565` |

   三者**误差均随 `n` 增大单调不增**（骨架当场判定「是」）；`spline` 下降最快（符合 `h⁴`）。
2. ★ **高阶多项式 ≠ 更好**：等距节点上高阶多项式有 **Runge 振荡**（`f(x)=1/(1+25x²)` 是经典反例）。**本骨架不用多项式插值**，用分段（样条 / pchip）规避这一问题（凭经验 + 教科书级结论）。
3. **采样点未排序 / 有重复 `x`**：`interp1` 会报错或给错结果（凭经验）。
4. **拿插值做外推**：`xq` 超出范围时 `interp1` 返回 `NaN`（默认）或按 `extrap` 外推 —— **别默认它可靠**（凭经验）。
5. **把插值当"预测"**：插值只在**已知点之间**有意义，不含未来信息（凭经验）。

关键片段（**不整份复制**）：
```matlab
xt = linspace(0, 1, n);  yt = f(xt);         % 采样
yq = interp1(xt, yt, xf, 'spline');          % 回原函数（xf 为细测试网格）
err = max(abs(yq - f(xf)));                  % 最大绝对误差 ⇒ 应随 n 下降
```
