# 回归预测（`regression.m`）

> **用自变量预测因变量**：当要预测的量**不是纯时间序列**、而是**由若干可测自变量决定**时，拟合 `y = Xβ + ε`，用估出的系数做预测与解释。★ 本类是"**预测任务**"；**回归诊断**（残差/异方差/共线性）属 `statistics`。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/regression.m` · 参照 `tests/skills/model-select/verify/regression.md`。
★ **与 `statistics` 的边界**（类索引已写明）：**回归预测**留本节（预测任务）；统计侧只把「回归诊断」当作统计方法的一部分、**不另立条目**。

## ① 适用判据

- **用**：有**明确的自变量-因变量关系（非纯时间）**、要**预测**（外生变量给定后算 `y`）或**量化各因素影响**；关系可 **线性**或**可线性化**（多项式、对数、幂）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **只有时间一个自变量、且是序列** ⇒ 用时间序列模型（`references/prediction/arima_forecast.md` · `references/prediction/exp_smoothing.md`）。
  2. **关系强非线性、不想设解析式** ⇒ 用神经网络预测（`references/prediction/nn_forecast.md`）。
  3. **要"类别判别"而不是数值预测** ⇒ 那是分类（`ml` 的 `nn_classify` / `svm_classify`），不是回归预测。
  4. **自变量高度共线 / 样本 < 变量数** ⇒ 系数不稳、甚至不可辨识 ⇒ 先降维（`statistics` 的 PCA）或用岭回归/正则（`ml`）。
  5. **把相关当因果** ⇒ 回归给的是**相关结构**，因果须靠实验设计或额外假设。

## ② 标准建模步骤

1. 定**因变量 `y`** 与**自变量 `X`**（含截距列），检查量纲与异常值。
2. **拟合**：`βhat = (XᵀX)⁻¹Xᵀy`（等价 `X \ y`）。
3. **诊断**：残差图（应无结构）、共线性（VIF）、异方差、离群点（**这一步属 `statistics`**）。
4. 算 **`R²` / 调整 `R²`**、系数**标准误 `se` 与 `t` 统计量**。
5. **预测**：对新 `X_new` 算 `yhat = X_new·βhat`；如需，给**预测区间**。
6. 报告**系数是否显著 / 符号是否合业务**。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `X`（n×p，首列常为截距）· `y`（n×1）· 新样本 `X_new` |
| **输出** | `βhat` · `se` · `t` · `R²` / 调整 `R²` · 残差 · 预测 |

**显式假设（必须写进论文 · 线性回归的经典诸假设）**：
1. **线性**：`E[y|X] = Xβ`（含"没漏变量"）。
2. **误差独立、同方差**：`Var(ε|X) = σ²I`（否则标准误 / 检验失效）。
3. **无明显共线性**：`XᵀX` 可逆。
4. **`ε` 与 `X` 无关**（无内生性）。
5. ★ **预测的可信度依赖"新样本落在训练分布内"**（外推要谨慎）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **只看 `R²` 就下结论**：`R²` 高不等于预测准（自变量多会抬高 `R²`）。**实测**（本骨架 `regression.m`，`n=200`、真系数 `[2,-3,1.5,0.5]`、`σ=0.1`、`seed=20261004`）：`R² = 0.99916`、`R²_adj = 0.99914`，`βhat = [1.9958, -2.9980, 1.5009, 0.5069]`，`σhat = 0.0907`（真 `0.1`）。
2. ★ **系数没回到真值就宣称"模型对"**：用**已知系数的合成数据**才能验证。**实测**：`|βhat − βtrue|` 最大 `0.0069`，`(βhat−βtrue)/se = [-0.63, 0.30, 0.14, 1.10]` —— 全落在 ±2 个标准误内 ⇒ 与"系数可复原"一致（`±2` 是标准的 `t ≈ 2` 惯例 ⇒ **该阈值标 `[社区]`**）。
3. **忘了截距列**：会强行过原点、系数有偏（凭经验）。
4. **多重共线性**：`XᵀX` 近奇异 ⇒ 系数巨大且符号反常；`inv` 直接算会放大数值误差（凭经验）。
5. **拿训练 `R²` 当泛化性能**：须留出测试集或交叉验证（凭经验）。
6. **把"回归 ≠ 因果"忘了**：相关显著不等于因果（凭经验）。

- **系数表**（`βhat` / `se` / `t` / `p`）+ **拟合优度行**（`R²` / 调整 `R²` / 残差标准差）+ **预测表**（新样本 `X_new` → `yhat`）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/regression.m`（**零参可跑**，**已知系数**的合成数据 + 系数复原 + `R²`/残差）。

关键片段（**不整份复制**）：
```matlab
rng(seed);
X = [ones(n,1), randn(n, p-1)];              % 设计矩阵
y = X * beta_true + sigma * randn(n,1);      % 已知系数的合成数据
beta_hat = X \ y;                            % 最小二乘
resid = y - X*beta_hat;
s2 = (resid.'*resid)/(n-p);
se = sqrt(diag(s2 * inv(X.'*X)));            % 系数标准误
R2 = 1 - sum(resid.^2)/sum((y-mean(y)).^2);
```
**独立参照**：`tests/skills/model-select/verify/regression.md`（**第 4 类：已知系数的合成数据**，系数可复原 + `R²`/残差核对）。
