# 移动平均（`moving_average.m`）

> **用最近 m 个点的均值抹掉随机波动**：每向前走一步就"丢尾进头"，得到一条比原序列平滑得多的**均值走势**，再用它做短期预测。加权版本让**最近的点权重更大**。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/moving_average.m` · 参照 `tests/skills/model-select/verify/moving_average.md`。

## ① 适用判据

- **用**：序列**围绕一个缓变的均值上下抖**、要**消除随机波动看走势**；或做**短期（1–2 步）平坦预测**；预测值就取"最近窗口的均值"。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **序列有明显趋势** ⇒ 移动平均**滞后于趋势**，应先用趋势外推（`references/prediction/trend_extrapolation.md`）或对趋势序列做**趋势移动平均**。
  2. **要"对近期数据加权"** ⇒ 用指数平滑（`references/prediction/exp_smoothing.md`），它天然几何加权、无需定窗口。
  3. **数据是纯白噪声** ⇒ 移动平均只是把噪声再平滑一遍，**无预测力**。
  4. **窗口 `m` 取很大** ⇒ 严重滞后；`m` 取很小 ⇒ 不平滑。`m` 是**显式超参**，须说明取法。

## ② 标准建模步骤

1. 选**窗口长度 `m`**（奇数常用；一般由"要多平滑 / 允许多大滞后"定，`m` 越小越灵敏）。
2. 算**简单移动平均** `MA_m(t) = (1/m)·Σ_{i=0}^{m-1} x(t−i)`，`t = m..n`。
3. （可选）算**加权移动平均** `WMA(t) = Σ_i w_i·x(t−m+i) / Σ_i w_i`，`w` 递增 ⇒ 近期权重大。
4. 用**最后一个 MA 值**做一步预测（趋势不明时用 MA，不用趋势外推）。
5. 残差诊断（MA 的残差应有结构，若残留趋势 ⇒ 换模型）。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `x`（1×n）· `m`（窗口，`1 ≤ m < n`）· （WMA）`w`（长度 m，本骨架默认 `1:m`） |
| **输出** | `MA`（长度 `n−m+1`）· `WMA` · 一步预测值 |

**显式假设（必须写进论文）**：
1. 序列**局部平稳**（窗口内近似常数均值）—— 这是 MA 能作预测的前提。
2. **窗口长度 `m` 及其取法**必须写明（本骨架默认 `m = 3`，只是示例）。
3. WMA 的**权重方案**是显式选择（本骨架用递增整数 `1:m`，归一后使用）。
4. 预测值 = 最后一个窗口均值 ⇒ 隐含"下一期回到局部均值"。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **窗口长度与输出长度**：`MA` 的输出比原序列**短 `m−1` 个**（前 `m−1` 期无值）。**实测**（本骨架 `moving_average.m`）：`x=[10 12 13 15 14]`、`m=3` ⇒ `MA=[11.666667, 13.333333, 14]`（3 个值）。
2. ★ **加权方向**：权重递增 ⇒ 最近的观测权重大；若写成递减，则预测偏向**旧数据**。**实测**（本骨架，`w=[1 2 3]`）：`WMA=[12.166667, 13.833333, 14.166667]`——末尾值 `14.166667 > MA 的 14`，因为最近的 `14` 权重最大。
3. **对趋势序列直接用 MA**：预测会系统性偏低 / 偏高（滞后），须先差分或转趋势模型（凭经验）。
4. **`m` 越大越平滑但越滞后** —— 存在偏差-方差权衡，`m` 要说明依据（凭经验）。
5. **把 MA 残差当"随机噪声"**：MA 残差里往往仍含趋势/季节结构（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/moving_average.m`（**零参可跑**，小序列 + `m = 3`）。

关键片段（**不整份复制**）：
```matlab
for t = m:n
    ma(t - m + 1) = mean(x(t - m + 1 : t));                 % 简单
    wma(t - m + 1) = sum(w .* x(t - m + 1 : t)) / sum(w);   % 加权
end
ma_fc = ma(end);                                            % 一步预测
```
