# 神经网络预测（`nn_forecast.m`）

> **不想设解析式、关系强非线性时用**：用前馈网（或 LSTM/RNN）**从数据里学**一个非线性映射来预测。代价是**结果随初值随机**、要**固定种子 + 给多次运行的分布**。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/nn_forecast.m` · 参照 `tests/skills/model-select/verify/nn_forecast.md`。
★ **与 `ml` 的边界**：本类的**神经网络预测**管「**序列 / 函数预测**」（输出连续值）；`ml` 的**神经网络分类**管「**类别判别**」（输出类别）—— 本条不越界。

## ① 适用判据

- **用**：关系**强非线性**、**解析式难设**、样本量**较大**（相对参数量）、允许**黑箱**、只要**预测准**而不强调解释。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **样本很少**（几十个点）⇒ 网络过拟合、**结果不可靠**；应回到回归 / 灰模型 / 平滑。
  2. **要求可解释的系数 / 因果** ⇒ 用回归（`references/prediction/regression.md`），神经网络给不出。
  3. **要稳定的可复现结果** ⇒ 网络是**随机量**，必须**固定种子**；否则每次跑的数不同（本条纪律的关键）。
  4. **要"类别判别"** ⇒ 那是分类，走 `ml`（`references/../ml/nn_classify.md`），不是本方法。
  5. **打比赛时"无脑堆网"** ⇒ 若简单模型已够，神经网络只增加不确定性与解释成本（凭经验）。

## ② 标准建模步骤

1. **预处理**：标准化输入/输出；序列预测则构造**滑窗**样本。
2. **定结构**：隐层数与神经元数（本骨架 `fitnet(10)`）；训练算法（本骨架 `trainlm`）。
3. ★ **固定种子**：`rng(seed)` ⇒ 网络初值确定，保证**可复现**。
4. **划分**：本骨架用 `dividetrain`（全部训练，避免随机划分带来的另一重随机）；正式建模应留验证集。
5. **训练**：监控训练误差随轮数下降。
6. ★ **多次运行给分布**：换若干种子各训一次，报 **MSE 的均值 ± 标准差**（**不是跑一次宣称达标**）。
7. **测试集**评估泛化误差。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 训练 `(x,y)` · 隐层规模 `H` · 训练轮数 `epochs` · 种子 `seeds` |
| **输出** | 每次运行的测试 MSE（分布）· 误差-轮数表 · 模型 |

**显式假设（必须写进论文）**：
1. **映射可通过给定结构的网络逼近**（通用逼近性只保证"存在"，不保证"训练得到"）。
2. **训练数据代表总体分布**（网络外推能力弱）。
3. ★ **结果是随机变量**：必须报**固定种子下的可复现值** + **多种子的分布**；**单次跑的 MSE 不能当性能**。
4. **训练轮数 / 隐层规模是显式超参**；过训 / 欠训都会影响结论。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就宣称达标**（本方法**最常犯**的错）：网络初值随 RNG，单次 MSE 有**数量级**波动。**实测**（本骨架 `nn_forecast.m`，`f(x)=sin(2πx)`、`H=10`、`ntr=40`、`epochs=200`）：5 个种子的测试 MSE = `8.906e-8 / 6.749e-9 / 9.240e-8 / 9.308e-8 / 6.791e-9`，**均值 ± 标准差 = `5.762e-8 ± 4.644e-8`** —— **标准差与均值同量级**，单次读数根本不能代表性能。
2. ★ **可复现性**：固定 `rng(seed)` 后，**跨进程重跑逐位相同**。**实测**（本骨架，两次独立 `matlab -batch`）：`seed=1` 的 MSE 两次都为 `8.906095357e-08`，均值两次都为 `5.761638652e-08` ⇒ 种子确实锁住了随机性。
3. ★ **误差随训练轮数下降**：**实测**（同种子）：`epochs = 5/20/60/200` ⇒ MSE `7.622e-4 → 2.994e-6 → 3.926e-7 → 8.906e-8`（单调不增）—— 这是"训练有效"的证据，**但要防止过拟合**（轮数不是越多越好）。
4. **不做标准化**：输入尺度差异大时训练不稳、收敛慢（凭经验）。
5. **训练误差当泛化误差**：本骨架用**细网格测试点**评估，避免只看训练 `MSE`（凭经验）。
6. **隐层太大 / 数据太少**：过拟合、测试误差随轮数**反弹**（凭经验）。

## ⑤ 输出模板

- **MSE 分布表**（各种子 + 均值 ± 标准差）+ **误差-轮数表**（训练有效性证据）+ 预测-真值对比图。
- 预测-真值对比图 / 误差曲线 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）；MSE 表 → `mcm-table`（`.claude/skills/mcm-table/`）。
- ★ **不复述这两个 skill 的排版规则**。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/nn_forecast.m`（**零参可跑**，5 种子分布 + 误差-轮数表；**固定种子、可复现**）。

关键片段（**不整份复制**）：
```matlab
for s = 1:numel(seeds)
    rng(seeds(s));                          % ★ 固定种子
    net = fitnet(H);
    net.trainFcn = 'trainlm';
    net.divideFcn = 'dividetrain';          % 全部训练，避免随机划分
    net.trainParam.epochs = epochs; net.trainParam.showWindow = false;
    net = train(net, xtr, ytr);
    mse_seeds(s) = mean((net(xte) - yte).^2);   % 多次运行给分布
end
```
**独立参照**：`tests/skills/model-select/verify/nn_forecast.md`（**第 4 类：已知函数的合成数据** —— 拟合误差随训练下降 + 固定种子 + 多次运行的分布）。
