# 自适应滤波（`adaptive_filtering.m`）

> **让权重自己"追着数据跑"**：用一个**可学习的线性预测器** `yhat(t) = Σ w_i·y(t−i)`，每来一个点就按**误差方向**微调权重（LMS/NLMS）。数据变了、权重跟着变，从而**自适应跟踪变化、抑制噪声**。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/adaptive_filtering.m` · 参照 `tests/skills/model-select/verify/adaptive_filtering.md`。

## ① 适用判据

- **用**：序列**统计特性缓慢漂移**（非平稳），固定系数的平滑/AR 会失配；要**在线、逐点**更新、**误差越小权重越收敛**的预测器。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **序列平稳、样本多** ⇒ 直接最小二乘 / ARIMA（`references/prediction/arima_forecast.md`）更省事、更有统计保证。
  2. **要显式统计推断（区间 / 显著性）** ⇒ LMS 只给点预测，无推断框架。
  3. **数据尺度极大且不归一化** ⇒ 未归一 LMS 会**发散**（见 ④-1），必须归一化 / 标准化。
  4. **学习率 / 阶数不说明** ⇒ 结果不可复现；这两个都是**显式超参**。

## ② 标准建模步骤

1. 定**阶数 `k`**（用过去 `k` 个值）与**初始权重 `w0`**。
2. 定**学习率 `mu`**（本骨架用**归一化 LMS**：步长按输入能量归一 ⇒ 对尺度稳健）。
3. **逐点递推**：`xs = [y(t−1),…,y(t−k)]`；`yhat = w·xsᵀ`；`e = y(t) − yhat`；
   `w ← w + mu·e·xs / (‖xs‖² + ε)`。
4. **多 pass 直到收敛**（本骨架默认 10 个 pass）；监控**训练 MSE** 是否下降。
5. **预测**：用序列末端的 `k` 个值乘最终权重。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `y`（序列）· `k`（阶数）· `mu`（学习率）· `w0`（初值）· `passes`（遍历轮数） |
| **输出** | 最终权重 `w` · 每 pass 的 MSE · 前 3 次迭代轨迹 · 一步预测 |

**显式假设（必须写进论文）**：
1. **预测是过去 `k` 个值的线性组合**（线性预测器假设）。
2. **步长是归一化的（NLMS）**：与未归一 LMS 不同 ⇒ 必须写明用的是哪一种（这决定了尺度稳健性）。
3. **`k`、`mu`、`w0`、`passes` 都是显式超参**（本骨架默认 `k=2, mu=0.5, w0=1/k·1, passes=10`，仅示例）。
4. 收敛是**均方意义**下的（MSE 单调下降），不是每一点误差都下降。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **未归一 LMS 对数据尺度极敏感、会发散**：教科书原始更新 `w ← w + 2μ·e·xs`（Widrow-Hoff，**未归一**）在中等尺度数据上会爆。**实测依据（本机 python 复算，非骨架）**：对 `y=[10 12 13 15 14]`、`k=2`、`w0=[0.5 0.5]`，学习常数取 `0.5/0.1/0.05/0.02/0.01` ⇒ **第 1 个 pass（3 次更新）末**权重分别为 `[2.88e6, 2.49e6]` / `[2.2e4, 1.9e4]` / `[2616, 2263]` / `[141, 122]` / `[13.0, 11.2]`（首 pass MSE `1.2e10 / 1.9e7 / 1.1e6 / 2.1e4 / 779`）—— **一个 pass 就已发散**；**长期行为是发散**（`μ=0.5` 于第 41 个 pass 末逼近 `~2.5e305`、随即溢出为 `inf`/`NaN`；`μ` 越小越慢，但均不收敛）⇒ 本骨架改用 **NLMS** 兜住尺度。（复算口径见 `tests/skills/model-select/verify/adaptive_filtering.md` ② 的可复跑命令。）
2. ★ **前 3 次迭代的手算校验**（**实测**，本骨架 `adaptive_filtering.m`，`y=[10 12 13 15 14 16 17]`, `k=2`, `mu=0.5`, `w0=[0.5 0.5]`）：
   - `t=3`：`xs=[12,10]`、`yhat=11`、`e=2`，`w ← [0.54918033, 0.54098361]`；
   - `t=4`：`xs=[13,12]`、`yhat=13.631148`、`e=1.3688525`，`w ← [0.57760698, 0.56722359]`；
   - `t=5`：`xs=[15,13]`、`yhat=16.038011`、`e=-2.0380113`，`w ← [0.53881234, 0.53360158]`。
3. **MSE 单调下降 ≠ 每点误差下降**：单点误差会来回摆（实测轨迹 `e`：`2 → 1.369 → -2.038`），看的是**每 pass 的平均 MSE**（本骨架：`2.137623 → … → 1.459574`，单调不增）。
4. **`mu` 过大仍会震荡**；NLMS 稳定范围 `0 < mu < 2`（凭经验）。
5. **`k` 取太大 ⇒ 需更多数据、易过拟合**；太小 ⇒ 表达力不足（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/adaptive_filtering.m`（**零参可跑**，NLMS，含前 3 次迭代轨迹与收敛 MSE）。

关键片段（**不整份复制**）：
```matlab
for t = k+1:n
    xs = y(t-1:-1:t-k);                    % [y(t-1), ..., y(t-k)]
    yhat = w * xs.';
    e = y(t) - yhat;
    w = w + mu * e * xs / (sum(xs.^2) + 1e-12);   % NLMS 更新
end
fc = w * y(end:-1:end-k+1).';              % 一步预测
```
