# 指数平滑（`exp_smoothing.m`）

> **给近期数据更大权重**：用"上一个平滑值 + 当前观测"的**加权平均**逐点滚动，一次平滑消噪声、二次（Holt）跟踪趋势、三次（Holt-Winters）再叠季节。**越近的观测权重越大**（几何衰减）。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/exp_smoothing.m` · 参照 `tests/skills/model-select/verify/exp_smoothing.md`。

## ① 适用判据

- **用**：序列**平稳或缓趋势**、要**短期一步/几步预测**、要**对新近数据加权**；样本不多也能用；是无趋势（一次）/有趋势（二次）/有季节性（三次）的通用平滑器。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **强线性/指数趋势**且要中期外推 ⇒ 用趋势外推（`references/prediction/trend_extrapolation.md`），平滑会**滞后于趋势**。
  2. **序列是纯白噪声/无自相关** ⇒ 平滑没有预测价值（平滑只对"有惯性"的序列有效）。
  3. **要给出预测区间 / 显著性的统计框架** ⇒ 用 ARIMA（`references/prediction/arima_forecast.md`），平滑模型本身不含推断。
  4. **有明显 S 形饱和** ⇒ 指 Verhulst（`references/prediction/gm21_verhulst.md`）。
  5. **平滑系数不是估出来的、而是随手取** ⇒ 结论不可复现，必须写清 `α/β/γ` 的取法与依据。

## ② 标准建模步骤

1. 判**形态**：无趋势无季节 ⇒ 一次；有趋势无季节 ⇒ 二次（Holt）；有季节 ⇒ 三次（Holt-Winters）。
2. 设**平滑系数** `α`（水平）、`β`（趋势）、`γ`（季节），`∈ (0,1)`；一般**数值优化**（最小化一步预测误差）或按经验取。
3. 设**初值**（一次平滑 `S(1)=x(1)`；Holt `l(1)=x(1)`、`b(1)=x(2)−x(1)`；HW 用首个季节的均值与季节项）。
4. **递推**更新水平 / 趋势 / （季节）分量。
5. **一步 / h 步预测**：（一次）末平滑值；（Holt）`l(n) + h·b(n)`；（HW）再叠加对应季节项。
6. **残差诊断**：残差应接近白噪声；否则换模型 / 调系数。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `x`（序列）· `α`（· `β` · `γ`）· （HW）季节长度 `L` · 预测步数 `h` |
| **输出** | 各期的平滑值 / 水平 / 趋势 / 季节项；预测值 |

**显式假设（必须写进论文）**：
1. **α（β、γ）的取值必须写明**（本骨架默认 `α = 0.5`、`β = 0.3`、`γ = 0.2`；**这些默认只是示例，不等于"最优"**）。
2. **一次平滑假设**序列**无趋势、无季节**；**二次**假设趋势**局部线性**；**三次**假设季节**幅度恒定（加法）**。
3. **初值取法**是显式选择（本骨架 Holt 用 `b(1)=x(2)−x(1)`、HW 用首季均值），不同初值早期值不同。
4. 递推是**在线（逐点）**的：第 `t` 期只用 `≤ t` 的信息。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **平滑系数取错方向**：`α` 越大越"贴近新数据"、越小越"平滑"；`α→0` 退化成常数均值、`α→1` 退化成上一观测。**实测**（本骨架 `exp_smoothing.m`）：小序列 `x=[10 12 13 15 14]`、`α=0.5` ⇒ `S=[10, 11, 12, 13.5, 13.75]`，一步预测 `13.75`。
2. **忘了"平滑会滞后趋势"**：Holt 用趋势项补，但趋势项也是平滑来的，趋势突变时会**慢半拍**（凭经验）。
3. **HW 的季节长度 `L` 给错**：会算出一个无意义季节项；本骨架对 `n ≥ 2L` 下了 `assert`，**数据不足直接报错**（实测：`assert` 触发即停）。
4. **只报预测值、不报残差诊断**：无法判断平滑是否合适（凭经验）。
5. **把 α 的最优解当"客观值"**：α 依赖优化目标（SSE / 一步误差），换目标会变（凭经验）。

## ⑤ 输出模板

- **平滑序列表**（`t` / `x` / `S` 或 `l,b`）+ **一步/h 步预测值** + （一次平滑）**残差诊断**。
- 原序列-平滑序列对比图 / 预测图 → `mcm-figure-choose`（`.claude/skills/mcm-figure-choose/`）；平滑值表 → `mcm-table`（`.claude/skills/mcm-table/`）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/exp_smoothing.m`（**零参可跑**，含 SES + Holt 小序列算例与 HW 季节算例）。

关键片段（**不整份复制**）：
```matlab
% 一次（SES）
S(1) = x(1);
for t = 2:n; S(t) = alpha*x(t) + (1-alpha)*S(t-1); end
ses_fc = S(end);
% 二次（Holt）
l(1) = x(1); b(1) = x(2) - x(1);
for t = 2:n
    l(t) = alpha*x(t) + (1-alpha)*(l(t-1) + b(t-1));
    b(t) = beta*(l(t) - l(t-1)) + (1-beta)*b(t-1);
end
holt_fc = l(end) + h*b(end);
```
**独立参照**：`tests/skills/model-select/verify/exp_smoothing.md`（**第 3 类：手算标准算例**，SES 与 Holt 各一组逐步算式）。
