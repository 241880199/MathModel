# 灰色 GM(2,1) / Verhulst（`gm21_verhulst.m`）

> **给"有上限 / S 形饱和"的序列建模**：当增长会**碰到天花板**（种群、市场渗透、传染累计），用 Verhulst 的 `dx/dt + a x = b x²` 描述"先快后慢、趋于饱和"的过程；GM(2,1) 是它的**一般二阶**版本。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/gm21_verhulst.m` · 参照 `tests/skills/model-select/verify/gm21_verhulst.md`。

## ① 适用判据

- **用**：序列**单调但增长在减速**、明显**趋向一个饱和值**；或**非单调的摆动 S 序列**（Verhulst 的适用面比 GM(1,1) 宽）。类索引把"**序列有增长上限 / S 形饱和**"指到本方法。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **序列近似指数、看不到饱和** ⇒ 用 GM(1,1)（`references/prediction/gm11.md`）；Verhulst 会**强行找出一个饱和值**、可能不存在。
  2. **样本很多、可用统计模型** ⇒ 直接拟合 logistic 回归 / 生长曲线（`references/prediction/regression.md`）。
  3. **只要短期平滑 / 无饱和结构** ⇒ 指平滑或趋势外推（`references/prediction/exp_smoothing.md` · `references/prediction/trend_extrapolation.md`）。
  4. **需要二阶动力学的机理**（阻尼振动等）⇒ 走机理（`mechanism`），不要用灰色二阶硬套。

## ② 标准建模步骤

1. 取**饱和序列** `x1`（本骨架的约定：**输入即视作一次累加 / 饱和序列**，与盘上素材 `GM_Verhulst.m` 同源）。
2. 令差序列 `x0(1) = x1(1)`、`x0(k) = x1(k) − x1(k-1)`（`k = 2..n`）。
3. **紧邻均值** `z1(k) = 0.5·(x1(k) + x1(k-1))`，`k = 2..n`。
4. **最小二乘**估参 `[a; b] = (BᵀB)⁻¹BᵀY`，其中 `B = [-z1(k), z1(k)²]`、`Y = x0(k)`（`k = 2..n`）。
5. **白化方程** `dx1/dt + a·x1 = b·x1²` ⇒ **时间响应式**
   `x1hat(k) = a·x1(1) / ( b·x1(1) + (a − b·x1(1))·e^{a k} )`，`k = 0..n-1`；
   ★ 饱和值 `x1(∞) = a/b`（`a`、`b` 同号时才有正饱和值）。
6. **累减还原** `x0hat(k) = x1hat(k) − x1hat(k-1)`。
7. 精度检验（残差 / 相对误差，必要时后验差）；外推。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `x1`（1×n 饱和序列，n ≥ 4） |
| **输出** | `a`、`b`、`x1hat` / `x0hat`、残差、平均相对误差 |

**显式假设（必须写进论文）**：
1. **序列服从 Verhulst 型饱和规律**（这正是不该用在无饱和序列上的原因）。
2. **参数符号约定**：本骨架用 `dx1/dt + a·x1 = b·x1²`。**增长+饱和**时 `a < 0`、`b < 0`（等价于 logistic `dx/dt = r x (1 - x/K)` 里的 `r>0`、`K>0`）⇒ 饱和值 `a/b > 0`。**论文里必须写清用的是哪套符号**。
3. 相邻点等时距；`a`、`b` 由**最小二乘**估计。
4. **GM(2,1)**（`d²x/dt² + a1·dx/dt + a2·x = b`）是更一般的二阶形态，需要**两个定解条件**（常取首末点），并常常要 Symbolic Toolbox 求解 —— 本骨架**只实现 Verhulst**，GM(2,1) 的起点素材见 `corpus/algorithms/src/GreySystem灰色系统/GM_2_1.m`（教辅级，**不作独立参照**）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **符号约定不写清 ⇒ `a`、`b` 的正负会让读者误判**：本骨架默认饱和序列上得 `a < 0`、`b < 0`（`a/b > 0` 为饱和值）。**实测**（本骨架 `gm21_verhulst.m`，教科书饱和算例）：`a = -0.1280393311`、`b = -0.008943648927`，饱和值 `a/b ≈ 14.32`——若论文写的是 `dx/dt = ax - bx²`，这里的符号要**反过来报**。**判据**：看数据是否趋向 `a/b`。
2. **把 GM(2,1) 与 Verhulst 混为一谈**：两者适用面相近、但**阶数不同**，参数个数与定解条件不同（凭经验）。
3. **饱和值超出常识仍照用**：`a/b` 若给出物理上不可能的饱和值 ⇒ 说明数据不支持饱和假设，该换模型（凭经验）。
4. **拟合优度只看平均相对误差**：饱和拐点附近误差天然偏大，别只报一个平均值（凭经验）。
5. **样本太短**：二阶/饱和模型要**跨过拐点**才有辨识力，全在上升段很难定饱和值（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/gm21_verhulst.m`（**零参可跑**，自带教科书饱和序列算例）。

关键片段（**不整份复制**）：
```matlab
x0 = [x1(1), diff(x1)];                 % 视 x1 为一次生成序列
z1 = [0, 0.5 * (x1(2:end) + x1(1:end-1))];
B = [-z1(2:end).', z1(2:end).'.^2]; Y = x0(2:end).';
ab = B \ Y;  a = ab(1); b = ab(2);      % 最小二乘
k = 0:n-1;
x1hat = a*x1(1) ./ (b*x1(1) + (a - b*x1(1))*exp(a*k));   % 时间响应式
x0hat = [x1hat(1), diff(x1hat)];        % 累减还原
```
