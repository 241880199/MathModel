# 灰色预测 GM(1,1)（`gm11.m`）

> **小样本、弱信息也能外推**：把原始序列**一次累加**成看起来更光滑的生成序列，对它建**一阶单变量**灰微分方程，用最小二乘估出发展系数与灰作用量，再**累减还原**回原序列并外推。

**归属**：类索引 `references/prediction.md` · 骨架 `assets/matlab/prediction/gm11.m` · 参照 `tests/skills/model-select/verify/gm11.md`。

## ① 适用判据

- **用**：样本**很少**（经验上 4–10 个点）、近似**指数/单调**增长、**不想设机理方程**；只要**短期趋势 / 一步或几步外推**。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **序列明显摆动 / 周期 / 多峰** ⇒ 灰指数假设不成立，改用平滑或 ARIMA（`references/prediction/arima_forecast.md`）。
  2. **增长有饱和上限（S 形）** ⇒ 应走 **GM(2,1) / Verhulst** `references/prediction/gm21_verhulst.md`，GM(1,1) 会一直指数外推、把饱和段**外推成长**。
  3. **样本很多（几十上百）** ⇒ 用 GM(1,1) 是**浪费信息**，回归 / ARIMA 更合适（`references/prediction/regression.md`）。
  4. **要"为什么这样变"的解释** ⇒ 灰模型只给趋势、不给因果 ⇒ 走机理或统计（`statistics`）。
  5. **要做**长期（远超样本跨度）**外推** ⇒ 灰指数发散快、区间无控制（凭经验）。

## ② 标准建模步骤

1. 取**原始序列** `x0`（n ≥ 4）；必要时做**级比检验**（`x0(k-1)/x0(k) ∈ (e^{-2/(n+1)}, e^{2/(n+1)})`），不过则先做**平移/开方**等弱化处理。
2. **一次累加生成** `x1(k) = Σ_{i≤k} x0(i)`（1-AGO）。
3. **紧邻均值生成** `z1(k) = 0.5·(x1(k) + x1(k-1))`，`k = 2..n`。
4. **最小二乘**估参 `[a; b] = (BᵀB)⁻¹BᵀY`，其中 `B = [-z1(k), 1]`、`Y = x0(k)`（`k = 2..n`）。
5. **时间响应式** `x1hat(k+1) = (x0(1) − b/a)·e^{−a k} + b/a`，`k = 0..n`。
6. **累减还原** `x0hat(k) = x1hat(k) − x1hat(k-1)`（`x0hat(1) = x0(1)`）。
7. **精度检验**：残差 / 相对误差；**后验差比** `C = S2/S1`（`S1` = 原序列标准差、`S2` = 残差标准差）与小误差概率 `P`；常按 `C<0.35` 好、`C<0.5` 合格（阈值 **`[社区]`**）。
8. 外推 `x0hat(n+1), x0hat(n+2), …`。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | `x0`（1×n 原始序列，n ≥ 4） |
| **输出** | `a`（发展系数）、`b`（灰作用量）、`x1hat` / `x0hat`、残差、`C`、`P` |

**显式假设（必须写进论文）**：
1. **原始序列近似指数规律**（这是灰指数模型的核心假设，不是自动成立的）。
2. **相邻点近似等时距**（否则要先做等时距化）。
3. `a` 的大小限定外推可信范围：**经验上 `|a| < 0.3` 才适合做中长期预测**，`|a| ≥ 0.3` 只宜短期（**`[社区]`**）。
4. 发展系数 `a` 与灰作用量 `b` 的估计用**最小二乘**，且以**紧邻均值**离散化白化方程。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★ **`x0hat` 长度是 `n+1`（末项才是外推）**：骨架里累减还原得到 `n+1` 个数，**观测期的残差只能取前 `n` 项**。**实测**（本骨架 `gm11.m`）：若直接 `x0 - x0hat` 会**维度不匹配直接报错**（本骨架已按 `x0hat(1:n)` 修正）。
2. ★ **后验差检验的 `C` 用总体标准差（除以 n）还是样本标准差（除以 n−1）要写明**：两种算法数值不同。**实测**（本骨架）：用**总体**标准差 `std(·,1)` 得 `C = 0.212472`（小样本 n=5 下，用样本标准差会得到另一个值）⇒ 论文里须注明口径。
3. **不做级比检验就硬套**：数据不满足灰指数假设时，`a`、`b` 无意义（凭经验）。
4. **把灰预测当"有置信区间"的预测**：GM(1,1) 给的是**点估计**，`C`、`P` 只是**拟合精度**，不是预测区间（凭经验）。
5. **外推过远**：`e^{−a k}` 随 `k` 指数放大，外推步数应**远小于**样本跨度（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/prediction/gm11.m`（**零参可跑**，自带教科书标准算例）。

关键片段（**不整份复制**；完整实现见上述路径）：
```matlab
x1 = cumsum(x0);                        % 1-AGO
z1 = 0.5 * (x1(2:end) + x1(1:end-1));   % 紧邻均值
B = [-z1(:), ones(n-1,1)]; Y = x0(2:end).';
ab = B \ Y;  a = ab(1); b = ab(2);      % 最小二乘
k = 0:n;
x1hat = (x0(1) - b/a) * exp(-a*k) + b/a;    % 时间响应式
x0hat = [x1hat(1), diff(x1hat)];            % 累减还原（长度 n+1）
```
**独立参照**：`tests/skills/model-select/verify/gm11.md`（**第 3 类：手算标准算例**，含 AGO / 紧邻均值 / 最小二乘 / 复原序列的逐步算式与期望值）。
