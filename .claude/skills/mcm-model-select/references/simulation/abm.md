# ABM（多智能体 · `abm.m`）

> **由大量异构个体各按自己的规则互动、涌现宏观行为时用**：没有全局方程，宏观量从**个体决策 + 交互拓扑**里长出来（意见动力学、市场、疏散、生态个体）。

**归属**：类索引 `references/simulation.md` · 骨架 `assets/matlab/simulation/abm.m`（**Task 3 已交付**）· 参照 `tests/skills/model-select/verify/abm.md`（**Task 3 已交付、已过独立复核**）。

## ① 适用判据

- **用**：个体**异构**、**有自己的状态 / 规则 / 决策**；个体间有**交互拓扑**（谁影响谁）；关心**涌现的宏观行为**（共识、分化、聚集、相位转变）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **个体同构、固定在格点、规则统一** ⇒ 用 `cellular_automata`（更简单、更省算力）。
  2. **能写连续 / 离散方程**（有均值场近似且够用）⇒ 走 `mechanism`。
  3. **只要一个期望 / 概率**，不关心个体互动 ⇒ 走 `monte_carlo`。
  4. **没有 ground truth 却宣称"验证了"** ⇒ ABM **无解析解**，参照只能**人工兜底**（见 ⑥），**不许写成"已验证"**。
  5. **个体数很小**（只有几个）⇒ 逐个体推演即可，不必上 ABM 框架（凭经验）。

## ② 标准建模步骤

1. **定个体**：状态变量、行为规则（决策函数）、异质性来源。
2. **定交互拓扑**：全连接 / 网络 / 邻域 / 权重矩阵（谁影响谁、影响强度）。
3. **定调度**：**同步**还是**异步**更新、更新次序（谁先动会影响结果）。
4. **定边界与外部环境**：边界行为、外部驱动、事件。
5. **迭代推演**，记录**宏观量**（均值、方差、簇结构）随步数 / 时间的演化。
6. **数值验证**（★ 见 ⑥）：**人工兜底** —— 2–3 个 agent 的**确定性手算小例** + **性质检查**（守恒量 / 边界行为 / 参数单调性）。
7. **报告**：宏观量演化图 + 个体规则与拓扑的显式描述 + 参数敏感性。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 个体数与状态 · 行为规则 · 交互拓扑（权重 / 网络）· 调度方式 · 步数 · 种子（若含随机） |
| **输出** | 宏观量时间序列 · 簇 / 分化结构 · 收敛或周期行为 |

**显式假设（必须写进论文）**：
1. **个体规则**是外生给定的（不是从数据学出来的）。
2. **交互拓扑**已知或已假设（全连接 / 特定网络 / 邻域）—— 它**强烈影响**宏观结果。
3. **调度方式**（同步 / 异步）写清；异步要写更新次序。
4. **个体数足够多**才代表"群体"（凭经验）；含随机项时**固定种子 + 多次运行**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **拿 ABM 当"可说清结果"的黑箱**：**无 ground truth** ⇒ 别写"验证了涌现行为对了"（设计 §4.1）。**实测**（Task 3）：本骨架只能核**第 1 步手算**与**性质**（守恒 / 收敛到均值）；**这两行是"按构造恒真"、不构成独立数值验证**。
2. ★ **把低使用度写成"常用"**：**实测**（2026-10-04 带锚复跑）`agent-based` / `ABM` **0 命中** ⇒ **不许写成"常用"**（P5）。
3. ★ **不写调度方式**（同步 / 异步、次序）：会悄悄改变宏观结果（凭经验）。
4. ★ **交互拓扑不写明**：拓扑变了结论就变；别把"全连接"当默认（凭经验）。
5. **随机项只跑一次**：要给**固定种子 + 多次运行的分布**（凭经验 / 本仓通则）。
