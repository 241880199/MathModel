# 蒙特卡洛（`monte_carlo.m`）

> **要对随机量做大量抽样、估计一个难算的期望（或积分、概率）时用**：把答案写成"某随机变量的期望"，用样本均值逼近；误差按 `1/√n` 下降、**与维数无关**。

**归属**：类索引 `references/simulation.md` · 骨架 `assets/matlab/simulation/monte_carlo.m` · 参照 `tests/skills/model-select/verify/monte_carlo.md`。
★ **与相邻方法的边界**：要"按规则推演空间 / 时间演化" ⇒ `references/simulation/cellular_automata.md`；有"到达-排队-服务"结构 ⇒ `references/simulation/queueing.md`；要找**最优解**（不是估计期望）⇒ `references/optimization/sa.md` 等。

## ① 适用判据

- **用**：要求的量能写成**随机变量的期望** `E[f(X)]`（或概率、积分）；解析算不出、确定性数值积分太贵（**高维**尤其适用，`1/√n` 不随维数恶化）；只要**统计意义**上的精度（带误差棒）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **低维光滑积分** ⇒ 确定性求积（梯形 / Simpson / 高斯）更快更准（凭经验）。
  2. **要的是最优解 / 决策** ⇒ 走 `optimization`（MC 不找极值，只估期望）。
  3. **有闭式解** ⇒ 走 `mechanism`（别用一个估计去代替一个能算准的数）。
  4. **要求高精度且维数不高** ⇒ MC 的 `1/√n` 收敛太慢（要 10 倍精度就得 100 倍样本）。
  5. **方差无穷 / 重尾** ⇒ 样本均值不收敛（CLT 前提破），置信区间失效（凭经验）。

## ② 标准建模步骤

1. **把目标量写成期望**：`θ = E[f(X)]`（概率 = 指示函数的期望；积分 = 均匀分布的期望）。
2. **定抽样分布**：简单题按原分布抽；难抽 / 稀有事件用**重要性抽样**降方差。
3. **抽 `n` 个 i.i.d. 样本**、算样本均值 `X̄_n`。
4. **估误差**：标准误 `sd/√n` + 置信区间（CLT）。
5. **核收敛率**：`n × 4 ⇒ 误差减半`（`1/√n`）—— 至少报两档 `n` 的误差比。
6. ★ **固定种子 + 多次运行**：给**逐次读数 + `mean ± sd`**（不是跑一次）。
7. **报告**：估计值 + 标准误 + 置信区间 + 收敛表 / 图。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 抽样分布 / 被估函数 `f` · 样本量 `n` · 种子 · 重复次数 |
| **输出** | 估计值 `X̄` · 标准误 `sd/√n` · 置信区间 · 收敛表（`n`、误差、比值） |

**显式假设（必须写进论文）**：
1. **样本 i.i.d.**（独立同分布）；用了相关 / 时序抽样则方差公式失效。
2. **方差有限**（`Var[f(X)] < ∞`），否则 CLT 与 `1/√n` 都不成立。
3. **`n` 足够大**（CLT 生效）；小 `n` 的正态近似不可靠。
4. ★ **随机数质量与种子**：固定种子以便复现；报告里**写明种子**。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **只跑一次就报结果**（本方法最常犯的错）：结果随 RNG 变。**实测**（本骨架，`seeds = 1:20`，`n = 1000`）：均值估计的 `sd = 0.00794778`，逐种子估计散布在 `0.485820–0.512792` ⇒ 单次值不能当性能。
2. ★★ **不报 `n` / 误差**：`1/√n` 只是"误差的量级"，**不报 `n` 就无法判断可信度**（凭经验）。
3. ★ **用固定种子却不报种子** ⇒ 不可复现（凭经验）。
4. ★ **拿 MATLAB 内置当"独立参照"**：同机同实现**不独立**（任务书 B）；参照应是**解析给出的真值 + `1/√n` 收敛率**。
5. **方差无穷 / 重尾** ⇒ 样本均值收敛慢、置信区间失效（凭经验）。
6. **样本相关**（用时间序列 / 依赖抽样）⇒ 方差公式失效、低估误差（凭经验）。

## ⑥ 代码骨架

**路径**：`assets/matlab/simulation/monte_carlo.m`（**零参可跑**，自带算例：估 `U(0,1)` 的已知期望 `0.5`，4 档 `n` × 20 种子）。

关键片段（**不整份复制**）：
```matlab
T = 0.5;                                     % U(0,1) 的已知期望
ns = [1000 4000 16000 64000];                % 每档 n×4 ⇒ 误差应减半
for k = 1:numel(ns)
    for s = 1:numel(seeds)
        rng(seeds(s));                       % ★ 固定种子（可复现）
        est(s) = mean(rand(1, ns(k)));       % 样本均值
    end
    sd(k) = std(est);                        % 各档误差 = 估计量的样本标准差
end
ratio = sd(1:end-1) ./ sd(2:end);            % 相邻档（n×4）比值，期望 ≈ 2
```
