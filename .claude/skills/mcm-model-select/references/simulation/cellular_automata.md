# 元胞自动机（`cellular_automata.m`）

> **演化发生在固定网格上、规则局部确定时用**：每个格点只按邻居更新，全局形态从局部规则**涌现**（生命游戏、森林火灾、渗流、SIR 网格版）。写不出闭式解 ⇒ 只能迭代推演。

**归属**：类索引 `references/simulation.md` · 骨架 `assets/matlab/simulation/cellular_automata.m` · 参照 `tests/skills/model-select/verify/cellular_automata.md`。
★ **与相邻方法的边界**：个体**不在网格上**、规则各异 ⇒ `references/simulation/abm.md`；核心是**对随机量抽样估计一个期望** ⇒ `references/simulation/monte_carlo.md`；能写**连续 / 离散方程** ⇒ `references/mechanism/difference_equations.md`。

## ① 适用判据

- **用**：状态空间是**规则网格**（一维 / 二维 / 三维）、更新**同步**且**局部**（只看邻域）、规则**确定**（或含少量随机）；关心**宏观形态 / 相变**（扩散、聚集、传播、自组织）。
- **反面（什么时候不该用 · 会误用的场合）**：
  1. **有闭式 / 数值解方程** ⇒ 走 `mechanism`（元胞自动机是"规则驱动"，不是"方程驱动"）。
  2. **个体异构、能移动、各有策略** ⇒ 走 `abm`（元胞自动机**同构**、固定在格点）。
  3. **只要一个期望 / 概率的估计** ⇒ 走 `monte_carlo`（别用格点演化硬凑）。
  4. **规则依赖全局信息**（每个格点要看全体状态）⇒ "局部规则"这一前提被破坏，改用其它模型。
  5. **网格太粗** ⇒ 离散化伪影主导结果；**网格太细** ⇒ 步数与存储爆炸（凭经验）。

## ② 标准建模步骤

1. **定网格与状态**：几维、多大、边界（环面 / 固定）、每格状态集合（二元 / 多态）。
2. **定规则**：邻域（von Neumann / Moore）+ 更新规则（出生 / 存活 / 死亡，如 B3/S23）。
3. **定初值并同步**：初始图案 / 随机密度；★ **同步更新**（用上一时刻快照，别原地改）。
4. **迭代**：每步对全体格点按规则更新，记录感兴趣的量（活细胞数、密度、团簇大小）。
5. **观察涌现量**：稳态 / 周期 / 相变阈值（如森林火灾的树木密度阈值）。
6. **数值验证**（★ 见 ⑥）：对**已知规则的标准图案**核周期（生命游戏 glider = 4、blinker = 2），或**前几步手算**。
7. **报告**：时空图 / 多时刻快照 / 宏观量随步数曲线 + 网格与边界条件。

## ③ 参数与假设

| 项 | 说明 |
| :--- | :--- |
| **输入** | 网格尺寸与维度 · 边界条件 · 邻域 · 更新规则 · 初始图案 / 密度 · 步数 |
| **输出** | 每步的状态场 · 宏观量时间序列 · 周期 / 稳态 |

**显式假设（必须写进论文）**：
1. **离散网格**能代表原问题的空间尺度；格距与现象尺度匹配。
2. **局部 + 同构 + 同步**：每格点同规则、只看邻域、同时更新。
3. **边界条件**（环面 / 固定 / 反射）写清 —— 它影响传播与稳态。
4. **规则是外生给定的**（不是从数据学出来的；"从数据学规则"是另一类问题）。

## ④ 常见坑（每条：实测依据 / 或标明"凭经验"）

1. ★★ **异步更新**（原地改、边算边用新值）：会把同步 CA 变成另一种动力学、结果全错（凭经验，教材级 —— 一致性与格点次序都会改变动力学）。
2. ★★ **拿"跑通"当"算对"**：CA 无闭式解 ⇒ 实跑只证明"不崩"（本仓铁律）。**实测**（本骨架）：对标准图案核周期 —— **blinker 周期 = 2、glider 周期 = 4**；见 verify 记录。
3. **边界条件与网格尺寸掩盖行为**：图案太靠近边界 ⇒ 环面 / 固定边界的影响盖过规则本身（凭经验）。
4. **只报最终一帧、不报演化**：CA 的价值在**演化过程**；只给末帧会丢掉周期 / 相变信息（凭经验）。
5. **把 CA 与 ABM 混写**：CA 是**同构格点 + 局部规则**，ABM 是**异构个体 + 各自规则**，别互相冒充（见类索引边界）。

% 一步 B3/S23（环面：邻居用 circshift 环绕；★ 同步更新 —— 先数邻居、再整体更新）
n = zeros(size(g));
for dr = -1:1; for dc = -1:1
    if dr == 0 && dc == 0; continue; end
    n = n + circshift(g, [dr dc]);
end; end
g2 = double((g == 1 & (n == 2 | n == 3)) | (g == 0 & n == 3));
