> **这份文件回答什么**：2025 年 MCM/ICM **O 奖**论文里的图**通常长什么样**。
> **不回答**：你这道题该选哪种图型（那在 `chart-types.md`）；更**不回答**"像不像获奖论文"（见 H13）。
>
> **三条纪律**：① 本文件的每一个数都能被 `provenance.md` 里的命令当场重跑出来；
> ② 每个数都标**出自哪支仪器**（同一条阈值换仪器会放宽/收紧闸门，见 H4）；

## 0. 样本范围 · 措辞下限 · 交付形态 · 与 provenance 的分工

**样本范围**：2025 单年 **43 份**论文 / **662 张图**（`corpus/papers/figures/**/fig-*.png`，**200 dpi** 渲染带，
分母 = 该篇正文行宽 p90 的全局中位 6.31 in）；同批另抽到 **246 张表**，**不在本规范射程**（表是黑白排版件）。
**O 奖无对照组**——没有非获奖样本可比 ⇒ 本规范**只描述分布，不产生"照做就能获奖"的因果**；
**其余 158 份未抽取**。

**三条"不许吹"的措辞下限**（侦察已证伪过一批，此处是硬上限）：

1. **默认色序**（H5）只能说到"**在获奖样本中未观察到广泛使用**"——严判据给的是**下界 0.9%**，
   **下界 ≠ 上限**，不得写成"获奖论文都不用默认色序"。

3. **网格线 / 图例 / 双 Y 轴**（H11）**宁可不写**：图例判据与判断层的一致率只有 15.8%（**已证废**），
   网格 27.3% **只是判据读数、不是结论**。

**★ 交付形态前提：一个图文件 = 一页。**

### H1. 图宽：贴近正文宽

**规则**：默认**贴近正文宽**（**0.95–1.0×**）；**不窄于 0.80×**；**不超过 1.20×**；**别把图拉得比正文宽**。
**来源**：实测
**依据**：全 662 图，比值 =（图宽 ÷ 6.31 in）：**比值中位 0.951**、p25 **0.797**（= 下限 0.80 的来源）、
p75 1.010、max **1.189**（= 上限 1.20 的来源：**超 1.19 的一例都没有**）。
分母口径见 H2。**这是分布、不是合规率**：同一把尺子量回这批获奖论文，只有 **74.5%** 落在 [0.80,1.20] 内，
低于 0.80 的占 **25.5%**、高于 1.20 的 **0.0%** ⇒ 不能拿"参照分布"当及格线（H13）。
**违反判据**：出货检查器 **F1** 报 FAIL（比值 ∉[0.80,1.20]）。作者动作 = 先试"占满正文栏"，
只有图本身很窄时才退到 0.8 以下（那在本样本里是少数派）。
**复跑命令**：`python tests/skills/figure-choose/house-metrics.py --metric h1_med`
**验证**：规则 ①（出货 F1）· 数 ①（`G-H1-lo` / `G-H1-med` / `G-H1-hi`，另 `G-H1-const-lo` / `G-H1-const-hi`
把文档里的 0.80 / 1.20 钉到出货常量 `F1_LO` / `F1_HI` 上）

### H2. 分母口径（写死）

**规则**：正文栏宽 = **该篇正文行宽 p90**（英寸）。**凡说"图宽占正文多少"必须同时写明用的是哪种分母**；
本规范一律用**全局中位 6.31 in**。
**来源**：实测（口径歧义是实测暴露的）
**依据**：43 篇正文行宽 p90 的**全局中位 6.31 in**（未舍入 6.3099）。**分母一换、结论就变**：
同一批 662 图取区间 [0.9,1.1) 时，**全局分母 56.6%**、**逐篇分母 59.4%**——
**中位数相同（都是 0.951）、百分比不同** ⇒ "分母没钉死"是本文件要避免的第一号错误。
**违反判据**：规范 / 报告 / 判词里出现"图宽占正文 X%"却不写分母 ⇒ 记违反。
**复跑命令**：`python tests/skills/figure-choose/house-metrics.py --metric h2_colw_p90_median`
**验证**：规则 ③（**没有机械判据能判"报告里有没有写分母"**——检查器的 `--textwidth-in` 是调用方传的）·
数 ①（`G-H2-den` / `G-H2-fork-global` / `G-H2-fork-perpaper`）

### H3. 取向与图高：默认横向

**规则**：默认**横向**；宽高比常见带 **2–3**（样本内 **37.2%** 落在带内）；图高按 **2.6 in 量级**。
**来源**：实测
**依据**：全 662 图：**横向占 98.0%**（竖向只有 1.96%）、**宽高比中位 2.09**、**宽高比 ≥2 占 53.5%**、
**图高中位 2.63 in**（p25 2.17 / p75 3.24）。
⚠️ **与设计稿不一致、已按实测改写**：设计稿写"宽高比中位 2.42"，出处是 `progress.md` 的
「908 张 PNG；抽样 120 张 ⇒ 宽高比中位 2.42」——**样本是 908 张（含 246 张表）、抽样过程未落文**。
复核：在**同一个 908 池**里按固定种子集重抽 120 张，中位落在 **2.24–2.42** ⇒ **该数不可复跑**
（不是错，是抽样的偶然）；662 张图上实测 **2.09**（侦察报告 §3.1 的 FIG662 表亦是）。
**原先把 2.42 归给"单张图 `A/2500836/fig-07-p9.png` 的 aspect = 2.427"是错的**——那个 2.427 与 2.42
只是**巧合**，不是它的来源 ⇒ 以实测 **2.09** 为准（差异已登记）。
**违反判据**：竖向图只占 2.0% ⇒ 除非题目本身要求（流程图、时序、树），默认横向；
宽高比落在 [2,3] 之外**不算违反**（p25 1.59 / p75 2.69 都在带外）。
**复跑命令**：`python tests/skills/figure-choose/house-metrics.py --metric h3_aspect_med`
**验证**：规则 ③（出货检查器不判几何取向）· 数 ①（`G-H3-land` / `G-H3-aspect` / `G-H3-ge2` / `G-H3-h`）

### H4. 配色密度：主色 ≤4，单色/灰度是正常选择

**规则**：彩色**主色 ≤4**；**单色/灰度是正常选择**（不是"没上色=偷懒"）。
**来源**：实测（**两支仪器，别混用**）
**依据**：同一批 662 图：

- **出货仪器**（`check-figure-style.py` 的 `color_count`：320×320 **NEAREST** + `//16` 分箱 + 去近灰 + **0.5% 地板**）：
  出货：主色中位 **2**、出货：零彩色 **30.5%**（202/662）、出货：≤4 覆盖率 **66.3%**（439/662）。
  ⚠️ **这三项是在全 662 上算的**，而其中 **72.81%** 被下面那道连续色图闸门判为"F2 条数不可引用"
  ⇒ 它们**不构成"获奖论文的图都是少数色"的证据**，只作"F2 闸门会放行多少张"的读数。
  只看**闸门补集**（未被判为连续色图的 **180 张**）：主色中位 **1**、零彩色 **42.78%**、≤4 覆盖率 **88.33%**。
- **侦察仪器**（`quantize(32, MEDIANCUT)`；本任务把它重写了一遍，与入库台账 `c-color-count.tsv`
  **台账逐格一致 662**）：侦察：主色中位 **3**、侦察：零彩色 **19.5%**、侦察：≤4 覆盖率 **58.6%**（388/662）。
- **口径分叉的方向 = 闸门被放宽**：同一个 `≤4` 阈值，**出货仪器覆盖 66.3% > 侦察仪器 58.6%**
  （同一批 662 图、同一支对比）。Task 1 复审 N-2 引的那一对 **72.9% / 57.2%** 是 **166 张抽样**上的数，
  本任务当场核过：**两个都能复现**，但 **57.2% 不是真侦察仪器的读数**——它是 baseline §7 的
  **转写口径**（`min>=240` **且** 含 `//16` 分箱；中位 **4.0**、零彩 **15.66%** 与 baseline §7 的表逐格相同）
  在**同一 166 抽样**上的读数；真侦察仪器（`max>=240`、**不分箱**）在同一 166 抽样上给 **63.86%**、
  在 662 上给 58.6%，而那支转写口径在 **662** 上是 **51.81%** ⇒ **57.2% 与 72.9% 不同源、不可对举**
  ⇒ 本文件只引用**同一支仪器、同一批图**上可复跑的那一对：66.3% vs 58.6%。
- **连续色图在不在射程内（★ 先界定，不许含糊）**：F2 的**条数只对离散配色图**（分类色、离散色阶）计。
  对**连续色图**（渐变、发散热图）**红绿方向可信、条数不可引用**。依据：一张连续红蓝发散热图
  （`red/out-R2/figure.pdf`）**连续色图按 F2 计到 7 条**；未设地板时的彩色箱有 **152** 个，其中
  **最高落选箱 0.370%**、**离 0.5% 地板仅 0.130pp**（**入选的最低箱 0.689%**）⇒
  **条数是地板把连续谱切出来的产物**，栅格化/阈值稍有变化就会改数。
- **★ 闸门（本节最软的数，已按实测重标定；不再写"标定样本仅 3 张"）**：
  `f2-diagnose.py` 报的**彩色箱数 ≥100** **或** **最高落选箱 ≥0.4%** ⇒ 按**连续色图**处理，
  **不引用 F2 条数**（要引也只引"有没有彩色"）。旧闸门（彩色箱数 **≥20** **且** 最高落选箱 **≥0.3%**）
  **两处都被实测否掉**：
  - **箱数那一半形同虚设**：全 662 里 **95.62%** 过这一关（<20 箱的只有 **29 张**）⇒ 真正在筛的
    只剩"最高落选箱"一条腿。
  - **"最高落选箱 ≥0.3%" 在真语料上两个方向都不站得住**：把语料里**图注带 `heatmap` 的 13 张**
    （正则 `heat\s*-?\s*map`，可复跑）逐张打，旧闸门只命中 **5/13**；其中 **F2 条数 >4**（= 会被当离散
    读数引用）的 **9 张里旧闸门只命中 4 张**。两个漏掉的典型（`图 | F2 | 最高落选箱`）：

    | 图 | F2 | 最高落选箱 |
    | :--- | ---: | ---: |
    | `B/2517929/fig-10-p19.png` | 24 | 0.123% |
    | `C/2505964/fig-08-p13.png` | 17 | 0.094% |

    而 **0.094% 低于离散标定件 R1 的 0.127%** ⇒ **这条线连方向都反了**：它**不区分连续/离散**
    （0.3% 卡掉的是"地板边上的连续谱"，卡不住"箱很多但每箱都不大"的连续谱）。
  - 新闸门（**或**）在同一 13 张上命中 **11/13**、**那 9 张全部 9/9 命中**（两张漏网的都是 **F2=0**、
    本就无条数可引）；三张标定件里 **R2 仍命中、R1/R3 仍不命中**（R3 的最高落选箱 **0.081%** 也低于新线
    ⇒ **标定证据仍只有这 3 张**，闸门是手工构造的保守方向、不是标定过的判别器）。
    **代价照实写**：全 662 的命中率由 **49.40%** 升到 **72.81%** ⇒ 本样本 **72.81%** 的图**被这道闸门**判为"条数不可引用"
    （批量清 `T3-R3` 订正措辞：**这是闸门的性质，不是"72.81% 的图有问题"** —— 原文写成"图的属性"）。
  - **不写"箱数 ≫ `color_count`"这条判据**：实测方向是反的——离散标定件 R1 的 箱数/条数 = **26.00**，
    真热力图 `B/2517929/fig-10-p19.png` 只有 **9.12** ⇒ 它会**把热力图判成离散、把离散图判成连续**。

**违反判据**：出货检查器 **F2** 报 FAIL（`color_count > 4`）——**但只在离散配色图上引用**；
连续色图上**不得**拿 F2 条数下结论。
**复跑命令**：`python tests/skills/figure-choose/house-metrics.py --metric color_cov4_pct`
**验证**：规则 ①（出货 F2，**同一支** `color_count`）· 数 ①（`G-H4-*` 一族：两仪器各三项 + 各项张数 + 台账逐格 +
N-2 那一对的复现核对 + 连续色图四读数 + 地板常量 + **闸门六组读数**（新旧命中率 / 旧闸门箱数腿 / heatmap 样本 /
两个漏检典型 / 比值判据 / 闸门补集三项）；另 `G-H4-max` 把文档里的 ≤4 钉到出货常量 `F2_MAX`，
`G-H4-gate-box` / `G-H4-gate-sub` 把闸门两个常量钉到 `CONT_BOX_MIN` / `CONT_SUBFLOOR_MIN_PCT`）

### H5. 默认色序：不用 matplotlib 默认色序（措辞上限）

**规则**：**不用 matplotlib 默认色序（tab10）**。措辞**只能**到"**在获奖样本中未观察到广泛使用**"。
**来源**：实测（**只给下界**）
**依据**：严判据（`quantize(64)` + 非灰 tab10 色 + RGB 距离 ≤3 + 占比 ≥0.3% + 命中 ≥2）：
**严判据命中 6 张 / 662** = **严判据读数 0.9%**（未舍入 0.91%），且这 6 张**人眼复核 6/6 都是真命中**。
**松判据**（容差 40）**松判据读数 17.8%**（118/662）**已被人眼证伪**（抽查的"命中"里**大多数是照片**，
靠"任意两色碰巧落在 tab10 附近"就能过；照片的最近距离分布平滑、**没有自然间隙**，调容差调不出可信判据）⇒
**17.8% 不得引用**。**0.9% 是下界**：它能证明的是"**没观察到广泛使用**"，不是"没人用"。
**违反判据**：**判断层**（人判配色是否像默认色序）。⚠️ 判者提示词里**没有**这条规则 ⇒
**这条规则现在没有任何实际把关**（写手自觉）。
**复跑命令**：`python tests/skills/figure-choose/house-metrics.py --metric tab10_strict_pct`
**验证**：规则 ③（出货检查器不判 tab10；判断层提示词未内嵌此规则）· 数 ①（`G-H5-strict` / `G-H5-strict-n` /
`G-H5-loose`；严判据重写件另有台账逐格一致读数）

### H6. 不用饼图

**规则**：**构成数据不画饼图**（用堆叠条 / 三元图 / 直接标注数值）。
**来源**：实测
**依据**：判断层随机 120 张里：**饼图 0 张**、**饼图占比 0.0%** ⇒ 在获奖样本里饼图是罕见选择。
**违反判据**：判断层（判者判"构成数据画成饼图"即违反）。**这一条是判者提示词里唯一逐字内嵌的规范规则**
