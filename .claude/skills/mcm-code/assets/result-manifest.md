# 结果清单（模板 · **可直接复制**）

> **用法**：把下面 `## 结果清单` 一节整段复制进你的结果清单文件（如 `results.md`），**列头逐字保留、不要改**。
> 行数自定 —— 但**零行不算合格**：清单在场就必须有数据行（空集不许判绿）。

## 结果清单

| 结果文件 | 对应正文编号 | 生成脚本 | 代码来自 | 确认 |
| :--- | :--- | :--- | :--- | :--- |

★ **五列填什么**（**不声称穷尽**，逐列口径见 `references/numbering.md`）：

- `结果文件` —— 落盘文件的**相对路径**（如 `build/table-1-estimate.csv`）；
- `对应正文编号` —— 它喂给正文的**哪一处**（`图 X` / `表 Y` / `式 Z`）；
- `生成脚本` —— 产出它的脚本路径；
- `代码来自` —— `本人` / `AI`；
- `确认` —— `已核（跑过人 + 日期）` / `待核`。

★ **`代码来自 = AI` 的行**：`确认` 必须记「已核（跑过人 + 日期）」—— **凡由 AI 写的代码，队员必须自己跑通并核对结果后方可采信**。

★ **下列两行是示例**（**只是给你看格式，不要复制进你的清单**）：

```
| build/table-1-estimate.csv  | 表 1 | build/run_model.py | 本人 | 已核（张三 2026-02-01） |
| build/figure-1-samples.csv  | 图 1 | build/run_model.py | AI   | 已核（李四 2026-02-01） |
```
