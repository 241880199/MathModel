# mcm-topic-select —— 选题决策：从六道题里挑一道

**只回答一件事**：贴**当天六道题的题面** → 出一份**可核**的选题依据 + **一个明确推荐**。
它**不替你决定**：它把「**已知什么 / 未知什么 / 依据在哪**」摆出来，
让**推荐**从这些读数里推出来，并**明写它可能错在哪**。

★ **它最值钱的一条**：给当天每题打的**每一个标签**，都**必须附一句当天题面的原句为证**，
且那句**必须是当天题面里逐字存在的**——这条**可机械核**（由 `tests/skills/topic-select/check-topic-select.py` 的 `S1` 守），
它挡的正是"**编一条看起来像题面的句子**"。

## 什么时候用

- 拿到**当天六道题**，要挑一道（或给几道排序），想知道**每道题难在哪、值不值得做**；
- 想把"看着会做"的直觉**换成一份能指着说清的判断**（分类有题面原句为证、历史有语料为证）；
- 想在**开赛头几个小时**内定题，不想拖到第 5 小时还在纠结。

**不用**：

- **替你查数据**（该题的数据到底有没有、在哪）⇒ 那是 M5 的 `mcm-data` / `mcm-code`；
- **替你建模 / 解模型** ⇒ 那是 M4；
- **排赛程**（现在该干什么、还剩多久）⇒ `mcm-playbook`（**已建**），本支不排；
- **替你写论文正文** ⇒ M2 的 `mcm-paper-architecture` **未建**（`mcm-section-writer` **已建** = 逐节写作范式；`mcm-memo` **已建** = 题面要求 letter/memo 时的写作范式）；
  **写作纪律的唯一权威表述**是 `docs/mcm-writing-discipline.md`（本支只给指针、不重述）。

## 怎么用：贴六道题的题面

**入口只有一样东西**：**当天六道题的题面**（贴文本，或给一个文件 / 目录的路径）。
★ **不要队伍画像** —— 本支**不向你要**（用户 2026-10-03 裁决：*「队伍画像不重要」*）。

**时间盒**：默认 **≤2 小时**（赛程 0–5 小时的**前半**），**到点必须给推荐、宁可粗**；
它是**默认、可覆盖**。★ **"何时值得超时"的判据与取舍规则见 `references/method.md`**。

## 输出契约（每次都交齐这几样）

**逐题**给：

1. **分类**：按语料口径打 `数学任务 × 数据形态` 标签，**每个标签附一句当天题面的原句为证**
   （★ 那句**必须是当天题面里逐字存在的**，归一化口径见 `references/corpus-lookup.md`）；
2. **同型历史**：这个 `数学任务 × 数据形态` 组合往年出现过没有、那道题当年怎么做
   （★ **边界随读数一起给**，见 `references/corpus-lookup.md`）；
3. **四轴证据档**：**逐轴**写「**已知什么 / 未知什么 / 依据在哪**」，
   **每轴标明可核性**（读数 / 半可核 / **判断**），★ **判断型不许写成读数**；
   四轴 = **① 数据可得性 + 可信度 · ② 难度 · ③ 拥挤风险 · ④ 创新空间**（逐轴怎么填见 `references/method.md`）；
4. **推荐 + 推翻条件**：一个明确推荐，并**明写"什么情况下该推翻它"**。

★ **每一样的逐字形态**（题标题行 · 标签表 · 历史读数两行 · 四轴四行 · 推荐两行）**见
`references/method.md` §5「产出的逐字形态」—— 判据 `S1`–`S4` 读的就是那份形态**：
**本节给的是语义**（要交齐哪几样），**形态**（每行逐字长什么样）**以 §5 为准**。

★ **四轴不编 1–5 分**（用户 2026-10-03 裁决）：只交**证据档**，推荐从证据档里推出来。

## 边界（最要紧的一条）

- ★★ **推荐仍是判断**：本支能保证「**依据可核**」，**不能保证「推荐是对的」**；
  所以**推翻条件**是输出契约的一部分，**不是客套**。
- **不查数据 / 不建模 / 不排赛程**（见上「不用」一节）；**不编分数**；**不写论文正文**。
- **不复述两份 references 的数值 / 规则**：语料读数、四轴的逐轴填法与可核性、四条边界
  **一律以 references 为准**，本文件**只给指针**（重述即造第二份权威）。
  ★ **例外只有一处**：**时间盒的默认值**（`≤2 小时`）**本文件给出** —— 它是**本 skill 的契约值**；
  它的**覆盖机制与"何时值得超时"**仍在 `references/method.md`。
- ★ **本 skill 是家族外第二个**（与 `mcm-playbook` 同）：**不属绘图家族**
  ⇒ **无 `house-style.md` 指针义务**、**无零数字约束**（那两条是绘图家族内 `SKILL.md` 的义务）；
  仍跟短契约风格，**那是为了一致性，不是判据逼的**。

## 指针（唯一权威）

- **四轴怎么填**（逐轴：它问什么 · 可核性 · 怎么填 · 常见误判）+ **取舍规则 + 时间盒 + 推翻条件** +
  **产出的逐字形态**（判据读的就是它）：`references/method.md`。
- **语料怎么用**（`PROBLEM_TYPES.md` 的词表与口径、两道推理轴、同型检索）+ **它已知的四条边界**：
  `references/corpus-lookup.md`。
- **语料根**：`corpus/papers/**`（★ **我们的标注件**，**不是官方**；已入库，本支**只读**，**不改**）。
