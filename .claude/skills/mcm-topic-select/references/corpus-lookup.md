# `mcm-topic-select` 语料用法：打标签 · 同型检索 · 四条边界

本文件是本 skill「**怎么用语料那套**」的唯一权威。语料 = `corpus/papers/**`
（★★ **我们的标注件，不是官方口径**；已入库，本支**只读、不改**）。

★★ **先记住一句话**：这套分类与检索**全是我们自己标的** ——
凡引用，**必带**这句边界（逐条见下 §4 的边界 ①）。

---

## 1. 打标签：`数学任务 × 数据形态`

拿 `PROBLEM_TYPES.md` 的**词表与口径**，给**当天每题**打一对标签：

- **`数学任务`** = `L1 名 · L2 名`（两级都必须**逐字命中**词表
  `tools/papers/vocab/problem_types.txt`），并标 **`核心`** 或 **`附带`**：
  * `核心` = 题干的**要求句**（`Requirement(s)` / `Your task` / 问题句）明确要求做这件事；
  * `附带` = 该要素在题面**出现**（背景 / 数据说明 / 可选提示），但不是被要求交付的东西。
- **`数据形态`** = **受控枚举**里挑**一个**：`无数据(纯机理/假设)` · `时序` · `截面` ·
  `面板` · `空间/地理` · `网络` · `文本/文献` · `混合`
  （本行**第一个词**必须是枚举值；括号里补的是"这题具体是什么数据"，只作说明）。
- **`场景`** = 自由写，**只作检索标签**（见边界 ④）。

★ **配对的推理轴只有两条：`数学任务 × 数据形态`**（语料口径 7 的**用户裁决**）——
**`场景` 不进配对**。

## 2. ★★ 每个标签必须附当天题面的原句（本 skill 的"可核"故事）

**本 skill 给当天每题打的每一个标签，都必须附一句当天题面的原句**，
且那句原句**必须是当天题面里逐字存在的**（**子串**）。

- **归一化口径复用**：按 `tools/papers/taxonomy.py` 的 `normalize_for_locate` /
  `normalize_quote` —— **行尾归一 → 去项目符号 → 空白折叠 → 引号折叠（直/弯、单/双一律折成 `"`）
  → 大小写折叠**；引文侧**另去掉**自己加的强调标记（`*`、`` ` ``）。
  ★ **边界（2026-10-03 补）**：上面这条「引号折叠」折的是**被比较的文本**（题面侧与引文侧的**内容**），
  **不覆盖产出里取引文那一步** —— 产出里支撑句的**定界引号必须是直双引号 `"`**（写成 `“…”` ⇒ 判据取不到引文 ⇒ 红）。
  ★ **必须复用这一份口径**，**不许另写一套**（两套归一化 ⇒ 两支的"可核"会有一天对不上）。
- ★ **为什么这条要写死**：它挡的正是「**编一条看起来像题面的句子**」。
  **模型天生爱改写** —— 改写出来的句子**不是子串** ⇒ 必红。
  上面这些步骤**只动排版与字形、动不了任何一个词** ⇒ 它们**不可能**让"编造的句子"
  变成能命中的句子，而那正是这条要守的东西。

## 3. 同型检索（历史）

- **2016–2026 的同型题**：查 `PROBLEM_TYPES.md`
  （它覆盖 **2016–2026 的题面**，**题面、非解答**；语料件自记 **67 份题面 PDF**，2026-10-03 复核）。
- **2025 的模型配对**：查 `MODEL_MAP.md`
  （它给「**历史同型题的 O 奖论文用过什么模型 / 算法**」；语料件自记 **43 篇 / 6 题**，2026-10-03 复核）。
- ★ 引用历史读数时，**边界必须随读数一起给**（尤其下 §4 的边界 ②）。
- ★★ **`- 历史：题 <YYYY> <字母> 用过模型 …` 那行里的「历史题」必须是"另一道题"** ——
  **不许引当天那道题自己**（同字母 / 同文）。理由：该行的语义是「**往年同型题**用过什么」，
  引当天那道题自己 ⇒ **语义退化**（变成"这题用这模型"的自证，不是历史）；且**判据 `S2` 抓不到**它 ——
  `check-topic-select.py` 只核 `MODEL_MAP.md` 里**那道题的篇数**与产出现取一致，**不看那题是不是当天题**。
  ★ 这一条与下 §4 的边界 ③（**当天六题不在语料里**）同源：③成立时**天然引不到自己**；
  **③一旦被绕开**（如测试时直接拿**语料里已有的旧题集**当"当天六题"），就得靠**这一条**守住。

## 4. ★ 四条已知边界（凡引用语料必带）

① **这是我们的标注，不是官方** —— `PROBLEM_TYPES.md` 的 `L1 · L2` 标签、`数据形态` 枚举、
   `MODEL_MAP.md` 的模型配对，**全是我们自己标的**（该文件的口径段自证）⇒
   **不许**写成"官方分类"。（同"不许把构造读成官方"。）

② **`MODEL_MAP.md` 只覆盖 2025 那一年** —— `corpus/历届优秀论文/` 里
   **只有 `2025美赛O奖论文` 这一本被建过索引**；其余合集（2022 / 2023 / 2024 三本与 UMAP 两本）
   **未建索引**。⇒ 拿它说「**历史上这类题常用 X**」时，**必须**带这句：
   **历史配对证据偏薄**，且**不许**拿别的年份的论文来凑（那不是配对、是编造）。

③ **当天六题不在语料里** —— 语料覆盖的是**往年**题面；**当天的分类是对当天题面现做的**，
   与语料自己的标注**可能有口径差** ⇒ **如实标**
   （别把当天新打的标签说成"语料里就是这么标的"）。

④ **`场景` 标签与模型选择无关** —— `场景`（考古 / 旅游 / 教育…）**只作检索标签**，
   **不进配对**（语料口径 7 的**用户裁决**，原文：*「'考古/旅游'等领域都只是一个场景，
   实际模型的确立并不与场景有关」*）。**配对的推理轴只有两条**：`数学任务 × 数据形态`。

## 5. 一条禁令（与 `method.md` 轴 3 同源）

★★ **不许拿"某题的历史获奖论文篇数"去代理"选它的人数"** ——
`corpus/papers/INDEX.md` 是「**2025 美赛 O 奖论文索引**」，**逐题登记了篇数**；
那些数**够得着、很诱人**，但**获奖篇数取决于评委怎么分奖，不取决于多少队选了它** ⇒
那是**拿两个不同的对象作比**。（完整口径见 `references/method.md` 轴 3。）
