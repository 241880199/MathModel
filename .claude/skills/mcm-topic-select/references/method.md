# `mcm-topic-select` 方法：四轴证据档 · 取舍规则 · 时间盒 · 推翻条件 · **产出的逐字形态**

本文件是本 skill「**怎么填那份判断**」的唯一权威。`SKILL.md` 只给契约与指针，不复述本文件的数值。

★★ **贯穿全篇的一条纪律**：**不许把判断写成读数**。四轴里有**三轴是判断**（见下），
「**逐轴证据档**」这个形态在这里**不是形式，是唯一诚实的载体** ——
每轴必须写清「**已知什么 / 未知什么 / 判断依据是什么**」。

---

## 1. 四轴（逐轴：它问什么 · 可核性 · 怎么填 · 常见误判）

### 轴 1 · 数据可得性 + 可信度

- **它问什么**：题面**给了数据吗**？没给的话**要自己去找吗**？找得到吗？
  来源是什么性质的（**官方库 / 论文附录 / 二手转载**）？
- **★ 可核性：部分可核** —— 题面**自己给的**那部分**可核**（引题面原句为证）；
  **要自找的**那部分当场核不了 ⇒ **只列候选来源 + 各自的边界**。
- **怎么填**：① 题面给了什么（**附题面原句**）；② 没给的话，**列几个候选来源**，
  每个写清**它的边界**（谁发布的 / 有没有文档 / 是不是二手转载）；③ 写清"这一轴到什么程度算够"。
- **常见误判**：
  - ★★ **替用户下"这个源可信 / 不可信"的定论** —— **不许**。本支只给**候选来源 + 各自边界**；
    可信度的最终判断是**用户的**（本支核不了它的真伪）。（设计 §7-3 / 计划 P6）
  - 把"题面**提到**了某数据"读成"数据**一定拿得到**"（题面提到 ≠ 附件里有）。

### 轴 2 · 难度

- **它问什么**：**做不做得出来** —— 太难 ⇒ **交不出东西**（接受 partial solutions，但手上得有东西可交）。
- **★ 可核性：判断（⚠️ 纯判断）** —— **没有任何数据**；必须**给推理**，不许写成读数。
- **怎么填**：写清「**难在哪**」（模型复杂度 / 数据规模 / 需要多少领域知识 / 有多少要自己补的假设），
  ★ 并**如实体感**：这是判断，不是读数。
- **常见误判**：
  - ★★ 把**"我熟不熟这个方法"**读成**"这题难不难"** —— 那是**两件事**；
  - 把"看着简单"当成"做起来简单"（★ 这一条与轴 3 也**不是**同一件事）。

### 轴 3 · 拥挤风险

- **它问什么**：**这道题面上有没有"会吸引人扎堆"的特征** ——
  **一眼就懂 / 套路常见（能套模板）/ 自带数据（省事）/ 趣味性强**。
  评奖是**相对的**，人多的题会把好答案淹掉。
- **★ 可核性：判断（⚠️ 纯判断 —— 无任何数据）** —— **必须给推理**。
  ★ 这里的「纯判断」是**描述**、**不是标签**：产出里写**标签**时一律写 `判断`
  （逐字形态见 §5；标成 `纯判断` 或 `读数` 都会被判据判红）。
- ★★★ **它判的是题面，不是队伍数**（用户 2026-10-03 当日追问后订正）：
  它**不是**"预计多少队伍会选它"，**也不给任何数字**。
  ★★ **赛期内没有任何可靠办法知道某题的选题人数** —— 结果的**赛后几个月才出**；
  当场**既不知道获奖篇数、也不知道选题人数**。
- **怎么填**：逐条比对上面那几个**题面特征**（一眼就懂 / 套路常见 / 自带数据 / 趣味性强），
  写清「**从题面的哪句话 / 哪个形态看出来它容易吸引人扎堆**」。
- ★★★ **禁令（硬性）**：**不许拿"某题的历史获奖论文篇数"去代理"选它的人数"**。
  - **为什么它们是两个不同的对象**：**获奖篇数取决于评委怎么分奖**
    （评奖是相对的、按当年整体水平调整），**不取决于多少队选了它**。
    拿 A 代理 B ⇒ **拿两个不同的对象作比**（本仓栽过多次，通则 13）。
  - ★ **这条禁令不是空设**：**语料就在盘上** —— `corpus/papers/INDEX.md` 是
    「2025 美赛 O 奖论文索引」，**逐题登记了篇数**；跑的时候 agent **够得着那些数** ⇒
    **很容易**顺手推出"获奖论文多 ⇒ 选的人少" ⇒ 所以必须**明文拦**。
- **常见误判**：
  - ★★ 用"往年这题的论文多 / 少"推"今年这题挤 / 不挤"（**即上一条禁令**）；
  - 把这一轴当**读数**填。★ 它是四轴里**最软**的一条 ⇒ 推荐时必须**当软证据**，
    并在推翻条件里写明**它可能整体偏**（"看着容易"未必等于"真会挤"）；
  - 把它写成"**预测**多少队会选"（**赛期内不可回答**）。

### 轴 4 · 创新空间

- **它问什么**：你能不能做出**与多数人不同**的一版 —— 还是说**再用套路 X 就只是跟随**。
- **★ 可核性：半可核** —— 语料能给**历史同型题的 O 奖论文都干了什么**（那部分可核）；
  但"**你这版算不算新**"仍是**判断**。
- **怎么填**：查 `corpus/papers/PROBLEM_TYPES.md`（2016–2026 同型题）+
  `MODEL_MAP.md`（2025 的模型配对）⇒ 写清「**历史上这个组合大家都用了什么**」
  ⇒ 指出「**你再用 X 会落在哪一堆里**」。
  ★ **边界随读数一起给**：`MODEL_MAP.md` **只覆盖 2025 那一年**（见 `references/corpus-lookup.md`）。
- **常见误判**：把"**这个模型高级**"读成"**这个点子新**"（**高级 ≠ 新**）；
  拿"往年的获奖论文"当"**今年**的参照系"（年份与题面都不同）。

★ **四轴里有三轴是判断**（轴 2 / 轴 3，以及轴 4 的后半）⇒ **判断型不许写成读数**。

## 2. 取舍规则（四轴读出来之后，怎么推推荐）

1. **先排"做不做得完"**：轴 1（数据够不够撑起模型）与轴 2（做不做得出来）**任一为"否"** ⇒
   该题**大概率要排除**（交不出东西，一切白搭）。
2. **在"做得完"的题里**，看轴 4（能不能做出不同的一版）与轴 3（会不会被淹）。
3. ★ **轴 3 是软证据**（无数据、可能整体偏）⇒ **它可以参与排序，但不能单独决定推荐**；
   当轴 3 与轴 1 / 2 / 4 冲突时，**以可核性更高的轴为准**，并**明说这个冲突**。
4. ★ **推荐必须带推翻条件**：写清「**什么情况下该推翻它**」。
   ★ 本工具能保证「**依据可核**」，**不能保证「推荐是对的」**（设计 §7-6）。

## 3. 时间盒 · 它的覆盖 · 与"何时值得超时"

- **默认时间盒：≤2 小时**（赛程 0–5 小时的**前半**）—— **到点必须给推荐、宁可粗**。
- ★ **它是默认，不是规则**：**可覆盖**（你的实际赛程你说了算，本工具不拦）。
- ★ **什么时候值得超时**（判据）：
  - 两条以上候选题**在轴 1 / 轴 2 上分不开**（"做不做得完"这一层还没定）⇒ 值得再花时间；
  - 某题**数据来源的关键事实**差一步就能核清（如题面提到了附件）⇒ **核清它比现在定题更值**；
  - ★ **反之不值得**：只是"想把轴 3 想得更准" —— 那一轴**无数据、本就最软**，
    再想也**买不到确定性**。
- ★ **到点仍分不开时**：**给推荐 + 写明"它可能错在哪"**（把"分不开"这件事**写进推翻条件**），
  **不要**为了"再稳一点"把定题拖过时间盒 —— 后面全是定题之后的时间。

## 4. 边界与「未建」（如实登记）

- ★★ **推荐仍是判断**：本支保证「依据可核」，**不保证「推荐是对的」**。
- ★ **数据可信度**：只能给**候选来源 + 各自边界**，**不能替你判断某个具体数据源可不可信**。
- ★ **"拥挤风险"是四轴里最软的一条** ⇒ 推荐时把它当**软证据**，推翻条件里写明它可能整体偏。
- ★ **时间盒是默认、可覆盖**（口径见 §3）。
- ★ **本支只读语料**：`corpus/papers/**` 是**我们的标注件**（不是官方），本支**不改**它。
- **未建的明写「未建」**（本支**无** `T3` 那种判据守它 ⇒ 靠**自律 + 复核**）：
  `mcm-paper-architecture` —— **未建**；`mcm-section-writer` · `mcm-memo` **已建**（逐节写作范式 / 题面要求 letter/memo 时的写作范式）。
  本支**不替你写正文**。
- **不声称穷尽**：上面四轴的"常见误判"是**已知的那些**，**不是"全部误判模式"**。

## 5. 产出的逐字形态（**判据读的就是它**）

★ `SKILL.md` 的「输出契约」给的是**语义**（要交齐哪几样）；**本节给的是形态**（每一样**逐字**长什么样）。
`tests/skills/topic-select/check-topic-select.py` 的 `S1`–`S4` 读的**正是下面这些行首形态** ——
**语义写对、形态不合，照样判红**。★ 本节**只公布判据真读到的形态**；判据不读的字段**不在此列**
（不 over-promise）。

**每道题一节**（`##` 或更多个 `#`；字母 = 被评估那道题的题号）：

★ **题小节内不要再起 `###` 子标题** —— `check-topic-select.py` 的 `split_sections` 把**任何 `^#{2,}` 行**都当小节边界
（`HEAD_ANY = re.compile(r"^#{2,}\s*(.*)$")`）⇒ 题小节里再起 `###`，它**后面的行**（历史行 / 四轴行）
会落进一个头既不是「题 X」也不是「推荐」的块里**被丢掉** ⇒ **`S3` 报"缺轴"**
（★ `S2` **只有"整份产出的历史行全丢"那一格才 fail-closed** —— 只丢一节时它**静默少算几行、仍判绿**，
所以这条告诫**真正咬住的是 `S3`**）。

    ## 题 <A–F> — <题干词>

    | L1 · L2 | 支撑句 |
    | :-- | :-- |
    | `核心` **<L1 名> · <L2 名>** | *"<当天题面的原句>"* |
    | `附带` **<L1 名> · <L2 名>** | *"<当天题面的原句>"* |

    - 历史：组合 `<L1 名> · <L2 名>` × `<数据形态枚举值>`，出现 <N> 次
    - 历史：题 `<YYYY> <字母>` 用过模型 `<模型名>`，<N> 篇
    - 轴 1 · 数据可得性 + 可信度【半可核】：已知…；未知…；依据…
    - 轴 2 · 难度【判断】：已知…；未知…；依据…
    - 轴 3 · 拥挤风险【判断】：已知…；未知…；依据…
    - 轴 4 · 创新空间【半可核】：已知…；未知…；依据…

**最后是推荐节**（`## 推荐`；不要与上面的题目小节混写）：

    ## 推荐

    - 推荐：题 <字母>
    - 推翻条件：<什么情况下该推翻它>

### 5.1 逐条的机读约束（`S1`–`S4` 各读什么）

- **题标题行**：`## 题 <字母>`（`##` 或更多个 `#`，中间可留空白；字母在「题」之后，
  **后面接词边界（`\b`，Unicode 语义）** —— 即后一个字符**不是 Unicode 词字符**（字母 / 数字 / **下划线**）
  或已到行尾 —— 如 `## 题 A — …`）。
  （★ 2026-10-03 Task 3 订正：原写「后面接**非字母数字字符**或行尾」，与 `check-topic-select.py` 的
  `PROB_HEAD` 所用 `\b` 不符 —— 实测 `## 题 A_` **不匹配**（`_` 是词字符、对 `\b` 不构成边界），
  故改为与 `\b` 相符的说法。**是改文档、不是改正则。**）
  **产出一节都解析不出 ⇒ `S1` fail-closed 红。**
- **标签表**：表头 / 分隔行 / 数据行的**表口径**逐字沿用
  `references/corpus-lookup.md` §1–§2（这也是语料的口径）；`核心` / `附带` 标在 `L1 · L2` 前。
  ★ **每个标签的支撑句必须是当天题面的原句**（按语料归一化口径后是**子串**）—— 这是 `S1`（心脏）。
  ★ 标签行**必须有支撑句**：表里一条引文都没有的标签行 ⇒ `S1` 红。
  ★ **支撑句的定界引号必须是直双引号 `"`** —— 写成 `“…”` ⇒ 判据在归一化**之前**取不到引文 ⇒ `S1` **红**
  （`check-topic-select.py` 借 `taxonomy.py` 的 `QUOTED = re.compile(r'"([^"]+)"')` 取引文，**只认直双引号**；
  ★ 归一化里那条「引号折叠（直/弯、单/双一律折成 `"`）」折的是**被比较的文本**，**不覆盖取引文这一步**）。
  ★ **`附带` 行不必交**：上面模板里那行 `附带` 只是**展示该行的形态**，**不是**「每题必须凑出一个 `附带` 标签」
  （`S1`/`S2`/`S3` 都不要求每题必有 `附带`）。★ 但凡**交上来的**标签行（无论 `核心` / `附带`）**都必须有支撑句**。
- **`- 历史：组合 `<L1 名> · <L2 名>` × `<数据形态枚举值>`，出现 <N> 次`**：
  `L1 名 · L2 名` 中间是**空格-中点-空格**（缺了 `L2` 即红）；`N` 必须与 `PROBLEM_TYPES.md`
  **现取**一致（`S2`）。
  ★ **`N` 的计法（此处钉死，与检查器逐字一致）**：`N` = 语料里**标注了该 `(L1 名, L2 名)` 对、且
  `数据形态` 等于该枚举值**的**标注条数** —— **含**标了 `附带` 的条（**不区分 `核心`/`附带`**）、
  **也含当天题本身**（若它恰好也在语料里；**「排除当天题」不是本口径**）。
  （检查器实现见 `check-topic-select.py` 的 `check_s2`：对每条标注，只要其 label 集合里**有**该 `(L1, L2)` 对、
  且 `data_regime` 相符即计 1，**不看 `核心`/`附带`**、**不排除当天题**。）
- **`- 历史：题 `<YYYY> <字母>` 用过模型 `<模型名>`，<N> 篇`**：`N` 必须与 `MODEL_MAP.md`
  （★ **只覆盖 2025**）**现取**一致（`S2`）。★ 产出里**一条 `- 历史：…` 行都没有** ⇒ `S2` fail-closed 红。
  ★ 那道「历史题」必须是**另一道题**（**不许**引当天那道题自己）—— 该语义规则见 `references/corpus-lookup.md` §3
  （`S2` **抓不到**它，只核篇数）。
- **四轴**：**四行都要**（缺哪轴报哪轴），每行形如 `- 轴 N · <轴名>【<可核性>】：…`；
  括号写 `【】`（`[]` / `（）` / `()` 也收）。**逐轴的可核性写死**：
  - 轴 1 / 轴 4 = **`半可核`**（同义写法 `部分可核` 也收）；
  - 轴 2 / 轴 3 = **`判断`**；★ 设计 §2 表里那句「纯判断」是**描述**、**不是标签** —— **标签写 `判断`**；
  - ★ 四轴**没有一轴是 `读数`** ⇒ 任何一轴标成 `读数` 都判红（这正是「判断型不许写成读数」那条）；
  - 轴名里要有对应关键词：轴 1「数据」· 轴 2「难度」· 轴 3「拥挤」· 轴 4「创新」（否则 `S3` 红）。
- **推荐节**：`## 推荐` 一节里要有 `- 推荐：…`（**要点名一道在场的题号**）与
  `- 推翻条件：…`（内容不能过短）；缺任一行 ⇒ `S4` 红。

★ **不声称穷尽**：上面列的是 `S1`–`S4` **真读到的**形态，**不是**"产出该有的全部" ——
各行的措辞、四轴的判断质量、推荐对不对，判据**都不判**。
★ **未公布的字段**：早先 fixture 里那行独立的 `- 数据形态：…` **不是判据读到的形态** ⇒
**已从本契约与 fixture 一并去掉**（`数据形态` 枚举仍以 `历史：组合 … × <枚举值>` 的形态出现，
信息没丢）。**不声称**"产出里不能再写别的行"——只是那些行**没有判据背书**。
