**★ = 该项目在 RED 六份基线或 GREEN 产物里**真的**失败过**（逐条证据见判分表 `tests/skills/mcm-abstract-quality-rubric.md`；

**依据指针简写**（完整 13 条指针表见判分表 §三/§四）：`i:` = `corpus/official/instructions.html`；`20YGA:` = `corpus/official/20YearsofGoodAdvice.txt`；`UMAP:` = `corpus/official/UMAP-2003-judges-commentary.txt`；`faq:` = `corpus/official/faq.html`。

### ★ 配方 → 自查动作（★ = 有基线失败的那几条）

★ **Q6 不让技术细节占版面**（形状类）
- **配方**：方法段写成"**每项方法 + 它解决了什么**"，用句子讲；模型结构一段说完（哪几块、各自把什么变成什么、靠什么定标）。
- **怎么查**：扫第 1 页找 `$...$`、独立公式行、`_`/`^`、等号右边的推导——每处都改写成语句，再通读一遍确认读者不需要公式也懂。
- **附注（禁令）**：不写主方程、不排符号、不带下标。
- **依据**：`20YGA:160` *"should not be overly technical"*（`[官方]†`）。实测 RED 5/6 份把主方程、Archard 式与下标排进了第 1 页。

★ **Q7 逐问作答**（形状类）
- **配方**：题面每个子问题 ⇒ 摘要里**一句判定**（不是判据）。
- **怎么查**：把题面每个子问题**抄成一行**，逐行问"摘要里哪一句回答了它"——答不上就是没答；只给了判据/阈值而没给结论的，同样算没答。
- **依据**：`UMAP:6565-6568`（评委原话："whether or not the team paid attention to the questions asked in the problem … they got cut quickly"）+ `i:1165`（*"Provide a conclusion and report results explicitly."*），两条都是 `[官方]`。实测 RED 5/6 份对"一致性"那一问只给判据不给判定。

★ **Q7 家族「结果没出来就显式标缺」（共同项 = `纪律 A1`）**（形状类）
- **配方**：没有算出来的项写成"该项未开展，数值缺失、不引用也不估"，**别用方法描述充数**。
  句式示例：*"The numerical work for (i)–(v) has not been carried out; those five results are marked as missing and no value is quoted for them."*
- **怎么查**：逐问回指正文——若正文里那一问只有判据/公式、没有任何算出来的值，摘要就必须显式标缺（实测五份里有三份只给判据不给判定，也没标缺）。
- **依据**：**`纪律 A1`**（`docs/mcm-writing-discipline.md`）—— 共同项规则原文以它为准，本清单不复述；`[官方]`；"显式标缺"的句式是本项目口径（`[社区]`）。

★ **Q11 简洁（一页装得下）**
- **配方**：一页 12pt 的**实测容量 ≈ 550–650 词**（本机 pdfLaTeX 实测：三份**刚好一页**的产物，第 1 页渲染词数 = 557 / 561 / 597，`abs-green-evidence.md` §4.2）；**留几行余量，别刚好填满**——本机编译一页 ≠ 网页端也一页（换页点可能不同）。
- **怎么查**：`check-summary.py` 报 `页数`，超页时它给"要砍多少字"（估算 + 硬下界）——**照着砍到 1 页**。
  再核余量：**工具在 `页数=1` 时不报填充率**，余量自己量 —— 口径是 `720pt`（正文栏底，`bottom=1in`）
  减去第 1 页正文最低文字块的底边；**量到低于 2 行（约 24pt）就再砍几行**。
  （口径与工具内部的 `page_body_stats()` 同源，量法见 `tests/skills/abs-green-evidence.md` §6.3。）
- **依据**：`faq:270`（"it must be on a single page with a readable font (12)"）· §2.5.6 *"clear and concise exposition"*。实测 RED 6/6 份超页（856–1319 词 → 编译均 2 页）。

★ **Q12 措辞克制（共同项 = `纪律 C1`）**（形状类）
- **配方**：结论句写成"**<量> = <值>（<区间>）**"；用数字、单位、区间说事；**模型的优点与局限各一句、都挂在数上**（那是 `i:1162` **要求**的内容，不能删）。
- **怎么查**：**要删的是"空话"与"未验证的比较级"两类，不是所有形容词**。
  - 第一类（空话/自评套话）：grep `honest` / `explicit` / `we report … rather than` / `not a guess` —— 命中处删掉或改写成带数的句子。
  - 第二类（未验证的比较级）：grep `better` / `faster` / `superior` / `outperform` —— 要么删，要么补上支撑它的数。
  - **不在删除对象里**：`robust` / `robustness` / `limitations` / `sensitivity` 这类**优缺点陈述**——判分表明确判它**不算失败**（*"属官方要求的优缺点陈述"*，`instructions.html:1162` 要求讨论优缺点），实测上一轮 `G1.tex:132`、`G3.tex:113` 各含 1 处 `robust`，当时**没扣分**。**照抄词表把合法的内容删掉，就是这一整轮在修的形态** ⇒ 见到它们要**留，并核一句"它挂没挂在数上"**。
  - （`rigorous`：**判分表对它未表态**，留在第一类里属**保守删除**——遇到时先看它是不是优缺点陈述，是就留。）
- **附注（禁令）**：不写自评式套话；不写未验证的比较级；**共同项规则原文见 `纪律 C1`（`docs/mcm-writing-discipline.md`）**。
- **依据**：**`纪律 C1`**（`docs/mcm-writing-discipline.md`）—— 共同项规则原文以它为准，本清单不复述；空话套话 `i:1132`、`20YGA:311`（`[官方]`）；"无未验证比较级"查不到官方原文（`[社区]`）。实测 RED 4/6 份把"本文写得多诚实"写进了摘要。

★ **Q9 数字必须自洽（共同项 = `纪律 A5`）**
- **配方（两步查法）**：① **结论与它引用的阈值是否同向**（正文明写 `RSA_k < 0.95` 即被修复过，却又用 `RSA = 0.02 < 0.05` 判"未修复"）；② **同一个量是否在正文出现两次且不等**（`G = 700 N` 与 WHO 权重算出的 `W·g = 616 N`；`1.14 people abreast` 与三峰推出的三人并行）。
- **怎么查**：摘要里每个数**回指正文那一处**，两步各过一遍；任一条命中 ⇒ 该数不带进摘要，改用同处干净的证据。
- **依据**：**`纪律 A5`**（`docs/mcm-writing-discipline.md`）—— 共同项规则原文以它为准，本清单不复述；`20YGA:249`（sanity check）+ `Contest_AI_Policy.txt:60-61`；"不许把正文自相矛盾的数带进摘要"是本项目口径（`[社区]`）。实测 RED 3/6 份踩过。

★ **Q2 开篇不复述题面**（形状类）
- **配方**：第一句写"**本题要从什么数据里恢复什么**"，第二句起就进入"我们怎么做 / 得到什么"；全篇不设"题目问什么"的独立段落。
- **怎么查**：逐句读首段——去掉后读者仍知道"我们干了什么"、且功能只是重列题面问句的句子，删。
- **附注（禁令）**：不搬题面的合规套话（non-destructive / low cost / small team with minimal tools）。
- **依据**：`i:1132` *"mere restatements of the contest problem … are generally considered to be weak"*、`UMAP:6469-6471`、`20YGA:162`。实测 RED 2/6 份有独立成段的 `**The questions.**`。

### 判分表 13 条之外：本轮新增的一条 ★（**摘要自身不许前后打架**）

★ **摘要自身不许前后打架**（本轮新增；**不在判分表 13 条内**，依据见 `tests/skills/abs-green-evidence.md` §8.4）
- **配方**：**同一件事在摘要里只能有一种说法**。标缺就通篇只标缺；声称"全部回答"就不要同时写"这一问没有值"。
- **怎么查**：通读一遍，**专找互相排斥的两句** —— 典型两类：① 一处写"未开展 / 标缺 / 不引用数值 / not evaluated"，另一处又写"全部回答 / 均已回答 / answers all five"；② 同一个量在同一页上有两个说法（`three abreast` 与 `1.14 people abreast`）。
  **命中即改**：先决定这件事到底做到了没有，再让全篇的说法与它一致；**别用结论句把标缺盖过去**。
- **依据**：**已观察到两次的真实失败**（不是假设）—— GREEN 侧 `G1c.tex:94-96` 写"一致性那一问……reported as missing and no value is quoted for it"，而 `:118` 又写"a single depth profile of one tread answers all five questions above"；
  RED 侧先例见判分表 §5-⑨（`red-P2` 结果段同句并列 `three abreast` 与 `1.14 people abreast`）。取 `[社区]`（本项目口径；与 `i:1165`"报告结果要明确"同向）。

### 规格（本次基线 0 失败，仍要逐条打勾）

- **Q1 最重要的结论在摘要里** —— 怎么查：摘要里必须有**带数的结论句**，不能只有"我们做了什么"。（`i:1131`；`20YGA:150-152`、`:310-312`；`UMAP:6460-6461`、`:6473`）
- **Q3 不逐字搬引言** —— 怎么查：grep 引言的成段特征句（如 `waiting to be explored`、`molded into different shapes`）；口径是**改写后能独立成立即合规**，逐字成段搬运才算违规。（`i:1132`；`UMAP:6560-6563`；`20YGA:157-159`）
- **Q4 方法不罗列，每项附"用它做了什么"** —— 怎么查：方法段逐项数一遍，哪一项后面没有"用它做了什么"，就补上或删掉这项。（`20YGA:160-161`、`:162`）
- **Q5 不按时间顺序记流水账** —— 怎么查：grep `first we` / `then we` / `finally we`；组织方式改成按模型部件或按 Task。（`20YGA:164-165`、`:318-321`）
- **Q8 数字与具名归属都要能回指正文（共同项 = `纪律 A2`）** —— 怎么查：摘要里每个数字在正文 `grep` 一次，**找不到即违规**；具名归属（国名、地名、材料名）同样要能回指。**共同项规则原文见 `纪律 A2`（`docs/mcm-writing-discipline.md`）、本清单不复述**。口径是本项目自定。（最近官方表述 `20YGA:249`；`[社区]`）
- **Q10 用数字与区间说事，不自夸** —— 怎么查：结论段每个句子要么含数字，要么是"该不该读正文"的判断；纯形容词句删。（`UMAP:6473`；`20YGA:150-152`、`:310-312`；`i:1162`）
- **Q13 读完摘要应能判断"该不该读正文"** —— 怎么查：找一句动机句 + 一句亮点句；两样都没有就补。**亮点句不许与别处的标缺句打架**（`G1c` 那次就是拿一句"回答了全部五问"当亮点，而同页另一句正写着"这一问标缺"——见下条）。（`i:1130`；`UMAP:6465-6468`；`20YGA:152-155`）
