# mcm-plot-origin —— 把图型决策落成 Origin 脚本

**只回答一件事**：图型定了、数据在手，**怎么用 Origin 把它画成规范里的那张图** —— 图页怎么建、
样式（底色、色序、字体）怎么套、图宽怎么钉、怎么导出、画完怎么验。

**不回答**：**该画成哪种图**（那是 `mcm-figure-choose` 的活）；**规范里每条规则的数值**
（规范在 `references/house-style.md`，本 skill **只给指针、不重述**）。
**不产** Python / MATLAB / TikZ 代码，也不出"这张图合规吗"的判词（判词在出货检查器的出口）。

## 什么时候用

- 图型已经定了（自己定的，或 `mcm-figure-choose` 给的），要把数据落成 Origin 脚本；
- 已经画出来了，但出货检查器的几条（图宽比 / 显式色序 / 底色）判红，要按规范重画；
- 要把一篇论文里的图统一到同一套外观（底色、色序、字体）。

**不用**：

- 只问"这组数据该画哪种图" ⇒ 走 `mcm-figure-choose`；
- 只问某条规范的具体数值或口径 ⇒ 直接读 `references/house-style.md` 与它旁边的 `provenance.md`
  （本 skill 不重述数值）。

## 怎么用

**前置条件（照实）**：本 skill 要跑 **OriginPro** —— **需要本机已安装且已授权**，且 `originpro`
这个 python 包能找到它（本机把 `originpro` 装在 `build/` 下的一个 `--target` 目录里，见
`references/workflow.md`）。**本 skill 不自动安装、也不代管许可证**。字体走**导出时施加的主题**
（点名即用；**不装任何字体**、**不复制入库字体**）。**干净检出复跑不相容**：没有本机的 OriginPro
就跑不出这些产物。**跨机未验**：本封装只在本机的一版 OriginPro 上验过。

入口（薄封装，实现在 `assets/mcmplot_origin.py`；本文件只讲怎么用）：

- `apply_style(page)`：给图页套 house style（**逐个 plot 设色序**），值**运行时**从样式表读。
  **建图后、导出前**调它。**它不动底色** —— Origin 默认导出即白底，白底由**产物**证
  （见 `references/workflow.md`）。
- `figsize_for(textwidth_in)`：把**正文栏宽分母**换算成**图宽**（英寸）。分母由**调用方**传入 ——
  它是论文的属性，本 skill 与检查器都**不预设**默认值。
- `save(page, path, dpi, theme)`：导出（`.png` / `.pdf`）。**宽度钉死**（按图页物理宽）、
  **主题在导出那一刻施加**；返回的读数里带**从产物实测的实际导出宽**。`dpi` 只对 PNG 有意义，
  且必须与送进检查器时的 `--dpi` **一致**。

完整流程（读规范 → 套样式 → 出图 → 机械层验 → **亲眼看图**）见 `references/workflow.md`。

## 输出契约（每次都交齐这几样）

- **一份可复跑的 `.py` 脚本**：调上面那几个入口，不手抄任何样式数值；**结尾收尾 `op.exit()`**。
- **产物图**：PNG 与 PDF 两种载体都出（两条载体上检查器的读数**不保证相同**）。
- **图注文本**：按规范写（图注形态由检查器那几条守）。
- **机械层读数**：产物送进出货检查器后的原始输出，判词逐条贴。
- **亲眼看图的一句话**：从这张图上读到了什么 —— 见 `references/workflow.md` 那一节。

## 边界

- **不重述任何规范数值**：阈值 / 占比 / 样本读数一律在 `references/house-style.md`。
  本文件**一个阿拉伯数字都没有**（规则编号也写成不带数字的 `H<n>` 形态）。要说的数回规范去说。
- **字体族那一格：本支落哪种态依产物而定**。产物的 PDF 里**可能含**一个内嵌的**过程字形**字体
  （PDF 规范里写作 `Type<n>` 的那类）⇒ 检查器按**它的族名**判：主题施加后族名是 Times 系 ⇒ 判 **PASS**；
  不施加主题时是宋体族 ⇒ 判 **FAIL**；一个内嵌字体都没有时落 **`N/A`**。
  ★ **别猜"什么会让它内嵌"** —— **直接量产物**（读判词那一行即可）。⇒ **族名有机械判据**，**字形的观感仍只能靠人看图**。
- **去上/右边框线与刻度朝向今天落不了地**：侦察**未找到**能让它落到产物上的属性 ⇒ 如实标，
  本 skill **不编一个看着像样的假法子**（该条规则在 Origin 支记"落不了地"，以规范里的验证状态为准）。
- **不判"图讲没讲清"**：机械层判不了这一层，它是判断层的事；这一层的入口写在
  `references/workflow.md` 的固定一节里。
- **不产别的载体**：Python / MATLAB / TikZ 是同层其余 skill 的事。
- **不自动装依赖**：见「怎么用」的前置条件。

## 指针（唯一权威）

- **规范正文**（图通常长什么样、每条规则的数值与验证状态）：`references/house-style.md`
  —— 本 skill 对样式的主张以它为准，本文件不复述其中任何一个数。
- **口径与复跑命令**（每个数的分母、样本范围、已知偏差）：`references/provenance.md`
- **图型决策**（该画哪种图）：`mcm-figure-choose` 那个 skill
- **出货检查器**（机械层判词）：`tests/skills/figure-choose/check-figure-style.py`
- **本 skill 的流程正文**：`references/workflow.md`
