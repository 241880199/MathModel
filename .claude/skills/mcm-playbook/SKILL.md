# mcm-playbook —— 赛程编排：现在该干什么

**只回答一件事**：给 **开赛时刻 + 当前进展** → 报「**现在该干什么**」：
**当前阶段 · 动作清单 · 该调哪个已建 skill · 该阶段典型失误**。

★ **它的真价值不在那张时刻表，在依赖图**（设计 §1.1）：
**时刻表是外壳，依赖图是内核。** 在赛程的压力下真正难的不是"现在几点"，而是
"**这一刻该调哪个 skill、为什么**"——那部分背后是**各 skill 已经验过的输入 / 输出契约**，
不是编出来的经验。
官方**只有**报名 / 缴费截止、开赛 / 停止修改 / 提交截止这几个硬时刻，**没有任何内部里程碑**
⇒ 逐小时的阶段切分**全是构造**，本 skill **逐刀标了"为什么切在这"**（见 `references/timeline.md`）。

## 什么时候用

- 赛程推进中，想知道"**现在该干什么**"、这一阶段该调哪些 skill；
- 拿不准"**按表走还是按进展走**"（例：表上该写作了，模型却还没跑完）；
- 想要一份"**这一阶段的典型失误**"清单，避开官方明示的失分点；
- 事后复盘："我们当时在哪个阶段、漏了哪一步"。

**不用**：

- 要**交稿前自查**（判"能不能提交"）⇒ `mcm-selfreview`，本支不做；
- 要**选题决策**（哪个题更好、怎么比）⇒ `mcm-topic-select`，本支只给"选题要看哪几件事"；
- 要**教怎么写 / 怎么建模**（文风、结构、模型方法）⇒ 属 M2（论文写作线）/ M4（数学模型线），本支不教。

## 怎么用：时间 + 状态双驱动

**入口是两样东西**，缺一不可：

1. **时间**：给一个**开赛时刻** ⇒ 本支算出你**在第几小时**（时间位置）。
2. **状态**：给**当前的真实进展**（做到哪了、手上有什么产物）⇒ 本支拿它**校**时间位置。

★ **两者不一致时，明说**，**不假装大家都按表走**：

> "按表你应该在**写作阶段**，但你说**模型还没跑完**——表与进展打架。
> 以下动作**按进展**排（因为'该调哪个 skill'取决于**手里有没有可用的产物**，不取决于钟点），
> 并据此提示你**落后了多少**。"

★ **如实交底**：双驱动里"**按进展**"那一半**依赖你如实自报**，本工具**核不了**（设计 §8-5）。
报得含糊，输出就只能含糊。

## 输出契约（每次都交齐这几样）

- **当前阶段**：第几阶段 + 在第几小时（**若表与进展不一致，两个都报，并说明按哪个排**）；
- **动作清单**：这一刻**做哪几件事**，按先后排；
- **该调哪个已建 skill**：逐个点名，并说**为什么是它**；
  ★ **尚未建的 skill 一律明写「未建」**，不许含糊成"参考 M2"这类说法；
- **该阶段典型失误**：逐条报，**每条带出处与分级**（见 `references/phase-mistakes.md`）；
- **一条边界**：本支给的是"**官方要什么 ⇒ 缺了就是失分**"，**不是**"历史上大家怎么栽的"。

## 边界

- **不做交稿前自查**（"能不能提交"）⇒ `mcm-selfreview`。
- **不做选题决策**（哪个题更好）⇒ `mcm-topic-select`。
- **不教怎么写 / 怎么建模**（文风、结构、模型方法）⇒ M2（论文写作线）/ M4（数学模型线）；本支只**指路**，不**教**。
- **不复述两份 references 的数值**：时间、时长、阶段小时边界、失误出处一律以 references 为准，
  本文件**一个都不重述**（重述即造第二份权威）。
- ★ **本 skill 是家族外第一个**（不属绘图家族）⇒ **无 `house-style.md` 指针义务**（那义务 = 家族内 `SKILL.md` 必须指向家族样式单 `references/house-style.md`）、
  **无零数字约束**（那约束 = 家族内 `SKILL.md` 不复述任何规范数值）；
  仍跟短契约风格，**那是为了一致性，不是判据逼的**（设计 §0.6 / §5）。
- **"归哪个阶段"是构造，不是官方口径**：官方只说"评委看重 X"，
  **从没说过 X 该在第几小时做**——逐条标注见 `references/phase-mistakes.md`。

## 指针（唯一权威）

- **赛程时间线**（硬时刻 · 推算时长 · 北京时间换算 · 阶段表 · 覆盖机制）：`references/timeline.md`
  —— 本 skill 关于时间的**一切数值**以它为准，本文件不复述。
- **每阶段典型失误**（失误名 · 出处 · 分级 · 为什么归这个阶段 · 该调哪个 skill）：
  `references/phase-mistakes.md`。
- **写作纪律的权威表述**：`docs/mcm-writing-discipline.md`——写作阶段的纪律**只在那一份**，
  本 skill 只给指针、不重述。
- **官方事实基线**：`corpus/official/INDEX.md`（本 skill **引用官方事实**时一律写成稳定 `§id`，如 `§2.6.2`，**不引行号**；★ **一处限定**：**转述官方材料自身的记录**时**可能带它原样的行号**—— 那是**逐字转述**、非本支在引事实，见 `references/timeline.md` 转述 `§2.6.5` 处）。
