# `mcm-playbook` 每阶段典型失误（官方反推 + 本支构造）

**只从官方材料反推**（设计 §0.2，不做语料侦察）。
每条 = **失误名 · 出处（稳定 `§id`）· 分级 · 为什么归这个阶段（★ 标「构造」）· 该调哪个 skill**。

★★ **本文件的头号风险：把下面的「构造」读成官方口径。**
**"归哪个阶段"全部是本支的构造**——官方只说过"评委看重 X"，
**从没说过 X 该在第几小时做**。所以**逐条**标「构造」，**不是**在文件头声明一次就完
（通篇声明会被读成"底下那些都是官方的"）。

**一条必须写明的边界**：官方材料**没有**告诉我们"评委实际刷掉了什么"。
`corpus/official/INDEX.md` §1.3 的 2003 年评委点评是**背景语料、非规则要求**、且**年代久远**。
⇒ 本文件给的是"**官方要什么 ⇒ 缺了就是失分**"，**不是**"历史上大家怎么栽的"。
**不声称覆盖全部失误模式。**

**引用约定**：一律引 `corpus/official/INDEX.md` 的**稳定 `§id`**，**不引行号**。

### 阶段 0 · 选题（第 0–5 小时）

**失误 0-1：只按"熟悉 / 看着简单"选，不评估可行性**
- 出处：`corpus/official/INDEX.md` §2.6.3〔`[官方]`〕（六题方向任选其一、只提交一题）；§2.1.2〔`[官方]`〕（无最低页数、接受 partial solutions、鼓励完成尽可能多的部分）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方只说"任选其一"，**没说**"选题时要评估什么"
- 该调：`mcm-topic-select`——本阶段只给下面这份**构造**的"选题要看哪四件事"，**不做真正的选题对比**

> **选题要看哪四件事**（★ **整份清单是本支的构造**，官方无对应表述）：
> ① **数据 / 材料是否可得**（题面给的与能自己找的，够不够撑起模型）；
> ② **方法与团队能力是否匹配**（不是"哪个高级"，是"**你们做得出来吗**"）；
> ③ **结果能不能给出一个清晰结论**（否则摘要写什么，见 0-2）；
> ④ **在赛程内是否做得完**（无最低页数、接受 partial solutions，§2.1.2 ⇒ 宁可选一个做得完的）。
> ★ **本清单不声称穷尽。**

**失误 0-2：选题时没先想"这题最后能不能给出一个清晰结论"**
- 出处：`corpus/official/INDEX.md` §2.2.8〔`[官方]`〕（官方建议最后写摘要，须突出最重要的结论）；§2.2.6〔`[官方]`〕（评委极其看重摘要）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方说摘要分量重，**没说**"这要在选题时就想"
- 该调：`mcm-topic-select`

### 阶段 1 · 破题（第 5–14 小时）

**失误 1-1："问题重述"照抄赛题（官方明示的弱摘要之一）**
- 出处：`corpus/official/INDEX.md` §2.2.7〔`[官方]`〕（官方明示的弱摘要：仅重述赛题，或从 Introduction 复制粘贴套话）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方说"重述赛题"是弱项，**没说**重述该在第几小时做
- 该调：`mcm-section-writer`（逐节写作范式）——M2 的 `mcm-paper-architecture`（页数预算）仍**未建**

**失误 1-2：假设含糊、没有论证假设的合理性**
- 出处：`corpus/official/INDEX.md` §2.5.3〔`[官方]`〕（官方 10 条内容清单：变量与假设的清晰陈述 / 假设的合理性与论证）；§2.5.4〔`[官方]†`〕（优秀论文含 assumptions with justifications）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方把它列进内容清单，**没说**它该在第几小时做
- 该调：`mcm-section-writer`（逐节写作范式）——同上，M2 的 `mcm-paper-architecture` 仍**未建**

### 阶段 2 · 建模与求解（第 14–50 小时）

**失误 2-1：模型没做检验（误差分析 / 灵敏度 / 稳定性）**
- 出处：`corpus/official/INDEX.md` §2.5.3〔`[官方]`〕（官方 10 条内容清单的"模型设计，并讨论如何检验：误差分析、灵敏度、稳定性"这一条）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方要求"讨论如何检验"，**没说**它该在第几小时做
- ★ **同族另一条**：§2.5.3 里"**讨论模型或方法的明显优缺点**"是**单列**的一条——官方把它单列，
  说明**常被漏**（本句读法为**本支的构造性观察**，非官方自述）
- 该调：无（求解产物要出图 / 表 ⇒ `mcm-figure-choose` → `mcm-plot-python` / `mcm-plot-matlab` / `mcm-plot-origin` / `mcm-table` / `mcm-schematic`）

**失误 2-2：图和表拖到最后才做（写作阶段要引用它们）**
- 出处：`corpus/official/INDEX.md` §2.1.4〔`[官方]`〕（Reference list / notes / 附录均计入页数上限）；§2.5.3〔`[官方]`〕（正文只放推导 / 计算摘要，冗长部分入附录）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方只约束页数与内容形态，**没说**"图该早画"；
  "图要早出"是本支的**依赖**判断（写作阶段要引用它们）
- 该调：`mcm-figure-choose` → `mcm-plot-python` / `mcm-plot-matlab` / `mcm-plot-origin` / `mcm-table` / `mcm-schematic`

### 阶段 3 · 写作主体（第 50–80 小时）

**失误 3-1：摘要最后草草写 / 摘要只是重述赛题**
- 出处：`corpus/official/INDEX.md` §2.2.7〔`[官方]`〕（弱摘要：仅重述赛题、或复制粘贴套话）；§2.2.8〔`[官方]`〕（建议最后写摘要，须突出最重要的结论）；§2.2.6〔`[官方]`〕（评委极其看重摘要）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方说摘要最后写、分量重，**没说**"写摘要"属第几小时
- 该调：`mcm-abstract`

**失误 3-2：引用不规范（只在末尾列文献、正文无标注）**
- 出处：`corpus/official/INDEX.md` §2.5.7〔`[官方]`〕（官方以 `must` 写死：**两件都要**——① 用足注 / 尾注 / 正文内标注标出每一处外部来源，② 在文献表或参考书目中给出对应条目）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方规定的是**义务与形态**，**没说**它该在第几小时做
- 该调：`mcm-section-writer`（逐节写作范式）· `docs/mcm-writing-discipline.md`（M2 的 `mcm-paper-architecture` **未建**）

**失误 3-3：把冗长推导全塞正文**
- 出处：`corpus/official/INDEX.md` §2.5.3〔`[官方]`〕（官方 10 条内容清单："正文只放推导 / 计算摘要，冗长部分入附录"）
- 为什么归这个阶段：★ **此归类是本支的构造**——这是内容形态要求，**没说**在第几小时改
- 该调：`mcm-section-writer`（逐节写作范式）· `docs/mcm-writing-discipline.md`

### 阶段 4 · 收口与自查（第 80–99 小时）

**失误 4-1：交稿前才发现页数 / 页眉 / 匿名不合规**
- 出处：`corpus/official/INDEX.md` §2.1.1〔`[官方]`〕（25 页上限，覆盖整个提交物）；§2.3.1〔`[官方]`〕（每页顶部含队号与页码）；§2.3.2〔`[官方]`〕（全文不得出现姓名 / 机构名 / 可识别信息）
- 为什么归这个阶段：★ **此归类是本支的构造**——合规是**收口**动作（官方只规定"合规长什么样"，没说什么时候查）
- 该调：`mcm-selfreview`（**合规组一票否决**）

**失误 4-2：摘要页 `Problem Chosen` 栏没填（保留占位符 `ABCDEF`）**
- 出处：`corpus/official/INDEX.md` §2.2.9〔`[官方]`〕（须填所选题目，不得保留模板占位符 `ABCDEF`）
- 为什么归这个阶段：★ **此归类是本支的构造**——这是收口时的"最后一改"
- 该调：`mcm-selfreview` · `mcm-latex-format`

**失误 4-3：AI 使用未披露 / 披露不合规**
- 出处：`corpus/official/INDEX.md` §2.4.2〔`[官方]`〕（双位置披露：正文内 inline citation + References 列出；并在 25 页之后追加独立章节）；§2.4.4〔`[官方]`〕（章节标题用 `Report on Use of AI`）；§2.4.8〔`[官方]`〕（未披露的后果）
- 为什么归这个阶段：★ **此归类是本支的构造**——官方规定披露**义务**，**没说**它该在第几小时写
- 该调：`mcm-ai-disclosure`

**失误 4-4：提交物形态不合规（不是单个 PDF / 超 25MB / 文件名不是队号）**
- 出处：`corpus/official/INDEX.md` §2.3.4〔`[官方]`〕（全部解答须在**一个** PDF 内，文件名为队号）；§2.3.7〔`[官方]`〕（PDF 附件必须小于 25MB）；§2.3.8〔`[官方]`〕（只接受 Adobe PDF、每份提交表单限一份 solution）
- 为什么归这个阶段：★ **此归类是本支的构造**——打包是收口的最后一步
- 该调：`mcm-selfreview` · `mcm-latex-format`

`corpus/official/INDEX.md` §2.5.5 记着一份 COMAP 官方人员公布的 `A Sample Final Judging Rubric`
（Executive Summary 10 / Assumptions & Justification 15 / **Model / Value Added 40** /
Sensitivity, Strength & Weakness 15 / Required Documents 10 / Clarity of Writing 10 = Total 100），
分级 `[半官方]†`。

★ **本文件的任何"评委看重 X"表述都不得据此升格成"X 占 N 分"**。
照抄 `INDEX.md` **注 2** 的三条限定：

> 2.5.5 的评分表**不得**被当成固定权重公式引用。skill 中如要使用，必须①标 `[半官方]`、
> ②带上"A Sample / 可按题目调整"的限定语、③不得写成"模型占 40%"这类定论。

★ 另（同出 §2.5.5）：官方原文写它是 "**A Sample**" / "**A starting rubric**"，
终审评委团会"**adjusting categories and points as needed**"（按题目调整类别与分值）；
且它管的是**终审（Final Judging）**，**不是初筛**。
⇒ 可用的只是**相对重要性的参考信号**，**不是公式**。
