#   1. **按 genus 判，不按枚举判**：§3 的 `场景` 原始定义是「**非方法**的语义词」，
#      后面的枚举（领域/地点/赛事/政策语境/研究对象/物理量/概念框架/任务名）是**举例**。
#      本表据此把 **机构名 / 期刊名 / 数据集名** 也归入 `场景`。

#      改 §3 与本表（判据侧不用改：M-10 只判「`场景` ⇒ `不收`」这条约束）。

#   3. **`待定` 的两种含义**（都在理由里写明是哪一种）：① **判不了**（缺口径或缺展开式：
#      `TPE` 同形异义、`FR` 读不出所属短语）；② **判得出「不可收」而分类轴里没有它的位置**
#      （`II`/`III`/`IV` 是论文自己的编号）——第 ② 种**不是「没见过」**，是**分类轴的缺口**。
