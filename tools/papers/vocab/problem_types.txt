# 受控题型分类法（Task 6b 阶段 1）· 官方赛题 2016–2026 的「数学任务形态」
#
# 格式：一行一条，`级别 | 名字 | 一句话定义`。`#` 注释、空行忽略。
#
#   * **L1** 是任务的**大形态**，**L2** 是它下面的**子形态**；两级都是**受控集合**，
#     标注里的每个标签必须逐字命中这里的一行（判据 T4）；
#   * 名字**带编号**，标注里写「L1 名 · L2 名」（` · ` 分隔，照 2025 样板）；
#   * 层级**止于「任务形态」**，**不细到方法名**——方法活在 `tools/papers/vocab/models.txt`
#     里。**两级名字都不得与 `models.txt` 的词条/变体同名**（判据 T3）：
#     同名会让「题型 → 模型」的配对退化成同义反复（用户 2026-09-26 的原始要求是
#     「将题目的类型与论文模型/算法对应」）。
#
# 起点 = 任务书 §一 给的那 9 个 L1（2025 样板试出并已补 3 处）。**本阶段动了 8 处**，
# 逐条理由都在下面的条目注释里，改动类型只有两类：
#   (a) **T3 改名**（4 处 + 1 处去括号）：名字与词表撞车，不改就退化成同义反复；
#   (b) **新增**（2 个 L2 + 1 个 L1）：66 题里出现了现成条目放不下的任务形态。
# 另有 **1 条零命中登记**（见文件末尾）——「算得出来」不等于「用得着」，
# 沿用 `models.txt` 的零命中登记口径：不藏。
#
# 与 `models.txt` 的分工（**读的人先看这一句**）：本文件的条目回答「**题目要你做什么**」，
# `models.txt` 的条目回答「**论文用了什么方法**」。阶段 2 的配对 = 两者的笛卡尔积
# 按 `(L1, L2) × data_regime` 聚合。

# ---- 1 预测 ---------------------------------------------------------------
L1 | 1 预测 | 要求对未来（或未见）时点、情形下的取值给出估计，并给出该估计的不确定度。
L2 | 1.1 时序外推 | 用同一对象自身的历史序列外推未来值（趋势、季节、自相关驱动）。
L2 | 1.2 回归/相关预测 | 用解释变量与被预测量之间的（回归/相关）关系外推未来值。
L2 | 1.3 情景与概率预测 | 预测「在给定情景或假设下会怎样」，并给出概率或区间（含最好/最坏/最可能）。
L2 | 1.4 组合预测 | 把多个模型或多个来源的预测合成一个预测（集成、加权组合）。
L2 | 1.5 零膨胀/受限计数预测 | 因变量是非负计数、且大量取值恰为 0 或受上下限截断时的预测（如「尚未得牌国家」）。

# ---- 2 评价与排序 ---------------------------------------------------------
L1 | 2 评价与排序 | 把多个对象按「好坏」归置：建指标、打分、排序、分级、比较方案。
L2 | 2.1 指标体系构建 | 先解决「用什么量来刻画」——建立指标的集合与定义（含可获得性论证）。
L2 | 2.2 多指标综合评价 | 把多个指标合成一个综合值（含权重确定与量纲处理）。
L2 | 2.3 排序规则/权重设计 | 要的不是综合值本身而是名次/优先级，重点在排序规则与权重怎么设计。
L2 | 2.4 方案比较 | 把若干候选方案并排比较优劣：不求解最优，只给出可比较的证据。
L2 | 2.5 分级/阈值划定 | 把连续量切成**有名字的等级**（脆弱/稳定、低/中/高风险），重点在阈值怎么定。
# ↑ 2.5 为**本阶段新增**：2018 E 要求「identify when a state is fragile, vulnerable, or
#   stable」、2023 E 要求「identify the light pollution risk level of a location」、
#   2023 C 要求「classify solution words by difficulty」——三者都是「先定阈值再贴等级」，
#   而 2.1（建指标）/2.2（合成综合值）都装不下「等级的名字与分界从哪来」。

# ---- 3 优化 ---------------------------------------------------------------
L1 | 3 优化 | 在约束下选一族决策变量使目标最优；主语是「选什么、选多少」。
L2 | 3.1 连续/非线性 | 决策变量连续，目标或约束非线性（含几何形状的连续设计）。
L2 | 3.2 离散/组合 | 决策变量是整数、0-1 或排列（选择、指派、组合可行集）。
L2 | 3.3 多目标/权衡 | 同时优化若干互相冲突的目标，必须显式给出权衡方式（Pareto/加权/ε-约束）。
L2 | 3.4 动态与随机 | 决策随时间展开，或目标/约束含随机性（动态规划、随机规划、可靠性）。
L2 | 3.5 调度与配置 | 决定「何时、多少、按什么次序」去做（排程、资源配置、吞吐）。
L2 | 3.6 选址与布局 | 决定「放在哪里、怎么排布」（设施选址、网络布点、空间布局）。
# ↑ 3.6 为**本阶段新增**：2018 D「Determine the optimal number, placement, and distribution
#   of charging stations」、2021 B「optimizing the locations of hovering VHF/UHF radio-repeater
#   drones」、2024 B「recommend initial points of deployment」——选址是独立的任务形态，
#   原先只能塞进 3.2（它管的是「整数/组合」这个**变量类型**，不是「空间位置」这个**语义**）。

# ---- 4 机理建模与仿真 -----------------------------------------------------
L1 | 4 机理建模与仿真 | 从机制出发写出系统的演化方程或规则，再据此推演（正问题）。
L2 | 4.1 物理/化学机理建模 | 用守恒律与本构关系（热、力、电、流体、化学反应）写连续时间的演化方程。
L2 | 4.2 生态/生物动力学 | 用种群、物种、个体之间的相互作用（竞争、捕食、共生）写动力学。
L2 | 4.3 随机仿真/概率模拟 | 重复随机抽样推演系统，得到结果的分布（而不是解析解）。
L2 | 4.4 局部规则演化/个体交互仿真 | 由个体的局部规则与相互作用推演宏观格局（空间离散演化、多主体）。
L2 | 4.5 离散事件 | 系统状态只在事件时刻跳变，主体是到达/排队/服务（含流程图式的过程建模）。
L2 | 4.6 反馈结构与动态演化 | 变量之间有回路（存量-流量、正负反馈），重点是「结构决定动态行为」。
# ↑ 4.1 的**去括号**、4.3/4.4/4.6 的**改名**都是 T3 逼出来的（原名与 `models.txt` 撞车）：
#   `4.1 物理/化学机理(ODE/PDE)` —— `ODE`/`PDE` 是词表变体（词表 86/87 行）；
#   `4.3 随机仿真/蒙特卡洛` —— `蒙特卡洛` 是词表变体（`Monte Carlo` 行）；
#   `4.4 元胞自动机/多智能体` —— `元胞自动机` 是词表词条（`cellular automata` 行）；
#   `4.6 系统动力学/反馈结构` —— `系统动力学` 是词表词条（`system dynamics` 行）。
#   **名字里带着模型名，配对就是同义反复**（「用了系统动力学的题」标成「系统动力学题型」）。
#   注：4.6 的名字在**用户已审定的 2025 样板**里就叫「系统动力学/反馈结构」，
#   本阶段按 T3 改名，**这一处要请用户确认**（见草案头部与任务报告的「与样板的偏离」表）。

# ---- 5 统计推断与因果 -----------------------------------------------------
L1 | 5 统计推断与因果 | 从数据出发回答「差异/关系/效果是否真实存在、有多大」。
L2 | 5.1 差异显著性检验 | 判定观测到的组间差异是否超出随机波动（检验统计量与区间估计）。
L2 | 5.2 回归系数与效应量 | 估计某个因素对结果的影响有多大（系数的点估计与区间）。
L2 | 5.3 因果/政策评估 | 回答「这一政策或干预是否造成了结果变化」（反事实、准实验、政策前后对照）。
L2 | 5.4 不确定性与敏感性 | 量化结论自身的不确定度，并考察结论对假设与参数扰动的敏感程度。
L2 | 5.5 关联/相关模式 | 只主张「变量之间存在关联或共现模式」，既不主张因果、也不要求效应量。
# ↑ 5.5 为**本阶段新增**：2020 C「identify ... meaningful quantitative and/or qualitative
#   patterns, relationships, measures, and parameters within and between star ratings,
#   reviews, and helpfulness ratings」——「找关联模式」比 5.2（估效应量）弱、比 5.3（因果）
#   也弱，而 66 题里这类任务很多（题目往往明确不要因果，只要 pattern）。
#   5.1 由「假设检验/显著性」**改名**为「差异显著性检验」：`假设检验` 是词表变体（词表 113 行）。

# ---- 6 反演与参数估计 -----------------------------------------------------
L1 | 6 反演与参数估计 | 观测量已知、原因未知：由观测反推隐藏的参数、历史或状态。
L2 | 6.1 由观测反推参数/历史 | 由观测到的结果反推产生它的参数、过程或历史（逆问题）。
L2 | 6.2 逆向设计 | 先给定「要达到的性能」，再反推能满足它的结构或参数（设计型逆问题）。
L2 | 6.3 状态估计/数据同化 | 由带噪声的观测序列在线估计不可直接观测的状态（跟踪、同化、搜索）。

# ---- 7 分类与聚类 ---------------------------------------------------------
L1 | 7 分类与聚类 | 把对象归入类别：有标签用监督、无标签用结构，或先把维度压下来。
L2 | 7.1 监督分类/识别 | 用有标签样本学一个判别规则，去预测新样本的类别或身份。
L2 | 7.2 无监督聚类/分段 | 无标签地把对象分成若干组、或把序列切成若干段（含模式与区制划分）。
L2 | 7.3 降维与特征 | 为后续建模构造或筛选特征，或把高维对象压成低维表示。

# ---- 8 网络与图 -----------------------------------------------------------
L1 | 8 网络与图 | 把系统建成「点—边」结构，在结构上算量、算流、算传播。
L2 | 8.1 网络结构与重要性 | 刻画网络的结构特征与节点/边的相对重要程度（中心性、模体、社群）。
L2 | 8.2 流量分配/路由 | 在网络上分配流量或路径（通行、疏散、路径选择与均衡）。
L2 | 8.3 传播与级联 | 沿网络传播的过程（信息、影响、疾病、失效的扩散与连锁）。
L2 | 8.4 连通性与鲁棒性 | 网络在断点或攻击下的连通性与功能维持（含关键环节识别）。
# ↑ 8.1/8.2 改名是 T3：`中心性` 是词表变体（`centrality` 行）、`网络流` 是词表词条（`network flow` 行）。

# ---- 9 决策与博弈 ---------------------------------------------------------
L1 | 9 决策与博弈 | 有多个主体或多个准则时，怎么选、怎么定规则。
L2 | 9.1 多准则决策 | 在多个（定性或定量）准则下对方案做取舍与推荐，并显式处理准则之间的冲突。
L2 | 9.2 博弈与策略 | 主体之间有策略互动（对手会反应），求均衡或最优应对。
L2 | 9.3 风险与效用 | 决策的对象是风险本身：定价、承保、投保、效用与期望损失。
L2 | 9.4 机制/规则设计 | 设计一套规则或制度（投票、分配、激励、合同、流程），并论证其性质。

# ---- 10 文本与语义处理 ----------------------------------------------------
L1 | 10 文本与语义处理 | 输入是非结构化的自然语言文本，必须先把文本变成可算的量。
L2 | 10.1 文本特征与情感抽取 | 从文本里抽出可度量的特征（词、情感、质量描述词）供后续分析使用。
L2 | 10.2 主题与语义归类 | 按内容或主题把文本归类、或在文本之间做语义匹配（含政策文本的比较归类）。
# ↑ L1「10 文本与语义处理」与 10.1 为**本阶段新增**：2020 C 的题干直接要求从评论文本里
#   抽「quality descriptors such as `enthusiastic', `disappointed'」（核心任务），
#   而 7.3（降维与特征）说的是**数值**特征的构造、10 说的是**文本→量**这一步。
#   10.2 在 66 题上是**零命中**（见文件末尾登记），留着是为 2027 及以后的中文语料/文本题；
#   「零命中」是语料事实、不是判据失效——与 `models.txt` 的零命中登记同一口径。
