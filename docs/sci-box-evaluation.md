## 2. 逐半判决

### 2.1 `scibox-diagram` —— 判：**高价值，值得取**

**构成**（已核实）：7 个脚本 + 10 个 references + 4 套版式模板 + 100 个 Tabler 图标（MIT）。

**已被阅读的**：`SKILL.md`、`references/authoring.md`（全文）。
**仅有其 SKILL.md 自述、未逐字读**：`self-check.md`（九区盘点 / 红队 / 自评分卡）、`preflight-rules.md`、`replication.md`、`icons.md`、4 个模板说明书、`adding-templates.md`。→ 凡涉及这些文件的判断，均属**转述其自述**，不是核验过的结论。

**实测挣来的知识，举例**（`authoring.md`，逐条可核）：

- 中文字宽模型：全角≈字号、半角≈字号/2、行高≈字号+3；"16px 字号下 160px 宽的盒子每行最多 9 个汉字"。
- 竖排**不要**用 `horizontal=0`——那是整块旋转 90°，中文会躺倒；要逐字 `<br>` 堆叠。
- `value` 属性里**永远不出现裸 `<`**；拼接顺序必须是"先 `html.escape(原文)`、再拼自己的标签"，反了原文里的 `<` 会被当标签吃掉。
- 连接器端点离盒边留 **1px**，否则被判"箭头穿盒"。
- 一分多 / 多合一要画成"竖线 + 横母线 + 分支"，**不是** N 条独立斜线——语义不同。
- `shape=mxgraph.arrows2.bendArrow` 是直角 L 形块箭头不是弧；`orthogonalEdgeStyle` 上加 `curved=1` 只会把直角**磨圆**，要成弧必须 `edgeStyle=none;curved=1`。

**工程化配套**：`check_layout.py` 静态检查（中文字宽模型；查文字溢出/越界/重复 id/端点压边/盒子重叠/连线穿盒）、`preview_html.py` 浏览器预览（无需 drawio 命令行）、`export_figure.py` 出 PNG + 矢量 PDF（**需 drawio 命令行，本机大概率没有，属可选项**）。

**为什么对口本项目**：

1. 输出是**可编辑矢量**，且全程**不需要本机 TeX**。~~——你恰好没有 TeX。~~ 这是比原计划的 TikZ 更实的一条路。
   （⚠️ **2026-09-24 更正**：本机**已装 TeX Live 2026**，"恰好没有 TeX"这半句已失效；但"**全程不需编译** +
   产出可编辑矢量"两条理由仍成立，故本条结论不变。见 `docs/mcm-suite-lessons.md` 通则 6。）
2. `check_layout.py` **纯 stdlib**，本机可直接跑，能进 `tests/` 做回归。
3. 它的"**不看渲染图不算画完**"与设计文档 §7「图表类必须**视觉复核**，不能只靠程序化自检」是**同一条原则**，接得上。

### 2.2 `scibox-figure` —— 判：**低价值，不建议搬**

四条理由，前三条是硬伤：

1. **11 个模板全是硬编码模拟数据的"复刻件"**。泰勒图里 XGBoost / ANN / GPR / NGBoost 的 std 与 corr 全部写死在源码里。拿来即用会产出"**假数据真格式**"的图，赛中不可用。
2. **SKILL.md 深度绑定某个托管沙箱**：路径写死 `/home/user/.claude/skills/mathmodel-figure-templates`，触发词是产品内部口令（"Improve tab"、`$mathmodel-figure-templates`），并声明 `allowed-tools: Bash(*)`。按原样安装会**污染触发面**并引入宽授权。
3. **无统一 house style**——这条正好撞上设计文档的明文禁令。11 个模板的 `font.family` 分成 **5 个 serif / 6 个 sans-serif 两派**，`font.size` 取值 **8 / 9 / 10 / 11 四种**，`axes.spines.top/right` 有的关有的不关。而设计文档 M3 明写"三个 `mcm-plot-*` 必须与 `mcm-figure-choose` 共用同一份规范来源，**不允许各自收敛出不同视觉标准**"。把 11 份各自的样式块搬进来 = 把这条禁令反着执行。
4. 净判决：**当"画法配方"读一遍**——`references/plot-recipes.md` 那 11 行是高密度索引（云雨图＝半边小提琴+抖动散点+箱线几何+均值菱形+均值连线；ROC+CI＝折线插值到共享 FPR 网格+均值曲线+标准差带…）。**不搬脚本**。

> **更正**：评估过程中我一度断言"模板带中文标签，与英文论文不匹配"。那是 `grep '[一-龥]'` 的**字节范围假命中**（把 `β`、`°`、`±`、`—` 也counted 了）。按 Unicode `U+4E00–9FFF` 精确统计，**11 个文件 CJK 字符数均为 0**，标签本来就是英文（`β-Propeller`、`PCM(°C)`、`Pred vs True`）。**该条不成立，撤销。**

**唯一值得单独留下的一条**：11 个模板统一设了 **`pdf.fonttype: 42`**（`svg.fonttype: none`），即 PDF 内嵌 TrueType、文字保持可编辑可搜索。这是期刊级做法，与 LaTeX 插图直接相关，值得未来记进 `mcm-figure-choose`。

## 3. 三条风险 / 阻塞

### 3.1 许可缺口（**已改判：2026-09-23 作废**）

> **本节结论已失效。** 2026-09-23 用户确立新政策：**第三方素材不因许可证排除，按价值判断收录**（见 `docs/mcm-suite-todo.md` §E，该条取代设计文档 §8）。故下文的"取证风险"不再构成否决策由。
> **但 §2.1/§2.2 的技术判决全部照旧成立**——sci-box 的问题从来不只在许可证上：figure 半边是假数据 + 沙箱耦合 + 无统一 house style，diagram 半边要与既有 TikZ/Mermaid 决策打架。**许可证这条撤掉后，结论仍是"先不整合"**，只是理由少了一条。

原判（保留备查）：仓库根目录**无 LICENSE**。`ATTRIBUTION.md` 只覆盖 `assets/icons/tabler/`（MIT，其子目录留有许可证原文，随文件保留），对"除此之外……均为自有内容"**只是内容声明，不是授权声明**。缺许可证默认 = 保留所有权利。

- 你**自用不分发**，实务风险低。但设计文档 §8 已立过政策："多数项目无 License……本项目的做法是**只借方法论与结构，内容从自己提供的语料重新提炼**"。**取 diagram 的代码 = 破这条政策**，需要明确点头，且必须在仓库留一份 **provenance 记录**（借了什么 / 何时 / 上游 commit / 许可状态），否则半年后说不清哪段不是自己的。
- 附带：其 `allowed-tools: Bash(*)` 是宽授权，若将来安装，这条要单独审。

### 3.2 架构改动

设计文档 M3 把 `mcm-schematic` 的输出定死为 **TikZ 或 Mermaid**。取 draw.io 就要改这一行——改动本身我认为**是对的**（见 §2.1 第 1 点），但它是"**已定架构的变更**"，不能顺手做，须显式登记。

### 3.3 本轮未做运行验证

我尝试执行其脚本做可行性验证，被权限分类器拦下，理由正当：你要求的是"整合/评估"，不是"执行外部代码"。**故本文件关于"能跑、输出正确"的判断一条也没有——全部是静态读出来的。**

若将来要走吸纳路径，第一步必须是**取得授权后实跑**：4 个 diagram 脚本 + `check_layout.py` + 抽查 figure 模板，并把逐字输出归档进 `tests/`（教训 7：证据须入受版本控制的目录，`mcm-latex-format` 的 GREEN-1 已因只写进 gitignore 目录而永久丢失）。

## 4. 若将来要取：推荐路径与代价

推荐 **「取方法、重写内容」**——**注意：此推荐现在与许可证无关**（§3.1 已改判）。理由是技术性的：figure 半边搬进来会带进假数据与 11 份互相冲突的样式块，diagram 半边的 `check_layout.py` 重写后能加美赛专有合规规则（匿名、队号），而上游完全不管这些。

- `mcm-schematic` **自写 SKILL.md**（契约式、< 150 行），把 draw.io 的中文字宽模型、连接器语义、四个必踩的坑下沉到 `references/`。
- `check_layout.py` 这一层**要么自己重写、要么显式标注第三方并留 provenance**。它纯 stdlib、逻辑透明，重写成本不高，且重写后可加**美赛专有规则**——例如"图内不得出现队号 / 校名"这类合规检查，**sci-box 完全不管匿名、页数这些硬约束**。
- 11 条画法配方不搬脚本，提炼成 `mcm-figure-choose` 的**图型目录条目**。

**代价**：比直接 `cp` 高，约多一轮任务量。
**收益**：不欠许可证；能把 M3 的合规检查接进去；house style 由自己钉死，不继承它的 5/6 分裂。
