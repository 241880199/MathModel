## 2. 职责与边界

**职责**：给定「你有什么数据 / 你要回答什么」，输出
① **推荐图型 + 理由**（决策树）；② **该图的设计要点**（几何 / 配色 / 坐标轴 / 图例 / 信息密度 / 图注）。
**语言无关**——不产生 Python / MATLAB / Origin 代码。

**边界（不进）**：
- **不产生代码**（那是 `mcm-plot-python` / `mcm-plot-matlab` / `mcm-plot-origin`）。
- **不做"图合规全自动检查"**（YAGNI：那是独立 skill 的活；本 skill 只自带 RED/GREEN 判据脚本）。
- **不补图型分布的视觉判读轮**（已裁决：语料作参照分布，不作模仿目标）。
- **只读 `corpus/`**，不写。
- **不重造 SciencePlots 已有的能力**（实现层底层用它）。

## 4. 规范条目（house-style.md 的内容）

**每条的体例**：`规则` + `来源`（**实测** / **规范性** / **量不到**）+ `依据与复跑命令` + `什么情况下算违反`。

| # | 条目 | 规则 | 来源与依据 |
| :--- | :--- | :--- | :--- |
| 1 | 图宽 | 默认**贴近正文宽（0.95–1.0×）**；不窄于 **0.80×**（p25）；**不超过 1.2×**（max 1.19 以上无一例） | **实测** n=662：中位 0.951 · p25 0.80 · p75 1.00 · max 1.19 |
| 2 | **分母口径（写死）** | 正文栏宽 = **该篇正文行宽 p90**（全局中位 6.31 in）；**规范里必须写明用的是哪一种**，并附复跑命令 | 实测暴露的口径歧义：全局分母得 56.6%、逐篇分母得 59.4%（**中位数一致、百分比不一致**）。**这类"分母没钉死"是本文件必须避免的第一号错误** |
| 3 | 取向 / 图高 | 默认**横向**、宽高比 **2–3**（中位 2.42）；图高按 **2.6 in** 量级（中位 2.63） | **实测**：横图 98.0% · 宽高比中位 2.42 · `aspect≥2` 53.5% · 高中位 2.63 in |
| 4 | 配色密度 | 彩色**主色 ≤4**；**单色/灰度是正常选择** | **实测**：主色中位 3 · 19.5% 零彩色 · **表 83.3% 零彩色** |
| 5 | 默认色序 | 不用 matplotlib 默认色序；措辞**只能到"在获奖样本中未观察到广泛使用"** | 实测**只给下界 0.9%**（人眼复核 6/6）；**松判据那版 17.8% 已证伪，不得引用** |
| 6 | 饼图 | **不用** | **实测**：n=120 判断层里 **0 张** |
| 7 | 3D 图 | 可用但少用 | 实测（判据读数）：9.2% |
| 8 | 多面板 | 多面板是常态，别怕拆子图 | 实测**只能当上界**：判据 50.8%，人判一致率 55.8% |
| 9 | 图注模板 | `Figure N:` + **ASCII 冒号**；**中位 5 词 / 上限 12 词 / 不超过 17 词**；**句末不加句号**；**必须自足** | **实测**（本批最干净）：662/662 可切 · 87.3% ASCII 冒号 · 5 / 12 / 17 词 · 94.6% 无句号 · 17 张空图注当**反例** |
| 10 | 坐标轴 | 去顶右框线、刻度方向、轴标签带单位 | **规范性**〔社区〕——本样本**量不到**刻度朝向 |
| 11 | 网格线 / 图例 / 双 Y 轴 | **本规范暂不覆盖** | 侦察判"要更多语料/换判据面"；图例判据**人判一致率 15.8% ⇒ 已证废**；网格**只是判据读数、不是结论** |
| 12 | 字号 / 线宽 / 字体族 | 图内字号 = 正文的 **0.8–1.0×**、最小 **≥7 pt**；线宽与字体族随论文正文 | **规范性**〔社区〕，**非实测**——**本样本量不到**（PNG 连通域反推得 1.54–11.31 pt 乱值）。**若要实测，走 PDF 文本层**（`textmd.py` 能取 `span["size"]`，需新增"图内 span"剔除逻辑，本仓尚无） |
| 13 | 参照分布 | 只回答"获奖论文通常长什么样"，**不得作为判据** | 口径纪律：**"像不像获奖论文"从来不是判据**（与写作指标同一把尺） |

**决策树（chart-types.md）**：按**数据关系**分入口——比较 / 分布 / 相关 / 构成 / 时序 / 空间 / 流程 / 机理 / 不确定性——
每题给 **首选图型 · 备选 · 禁忌**；**不按题型组织**（题型是题目属性、不是数据属性），但挂一条**题型索引**指向
既有 `corpus/papers/PROBLEM_TYPES.md`（67 题已标注），供"评价类题通常给什么数据"反查。
**radar 立类但标低频**（规则层 5 次 `Radar chart` 全被 `line` 兜住；判断层 1/120）。

**三条"不许吹"的措辞下限**（侦察已证伪过一批）：默认色序只能到"未观察到"（**下界 ≠ 上限**）· 多面板**只能当上界** · 网格/图例**宁可不写**（判据未通过人判对照就不许进规范）。

## 5. 判据与证据（RED → GREEN）

**RED 场景**（取材真实题目数据，三个子场景各压决策树一个分支）：
- **R1 构成数据（占比）** → 看它会不会选**饼图**（预期会，而实测 n=120 里 0 张）
- **R2 多变量对比 / 相关** → 看选什么图型、要不要拆多面板
- **R3 交付形态** → 图宽是否贴正文、是否用默认色序、图注写法

**判据分两层**（缺一层就会漏）：
- **机械可判**：图宽/正文宽比值 · 主色数 · 图注词数 / 冒号形态 / 句末标点 → 做成**一个可执行检查器**（落 `tests/skills/figure-choose/`），
  **RED 与 GREEN 共用同一把尺**，并**用一次变异证明它会红**（本仓已栽过"判据恒绿"六次）。
- **判断题**：图型选得对不对、决策树理由是否自足 → 独立判者判；**判者不得看 skill、只看产物**。

**GREEN**：同一场景 + skill 重做；**判据与测量脚本一字不改**（只换被测对象）——这才叫对照。
**证据逐字入 `tests/`**（通则 7；`.superpowers/` 会被 gitignore，别把证据只放那儿）。
