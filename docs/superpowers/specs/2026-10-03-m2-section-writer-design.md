## 1. 定位与形态

| | |
| :--- | :--- |
| **是什么** | **按节写作的范式交付器**。告诉你"这一节该回答什么、按什么次序组织、最容易在哪几条纪律上翻车、哪些内容**不属于这一节**"；产出**该节 `.tex` 片段** + **该节的按节自查单** |
| **不是什么** | ① **不排版**（骨架是 `mcm-latex-format`）② **不写摘要页**（`mcm-abstract`）③ **不出图/表**（M3）④ **不做全稿提交前合规**（`mcm-selfreview`，一票否决那一组）⑤ **不做页数预算**（`mcm-paper-architecture` 已决定不做）⑥ **不判"这段是不是 AI 生成的"** —— 三处原文：`judge.md:133`：*"我不足以据此判定产物由 AI 直接生成"* · `:244`：*"证明不了产物是 AI 直接生成的"* · `:240`：三条 AI 判据*"必须是'报数 + 可复核'，不能是'下判定'"* |

**输入契约**：**题面** + **你正在写哪一节** + **该节的要点清单**（形态照 `tests/skills/arch-cases/brief-S1.md`：一条条要点、不成句） + **已定稿的图表与结果**。
★ **不向用户要"论文全文"** —— 它是**逐节**工具；跨节一致性由 `纪律 B6` 管辖，落点在「节边界表」（§3 第 4 格）。

### 1.1 ★ 它最值钱的一条设计：**把"措辞层"从"勾选"变成"可核"**

GREEN 轮的结论（`judge-green.md:265`）**明写**：纪律文档是**逐条 checklist**，被测写手的表现"正是一个照着清单勾选的写手的样子"，**无法区分"内化"与"勾选"**。
⇒ 本支的对策：**逐节范式 + 一台真检查器**。范式解决"勾选时该看哪几条"（14 条不必每节全看），检查器把**其中能机判的 8 项**变成可跑的东西（§4）。
★ **不许夸大检查器的射程**：它**只覆盖 §4 的 `SW1–SW8` 八项**，其中**只有 `SW1`/`SW2` 是硬失败**，其余六项**一律"提请复核"**；`纪律 A3/A4/A5/B2/B4/B5/B6` 等条目**仍靠人工逐条**。**"检查器 PASS" ≠ "这一节写好了"**（同 `mcm-abstract` 的口径：*工具只判形式*）。

## 4. `check-section.py` 的判据与**它的边界**

**它是什么**：对**一份节文本**（`.tex` 或 `.md`）跑一组检查，报告 `PASS` / `WARN` / `FAIL`。**只有 `FAIL` 是硬失败。**

| # | 判据 | 出处 | 报告方式 |
| :--- | :--- | :--- | :--- |
| `SW1` | **数字与出处成对**：抽表题/表前句/表内数字/具名来源，回**写手输入**搜；"来源名在正文出现而数字一个都搜不到" ⇒ 硬失败 | `judge.md:222-225`（`:223`） | **`FAIL`** |
| `SW2` | **无出处数字须带标注**：对该表行号区间跑 `grep -n -iE 'assum\|illustrat\|placeholder\|to be (replaced\|supplied)'`，**命中 0 即失败** | `judge.md:224` | **`FAIL`** |
| `SW3` | 段末总结率（`纪律 C1` 家族的实测读数之一） | `judge.md:309`（`≥90%` 且 `≥6` 段 ⇒ 提请复核） | `WARN` |
| `SW4` | 膨胀比 | `judge.md:235` | `WARN` |
| `SW5` | 对比式 + 强调式构造密度（对应 `纪律 C2`） | `judge.md:236` | `WARN` |
| `SW6` | 自评式元话语数（对应 `纪律 C1`） | `judge.md:237` | `WARN` |
| `SW7` | 极短断言句（`纪律 C3`：最短句 `<8` 词且全节 `≥3` 处） | `judge.md:308` | `WARN` |
