## §5 `N/A` 与空集口径（`GC5` / `GC6`）—— **三种情形 + 一个第四态**

★ **三种情形不许互相混**（尤其"节不在"与"节在但零行"）。这是外检（`--scope artifact`）能成立的前提。
★ 另有**第四态**（"节在、但表头与契约不符"）—— 它**既不是 `N/A` 也不是空集**，见下方情形 D。

### 情形 A「目标物不存在」⇒ 判 `N/A`

`--scope artifact` 下，判据的**整体目标**（来源表文件 / 结果清单文件 / 代码目录 / 论文文件）**不存在**。理由（`GC5`）：外检的靶子是用户赛期真实产物，**形态未知**，查不到不等于违规。

### 情形 B「节不在」⇒ 判 `N/A`

**目标文件在场**，但**契约要求的那一节**（`## 来源表` / `## 清洗步骤` / `## 结果清单`）**不在该文件里**。理由（`P7`）：解析器找不到该节 ⇒ 该判据**无从判** ⇒ `N/A`（**不计入失败**）。

### 情形 C「节 / 表 / 目录在场但零行 / 零文件」⇒ 判 `FAIL`

契约要求的那一节**在场**，但其下**表体零数据行**；或**目录在场但零文件**。理由（`GC6`）：**空集不许判绿**，照 M4 `MS6` 口径，一律判**红**。

### 情形 D「节在、但表头与契约不符」⇒ 判 `FAIL`（**第四态** · `T3` 落地）

契约要求的那一节**在场**，但其下**表块的表头**与 §1 的逐字列头**不符**（列名 / 列数 / 顺序对不上）。⇒ 判 **`FAIL`**（**不是 `N/A`、也不是 `PASS`**）。理由：表头不符 ⇒ 无法按下标取列 ⇒ 列内判据无从判；但它**不属情形 B**（节在场）、**也不属情形 C**（不是零行空集），故是三分之外的**第四态**。按 fail-closed 取向一律判红，并打印"表头与 §1.1 不符"，**不许静默放过、也不许降级为 `N/A`**。

### 5.1 与"列内取值"的关系（`GC5` 后半句）

**一旦表在场（有数据行），列内取值缺失即判红，不再走 `N/A`。** 即：`N/A` 出口只对"整体目标缺失 / 契约节缺失"两种**结构性**情形开放；表见着之后，`DA1` / `DA3` / `CD6` 这类**列内非空**判据按列逐行判红。
