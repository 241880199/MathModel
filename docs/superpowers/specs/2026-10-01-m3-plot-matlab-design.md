## 0. 已裁决策（不要再问）

1. **导出载体 = `print` 家族为权威**（用户 2026-09-30 裁）：`print -dpng` 跟 **`PaperPosition`**、`print -dpdf` 跟 **`PaperSize`**；
   设 `6.31 in` ⇒ **F1 = 1.000 / 1.001**（按构造）。
   **`exportgraphics` 不作为权威交付载体**（它的宽**是内容包围盒的函数**，实测 F1 0.861/0.865），**只在文档里给用法与风险**。
2. **字体 = 系统 `Times New Roman`**（用户 2026-09-30 裁）：点名即内嵌 `TimesNewRomanPSMT`、**不是静默回退**；
   与 `TeXGyreTermesX` **同属 Times 系** ⇒ 在"**按族等价**"目标下**已经算一致**。
   **入库 OTF 那条路已否**（实测只能靠"在目标机上装一次系统字体"实现，且**干净检出上静默降级 `SimSun`** ⇒ 与"证据可从干净检出复跑"不相容）。
3. **每张 figure 必须显式上浅色主题**（实测逼出）：`figure(...,'Theme','light')`（98.1% 近白）或 `theme(fig,'light')` + 显式设色。
4. **颜色目标 = 同值**（精确 hex，与 python 一致）；**字体按族等价**；**H11 不覆盖**（网格/图例/双 Y 轴）。
5. **★ 验收要把生成的图渲染出来给人看**（用户 2026-09-30 裁，**通用要求、从本模块起生效**）——
   机械层验不了的，用眼睛验。

## 1. 这一支凭什么能对得上同一套规范

**它读同一张表**：`mcm-style-single-source` 的 `.claude/skills/mcm-figure-choose/assets/mcm-style.json`（**14 条**）里，
`carriers.matlab` 那三列**已填好**（Task 2 落定）。⇒ **MATLAB 支不许自己再抄一份样式**
（这是本设计线的核心：**消灭"第二份来源"**；python 侧的先例是 `gen-mcm-style.py` 从表读、不再是第二份）。

**已实测、可直接落进生成器的三条**：
- **宽度**：PNG 跟 `PaperPosition`（in）、PDF 跟 `PaperSize`（in）⇒ **两条口径要分别写清**（这是 `print` 家族的固有形态）。
- **底色**：默认**深色**（`#212121`）⇒ 必须显式上浅色主题（§3.1）。
- **色序**：`set(gca,'ColorOrder',…)`；**H14 的八色**。

## 2. 已知缺口（**写进文件头，不许藏**）

1. **★ 默认主题是深色，且机械判据对它全 PASS**（实测：深色底产物四载体满分通过；`F2` 因**先剔近灰**（`max−min<24`）而对深底**等于不存在**）
   ⇒ **这条必须靠"每张 figure 显式上浅色主题"来堵**，而**判据只能落在产物像素上**（`F4` 已能兜住 —— Task 3 落地）。
2. **`theme('light')` 不带句柄 = 静默空操作**（实测：`ok=1`、图仍深色 84.8%）⇒ **不许用这个写法**。
3. **`get(ax,'Color')` 会骗你**（设过白仍回 `[0.0706…]`）⇒ **"设上了"只能由产物证明**。
4. **`exportgraphics` 的宽度不可控**（内容包围盒）⇒ 不作权威载体（§0.1）。
5. **`F2` 对折线图基本无承重**（7 条默认色序序列只读 3）—— **与 Origin 侧同型，如实登记**。
6. **`run('相对路径.m')` 会把 cwd 切到脚本所在目录**（实测）⇒ **`mcm-plot-matlab` 出具的 `.m` 脚本必须用
   `mfilename('fullpath')` 反推仓根**，别用相对路径。
7. **入库 OTF 用不了**（§0.2 已否）· **不装系统字体 = 0 条通路**（侦察试过 `AddFontResourceEx` / `regsvr32` / `latex` 解释器 / `addpath`，全无效）。
8. **本机只有 R2025b Update 5** ⇒ 跨版本/跨机未验，**如实登记**。

## 3. 实施约束（**实测逼出来的，必须写进生成器**）

1. **每张 figure 上浅色主题**：`figure(...,'Theme','light')`（或 `theme(fig,'light')` + 显式 `set` 颜色）。
   ⚠️ **主题翻转的触发点是"axes 内容第一次被真正渲染"**（实测逐步隔离：建 figure 不翻、`axes()` 单独不翻、`axes+plot+drawnow` 才翻）
   ⇒ **别在"建 figure 之后、画图之前"去判断主题**。
2. **导出走 `print`**：`set(fig,'PaperUnits','inches','PaperPositionMode','manual', …)`；
   **PNG 与 PDF 的两条口径分别设**（§1）。
3. **字体点名 `Times New Roman`**；**判据只能读产物内嵌字体**（`F6`），**不能看属性设没设**（§2.3）。
4. **`.m` 脚本用 `mfilename('fullpath')` 反推仓根**（§2.6）。
