## 1. 这一支凭什么能对得上同一套规范

**它读同一张表**：`mcm-style-single-source` 建立的 `.claude/skills/mcm-figure-choose/assets/mcm-style.json`（**14 条**）
里，`carriers.origin` 那三列**已经填好了**（Task 2 落定、值来自两轮侦察的实测）。
⇒ **Origin 支不许自己再抄一份样式**（本设计线的核心就是消灭"第二份来源"）。

**三条已实测、可直接落进脚本的事实**：
- **导出宽度**：`GPage.save_fig(width=N)` / `expGraph … tr1.Unit:=2 tr1.Width:=N`（英寸用 `tr1.Unit:=0`）；
  PNG 像素**逐值精确命中**、PDF 页盒量化 **1/72 in**（`6.31 → 6.31944`）；`tr.Margin` 四态下**宽度恒等于请求值** ⇒ **无隐式裁剪**。
- **底色**：**默认就是白**（四角 `255,255,255`）。
- **显式色序**：hex **逐色精确可设**，且**无会话内翻转**（与 MATLAB 相反）。

## 2. 已知缺口（**写进文件头，不许藏**）

1. **★ 字体族：设得住、验不了**。`expGraph … theme:="Times New Roman Font"` 实测能让产物字体名
   `SimSun → TimesNewRomanPSMT`；但 **Origin 的 PDF 一个字体文件都不内嵌**（**34/34** 个产物 `/FontFile*` = 0）
   ⇒ `check-figure-style.py` 的 **`F6` 对它只能判 `N/A`**。
   ⇒ **这一格没有机械承重**：只能靠"导出命令里写了主题" + **人看图**（见 §0.5）。
   ⚠️ **`themeApply2g` 那条路有次序坑**（见 §5）。
2. **导出 DPI 未测到效果**：`tr.Advanced.DPI`（100/300/600）在"宽按英寸钉住"时**没测到效果**（换算恒 300）。**今天按 300 走，如实标注。**
3. **会话内一个残留进程是用 `atexit` 漏掉的**（`originpro` 不走到 `op.exit()` 时只 `Detach(releaseonly=True)`）⇒ **§5 强制 `try/finally`**。
4. **靠本机商业软件**：`originpro` 需要**已安装且已授权**的 OriginPro（本机 2026 / 教育版）。
   ⇒ **干净检出复跑不相容** —— 复跑前置必须写明这一条。
5. **框线 / 刻度朝向未找到可用属性**（侦察结论：差分全 0；反证：连 `layer.x.show=0` 也 0 差分）。
   ⇒ **H10 的"去上右框线 / 刻度朝内"在 Origin 支今天落不了地**，如实标（**不许编一个看着像样的假法子**）。
6. **中文字形不在射程**（本设计线 §10.4 已登记）：本支已裁**图内标签用英文** ⇒ 今天不触发。

## 5. 实施约束（**实测逼出来的，必须写进 helper**）

1. **★ `try/finally: op.exit()`** —— 每一条启动 Origin 的路径都要包。**不走到它必漏进程**（侦察期实测漏过）。
2. **★ 主题必须在"导出那一刻"施加**：`themeApply2g` **只作用于施加那一刻已存在的对象**
   ⇒ 之后新建的文本注释**回到 SimSun**（实测：**半张图两种字体**，比全宋体更难看）。
   ⇒ 正确做法 = `expGraph … theme:="Times New Roman Font"`（实测**覆盖导出前加好的注释**）。
3. **★ 失败是静默的**：给**不存在的主题名**，`themeApply2g` 与 `expGraph theme:=` **两条路都静默成功**
   （`exec_ok=True`、产物毫无变化）。⇒ **"设上了"只能由产物证明**。
   另：`page.font$=` / `layer.font$=` / `sys.font$=` 返 **`False`**（属性真不存在），而 `xb.font$=…` 静默返 `True` 却什么都没做
   ⇒ **`False` 能当"不存在"用，`True` 什么都不能当**。
4. **导出 DPI** 按 300 走（§2.2 未测到更细的控制）。

## 6. helper 的公开接口（**实现者按此写，不许自造**）

```python
apply_style(page)                 # 底色 + 色序（值从 mcm-style.json 读）
figsize_for(textwidth_in)         # → 宽度（英寸），乘数从表里取
save(page, path, dpi=300, theme="Times New Roman Font")
                                  # 导出：宽度钉死 + 主题在导出那一刻施加
```
**约束**：① **所有样式数值从表里读**，helper 内**零规范字面量**（除"怎么调 API"本身）；
② **`save()` 内部负责 `try/finally`**；③ **`save()` 之后要能拿到"实际导出宽"**以自证（供判据用）。
