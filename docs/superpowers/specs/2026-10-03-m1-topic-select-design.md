# `mcm-topic-select` 设计（2026-10-03）

**本设计件是 `mcm-topic-select` 的最高依据。** 每条规则都带**出处**（语料读数 / 官方材料 / 构造），并**与出处同时写明它的边界**。

**读数来源**：
- **官方**：`corpus/official/INDEX.md`（§2.5 评审导向 · §2.6 赛制与时间）
- **语料**：`corpus/papers/{PROBLEM_TYPES.md, MODEL_MAP.md, INDEX.md, TAGS.md}`（**我们的标注件**，已入库）
  ★ **边界**：`MODEL_MAP.md` **只覆盖 2025 那一年**的 O 奖论文；`PROBLEM_TYPES.md` 覆盖 **2016–2026 的题面**（题面、非解答）。

## 0. 已裁（**用户 2026-10-03 拍板，不要再问**）

1. **推荐以「逐轴证据档」交，不编分数** —— 四轴**逐轴**给「已知什么 / 未知什么 / 依据在哪」，**不编 1–5 分**；
   推荐从这些读数里推出来，并**明写它可能错在哪、什么情况下该推翻它**。
2. **带上语料那套分类与检索**：用 `PROBLEM_TYPES.md` 的**词表与口径**给当天每题打标签，再查历史同型。
3. **硬时间盒：默认 ≤2 小时**（赛程 0–5 小时的**前半**），**到点必须给推荐、宁可粗**；并写明**什么时候值得超时**。
4. ★ **队伍画像取消**（用户原话："队伍画像不重要"）—— **不向用户要画像**。
5. ★ **四轴 = 数据可得性+可信度 / 难度 / 拥挤风险 / 创新空间**。
   （设计文档原写"数据可得性 / 建模难度 / 创新空间 / **队伍匹配度**" —— **队伍匹配度那一轴按 §0.4 撤掉**，换成**拥挤风险**。）
   ★★ **第 3 轴的订正（用户 2026-10-03 当日追问后定）**：它**不是"预计多少队伍会选它"**（**赛期内不可回答** —— 结果赛后几个月才出）
   ⇒ 它**只判"题面上有没有会吸引人扎堆的特征"**（一眼就懂 / 套路常见 / 自带数据 / 趣味性强），**是判断题面的，不是预测队伍数的**，**不给数字**。
6. **家族外第二个 skill** ⇒ 与 `mcm-playbook` 同：**不进 `FAMILY_RE`**，**无 `K2` 指针义务、无零数字约束**。

## 1. 定位与形态

| | |
| :--- | :--- |
| **是什么** | **选题决策**。你贴**当天六道题** → 它出：**每题按语料口径的分类**（`数学任务 × 数据形态`，**每条附题面原句为证**）· **2016–2026 同型历史** · **四轴证据档** · **一个明确推荐 + 它的推翻条件** |
| **不是什么** | ① **不替你查数据**（那是 M5）② **不替你建模**（那是 M4）③ **不排赛程**（那是已建的 `mcm-playbook`）④ **不编分数**（§0.1） |

**输入契约**：**只要六道题的题面**（贴文本或给路径）。★ **不要队伍画像**（§0.4）。

### 1.1 ★ 它最值钱的一条设计

语料的 `PROBLEM_TYPES.md` 已有一条**建好的纪律**（其「口径」2）：

> **每个标签必须附题面原句，且那句必须是题面的子串**（归一化后逐字命中）。

⇒ **本支照搬**：它给当天每题打的**每一个标签**，**都必须附一句当天题面的原句**。
⇒ 这条**可机械核**（判据 `S1`），且它挡的正是"**编一条看起来像题面的句子**"。
★ **模型天生爱改写** —— 改写出来的句子**不是子串** ⇒ 必红。

### 1.2 文件结构

```
.claude/skills/mcm-topic-select/
├─ SKILL.md                     # 短契约：入口 · 时间盒 · 输出契约 · 指针
└─ references/
   ├─ method.md                 # 四轴证据档怎么填 · 取舍规则 · 推翻条件 · 常见误判
   └─ corpus-lookup.md          # 怎么用语料那套（词表 / 口径 / 两道推理轴）与它**已知的边界**

tests/skills/topic-select/      # 判据 + 变异 + RED/GREEN
```

**为什么没有 `assets/`**：它**不产图 / 表 / 代码**（产物是一份判断 + 依据），**不需要编译**（同 `mcm-playbook`）。

## 2. 四轴（**逐轴与它的可核性同写**）

| 轴 | 它问什么 | ★ 可核性 |
| :--- | :--- | :--- |
| **1 数据可得性 + 可信度** | 题面给了吗？**要自己联网找吗**？找得到吗？**来源可不可信**（官方库？论文附录？二手转载？） | **部分可核**：题面给的那部分可核；**自找的必须列出候选来源 + 各自的可信度边界** |
| **2 难度** | 做不做得出来（**太难 ⇒ 交不出东西**） | ⚠️ **判断** |
| ★ **3 拥挤风险** | **这道题面上有没有"会吸引人扎堆"的特征**：一眼就懂 / 套路常见（能套模板）/ 自带数据（省事）/ 趣味性强 —— 评奖是**相对的**，人多的题会把好答案淹掉 | ⚠️ **纯判断（无任何数据）** ⇒ **但必须给推理**；★★ **它判的是题面，不是队伍数**（见 §2.1.2）。★ **补注（2026-10-03）**：本格写的「纯判断」是**描述**、**不是标签**；**产出里的标签口径写 `判断`**（见 `references/method.md` §5）。 |
| **4 创新空间** | 你能不能做出**与多数人不同**的一版 | **半可核**：语料能给**历史同型题的 O 奖论文都干了什么** ⇒ "你再用 X 就只是跟随" |

### 2.1 ★ 两条必须如实说的

1. **四轴里有三轴是判断** ⇒ **"逐轴证据档"这个形态在这里不是形式，是唯一诚实的载体**：
   每轴必须写清"**已知什么 / 未知什么 / 判断依据是什么**"，**不许把判断写成读数**（判据 `S3` 守）。
2. ★★ **"拥挤风险"这一轴没有任何数据，而且这不是"数据没找全"、"赛期内不可回答"** ——
   **赛后几个月才出结果**，**当场既不知道获奖篇数、也不知道选题人数**。
   ⇒ 它的地位是**对题面的显式判断，不是读数**。
   ★★ **禁令（判据 `S6` 守）**：**不许拿"某题的历史获奖论文篇数"去代理"选它的人数"** ——
   获奖篇数取决于**评委怎么分奖**、不取决于**多少队选了它** ⇒ 那是**拿两个不同的对象作比**（本仓栽过多次，通则 13）。
   ★ **这条禁令不是空设**：**语料就在盘上**（`corpus/papers/INDEX.md` = "2025 O 奖论文索引"，逐题登记篇数）⇒
   跑的时候 agent **够得着那些数**，于是**很容易**推出"获奖论文多 ⇒ 选的人少" ⇒ 所以必须明文拦。**规范里要明写"赛期内没有任何可靠办法知道某题的选题人数"。**

### 2.2 语料怎么进来（**边界同时写**）

- **分类**：拿 `PROBLEM_TYPES.md` 的**词表与口径**给当天每题打 `数学任务 × 数据形态`。
  ★ 语料自己的口径 7 记着一条**用户裁决**：**"配对的推理轴只有两条：数学任务 × 数据形态"**，**场景只作检索标签、与模型选择无关**。
- **同型检索**：查 2016–2026 同组合的历史题（`PROBLEM_TYPES.md`）+ 2025 的模型配对（`MODEL_MAP.md`）。
- ★ **边界**：`MODEL_MAP.md` **只有 2025 一年** ⇒ 历史配对证据**偏薄**，引用时必须带这句。
- ★ **六题不在语料里** ⇒ 分类是**对当天题面现做**，与语料标注**可能有口径差**（如实标）。

## 3. 判据与验收

判据**另立**（`tests/skills/topic-select/check-topic-select.py`），**不照抄 `F`/`A`/`T` 任何一族**。六条，**每条 fail-closed**：

| | 判什么 | 为什么值得有 |
| :--- | :--- | :--- |
| ★★ **`S1`** | **每个标签的支撑句，必须是当天题面的子串**（按语料的口径归一化后：去项目符号 → 空白折叠 → 引号折叠 → 大小写折叠） | ★★ **整套判据的心脏**：挡"**编一条看起来像题面的句子**" |
| **`S2`** | 凡引历史（"这个组合出现过 N 次" / "那道题 O 奖论文用了 X"），读数**与 `PROBLEM_TYPES.md` / `MODEL_MAP.md` 现取一致** | 防"背下来的历史" |
| **`S3`** | 四轴**逐轴齐备**，且每轴**标明可核性**（读数 / 半可核 / **判断**）；**判断型不许写成读数** | "证据档"形态的守卫 |
| **`S4`** | 推荐**带推翻条件**（"什么情况下该推翻它"） | 与 `mcm-playbook` 的"双驱动不一致就明说"同一族 |
| **`S5`** | **时间盒声明在位**（≤2h + **什么时候值得超时**） | 防"分析到第 5 小时还没定题" |
| **`S6`** | **禁令在位**：**不许拿"历史获奖论文篇数"代理"选它的人数"**；且**规范里明写"赛期内没有任何可靠办法知道某题的选题人数"** | 守 §2.1 那条（**不许拿两个不同对象作比**）。★ **它拦的是一条真实可发的坏推理**（语料就在盘上、够得着那些篇数） |

★ **一条工程决定**（实施计划里要落）：**`S1` 的归一化规则要复用**语料那份口径
（`PROBLEM_TYPES.md` 口径 2 + `tools/papers/taxonomy.py`），**不另写一套** ——
两套归一化 ⇒ 两支的"可核"会有一天对不上。

### 3.1 变异驱动器

照本仓惯例，**每条判据至少一条变异** + **配"必须仍绿"的射程边界对照**：

- 把一条支撑句**改写成同义句** ⇒ **`S1` 红**（核心那条）
- 把历史读数**改一个数** ⇒ **`S2` 红**
- 把"判断"那轴**改标成"读数"** ⇒ **`S3` 红**
- 删掉推翻条件 ⇒ **`S4` 红**
- 抹掉时间盒声明 ⇒ **`S5` 红**
- 把禁令改成"获奖论文多的题选的人少" ⇒ **`S6` 红**

### 3.2 RED / GREEN

**RED 场景**：给隔离写手"**从这六道题里挑一道，并说明为什么**"的 brief + 六份题面，
**不给**语料、不给规范、不给判据（**新起干净上下文、不用 `fork`**）。
**预期**：没受过"逐字"约束的写手**会用自己的话复述题面** ⇒ **`S1` 红**。
★ 按 `mcm-playbook` 那支的教训：**"预期" ≠ "保证"** —— **写手若逐字抄了，照实记**（那也是一个真读数）。

> ★★ **订正（2026-10-03 · Task 3 实测：上面那条预测被推翻）** —— 不是"没触发"，是**错了**。
> **实测**：三位隔离写手**都没产出标签表/题小节/推荐行**（控制者探针独立复现：题小节 0 · 标签表行 0 · 推荐行 0）⇒
> **`S1` 在"解析不出 `## 题 X` 小节"那一步就 fail-closed 红**，**压根没走到"逐字 vs 改写"那一格**；
> 红集 `{S1,S2,S3,S4}` **全是 fail-closed 型** ⇒ **本轮 RED 对 `S1` 的判别力提供不了证据**。
> ★ **根因（本仓有先例）**：**`mcm-schematic` 的 RED 给了写手一份"中性骨架"**（有机械、无风格）⇒ 才产得出**可比**产物；
> **本支没给中性形态** ⇒ 写手产出的散文**不在判据的解析面内** ⇒ **RED 在解析层全军覆没**。
> ⇒ **本条的处置**：**RED 需按中性形态重跑**（shape-only：给标签表/历史行/四轴/推荐的**空壳**，不给逐字纪律）；
> 在重跑落地之前，**"`S1` 能抓改写"的正向证据只有变异驱动器 `MUT-S1a/S1b`，不在 RED 里** —— 两件事不许混为一谈。
**RED 的诚实边界**（写进证据件）：brief 已限定"要挑一道并说明理由" ⇒ **测不到"连推荐都给不出"**。**不声称覆盖全部失败模式。**

### 3.3 「看一眼」层

无产物可看 ⇒ 与 `mcm-playbook` 同样**如实标"不适用"**，并用替代品
（**把产出的"推荐 + 依据"拿给人读，问"照这个你能定题吗"**）；★ **标明它是替代品，不是等价物**。

## 7. 已知缺口（**不声称穷尽**）

1. ★★ **"拥挤风险"那一轴没有任何数据，且"赛期内不可回答"** —— 它**只能判题面特征**（一眼就懂 / 套路常见 / 自带数据 / 趣味性强），**不能预测队伍数**（结果赛后几个月才出）。
   已**钉成"显式推理 + 写明它错在哪"**，并**禁止**拿"历史获奖篇数"代理"选题人数"（判据 `S6`；**语料就在盘上 ⇒ 这条禁令不是空设**）。
   ★ **本轴的判断可能整体偏**（"看着容易"未必等于"真会挤"）⇒ **它是四轴里最软的一条，推荐时要把它当软证据**。
2. **`MODEL_MAP.md` 只有 2025 一年** ⇒ 历史配对证据**偏薄**（写进 `corpus-lookup.md` 的边界）。
3. **数据可信度**只能给"**候选来源 + 各自边界**"，**不能替你判断某个具体数据源可不可信**。
4. **六题不在语料里** ⇒ 分类是**对当天题面现做**，与语料标注**可能有口径差**。
5. **时间盒是默认**（≤2h），**可覆盖**。
6. **推荐仍是判断** —— 工具能保证"**依据可核**"，**不能保证"推荐是对的"**。
7. **网页端 / 跨机不适用**（无产物可复跑 —— 是**结论**，不是"未验"）。
