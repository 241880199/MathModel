## §0 已裁（用户 2026-10-04 拍板，不要再问）

1. **边界切法**：`mcm-data` = 数据侧、`mcm-code` = 代码侧；**「拿真实数据跑出结果」按段各归各** —— 数据准备段归 `mcm-data`、求解段归 `mcm-code`。仓内现有一处与之不符（`2026-10-04-m4-model-select-design.md` 把"跑你的数据"单归 `mcm-code`），按 §6 同批订正。
2. **检查器**:两个 skill 都出判据脚本；**外检（查用户赛期真实产物）才是价值所在**，内检（查本仓交付件自洽）保收工门。
3. **语言**：规范条文**语言无关**；检查器认 **MATLAB 与 Python 两套惯用法**；`assets/` 给两份最小脚手架。
4. **数据源范围**：**题目未提供、需自行获取的数据是主路**（用户明确指出："部分数据在题目中不会提供，需要自行获取"）。题面附件那条路是并列的一支，不是主线。
5. **验收机制**：判据 + **逐条正反样例对** + 驱动器（断言每条判据至少红过一次）+ 不动点证据件。
6. **不做往届数据附件索引**：`corpus/官方原题/` 的 15 件附件是**往届题面自带**的数据，与"检索题目没给的数据"不是一回事；盘点语料不是 M5 的职责。该目录无 `INDEX.md` 的缺口**只登记**（§6），不由 M5 建。
7. **人机确认闸**：**由 AI 检索到的数据，队员必须逐条确认可靠性后方可引用**；**代码侧同构** —— 由 AI 写的代码，队员必须自己跑通并核过结果方可采信。两侧各落成**一条可机械判的判据**（§3、§4）。

## §1 定位与形态

### 1.1 两个 skill 是什么 / 不是什么

| | `mcm-data` | `mcm-code` |

### 2.1 命名约定（硬）

1. **判据编号**：`mcm-data` 用 `DA1`–`DA5`、`mcm-code` 用 `CD1`–`CD6`。**全仓唯一**（当场核，**排除本件**的读数）：

   ★ **不加 `-I` 会有假阳性**（`.otf` / `.png` 等二进制被当文本扫）；★ **不加词边界 `\b` 也会**（绘图的色值字面量 `#0C5DA5` 里含 `DA5`，首版就是这么报出 42 行假命中的）。⇒ 命令按上面写死，别简写。

### 3.3 可信度五级（`[社区]` —— 本套件自订，非官方条文）

1. **官方统计口**（政府部门、统计局、央行）

### 4.3 三条跨判据口径

1. **N/A 出口**：`--scope artifact` 下，判据的目标物**不存在**时判 `N/A`（不计入失败）。这是外检能成立的前提 —— 用户的产物形态未知，查不到不等于违规。★ **`DA1`/`CD1` 这类"表/代码整体不在"的判 N/A；一旦表在场，其**列内取值**缺失即判红**。
2. **空集平凡绿**：照 M4 `MS6` 口径 —— 表在场但**零行**、或目录在场但**零文件**，一律判**红**，不许判绿。
3. **`--scope self` 内检**：查本仓交付件自洽 —— ① 两个 SKILL.md 的 §1.2 边界句在场；② `references/` 指针不悬空；③ `assets/` 模板的列头与 §3 逐字一致。这三条进收工门。

### 4.4 已知边界（外检**查不到**什么）

- **查不到"数据是不是真的"** —— `DA*` 只查来源表与确认记录在场，不查 URL 是否真有该数。
- **查不到"口径选得对不对"** —— 只查 `口径` 列非空，不判内容。
- **查不到"结果算得对不对"** —— `CD*` 只查工程规范，"算得对"归 M4 的参照层。
- **`CD5` 有假阳性空间** —— 只用启发式找路径字面量；故限定"可执行语句内"，且**样例对里必须有一条注释含路径的反例**压住它。

## §5 样例、驱动器与 RED / GREEN

**一对一样例**（`samples/<判据号>/{comply,violate}/`）：合规样例**必然绿**、违规样例**必然红**。

**驱动器** `mutate-data.py` / `mutate-code.py`：逐对跑 `check-*.py --scope artifact`，断言 ① 每条判据**至少红过一次**（违规侧）② 每条判据的合规侧**确实绿**（防"连好产物也判红"）③ 判据总数 == `samples/` 下的一级目录数（**分母不是常量**，照本仓 `check-*.py` 的 `E0` 口径）。

**证据件** `make-evidence.py`：跑完落一份 RED/GREEN 对照件；**不动点** = 重新生成字节级一致。

★ **`DA4` / `CD6`（人机确认闸）是这套里最重要的一对样例** —— 违规侧就是"AI 取数未确认 / AI 写码未核"这一行，它们红了才证明 §1.2 那两句不是自觉条款。
