## 二、清洗步骤（**逐条可重跑**）

1. **取数**：读 `2026_MCM_Problem_C_Data.csv`（**53 列 × 421 行**，`utf-8-sig` + `csv` 模块）；**列名逐字保留**，不改头。
   - 实测（`sim/2026/csv_probe.py`，2026-10-09）：列数 **53**、行数 **421**、季 **1–34**、
     `weekX_judgeY_score` **44 列**（11 周 × 4 评委）。
2. **宽转长**：把 44 个 `weekX_judgeY_score` 折成 `(选手, 季, 周, 评委)` 长表；
   **判"在场者" = 该周该季有非 N/A、非 0 的评委分**。
3. **派生量 ① `judge_total(选手, 季, 周)`** = 当周各 judge 分**之和**。
   ★ 小数 / bonus / 队舞**已在原始格里摊好**（题面 note 1a–1c）⇒ **不另加权、不另摊**。
4. **N/A 与 0 分开处理（不得合并）**：N/A ⇒ 该格不适用；0 ⇒ 已淘汰。
   - 实测：N/A 合计 **4741** 格 · 0 合计 **4671** 格（共 18524 格）——与题面 note 6/7 逐项吻合。
5. **识别周型**：由 `results` 字段判「淘汰周 / **无淘汰周** / **多淘汰周**」（题面 note 5 明说有后两类）。
6. **季次 → 合并规则映射**：S1–2 `rank`；S3–27 `percent`；**S28+** `rank` + 末二评委投票
   （★ 题面明说确切季次**不确定**，是**合理假设** ⇒ 这一条要写进论文的假设表，见 `04-模型选型.md` 的 A1）。
7. **可重跑**：脚本 `sim/2026/clean_c.py`（待写，**归 `mcm-code`**）；命令 `python -I sim/2026/clean_c.py`。
8. **外部信号取数**（**2026-10-10 新增**）：脚本 `sim/2026/code/external_signal.py`；
   命令 `python -I sim/2026/code/external_signal.py --refresh` —— **唯一会联网的一步**。
   取 Wikidata 季窗口、各季条目的参赛者表与播出日、维基条目逐日浏览量；
   原始响应**逐字**落 `sim/2026/data/wiki-cache/`（附 `PROVENANCE.md`：逐件 URL/时刻/状态/sha256）。
9. **零参复跑 = 只读缓存**：脚本同上；命令 `python -I sim/2026/code/external_signal.py` ——
   缺缓存**大声失败**、**绝不静默联网** ⇒ 此后结果完全确定（这是把"网络取数"变成可复现的那一步）。
10. **接进模型**：脚本 `sim/2026/code/external_constraints.py`；命令
    `python -I sim/2026/code/external_constraints.py` —— 产出 ρ 曲线与外部标尺。
   该脚本自带**基线自证**（ρ=∞ 且不排除任何周 ⇒ 必须与入库 `figure-2-season-width-summary.json`
   逐值相同，不等价即中止）。
   ★ **不手改中间文件**：任何手工改格都须写成一步并记在此处。

## 三、两条口径判定（浅推件当场问的）
