## 一、第一跳：题面特征 → 类（逐问判，主类 + 次类）

| 题面哪一问 | 题面特征（判据） | 落到哪一类 | 依据 |
| :-- | :-- | :-- | :-- |
| **(a)** 估计不可见的粉丝票 | 由**可观测**（当周淘汰者 + 该季合并规则）+ 规则约束 **反推不可观测量**，要**后验区间**与**一致性度量** | **`statistics`** —— 用 **贝叶斯推断** 那一叶 | ★★ 关键裁决：题面**不给任何机理方程**。`references/mechanism/param_id_stability.md` 的边界条款逐字写着「**若题面没有机理方程 ⇒ 属 `statistics`**」⇒ **不归 `mechanism`** |
| **(b)** rank 法 vs percent 法 | 把同一批估计**代进两套规则复算**、比较结局是否翻转 | **`statistics`（下游）** + **`evaluation`（方案比较）** | 复算是 (a) 的估计量上的**确定性变换**，不引入新模型 |
| **(c)** 舞者 / 年龄 / 行业的影响 | 问「**有没有影响、多大、对分数与票是否同向**」 | **`statistics`** —— 回归 / 效应量那一支 | 类级适用判据：「从样本对总体下判断（**估计**）」 |
| **(d)** 提出一种新的合并系统 | 在**规则空间**上求"更公平 / 更有趣"的最优 | **`optimization`** | 接缝表第 9 行：**机制 / 规则设计**（在规则空间上求最优）→ `optimization` |

★ **主类 = `statistics`，次类 = `optimization`**。**不声称一题只属一类。**

## 二、第二跳：类内 → 方法（候选 + 判据 + 推翻条件）

### 主类 `statistics`

**候选 1（★ 推荐）· 贝叶斯推断** —— `references/statistics/bayesian.md` · 骨架 `assets/matlab/statistics/bayesian.m`

- **为什么是它（逐条对 ① 的"用"）**：
  - 题面 (a) 要的是「**consistency 度量**」与「**certainty 度量**」——**一个分布而不是一个点**。
    `bayesian.md` ① 写「有先验、要用数据更新为**后验分布 + 可信区间**（不是 `p` 值）」⇒ 直接对齐。
  - 题面**明说粉丝票"未知、保密"** ⇒ 它是**潜变量**；给**后验分布**是唯一能同时交两把尺子的形式。
  - 题面自承「There are many possible values」⇒ **欠定**；`bayesian.md` 的反面 4 与 `param_id_stability.md`
    的反面 4 是同一句：「**参数不可辨识 ⇒ 必须给分布 / 区间，不给单点**」。
- **推翻条件**：
  1. **可行域普遍为空**（不存在任何票份额使当周被淘汰者是合并最低）⇒ 说明 A1 的**季次→规则映射**或清洗有错，
     **先改软约束似然（允许以概率 p 违反）**；仍不行 ⇒ 退回**纯可行域刻画**（每周 LP / hit-and-run 出区间，不给点估计）。
  2. **先验主导**（似然几乎不更新后验）⇒ 约束信息量过低，须引入**外部代理**（社交热度 / 搜索趋势）或跨季 pooling。
     ★ **2026-10-10 已试**（维基 pageviews）：**这条代理被淘汰记录否证** —— 见 `12-外部信号取数与对齐.md`
     与论文 §7。⇒ 本条的**下半句（跨季 pooling）成为唯一还站得住的那条**。
  3. **MCMC 不收敛**（`R̂` 远离 1）⇒ 后验数**不可用**（`bayesian.md` ④-3），不得报数。

**候选 2 · 回归 / 效应量**（专答 (c)）—— 见下"★ 接缝上的第二处不足"

- **为什么**：(c) 要「**效应量**」与「**是否同向**」⇒ 对评委分与票份额**各拟一个同形式的回归**，系数对比即答案。
- **推翻条件**：若响应用的是**候选 1 估计出来的**票份额（带区间）⇒ 用估计量当响应有**测量误差衰减**（系数被拉向 0）；
  届时改用**直接观测**（名次 / 存活周数）作响应，或把候选 1 的**后验样本直接喂进回归**（贝叶斯一体化）。

### 次类 `optimization`（答 (d)）

**候选 3 · 规则空间上的多目标搜索** —— `references/optimization/`

- **为什么**：决策变量是**规则本身**（合并函数的形式与参数），目标是一对冲突量（**公平度** vs **趣味性**）。
  按 `SKILL.md` 接缝表下的口径：**多目标走问 2 的启发式一族**并**明写"出 Pareto 前沿"**；只有"分层让步"才用 `goal_programming`。
- **推翻条件**：若规则空间小到可**穷举**（本问很可能如此）⇒ **不必上元启发式**，直接枚举 + 评估；
  启发式只在规则参数化后维数变大时才需要。

### 配套（不是候选，是执行件）

- **后验 / 可行域抽样** ⇒ `references/simulation/monte_carlo.md`
  （★ 边界逐字：`bayesian.md` 明写「**MCMC 抽样本身 ⇒ `simulation/monte_carlo.md`；本套件把后验抽样归本方法**」）

## 三、推荐（**候选排序，不是替队伍拍板**）

- **推荐组合**：**(a) 贝叶斯推断**（`statistics/bayesian`）为**主模型** →
  由它出粉丝票的**后验 / 可行域** → **(b)** 把后验样本代进 rank / percent / 末二三种规则**复算翻转率** →
  **(c)** 效应量（回归，见下） → **(d)** 在规则空间上**枚举 / 多目标搜索**出 Pareto 前沿。
- **推翻条件（总）**：见上各候选的三条；**任一成立 ⇒ 回本件重选**（不是"换个方法硬做"）。
- ★ **一处如实交底**：**本推荐的主模型与浅推给的那个基本一致**（浅推当时也是贝叶斯隐变量）——
  但**理由换了**：浅推是"看着就它合适"，本件是**按 `param_id_stability.md` 的边界条款逐字判出"不归 mechanism"**才落到 `statistics`。
  而且**浅推当时是"暂定"**（`method.md` §0 明令：模型选型归本阶段）。

## 五、被选中方法的**六格落点与骨架路径**

- **可跑骨架**：`.claude/skills/mcm-model-select/assets/matlab/statistics/bayesian.m`（零参可跑，自带共轭正态-正态算例）。
- **独立参照**：`tests/skills/model-select/verify/bayesian.md`（共轭闭式 + MCMC 双路对照；实测后验均值 `1.18425254`(MCMC) vs `1.18383118459`(闭式)）。

**题 C 要在六格上做的适配（只列题特异的几格，其余照原件）**：

| 格 | 骨架给的是 | 题 C 要改成 |
| :-- | :-- | :-- |
| ② 步骤 | 共轭正态-正态一步出闭式后验 | 似然换成**顺序淘汰的排序似然**（被淘汰者 = 合并名次最低），**按季接该季的合并规则**（S1–2 rank · S3–27 percent · S28+ rank + 末二两段似然）⇒ **闭式不可得，走 MCMC** |
